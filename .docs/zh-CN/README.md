## 项目简介

这是一个面向 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness) 的插件集合，收录了我们开发、适配或翻译的插件，以及适合 DSH 用户使用的独立项目和相关工具。

## 项目

每个插件都有独立的目录。仓库和各插件的文档集中在[文档目录](..)中。

| 目录 | 用途 | 状态 |
| --- | --- | --- |
| [`dsh-tonulls/`](../../dsh-tonulls/.docs/zh-CN/README.md) | 一次安装[项目目录](projects.md)中的技能，并为当前 Agent 开启或关闭技能自动选择。 | 开发中 |
