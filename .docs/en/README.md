## About

A collection of plugins we build, adapt, or translate for [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness). It includes standalone projects and related tools for DSH users.

## Projects

Each plugin has its own directory. Repository and plugin documentation is organized in the [documentation tree](..).

| Directory | Purpose | Status |
| --- | --- | --- |
| [`dsh-tonulls/`](../../dsh-tonulls/.docs/en/README.md) | Install the skills from the [project catalog](projects.md) together and toggle automatic skill selection for the current Agent. | In development |
