## О проекте

Коллекция плагинов для [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness). В ней собраны собственные плагины и адаптации открытых проектов для разработки, дизайна и исследований.

## Проекты

| Каталог | Назначение | Состояние |
| --- | --- | --- |
| [`dsh-tonulls/`](dsh-tonulls/README.md) | Устанавливает навыки одним пакетом. Команда `/dsh-tonulls on\|off` управляет автоподбором для текущего Agent. | Разработка |
