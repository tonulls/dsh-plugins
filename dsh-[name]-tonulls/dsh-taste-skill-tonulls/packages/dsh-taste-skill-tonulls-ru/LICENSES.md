# Лицензии и атрибуция

## Taste Skill

Основной набор Taste Skill взят из [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill/commit/12af471f627f866411b4bd785b19646d3672784c). Из [ревизии `f6b76575`](https://github.com/Leonxlnx/taste-skill/commit/f6b76575f949707b4e3c37cd86cb44b0b98643e8) добавлены восемь записей в `library/palettes.json` и справочник `references/type-options.json`. Текст лицензии сохранён в [`packages/skills/LICENSE.upstream`](packages/skills/LICENSE.upstream).

Этот DSH-адаптер и метаданные пакета являются интеграционным слоем проекта `dsh-taste-skill-tonulls`; они не изменяют лицензию исходного содержимого.
