# Humanizer для DSH

Редактирование текста с сохранением смысла и фактов, без типичных шаблонов машинного письма.

This is a skill-only DSH bundle; its upstream instruction body remains English while package metadata is localized. It adds no scripts, dependencies, network requests, or background services. See LICENSES.md for attribution.

## Автоподбор

Автоподбор выключен по умолчанию для каждого Agent. Используйте `/dsh-humanizer-tonulls on` и `/dsh-humanizer-tonulls off`; прямой вызов Skill остаётся доступен.
