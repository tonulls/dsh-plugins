# dsh-astryx-tonulls-ru

Русский DSH bundle для навыка `astryx`.

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-astryx-tonulls/packages/dsh-astryx-tonulls-ru'
```

Автоматический выбор выключен по умолчанию. Включите его командой `/dsh-astryx-tonulls on`; чтобы выключить, выполните `/dsh-astryx-tonulls off`. Навык также доступен напрямую: `/astryx`. Полное описание — в [корневом README](../../README.md).
