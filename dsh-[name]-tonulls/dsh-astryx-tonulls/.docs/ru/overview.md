# Обзор интеграции

DSH bundle регистрирует единственный пакетный skill `astryx` через Host service `skills.registerProvider`. Его содержимое встроено в пакет и локализовано; модель загружает инструкцию по запросу. Три workspace-пакета (`-ru`, `-en`, `-zh`) содержат одинаковую реализацию и отдельные переводы, patch rows, каталог skill, метаданные Plugin Manager и иконку.

## Границы возможностей

Bundle предоставляет инструкции и доступность skill для пользовательского и модельного вызова. Он не реализует DSH Tool и не запускает Astryx CLI. Пользователь/агент применяет команды через инструменты, уже доступные текущему DSH Agent. CLI должен быть установлен в целевом проекте; bundle не устанавливает Astryx runtime, зависимости, темы или CLI и не редактирует проект.

Инструкция требует проверить проект и версию CLI, не заменять имеющуюся дизайн-систему без запроса, считать внешние материалы недоверенными данными и не устанавливать/генерировать код без явного запроса пользователя. Это guidance для модели, а не механизм ограничения системных прав.

## Upstream

Снимок CLI-справки зарегистрирован в `UPSTREAM.json`: `@astryxdesign/cli` `0.7.17`, проверено 2026-11-21. Здесь не распространяются исходники/бинарные файлы Astryx; каталог метаданных описывает один встроенный skill.
