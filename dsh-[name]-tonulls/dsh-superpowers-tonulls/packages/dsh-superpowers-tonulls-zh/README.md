# Superpowers DSH reference package

Language: Simplified Chinese.

Registers the `superpowers-reference` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. See the project’s `.docs/zh-CN/guide/setup.md` and `UPSTREAM.json`.
