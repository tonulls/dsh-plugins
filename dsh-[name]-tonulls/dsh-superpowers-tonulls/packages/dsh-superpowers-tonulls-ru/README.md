# Superpowers DSH reference package

Language: Russian.

Registers the `superpowers-reference` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. See the project’s `.docs/ru/guide/setup.md` and `UPSTREAM.json`.

## Автоподбор

Автоподбор выключен по умолчанию для каждого Agent. Используйте `/dsh-superpowers-tonulls on` и `/dsh-superpowers-tonulls off`; прямой вызов Skill остаётся доступен.
