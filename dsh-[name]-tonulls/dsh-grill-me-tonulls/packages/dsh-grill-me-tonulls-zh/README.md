# DSH 决策追问技能

Two English skills for structured plan and decision interviews. Automatic selection is off by default and can be enabled for the current Agent with `/dsh-grill-me-tonulls on`; use `/dsh-grill-me-tonulls off` to turn it off.

## 自动选择

自动选择默认在每个 Agent 中关闭。使用 `/dsh-grill-me-tonulls on` 和 `/dsh-grill-me-tonulls off` 控制；仍可直接调用 Skill。
