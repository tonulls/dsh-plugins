# Motion for React DSH reference package

Language: English.

Registers the `motion-react-review` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. See the project’s [.docs/en/guide/setup.md](../../.docs/en/guide/setup.md) for installation and use; read the [lifecycle guide](../../.docs/en/guide/lifecycle.md) for startup, verification, update/restart, disable/stop limits, and removal. See [UPSTREAM.json](UPSTREAM.json) for source evidence.

## Automatic selection

Automatic selection is off by default for each Agent. Use `/dsh-motion-react-tonulls on` and `/dsh-motion-react-tonulls off`; direct Skill invocation remains available.
