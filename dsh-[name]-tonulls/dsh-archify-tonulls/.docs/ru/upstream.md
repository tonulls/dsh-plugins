### Сверка опубликованного архива v3.2.0

Список релизов GitHub по-прежнему указывает на `v3.2.0`. SHA-256 загруженного `archify.zip` совпал с полем digest GitHub и значением в `UPSTREAM.json`. Из 200 файлов архива 170 совпали с деревом навыка побайтово. В 30 файлах есть локальные отличия, в том числе в инструкции навыка, сценариях доставки и предпросмотра, HTML-примерах и проверке вывода. Дополнительно в адаптацию входят `LICENSE-MIT`, `NOTICE` и `renderers/shared/software-notices.mjs`. [Опубликованный релиз](https://github.com/tt-a1i/archify/releases/tag/v3.2.0).

Полный диапазон от исходников релиза до `8509a3d6` содержит 87 изменённых путей. Из них в поставляемом дереве навыка затронут только `archify/scripts/check-render-output.mjs`. Соответствующая правка уже применена в DSH. Для установки остаётся закреплён опубликованный архив v3.2.0. [Полный диапазон](https://github.com/tt-a1i/archify/compare/edf158c4e7a1d18d20cc329840f864289634c090...8509a3d63e763b4d454ea9aafa1f939545fcb1ea).

### Сверка архива адаптера DSH

Отдельно загружен `archify-dsh-1.1.0-official.tgz` из неизменяемого релиза `archify-dsh-v1.1.0`. Размер 4 481 707 байт и SHA-256 совпали с данными GitHub и `adapterRelease` в `UPSTREAM.json`. Локальный `LICENSE` сохраняет исходные уведомления и добавляет строку об авторстве адаптации. В оригинале `cordis.patch.yml` подключает файловый провайдер хоста; в локальном пакете патч подключает `dsh-archify-tonulls`. Локальная точка входа сохраняет разрешение каталога навыка через идентификатор установленного пакета и добавляет переключатель для текущего Agent. [Релиз адаптера DSH](https://github.com/tt-a1i/archify/releases/tag/archify-dsh-v1.1.0).
