# dsh-aks-tonulls-ru

Пакет DSH с навыком `karpathy-guidelines` и русскими инструкциями. Устанавливайте только один языковой вариант проекта в профиль DSH.

Навык доступен модели и пользователю по запросу. Он задаёт рекомендации по рабочему процессу, но не предоставляет разрешения и не меняет технические ограничения инструментов.

Источник инструкций: [Andrej Karpathy Skills](https://github.com/multica-ai/andrej-karpathy-skills), commit [`2c60614`](https://github.com/multica-ai/andrej-karpathy-skills/commit/2c606141936f1eeef17fa3043a72095b4765b9c2). Исходный проект заявляет лицензию MIT; текст лицензии включён в пакет.
