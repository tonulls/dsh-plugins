# dsh-aks-tonulls-en

A DSH package containing the `karpathy-guidelines` skill with English instructions. Install only one language variant of this project in a DSH profile.

The skill is available to the model and user on request. It provides workflow guidance; it does not grant permissions or change tool-enforced restrictions.

Instruction source: [Andrej Karpathy Skills](https://github.com/multica-ai/andrej-karpathy-skills), commit [`2c60614`](https://github.com/multica-ai/andrej-karpathy-skills/commit/2c606141936f1eeef17fa3043a72095b4765b9c2).
