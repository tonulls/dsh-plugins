# Verify ambitious interface effects

Describe the user-facing benefit and identify where the effect belongs. If it materially
changes a screen or workflow, agree on the direction before implementation. Build one
representative interaction using the project's available tools and measure it under relevant
conditions before expanding it.

Test how the effect behaves with reduced motion, slow devices, keyboard and touch inputs.
Keep the underlying action and information available when the effect is interrupted or
unavailable. Report the actual browser and device coverage.
