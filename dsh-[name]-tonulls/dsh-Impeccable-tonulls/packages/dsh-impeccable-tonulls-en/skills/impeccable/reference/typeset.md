# Typography

Inspect the rendered page and its source. Identify the established families, weights, and roles for headings, prose, controls, and data. Check whether those roles remain distinct in repeated components. Tune line length and leading to the face, language, and density. Load only used font assets and check that fallback and font loading preserve readable text and stable layout.

Verify long labels, localization, zoom, narrow widths, and missing font weights. If a heading needs a deliberate break, test it at every supported layout. Keep confirmed typefaces unless the task includes a change of visual identity.
