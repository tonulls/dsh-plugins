# Reading and decision surfaces

For a reading surface, put the material in a meaningful sequence and make it easy to resume.
Use a readable measure, clear headings and anchored navigation when the document is long.
Check narrow screens, zoom and keyboard navigation using the actual content.

For a decision surface, order the offer, evidence and action so visitors can understand what
they are choosing and what happens next. Use confirmed claims, costs and conditions.
Check that the main action remains understandable when the visual treatment is simplified.
