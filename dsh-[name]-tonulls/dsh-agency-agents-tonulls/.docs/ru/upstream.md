## Поведение адаптера

1. Каталог содержит имя `agency-<slug>`, исходные заголовок и описание, категорию, путь Markdown-файла и URL источника.
2. Провайдер проверяет commit, количество записей, уникальность имён, категорию и каждый относительный путь по allowlist.
3. Роль загружается только при запросе `get`; YAML frontmatter исходного файла удаляется из тела инструкции.
4. В начало и конец тела добавляются текстовые инструкции учитывать текущую сессию и доступные инструменты, не предполагать неявные разрешения и проверять область авторизации для security-тестирования. Это контекст для модели, а не техническая блокировка вызовов инструментов.
5. Человек не может напрямую вызвать отдельную роль: `userInvocable` выключен. Нативная команда `/dsh-agency-agents-tonulls on|off` включает или выключает автоматический выбор ролей моделью для текущего Agent. Команда управления — отдельная команда DSH, а не skill.

Для переключателя выпускаются три пакета: `dsh-agency-agents-tonulls-ru`, `dsh-agency-agents-tonulls-en` и `dsh-agency-agents-tonulls-zh`. Они локализуют описание и ответы команды управления, но не каталог ролей. Имена и описания навыков и исходные тела инструкций не переводятся этим пакетом и в основном остаются на английском. Язык пакета не гарантирует язык ответа модели. Устанавливайте только один вариант на профиль.

Исходные тела инструкций и описания skills в основном на английском, но могут содержать фрагменты на других языках. Основная документация проекта написана по-русски; корневой README переведён на английский и упрощённый китайский и размещён в `.docs/en/README.md` и `.docs/zh-CN/README.md`. `.docs/ru/overview/README.md` содержит подробное описание проекта и индекс ролей по направлениям; каждый файл направления перечисляет имена ролей, доступных для автоматического выбора после включения режима. Английский и китайский `overview.md` служат краткими индексами и ведут к русской документации. Файл `upstream.md` описывает источник и адаптацию на соответствующем языке. Перевод 283 ролевых промптов в этот выпуск не входит.

## Текущая проверка — 2026-11-03

- `npm test` прошёл все 12 проверок; тестовый файл находится только в EN-пакете и проверяет провайдер, а не полный lifecycle каждого языкового пакета. `npm run check:catalog` подтвердил актуальность каталогов RU, EN и ZH. Во всех трёх пакетах обнаружено по 283 файла ролей с одинаковым составом, а JavaScript-файлы пакетов синтаксически корректны.
- Установку по Git URL и запуск в живом DSH после языковой перестройки не проверял. Не проверялись и реальные границы разрешений, подтверждение побочных эффектов и enforcement со стороны DSH-инструментов. Профиль `web` не изменялся.

## Обновление upstream

Версия не обновляется автоматически. Для обновления нужно выбрать и проверить новый полный commit SHA, переснять только агентские Markdown-файлы из категорий upstream-конвертера во все три языковых пакета, обновить `UPSTREAM.json`, запустить `npm run build:catalog` и `npm test`, сверить число/slug каждого агента и включить актуальное уведомление лицензии. Изменение upstream-снимка — отдельная ревизия; не меняйте его на движущуюся ссылку `main`.
