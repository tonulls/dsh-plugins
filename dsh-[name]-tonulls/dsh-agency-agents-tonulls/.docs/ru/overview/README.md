# Что такое Agency Agents для DSH

Это набор из 283 специализированных ролевых инструкций из проекта [Agency Agents](https://github.com/msitarzewski/agency-agents), подготовленный для [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness). Пакет добавляет роли в DSH как навыки с именами `agency-<имя-роли>`. Роль задаёт контекст и способ работы модели для конкретной задачи: например, помогает провести ревью кода, спланировать исследование, подготовить маркетинговую стратегию или проверить доступность интерфейса.

Это не набор отдельных программ или автономных сервисов. Пакет не запускает агентам собственные процессы, не устанавливает инструменты upstream и сам по себе не выполняет действия во внешних системах. Он предоставляет DSH текстовые инструкции ролей; результат зависит от модели, запроса и доступных текущему Agent инструментов.

## Как пользоваться ролями

Роли не вызываются человеком по отдельным slash-командам. Чтобы разрешить модели автоматически выбирать их в текущем Agent, выполните `/dsh-agency-agents-tonulls on`, затем опишите задачу обычным сообщением. Идентификаторы ролей ниже помогают понять состав набора.

По умолчанию роли не доступны для выбора. Команда `/dsh-agency-agents-tonulls on` разрешает модели автоматически выбирать роли для текущего Agent; `/dsh-agency-agents-tonulls off` отключает эту возможность. Роли не отображаются как отдельные пользовательские команды. Команда управления является нативной командой DSH, а не отдельным skill.

Для каждой локализации существует отдельный установочный пакет: русский (`-ru`), английский (`-en`) и упрощённый китайский (`-zh`). Установите только один вариант в профиль. Пакет локализует описание и ответы команды управления. Имена и описания навыков и исходные инструкции ролей в основном остаются на английском; перевода всего каталога нет, а язык пакета не гарантирует язык ответа модели.

Набор полезен разработчикам, исследователям, дизайнерам, специалистам по продукту, маркетингу, продажам, поддержке и другим пользователям DSH, которым нужны готовые ролевые инструкции для разных типов работы. Он помогает быстрее задать модели профессиональную рамку задачи, но не заменяет проверку фактов, профильную экспертизу и оценку результата человеком.

Инструкции могут просить модель соблюдать границы безопасности, однако текст промпта не является техническим контролем доступа и не блокирует вызовы инструментов. Bundle не реализует авторизацию операций, ограничение доступа к ресурсам или подтверждение побочных эффектов. Перед использованием ролей с инструментами проверьте, что эти ограничения обеспечивает сам DSH и его интеграции; такое runtime-поведение в рамках данного проекта не подтверждено.
