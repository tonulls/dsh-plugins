# Fancy Components — DSH Skill（简体中文）

此中文 DSH bundle 包通过 Host `skills` provider 注册 Skill：`fancy-components`。始终可以手动调用 `/fancy-components`；模型自动选择默认关闭，可用 `/dsh-fancy-tonulls-zh on` 为当前 Agent 启用，再用 `/dsh-fancy-tonulls-zh off` 关闭。新 Agent 默认关闭。该包不添加工具，也不会向 React 项目安装组件。

包内仅含用于核实准确上游来源、依赖和许可证的原创指引。不复制 Fancy 组件代码、目录条目、文档、示例或图片。
