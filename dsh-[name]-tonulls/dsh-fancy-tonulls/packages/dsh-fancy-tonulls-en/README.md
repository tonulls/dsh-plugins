# Fancy Components — DSH Skill (EN)

The `fancy-components` skill helps assess Fancy components for React projects. Automatic selection is off by default and can be enabled for the current Agent with `/dsh-fancy-tonulls-en on`; use `/dsh-fancy-tonulls-en off` to turn it off. Direct invocation remains available.

The original source license and notices are included in the package.
