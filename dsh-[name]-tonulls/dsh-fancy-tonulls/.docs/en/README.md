# Fancy Components DSH documentation

The RU/EN/ZH bundle registers a real DSH Skill, `fancy-components`. Manual `/fancy-components` invocation is always available; model auto-selection is user-enabled per Agent. The bundle adds no tools or permissions and includes no Fancy component code.
