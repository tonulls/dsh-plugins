# Ask Emil

Choose one skill based on what the user needs. Confirm that it exists in the current DSH catalog before relying on it.

| Task | Skill |
| --- | --- |
| Build one web animation | animate |
| Coordinate a group of animations | choreograph |
| Build or refine a drag or swipe gesture | gestures |
| Build motion in React Native or Expo | animate-expo |
| Review an existing animation | review-animations |
| Investigate dropped frames | animation-performance |
| See where motion would help | find-animation-opportunities |
| Simplify excessive motion | remove-animations |
| Improve mobile web behavior | mobile-native |
| Work with Sonner notifications | ask-sonner |

Explain the choice in one sentence. If the user's request is ambiguous, ask what should change before suggesting an implementation. When a matching skill is unavailable, offer a short plan based on the current project and tools.
