### Применено в DSH

Если проект уже использует CLI Specify, для просмотра установленных расширений используйте `specify extension list`, а для поиска по активным каталогам — `specify extension search`. Сверяйте команды с установленной версией. Проверено на [`a4d57122`](https://github.com/github/spec-kit/commit/a4d571229e164e440f8950cac034607bae7b7518). Ревизия исходных материалов указана отдельно.

Сверены изменения четырёх файлов в `templates/commands/`. В DSH перенесены работа с итоговым шаблоном спецификации, ссылки из задач на `data-model.md` и проверка ограничений полей. Upstream удалил шаблон команды `taskstoissues`. В DSH этап экспорта задач в трекер отсутствует, поэтому менять его не потребовалось. Скрипты разрешения шаблонов принадлежат установленному CLI проекта. [Сверенные шаблоны](https://github.com/github/spec-kit/tree/a4d571229e164e440f8950cac034607bae7b7518/templates/commands).
