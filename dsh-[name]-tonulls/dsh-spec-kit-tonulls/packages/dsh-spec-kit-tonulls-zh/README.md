# dsh-spec-kit-tonulls-zh

Spec Kit 的简体中文 DSH 插件版本。技能描述和命令响应使用简体中文，SKILL.md 方法说明使用英文。

安装到 `web` profile：

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-spec-kit-tonulls/packages/dsh-spec-kit-tonulls-zh'
```

技能正文使用英文。

自动选择默认关闭。使用 `/dsh-spec-kit-tonulls on` 为当前 Agent 开启，使用 `/dsh-spec-kit-tonulls off` 关闭。也可直接调用 `/spec-kit`。
