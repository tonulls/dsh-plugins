# dsh-gstack-tonulls-ru

Русский вариант DSH-плагина GStack. Описания навыка и ответы команды локализованы; тело навыка — самостоятельная англоязычная DSH-адаптация.

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-gstack-tonulls/packages/dsh-gstack-tonulls-ru'
```

Install exactly one language variant per DSH profile.
