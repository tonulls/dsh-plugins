# dsh-gstack-tonulls-en

English DSH plugin variant for GStack. Skill descriptions and command replies use English; the skill body is an independent English DSH adaptation.

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-gstack-tonulls/packages/dsh-gstack-tonulls-en'
```

Install exactly one language variant per DSH profile.
