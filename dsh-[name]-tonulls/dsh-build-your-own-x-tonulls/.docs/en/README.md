# Build Your Own X for DSH documentation

This bundle adds a reference skill with direct invocation and optional automatic selection. It helps select and evaluate current GitHub tutorials from [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x); it does not copy the catalog or tutorial text.

- [Preparation and usage boundaries](guide/setup.md)
