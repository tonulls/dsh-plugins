# Документация Build Your Own X для DSH

Этот bundle добавляет справочный навык с прямым вызовом и автоподбором. Он помогает отобрать и оценить актуальные GitHub-туториалы из [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x); сам каталог и тексты tutorial не копируются.

- [README проекта](../../README.md)
- [Подготовка и границы использования](guide/setup.md)

Аудиторский commit и подтверждённая лицензия описаны в [`UPSTREAM.json`](../../packages/dsh-build-your-own-x-tonulls-ru/UPSTREAM.json).
