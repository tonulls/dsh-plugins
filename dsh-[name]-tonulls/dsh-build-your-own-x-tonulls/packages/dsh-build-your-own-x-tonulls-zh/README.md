# Build Your Own X — DSH 技能（简体中文）

用户手动调用的技能，用于选择和核验 GitHub 上从零构建项目的教程。这是原创 DSH 适配；不包含上游目录条目或教程文本。

源目录和审计提交记录在 [`UPSTREAM.json`](UPSTREAM.json) 中。本技能不会安装依赖或运行代码。

## 自动选择

自动选择默认在每个 Agent 中关闭。使用 `/dsh-build-your-own-x-tonulls on` 和 `/dsh-build-your-own-x-tonulls off` 控制；仍可直接调用 Skill。
