# Build Your Own X — DSH Skill (EN)

A skill based on Build Your Own X for finding and assessing tutorials about building technology from scratch. Automatic selection is off by default for each Agent and can be enabled with `/dsh-build-your-own-x-tonulls on` or disabled with `/dsh-build-your-own-x-tonulls off`.

The original source and license notices are included in this package; installation is adapted for DSH.

## Use

Invoke `/build-your-own-x` directly, or enable automatic selection for the current Agent with `/dsh-build-your-own-x-tonulls on`. Use `/dsh-build-your-own-x-tonulls off` to turn it off.
