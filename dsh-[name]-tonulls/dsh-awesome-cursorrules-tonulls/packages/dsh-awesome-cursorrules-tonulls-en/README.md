# Awesome Cursor Rules DSH reference package

A reference Skill based on Awesome Cursor Rules for finding and assessing Cursor rules that fit a project. Automatic selection is off by default for each Agent; use `/dsh-awesome-cursorrules-tonulls on` and `/dsh-awesome-cursorrules-tonulls off`. Direct invocation remains available.

## Install

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-awesome-cursorrules-tonulls/packages/dsh-awesome-cursorrules-tonulls-en'
```

## Use

Invoke `/cursor-rules-selector` directly, or enable selection for the current Agent with `/dsh-awesome-cursorrules-tonulls on`. Use `/dsh-awesome-cursorrules-tonulls off` to turn it off.
