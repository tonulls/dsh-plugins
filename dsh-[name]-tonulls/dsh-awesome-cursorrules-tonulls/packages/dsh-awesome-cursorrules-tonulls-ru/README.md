# Awesome Cursor Rules DSH reference package

Справочный Skill на основе каталога Awesome Cursor Rules. Помогает искать и оценивать правила Cursor, подходящие технологиям и требованиям проекта. Автоподбор выключен по умолчанию для каждого Agent; включайте его командой `/dsh-awesome-cursorrules-tonulls on` и выключайте `/dsh-awesome-cursorrules-tonulls off`. Skill также доступен по прямому вызову.

## Установка

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-awesome-cursorrules-tonulls/packages/dsh-awesome-cursorrules-tonulls-ru'
```

## Использование

Вызовите `/cursor-rules-selector` напрямую или включите автоподбор для текущего Agent командой `/dsh-awesome-cursorrules-tonulls on`. Для отключения используйте `/dsh-awesome-cursorrules-tonulls off`.

## Лицензия

Лицензия исходного репозитория и уведомления указаны в [UPSTREAM.json](UPSTREAM.json); для DSH адаптирован способ установки.
