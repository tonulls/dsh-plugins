# GSAP DSH reference package

用于分析项目中 GSAP 集成、API 使用、兼容性和动画方案的参考 Skill。 自动选择默认在每个 Agent 中关闭；使用 `/dsh-gsap-tonulls on` 和 `/dsh-gsap-tonulls off` 切换。仍可直接调用 Skill。

## 安装

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-gsap-tonulls/packages/dsh-gsap-tonulls-zh'
```

## 使用

直接调用 `/gsap-integration-review`，或使用 `/dsh-gsap-tonulls on` 为当前 Agent 启用自动选择。使用 `/dsh-gsap-tonulls off` 关闭。
