# GSAP for DeepSeek Harness (DSH)

[Русский](../../README.md) | **English** | [简体中文](../zh-CN/project.md)

## Description

Helps review GSAP API compatibility and plan animations for an existing interface.

## Installation

Install into the `web` profile. Substitute your profile name as needed.

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-gsap-tonulls/packages/dsh-gsap-tonulls-en'
```

## Start

Start DSH with the profile where the package is installed.

```sh
dsh web
```

## Verify

Check the DSH profile.

```sh
dsh --version
dsh plugin --profile web list
dsh --profile web --dump-config
```

## Usage

Automatic selection is off by default. Use these commands to control automatic skill selection for the current Agent.

```text
/dsh-gsap-tonulls on
/dsh-gsap-tonulls off
```

Direct skill invocation — `/gsap-integration-review`.

## Update

```sh
dsh plugin --profile web update dsh-gsap-tonulls-en
```

## Restart

Restart the DSH profile after updating.

## Stop

```text
/dsh-gsap-tonulls off
```

Turn off automatic selection for the current Agent with the command above. Press `Ctrl+C` in the terminal to stop DSH Web.

## Uninstall

```sh
dsh plugin --profile web remove dsh-gsap-tonulls-en
```
