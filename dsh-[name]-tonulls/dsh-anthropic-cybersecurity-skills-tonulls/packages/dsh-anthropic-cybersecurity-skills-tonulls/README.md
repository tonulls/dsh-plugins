# Defensive log triage for DSH

A DSH bundle with two skills based on the access-log procedures in [Anthropic Cybersecurity Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills). They help triage web-server and API Gateway logs and can be invoked directly or selected automatically for the current Agent.

The original procedures are distributed under Apache-2.0; the license and attribution notice are included in the package. This community project is not affiliated with Anthropic PBC.

Automatic selection is off by default for each Agent. Use `/dsh-anthropic-cybersecurity-skills-tonulls on` to enable it and `/dsh-anthropic-cybersecurity-skills-tonulls off` to turn it off. Direct skill invocation remains available.
