# Caveman — краткий стиль для DSH

Сокращает лишние слова, сохраняя технические факты и точность.

The upstream English skill is adapted for this DSH bundle. Automatic selection is disabled by default and can be controlled per Agent with `/dsh-caveman-tonulls on` and `/dsh-caveman-tonulls off`; direct invocation remains available. The source Apache-2.0 license, historical MIT terms, notices, and trademark information are preserved.
