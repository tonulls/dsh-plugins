# Справочный Skill Awesome Design Skills

Справочный Skill на основе каталога Awesome Design Skills. Помогает находить и оценивать дизайн-инструкции, подходящие интерфейсу и задаче проекта. Автоподбор выключен по умолчанию для каждого Agent; используйте `/dsh-awesome-design-skills-tonulls on` и `/dsh-awesome-design-skills-tonulls off`. Skill также доступен по прямому вызову.

## Установка

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-awesome-design-skills-tonulls/packages/dsh-awesome-design-skills-tonulls-ru'
```

## Использование

Вызовите `/awesome-design-skills` напрямую или включите автоподбор для текущего Agent командой `/dsh-awesome-design-skills-tonulls on`. Для отключения используйте `/dsh-awesome-design-skills-tonulls off`.
