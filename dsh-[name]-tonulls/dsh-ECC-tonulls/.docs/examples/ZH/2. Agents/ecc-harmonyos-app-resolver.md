# `/ecc-harmonyos-app-resolver`

**用途：**HarmonyOS 开发专家：审查 ArkTS 和 ArkUI、V2 状态管理合规性、导航、API 使用和性能。适用于 HarmonyOS/OpenHarmony。

## 简短提示词

```text
/ecc-harmonyos-app-resolver 检查此 ArkTS/ArkUI 代码片段中的 V2 状态、导航和 API 使用是否正确。
```

## 模板提示词

```text
/ecc-harmonyos-app-resolver

任务：检查或诊断 [目标或对象] 的 HarmonyOS/OpenHarmony 应用。
重点：ArkTS/ArkUI、state management V2、Navigation 路由、API 和性能。
限制：只读；不要修改文件，也不要运行主动或外部检查。

```
