# 提示词示例：`/ecc-loop-operator`

**调用命令：** `/ecc-loop-operator`

## 用途

帮助安全地监控自主代理循环，发现停止和重复失败，并确定暂停及恢复条件。

## 1. 简短请求

```text
/ecc-loop-operator 根据现有 checkpoint，判断循环 {标识符} 是否已安全停止。
```

## 2. 模板请求

```text
/ecc-loop-operator 根据可用日志和检查点评估循环 {名称/标识符} 的状态。不要启动、停止或更改循环；说明进度、停滞迹象、预算/重试、quality gates、baseline 和 rollback，并提出安全的下一步。
```

## 3. 详细请求

```text
/ecc-loop-operator 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：安全地监控自主代理循环，发现停止和重复失败，并确定暂停及恢复条件。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
