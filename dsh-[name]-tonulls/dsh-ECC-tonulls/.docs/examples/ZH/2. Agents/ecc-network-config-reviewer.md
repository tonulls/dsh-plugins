# 提示词示例：`/ecc-network-config-reviewer`

**调用命令：** `/ecc-network-config-reviewer`

## 用途

检查路由器和交换机配置的安全性、正确性、过时引用和危险命令。只做分析，不进行更改。

## 1. 简短请求

```text
/ecc-network-config-reviewer 以只读方式检查此网络配置并列出风险设置：{路径}。
```

## 2. 模板请求

```text
/ecc-network-config-reviewer 以只读方式检查 {设备/文件} 的配置，背景为 {计划更改}。找出错误、不安全设置、过时引用和维护窗口中的危险命令。不要连接设备或应用任何更改；按严重程度提供发现、证据和安全建议。
```

## 3. 详细请求

```text
/ecc-network-config-reviewer 在更改 {目标/维护窗口} 前，分步分析 {设备/文件} 的配置。

1. 根据提供的背景确定平台和检查范围；不要连接设备。
2. 检查设置的正确性和安全性、过时引用，以及可能中断管理或流量的命令。
3. 对每项结论提供配置片段/位置、可能影响和置信度；区分事实与假设。
4. 按优先级列出风险、缺少的检查以及维护窗口前的安全建议。
5. 最后简要评估准备情况并说明分析限制。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
