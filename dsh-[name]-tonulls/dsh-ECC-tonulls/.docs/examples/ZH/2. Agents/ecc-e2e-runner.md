# `/ecc-e2e-runner` — 提示词示例

## 用途

创建、维护并运行关键用户流程的 E2E 场景；优先使用 Vercel Agent Browser，Playwright 作为备用方案，并协助分析不稳定测试及其产物。

## 简短请求

```text
/ecc-e2e-runner 检查 {应用} 中的 E2E 场景 {流程}。先确认现有工具，并说明哪些操作可以安全执行。
```

## 模板请求

```text
/ecc-e2e-runner 为 {路径/应用} 覆盖流程 {起点 → 预期结果}。使用项目已有的 Vercel Agent Browser 或 Playwright，不要添加依赖。说明前置条件、检查、不稳定环节及所需产物；仅在获准时运行测试。
```

## 详细请求

```text
/ecc-e2e-runner 为 {环境/URL} 中的场景 {场景} 准备 E2E 覆盖。
1. 研究现有测试基础设施、可用命令和已记录的用户路径。
2. 仅在工具已可用时，选择受支持的工具（优先 Vercel Agent Browser，否则 Playwright）。
3. 定义步骤、可观察的检查项和不依赖脆弱界面细节的数据。
4. 遇到不稳定测试时，区分应用缺陷和 flaky 行为；只有理由充分时才建议隔离测试。
5. 只运行明确获准的测试；如果确实生成了产物，请列出。

格式：基础设施、场景及断言、测试更改、实际结果和限制。未经同意，不要安装软件包、访问网络或部署；未启动应用时，不要声称已验证实际流程。
```
