# `/ecc-django-reviewer`

**用途：**审查 Django 代码：ORM 正确性、DRF 模式、迁移安全、保护设置和生产就绪性。适用于 Django 项目中的更改。

## 简短提示词

```text
/ecc-django-reviewer 以只读方式审查此 Django 更改：检查 ORM/DRF、迁移和安全性。
```

## 模板提示词

```text
/ecc-django-reviewer
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 Django 应用更改。
重点：ORM/DRF、安全性、迁移、设置和生产就绪性。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-django-reviewer
为 [项目/组件/场景] 执行任务“检查 Django 应用更改”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：ORM/DRF、安全性、迁移、设置和生产就绪性。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
