# `/ecc-gan-evaluator` — 提示词示例

## 用途

通过 Playwright 按指定评分标准/量表评估运行中的应用，并为 Generator 提供具体反馈。需要能够访问已启动的应用。

## 简短请求

```text
/ecc-gan-evaluator 按照标准 {评分量表} 评估运行中的应用 {URL/环境}；检查指定流程 {场景} 并报告观察结果。
```

## 模板请求

```text
/ecc-gan-evaluator 按照量表 {标准/阈值} 评估在线应用 {地址或访问方式}。检查路径 {场景}；仅在可用时使用 Playwright。对每项评分说明观察结果和证据；最后为 Generator 准备具体反馈。不要修改应用。
```

## 详细请求

```text
/ecc-gan-evaluator 将运行中的版本 {应用/地址} 作为 GAN Harness 的一次迭代进行评估。
1. 根据 {规格/量表} 确认应用可访问性和评估标准；不要给应用附加不存在的要求。
2. 使用 Playwright 遍历场景 {主要用户路径}；只记录实际观察到的行为。
3. 按照 {量表/阈值} 为每项标准评分，并提供证据、问题严重程度和对用户的影响。
4. 为 Generator 准备与评估标准关联的、按优先级排序的调整清单。

格式：提供“标准 — 评分 — 证据 — 信息缺口”表格、与阈值对照的结论，以及单独的反馈列表。如果应用无法访问或未提供标准，请说明情况，不要编造分数。未经同意，不要编辑应用、安装依赖、访问网络或部署。
```
