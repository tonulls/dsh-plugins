# `/ecc-bengali-reviewer` — 提示词示例

## 用途

检查处理孟加拉文 (Bangla) 文本的代码：Unicode 和规范化正确性、文字处理以及国际化实践。请针对具体路径和涉及孟加拉文数据的场景使用。

## 1. 简短请求

```text
/ecc-bengali-reviewer 检查搜索表单中孟加拉文文本处理的 Unicode 和本地化错误。只做分析，不要修改代码。
```

## 2. 模板请求

```text
/ecc-bengali-reviewer 检查 {文件/模块}，项目技术栈为 {技术栈}。场景：{孟加拉文文本的输入、存储、搜索、显示}。检查 Unicode 规范化、字符串操作和本地化。对每项发现注明文件/行、输入示例和可观察到的影响；不要修改文件。
```

## 3. 详细请求

```text
/ecc-bengali-reviewer 以只读方式检查 {路径或模块} 中对孟加拉文 (Bangla) 文本的处理。背景：{数据来源及用途}；预期场景：{排序、搜索、输入、显示、存储}。

1. 找出解码、规范化、比较、拆分或转换文本的位置；追踪从输入到输出的数据路径。
2. 检查代码是否假设一个可见字符等于一个代码单元；根据实际场景评估 Unicode 规范化和组合符号操作的正确性。
3. 检查 Bangla 文本的生成、存储、搜索和显示，包括本地化假设。没有具体反例或可证实风险时，不要断言存在问题。
4. 将观察结果与相关测试进行对照（如有）；未经许可，不要创建或运行额外测试。

先按优先级列出已确认的问题，包括准确位置、文本示例/条件及修复方法；随后列出潜在风险、已检查范围和信息缺口。不要修改代码、安装依赖、使用网络或部署。
```
