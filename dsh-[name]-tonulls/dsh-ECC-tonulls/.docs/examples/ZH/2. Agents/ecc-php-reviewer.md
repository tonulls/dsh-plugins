# 提示词示例：`/ecc-php-reviewer`

**调用命令：** `/ecc-php-reviewer`

## 用途

检查 PHP 代码是否符合 PSR-12、类型正确性、Eloquent 安全模式，并审查漏洞和性能。只报告问题，不做修改。

## 1. 简短请求

```text
/ecc-php-reviewer 以只读方式审查 {路径} 中的 PHP 更改，重点关注安全性和类型。
```

## 2. 模板请求

```text
/ecc-php-reviewer 在 {功能/框架} 背景下，对 PHP 更改 {路径/diff} 进行只读审查。检查 PSR-12、类型、Eloquent 查询、输入安全和性能。对每项确切发现注明文件/行、风险和修复方案；不要修改代码。
```

## 3. 详细请求

```text
/ecc-php-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：检查 PHP 代码是否符合 PSR-12、类型正确性、Eloquent 安全模式，并审查漏洞和性能。只报告问题，不做修改。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
