# 提示词示例：`/ecc-performance-optimizer`

**调用命令：** `/ecc-performance-optimizer`

## 用途

查找性能瓶颈，包括算法、内存、渲染和 bundle 大小，并提出优化建议。

## 1. 简短请求

```text
/ecc-performance-optimizer 根据指标 {数据}，找出场景 {场景} 中可能的性能瓶颈。
```

## 2. 模板请求

```text
/ecc-performance-optimizer 研究 {组件} 中的慢速场景 {场景}，预期和当前耗时为 {指标}。先根据现有数据确定可能的瓶颈，提出可衡量的计划及优化方案，并说明回归风险。未经确认，不要修改文件或运行高开销的性能分析。
```

## 3. 详细请求

```text
/ecc-performance-optimizer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：查找算法、内存、渲染和 bundle 大小等性能瓶颈，并提出优化建议。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
