# `/ecc-gan-generator` — 提示词示例

## 用途

根据提供的规格实现功能，然后参考 evaluator 的反馈反复改进，直到达到指定质量阈值。阈值应由用户或规格定义。

## 简短请求

```text
/ecc-gan-generator 根据 {规格} 实现 {功能}；参考 {评分/反馈}。只修改与任务相关的文件。
```

## 模板请求

```text
/ecc-gan-generator 在项目 {路径} 中，根据规格 {链接/文本} 和评估 {反馈} 进行一次迭代。在 {允许范围} 内修复优先级较高的不符合项，然后列出修改内容及仍未经确认的标准。不要自行扩大范围。
```

## 详细请求

```text
/ecc-gan-generator 根据规格 {规格} 和 evaluator 的意见 {报告}，在 {项目} 中实现 {功能}。
1. 将意见与规格标准对照；如果存在冲突或歧义，请明确指出，不要臆造要求。
2. 在 {允许的文件/行为} 范围内选择最小的更改集合；不要影响无关功能。
3. 按优先级和质量阈值 {明确指定的阈值} 进行更改；没有相应评估数据时，不要声称已达标。
4. 仅执行 {命令/限制} 中允许的检查；报告实际结果。
5. 编写简短报告，供 evaluator 在下一轮核查。

格式：按标准说明更改、文件、检查及结果、剩余风险/问题。未经单独同意，不要安装依赖、访问网络或部署。
```
