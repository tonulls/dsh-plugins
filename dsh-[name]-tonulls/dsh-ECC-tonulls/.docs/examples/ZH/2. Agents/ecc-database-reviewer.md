# `/ecc-database-reviewer`

**用途：**PostgreSQL 专家：查询优化、架构设计、安全性和性能。适用于 SQL 和迁移工作以及数据库故障排查；也考虑 Supabase 实践。

## 简短提示词

```text
/ecc-database-reviewer 检查此 PostgreSQL 查询或迁移的正确性、安全性和性能；不要在数据库中执行任何操作。
```

## 模板提示词

```text
/ecc-database-reviewer
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 PostgreSQL 查询、架构或迁移。
重点：SQL 正确性、查询计划、索引、完整性、安全性和适用的 Supabase 实践。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-database-reviewer
为 [项目/组件/场景] 执行任务“检查 PostgreSQL 查询、架构或迁移”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：SQL 正确性、查询计划、索引、完整性、安全性和适用的 Supabase 实践。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
