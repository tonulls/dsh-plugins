# `/ecc-conversation-analyzer`

**用途：**分析对话记录，识别应通过钩子预防的行为。无参数时由 `/hookify` 命令调用。

## 简短提示词

```text
/ecc-conversation-analyzer 分析这段对话记录，找出可通过钩子预防的重复行为。不要创建钩子本身。
```

## 模板提示词

```text
/ecc-conversation-analyzer
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：在对话记录中找出重复的行为模式，并评估是否应针对 [目标或对象] 使用钩子加以预防。
重点：可观察到的片段、重复频率、误报，以及未来钩子的最小触发条件。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-conversation-analyzer
为 [项目/组件/场景] 执行任务“在对话记录中找出重复的行为模式，并评估是否应通过钩子预防”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：可观察到的片段、重复频率、误报，以及未来钩子的最小触发条件。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
