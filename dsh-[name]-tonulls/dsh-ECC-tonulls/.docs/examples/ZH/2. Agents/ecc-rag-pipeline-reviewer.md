# 提示词示例：`/ecc-rag-pipeline-reviewer`

**调用命令：** `/ecc-rag-pipeline-reviewer`

## 用途

审查 RAG 管道：检索质量、分块策略、嵌入和评估充分性。只做分析。

## 1. 简短请求

```text
/ecc-rag-pipeline-reviewer 根据管道描述 {管道} 和指标 {数据} 评估 RAG 检索质量；不要进行任何更改。
```

## 2. 模板请求

```text
/ecc-rag-pipeline-reviewer 根据查询类型 {查询类型}、语料库和指标 {数据}，评估 RAG 系统 {描述/diff}。检查分块、检索/重排序、嵌入和评估集是否具有代表性。不要访问外部网络或修改代码/索引；提供证据、信息缺口和优先实验建议。
```

## 3. 详细请求

```text
/ecc-rag-pipeline-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：检索质量、分块策略、嵌入和评估充分性。只做分析。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
