# 提示词示例：`/ecc-mle-reviewer`

**调用命令：** `/ecc-mle-reviewer`

## 用途

审查生产 ML/MLOps：数据契约、管道、可复现性、评估、服务、监控和回滚。不修改文件。

## 1. 简短请求

```text
/ecc-mle-reviewer 检查 ML 管道更改的可复现性和服务风险；不要编辑文件。
```

## 2. 模板请求

```text
/ecc-mle-reviewer 对 ML 组件 {描述} 中的更改 {路径/diff} 进行只读审查。检查训练/服务一致性、可复现性、数据泄露、离线/在线指标、监控和回滚。只报告有依据的发现，并提供证据和优先级。
```

## 3. 详细请求

```text
/ecc-mle-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：数据契约、管道、可复现性、评估、服务、监控和回滚。不修改文件。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
