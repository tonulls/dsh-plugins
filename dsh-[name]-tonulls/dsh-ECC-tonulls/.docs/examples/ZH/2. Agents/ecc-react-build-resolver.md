# 提示词示例：`/ecc-react-build-resolver`

**调用命令：** `/ecc-react-build-resolver`

## 用途

查找并以最小更改修复 React 构建故障：JSX/TSX、水合、服务端/客户端边界、类型和 bundler 配置。

## 1. 简短请求

```text
/ecc-react-build-resolver 分析 React 构建错误 {日志}；不要安装软件包。
```

## 2. 模板请求

```text
/ecc-react-build-resolver React 项目 {Vite/webpack/Next.js/其他} 构建失败，日志为 {日志}。在已修改文件中找出根因并提出最小修复。不要安装软件包或访问网络；在修改文件或运行有副作用的命令前先征求确认。
```

## 3. 详细请求

```text
/ecc-react-build-resolver 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：JSX/TSX、水合、服务端/客户端边界、类型和 bundler 配置。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
