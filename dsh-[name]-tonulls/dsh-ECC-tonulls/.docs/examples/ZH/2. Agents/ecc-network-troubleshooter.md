# 提示词示例：`/ecc-network-troubleshooter`

**调用命令：** `/ecc-network-troubleshooter`

## 用途

按 OSI 层诊断网络症状，仅使用可观察的数据，并形成有证据支持的根因摘要。

## 1. 简短请求

```text
/ecc-network-troubleshooter 帮我诊断 {症状}，不要更改网络设置。
```

## 2. 模板请求

```text
/ecc-network-troubleshooter 分析 {网段/设备} 上的问题 {症状}；开始时间 {时间}，已知更改 {更改}，检查结果 {数据}。从物理层/链路层逐步排查至 DNS/路由/策略；不要更改配置或扫描网络。区分事实与假设，并指出安全的检查方法。
```

## 3. 详细请求

```text
/ecc-network-troubleshooter 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：按 OSI 层诊断网络症状，仅使用可观察的数据，并形成有证据支持的根因摘要。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
