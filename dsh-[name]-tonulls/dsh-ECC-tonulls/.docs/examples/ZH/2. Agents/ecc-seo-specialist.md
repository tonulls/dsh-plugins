# 提示词示例：`/ecc-seo-specialist`

**调用命令：** `/ecc-seo-specialist`

## 用途

审计技术 SEO、页面元数据、结构化数据、Core Web Vitals 以及内容/关键词地图。

## 1. 简短请求

```text
/ecc-seo-specialist 为 {页面} 编写技术 SEO 检查清单；不要发起网络请求。
```

## 2. 模板请求

```text
/ecc-seo-specialist 根据可用的本地材料审计 {网站/页面} 的 SEO：目标为 {目标}，受众为 {受众}。检查元数据、结构化数据、sitemap/robots、Core Web Vitals 以及内容与查询的匹配度。不要发起网络请求或修改网站；指出无法核查的内容并按优先级排列建议。
```

## 3. 详细请求

```text
/ecc-seo-specialist 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：技术 SEO、页面元数据、结构化数据、Core Web Vitals 及内容/关键词地图审计。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
