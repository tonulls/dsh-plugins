# 提示词示例：`/ecc-refactor-cleaner`

**调用命令：** `/ecc-refactor-cleaner`

## 用途

查找未使用和重复代码，以便安全清理和整合；删除操作必须获得确认。

## 1. 简短请求

```text
/ecc-refactor-cleaner 在 {范围} 中找出可删除项，但不要删除或修改文件。
```

## 2. 模板请求

```text
/ecc-refactor-cleaner 分析 {目录/模块} 中的未使用代码和重复项。考虑动态导入、公共 API 和代码生成。先提供候选项及证据，并说明误报风险；未经我确认，不要安装工具、删除或修改文件。
```

## 3. 详细请求

```text
/ecc-refactor-cleaner 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：查找未使用和重复代码，以便安全清理和整合；删除操作必须获得确认。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
