# `/ecc-docs-lookup` — 提示词示例

## 用途

通过 Context7 MCP 参考最新文档，回答有关库、框架和 API 用法的问题，并提供适用的代码示例。

## 简短请求

```text
/ecc-docs-lookup 如何使用 {库及版本} 完成 {任务}？请给出示例并说明文档中提到的限制。
```

## 模板请求

```text
/ecc-docs-lookup 查找 {API/框架} 的最新文档，版本为 {版本或未知}。解释 {具体问题}，并提供适用于 {语言/环境} 的最小示例。区分来源明确支持的内容与假设；如果版本不明确，请说明适用性。
```

## 详细请求

```text
/ecc-docs-lookup 针对 {库/API} 解答问题 {问题}；使用的版本为 {版本}，项目背景为 {环境和限制}。
1. 通过 Context7 MCP 查找与问题相关的最新文档资料。
2. 明确哪些条款取决于版本；不要用猜测填补缺失信息。
3. 给出解决方案和符合指定环境的精简示例。
4. 列出重要限制、常见错误，以及文档中提到的替代方案（如有）。

格式：简短回答、示例、分步说明、所用章节的链接/名称及注意事项。不要修改项目文件，也不要声称通过执行验证了代码。
```
