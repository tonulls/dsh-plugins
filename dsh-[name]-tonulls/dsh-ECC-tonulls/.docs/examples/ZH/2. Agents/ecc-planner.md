# 提示词示例：`/ecc-planner`

**调用命令：** `/ecc-planner`

## 用途

在开始实现前，为复杂功能、架构更改或重构制定结构化计划。

## 1. 简短请求

```text
/ecc-planner 为 {功能} 制定分阶段计划；不要修改代码。
```

## 2. 模板请求

```text
/ecc-planner 为项目 {背景} 中的 {目标} 制定计划。限制：{兼容性/时间/范围}。拆分阶段，注明涉及范围、依赖项、风险和可验证的完成标准。不要执行计划或修改文件。
```

## 3. 详细请求

```text
/ecc-planner 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：在开始实现前，为复杂功能、架构更改或重构制定结构化计划。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
