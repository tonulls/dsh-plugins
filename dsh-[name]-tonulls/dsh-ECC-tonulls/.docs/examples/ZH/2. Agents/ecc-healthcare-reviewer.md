# `/ecc-healthcare-reviewer`

**用途：**审查医疗应用代码：临床安全、CDSS 准确性、PHI 保护和医疗数据完整性。专长包括 EMR/EHR 和临床决策支持系统。

## 简短提示词

```text
/ecc-healthcare-reviewer 以只读方式审查医疗相关更改中的临床风险、PHI 和数据完整性；不要在回复中包含真实患者数据。
```

## 模板提示词

```text
/ecc-healthcare-reviewer
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的医疗应用安全和完整性风险。
重点：临床安全、CDSS 正确性、PHI 保护和 EMR/EHR 完整性。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-healthcare-reviewer
为 [项目/组件/场景] 执行任务“检查医疗应用的安全和完整性风险”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：临床安全、CDSS 正确性、PHI 保护和 EMR/EHR 完整性。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
