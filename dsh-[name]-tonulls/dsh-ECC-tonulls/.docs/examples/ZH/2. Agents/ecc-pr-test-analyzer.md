# 提示词示例：`/ecc-pr-test-analyzer`

**调用命令：** `/ecc-pr-test-analyzer`

## 用途

评估 PR 测试覆盖的完整性和实用性，重点关注行为验证和防止真实回归。

## 1. 简短请求

```text
/ecc-pr-test-analyzer 检查 PR {链接/编号} 中哪些重要行为尚未被测试覆盖；不要修改文件。
```

## 2. 模板请求

```text
/ecc-pr-test-analyzer 以只读方式分析 PR {编号/diff} 相对于行为 {更改} 的测试覆盖。找出未测试场景、薄弱断言以及无法捕获可能缺陷的测试。将每项建议与需求/风险关联；不要修改文件或测试。
```

## 3. 详细请求

```text
/ecc-pr-test-analyzer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：评估 PR 测试覆盖的完整性和实用性，重点关注行为验证和防止真实回归。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
