# `/ecc-flutter-reviewer` — 提示词示例

## 用途

审查 Flutter/Dart 代码，不依赖具体的状态管理库：评估 Widget、状态架构、Dart 惯用法、性能和无障碍性。

## 简短请求

```text
/ecc-flutter-reviewer 检查 {屏幕/Widget} 中的 Flutter 错误、状态管理、性能和无障碍性。只做分析，不修改。
```

## 模板请求

```text
/ecc-flutter-reviewer 对 Flutter 应用中的更改 {路径/diff} 进行只读审查。考虑此处使用的状态管理方案 {如已知}、Widget 生命周期、重建、Dart 惯用法和无障碍性。对每项发现提供证据、影响和实用建议。
```

## 详细请求

```text
/ecc-flutter-reviewer 分析 {路径} 中的更改 {屏幕/流程}，不要假设项目使用了未实际发现的状态管理库。
1. 检查 Widget 边界和组合、状态及异步更新，以及生命周期正确性。
2. 查找代码有依据的多余重建或昂贵渲染操作。
3. 评估交互的无障碍性：受支持平台上的语义、焦点/键盘和流程可读性。
4. 检查影响行为或维护的 Dart 惯用法和架构问题；不要将主观意见当作缺陷。

格式：按优先级列出发现，并注明文件/行、触发条件、影响和建议；然后说明已检查方面及信息缺口。只做分析——不要修改代码或安装依赖；未经同意，不要访问网络或部署。
```
