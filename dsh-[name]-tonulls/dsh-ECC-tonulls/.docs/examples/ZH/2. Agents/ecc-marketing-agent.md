# 提示词示例：`/ecc-marketing-agent`

**调用命令：** `/ecc-marketing-agent`

## 用途

帮助规划营销活动，并为指定受众和渠道创建/审查文案。

## 1. 简短请求

```text
/ecc-marketing-agent 为面向受众 {受众} 的产品 {产品} 想出三个标题方案。
```

## 2. 模板请求

```text
/ecc-marketing-agent 为产品 {产品} 准备 {活动/材料类型}，受众为 {受众}，渠道为 {渠道}，目标为 {目标}，语气为 {语气}。提供文案选项并简要解释定位。不要发布或发送材料；注明假设，不要编造已确认的事实。
```

## 3. 详细请求

```text
/ecc-marketing-agent 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：帮助规划营销活动，并为指定受众和渠道创建/审查文案。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
