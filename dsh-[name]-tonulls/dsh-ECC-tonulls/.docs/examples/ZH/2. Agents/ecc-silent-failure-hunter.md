# 提示词示例：`/ecc-silent-failure-hunter`

**调用命令：** `/ecc-silent-failure-hunter`

## 用途

查找被悄然隐藏的错误、被吞掉的异常、危险的 fallback 分支以及错误未向上层传递的问题。只做审查。

## 1. 简短请求

```text
/ecc-silent-failure-hunter 找出 {路径} 中可能隐藏错误的位置；不要修改代码。
```

## 2. 模板请求

```text
/ecc-silent-failure-hunter 以只读方式分析 {文件/diff}，追踪 {操作} 的失败路径。查找空的 catch、被忽略的结果、掩盖问题的 fallback 和错误传播丢失。说明故障场景、位置、影响及安全修复方案；不要修改文件。
```

## 3. 详细请求

```text
/ecc-silent-failure-hunter 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：查找被悄然隐藏的错误、被吞掉的异常、危险的 fallback 分支以及错误未向上层传递的问题。只做审查。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
