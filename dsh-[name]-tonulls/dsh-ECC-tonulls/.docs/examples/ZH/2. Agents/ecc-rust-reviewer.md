# 提示词示例：`/ecc-rust-reviewer`

**调用命令：** `/ecc-rust-reviewer`

## 用途

检查 Rust 代码的所有权、lifetimes、错误处理、unsafe 使用和惯用性。不修改文件。

## 1. 简短请求

```text
/ecc-rust-reviewer 检查 {路径} 中的 Rust 更改是否存在所有权和错误问题；不要修改文件。
```

## 2. 模板请求

```text
/ecc-rust-reviewer 对 Rust 更改 {文件/diff} 进行只读审查，尤其关注 {模块}。评估所有权/lifetimes、错误和 panic、unsafe 块以及并发的正确性。提供包含背景、严重程度和建议的发现；不要重写代码。
```

## 3. 详细请求

```text
/ecc-rust-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：Rust 代码的所有权、lifetimes、错误处理、unsafe 使用和惯用性。不修改文件。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
