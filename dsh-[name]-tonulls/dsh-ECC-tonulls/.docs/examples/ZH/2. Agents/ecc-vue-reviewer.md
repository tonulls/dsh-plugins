# 提示词示例：`/ecc-vue-reviewer`

**调用命令：** `/ecc-vue-reviewer`

## 用途

检查 Vue 代码中的 Composition API 和响应性正确性、组件架构、模板安全性和性能。不做修改。

## 1. 简短请求

```text
/ecc-vue-reviewer 检查 {路径} 中的 Vue 更改是否存在响应性和模板安全问题；不要修改。
```

## 2. 模板请求

```text
/ecc-vue-reviewer 在组件 {场景} 中，对 Vue 更改 {文件/diff} 进行只读审查；考虑所用的 Pinia/Router/Nuxt。检查 Composition API、响应式依赖、模板转义、生命周期和性能。只报告已确认的问题，并注明位置和修复方法；不要修改文件。
```

## 3. 详细请求

```text
/ecc-vue-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：Vue 代码的 Composition API 和响应性正确性、组件架构、模板安全性及性能。不做修改。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
