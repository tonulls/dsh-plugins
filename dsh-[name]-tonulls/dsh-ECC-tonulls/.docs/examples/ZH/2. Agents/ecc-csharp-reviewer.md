# `/ecc-csharp-reviewer`

**用途：**审查 C# 和 .NET 代码：平台约定、异步、安全性、nullable 类型和性能。适用于 C# 项目中的更改。

## 简短提示词

```text
/ecc-csharp-reviewer 以 async、nullable 和安全性为重点，对此 C#/.NET 更改进行只读审查。
```

## 模板提示词

```text
/ecc-csharp-reviewer
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 C#/.NET 更改。
重点：async 正确性、nullable reference types、安全性和平台约定。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-csharp-reviewer
为 [项目/组件/场景] 执行任务“检查 C#/.NET 更改”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：async 正确性、nullable reference types、安全性和平台约定。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
