# `/ecc-go-build-resolver` — 提示词示例

## 用途

以最小更改修复 Go 构建和编译错误、`go vet` 警告及 lint 问题，不把诊断演变成架构重构。

## 简短请求

```text
/ecc-go-build-resolver 分析 Go 错误：{输出/命令}。找出根因并以最小更改修复，不要扩大修改范围。
```

## 模板请求

```text
/ecc-go-build-resolver 修复 {项目路径} 中的 {go build/go vet/lint 错误}，输出为：{文本}。先检查模块和受影响代码；仅以最小 diff 修复故障根因。不要更新依赖，并说明获准检查的结果。
```

## 详细请求

```text
/ecc-go-build-resolver 修复 Go 项目 {路径} 的构建，问题为 {命令及完整输出}。
1. 找出受影响的软件包并追踪错误消息至原始原因，区分级联错误。
2. 检查类型、导入和所用 API 是否一致；对于 vet/lint，评估警告是否源于实际缺陷。
3. 进行最小局部修复；除非确有必要，不要更改架构或公共行为。
4. 只运行获准的检查命令 {命令}；如果命令不可用或不允许，不要声称已验证修复。

格式：根因、修改文件及理由、已执行的检查及其准确结果、剩余错误。未经同意，不要安装软件包、访问网络或部署；不要更改无关文件。
```
