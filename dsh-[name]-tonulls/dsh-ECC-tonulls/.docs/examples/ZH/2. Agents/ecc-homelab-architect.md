# `/ecc-homelab-architect`

**用途：**根据设备清单、目标和运维人员经验设计家庭及小型实验室网络；提出安全的分阶段更改方案和回滚计划。

## 简短提示词

```text
/ecc-homelab-architect 根据这份设备清单，为 homelab 提出安全的网络方案，包含阶段安排和回滚步骤。
```

## 模板提示词

```text
/ecc-homelab-architect
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 设计安全的家庭或小型实验室网络。
重点：设备清单、目标和运维人员经验、分阶段更改及可验证的回滚方案。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-homelab-architect
为 [项目/组件/场景] 执行任务“设计安全的家庭或小型实验室网络”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：设备清单、目标和运维人员经验、分阶段更改及可验证的回滚方案。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
