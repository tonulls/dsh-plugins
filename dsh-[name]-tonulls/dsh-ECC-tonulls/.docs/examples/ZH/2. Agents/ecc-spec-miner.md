# 提示词示例：`/ecc-spec-miner`

**调用命令：** `/ecc-spec-miner`

## 用途

从现有代码中提取 OpenSpec 的行为需求和不变量，并关联实体与测试。

## 1. 简短请求

```text
/ecc-spec-miner 从 {路径} 中提取 capability {名称} 的需求和不变量；不要创建文件。
```

## 2. 模板请求

```text
/ecc-spec-miner 从 {路径} 中提取 capability {名称} 的现有行为规格。对照代码和测试；整理需求和不变量，并注明实体、保障机制、稳定 ID 和 test anchors。不要臆造缺失行为；先在回复中展示结果，未经确认不要创建 spec.md。
```

## 3. 详细请求

```text
/ecc-spec-miner 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：从现有代码中提取 OpenSpec 的行为需求和不变量，并关联实体与测试。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
