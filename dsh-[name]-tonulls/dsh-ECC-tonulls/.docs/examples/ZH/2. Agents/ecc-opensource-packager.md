# 提示词示例：`/ecc-opensource-packager`

**调用命令：** `/ecc-opensource-packager`

## 用途

为已清理的项目准备开源发布文件套件：文档、许可证、setup 和 issue 模板。

## 1. 简短请求

```text
/ecc-opensource-packager 为项目 {路径} 提出开源发布套件组成；暂时不要创建文件。
```

## 2. 模板请求

```text
/ecc-opensource-packager 为已确认清理的项目 {路径} 提出面向 {受众}、采用许可证 {许可证} 的开源套件内容。先列出计划文件和已发现的缺口；除非我明确确认准确的文件列表，否则不要创建或覆盖文件。不要安装软件或发布。
```

## 3. 详细请求

```text
/ecc-opensource-packager 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：文档、许可证、setup 和 issue 模板。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
