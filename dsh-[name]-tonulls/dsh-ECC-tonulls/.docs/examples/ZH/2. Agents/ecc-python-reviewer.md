# 提示词示例：`/ecc-python-reviewer`

**调用命令：** `/ecc-python-reviewer`

## 用途

检查 Python 代码的 PEP 8、语言惯用法、类型注解、安全性和性能。不编辑文件。

## 1. 简短请求

```text
/ecc-python-reviewer 以只读方式审查 {路径} 中的 Python 代码；只指出实际发现的问题。
```

## 2. 模板请求

```text
/ecc-python-reviewer 对 Python 代码 {文件/diff} 进行只读审查，用途为 {用途}。检查类型、错误处理、输入边界安全性和效率；区分实际缺陷与风格问题。只报告已确认的问题，并注明位置和建议；不要修改文件。
```

## 3. 详细请求

```text
/ecc-python-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：检查 Python 代码的 PEP 8、语言惯用法、类型注解、安全性和性能。不编辑文件。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
