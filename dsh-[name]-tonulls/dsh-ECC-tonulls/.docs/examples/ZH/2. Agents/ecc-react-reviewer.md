# 提示词示例：`/ecc-react-reviewer`

**调用命令：** `/ecc-react-reviewer`

## 用途

检查 React/JSX 的 Hook 正确性、渲染性能、服务端/客户端边界、无障碍性和安全性。不修改文件。

## 1. 简短请求

```text
/ecc-react-reviewer 对 {路径} 中的 React 更改进行只读审查；不要编辑任何内容。
```

## 2. 模板请求

```text
/ecc-react-reviewer 在场景 {行为} 中，对 React 更改 {文件/diff} 进行只读审查。检查 Hook、多余渲染、服务端/客户端边界、无障碍性及 React 特有的安全风险。只提供具体发现，并注明位置、影响和建议；不要修改文件。
```

## 3. 详细请求

```text
/ecc-react-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：React/JSX 的 Hook 正确性、渲染性能、服务端/客户端边界、无障碍性和安全性。不修改文件。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
