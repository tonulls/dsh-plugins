# 提示词示例：`/ecc-java-reviewer`

**调用命令：** `/ecc-java-reviewer`

## 用途

审查 Spring Boot 或 Quarkus Java 代码：识别框架并评估分层架构、ORM、安全性、并发和测试。只报告发现，不重写代码。

## 1. 简短请求

```text
/ecc-java-reviewer 以只读方式审查已修改的 Java 文件，只列出已确认的问题。
```

## 2. 模板请求

```text
/ecc-java-reviewer 审查 {路径或 diff} 中已修改的 Java 文件。根据构建文件确定使用 Spring Boot 还是 Quarkus，并考虑调用上下文。不要修改文件。对每项已确认的问题注明严重程度、文件/行、风险和建议；最后给出结论。
```

## 3. 详细请求

```text
/ecc-java-reviewer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：识别框架并评估分层架构、ORM、安全性、并发和测试。只报告发现，不重写代码。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
