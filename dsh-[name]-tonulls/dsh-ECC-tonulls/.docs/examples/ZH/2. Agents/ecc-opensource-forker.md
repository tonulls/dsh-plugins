# 提示词示例：`/ecc-opensource-forker`

**调用命令：** `/ecc-opensource-forker`

## 用途

准备项目副本以公开发布：识别机密/内部链接并提出清理方案；此操作会影响文件和历史记录。

## 1. 简短请求

```text
/ecc-opensource-forker 以只读方式列出项目 {路径} 公开前的风险；不要复制或删除任何内容。
```

## 2. 模板请求

```text
/ecc-opensource-forker 评估项目 {路径}，为准备公开副本做准备。先仅进行清点：检查机密风险（不要显示其值）、PII、内部链接和历史记录；提出复制/清理计划。未经单独确认，不要创建副本、删除或改写文件或 git 历史记录。不要发布。
```

## 3. 详细请求

```text
/ecc-opensource-forker 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：识别机密/内部链接并提出清理方案；此操作会影响文件和历史记录。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
