# `/ecc-agent-evaluator`

从准确性、完整性、清晰度、适用性和简洁性五个维度评估代理已完成的回答。此角色用于分析已完成的复杂任务，而不是执行新任务。

## 简短请求

```text
/ecc-agent-evaluator 从五个维度评估上一个回答。用可观察的例子支持评分，并提出最重要的改进建议。
```

## 模板

```text
/ecc-agent-evaluator 评估任务结果：“[任务简述]”。
代理的回答：[粘贴回答]
背景和限制：[要求、验收标准]
请对准确性、完整性、清晰度、适用性和简洁性评分；说明理由并提出具体改进建议。不要臆造背景中没有的事实。
```

## 详细请求

```text
/ecc-agent-evaluator 对结果进行可核查的评估。
1. 将回答与原始任务对照，分别列出已确认的事实和假设。
2. 评估五个维度：准确性、完整性、清晰度、适用性、简洁性。每项按 1–5 分评分，并简短说明依据。
3. 指出重要遗漏、矛盾和可能造成误导的陈述；没有依据时，不要把缺少信息视为错误。
4. 提出不超过三项优先级最高的改进建议。
格式：先给出总体评分，然后提供“维度 / 分数 / 证据”表格，接着列出意见和建议。仅分析以下回答：[粘贴回答]。任务标准：[粘贴标准]。
```
