# 提示词示例：`/ecc-kotlin-build-resolver`

**调用命令：** `/ecc-kotlin-build-resolver`

## 用途

查找并最小化修复 Kotlin 和 Gradle 构建/编译错误。

## 1. 简短请求

```text
/ecc-kotlin-build-resolver 帮我找出 Kotlin/Gradle 错误的原因：{粘贴错误消息}。
```

## 2. 模板请求

```text
/ecc-kotlin-build-resolver 项目 {模块} 中的 {构建命令} 失败，错误为：{错误文本}。找出 Kotlin/Gradle 配置中的根因并提出最小修复。不要安装依赖或访问网络；在修改文件或运行会更改内容的命令之前，请先征求确认。
```

## 3. 详细请求

```text
/ecc-kotlin-build-resolver 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：查找并最小化修复 Kotlin 和 Gradle 构建/编译错误。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
