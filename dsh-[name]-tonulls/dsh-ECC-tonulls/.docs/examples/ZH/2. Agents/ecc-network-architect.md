# 提示词示例：`/ecc-network-architect`

**调用命令：** `/ecc-network-architect`

## 用途

根据需求、设备和限制，设计企业网络或多站点网络架构。

## 1. 简短请求

```text
/ecc-network-architect 为 {数量} 个工作站和 {数量} 个站点提出安全的网络方案。
```

## 2. 模板请求

```text
/ecc-network-architect 为 {站点/用户数} 设计网络，需求为 {服务/可用性}，限制为 {预算/设备/技能}。描述拓扑、分段、路由、容错能力和迁移阶段，包含验证与回滚。不要更改真实网络或连接网络。
```

## 3. 详细请求

```text
/ecc-network-architect 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：根据需求、设备和限制设计企业网络或多站点网络架构。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
