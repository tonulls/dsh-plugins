# `/ecc-fsharp-reviewer` — 提示词示例

## 用途

专业审查 F# 的函数式惯用法、类型安全、模式匹配、计算表达式和性能。

## 简短请求

```text
/ecc-fsharp-reviewer 检查 {文件/diff} 中的 F# 缺陷：类型、模式匹配、计算表达式和性能。不要进行任何更改。
```

## 模板请求

```text
/ecc-fsharp-reviewer 以只读方式审查 {路径} 中的 {模块/更改}。检查类型表达不变量的能力、模式匹配的完整性、计算表达式的正确性、代码惯用性及显著瓶颈。提供已确认发现的位置、影响和建议。
```

## 详细请求

```text
/ecc-fsharp-reviewer 分析 F# 项目 {路径} 中的更改 {描述}，并考虑其用途 {背景}。
1. 追踪数据转换，检查类型和构造在多大程度上限制了无效状态。
2. 检查模式匹配是否存在分支不完整或错误，以及错误处理是否正确。
3. 根据实际代码审视计算表达式和副作用；不要臆测未知语义。
4. 只有在有具体依据时才指出性能问题；区分风险与风格偏好。

格式：按严重程度列出发现（文件/行、场景、影响、建议），然后说明已检查范围和未知事实。只做分析：不要编辑源文件、安装软件包、访问网络或在未经同意时部署。
```
