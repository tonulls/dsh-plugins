# 提示词示例：`/ecc-opensource-sanitizer`

**调用命令：** `/ecc-opensource-sanitizer`

## 用途

检查公开副本中的机密、个人数据、内部链接和危险文件，并给出 PASS/FAIL/PASS-WITH-WARNINGS 结果。只做分析。

## 1. 简短请求

```text
/ecc-opensource-sanitizer 检查公开副本 {路径} 是否存在泄露，并给出简要状态；不要修改文件。
```

## 2. 模板请求

```text
/ecc-opensource-sanitizer 以只读方式检查准备发布的副本 {路径}。不要透露发现的机密/PII 值；注明文件和安全上下文、类别及严重程度。检查内部链接和危险文件，并在说明验证限制的同时给出 PASS/FAIL/PASS-WITH-WARNINGS 结果。不要修复文件。
```

## 3. 详细请求

```text
/ecc-opensource-sanitizer 请针对任务 {场景/更改} 执行分步分析。

1. 记录初始背景，仅研究相关材料。
2. 检查此角色关注的关键风险和标准：检查公开副本中的机密、个人数据、内部链接和危险文件，并给出 PASS/FAIL/PASS-WITH-WARNINGS 结果。只做分析。
3. 区分已确认的事实与推测，并指出缺失的信息。
4. 生成按优先级排序的结果，附上证据、验证限制和具体后续步骤。

边界：不要泄露机密或个人数据；未经明确许可，不要执行网络操作、安装软件包、部署或运行潜在危险的命令。分析期间不要修改文件；任何更改、删除、启动循环或应用配置的操作，都必须先协商并等待我的确认。
```
