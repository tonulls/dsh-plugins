# `/ecc-doc-updater` — 提示词示例

## 用途

根据项目实际状态更新文档和代码库地图；可在指定范围内处理 README、指南和 `docs/CODEMAPS/*`。

## 简短请求

```text
/ecc-doc-updater 根据 {功能} 的更改更新文档 {路径/章节}。将陈述与代码核对，不要超出指定章节范围。
```

## 模板请求

```text
/ecc-doc-updater 使 {文档或地图} 与 {功能/模块} 的实现保持一致。检查相关源文件 {路径}，保留项目风格，列出已修改文件和未经确认的细节。只修改 {允许路径}；不要编辑其他文档。
```

## 详细请求

```text
/ecc-doc-updater 为 {受众} 编写更改 {描述} 的文档。
1. 研究相关源文件和现有文档；区分事实与假设。
2. 确定哪些页面或代码库地图确实已过时。
3. 只更新 {允许的文件}，保持项目结构和术语；不要承诺未经证实的功能。
4. 检查链接、命令以及描述与实现的一致性。

回复中列出文件、更改概要和剩余信息缺口。不要修改代码或超出允许范围的文件；未经同意，不要安装依赖、访问网络或部署。
```
