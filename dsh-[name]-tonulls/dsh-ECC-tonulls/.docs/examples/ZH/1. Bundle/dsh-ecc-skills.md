# `dsh-ecc-skills` — 工作模式与提示词示例

**用途：**为当前会话启用或停用 ECC Skills 的自动选择。此开关仅对用户可用。如果尚未明确具体任务，请先从研究开始，再进行分析；确定要实施的更改后再使用实现。这三个标题表示后续请求的类型，并非额外的切换命令。

若要启用自动选择，请由用户单独发送一条直接消息：

```text
/dsh-ecc-skills on
```

不要在命令中附加任务。收到确认后，从下方选择一个模板，并在下一条单独消息中发送。若要停用自动选择，请另行发送：

```text
/dsh-ecc-skills off
```

即使关闭了自动选择，仍可显式调用 `/ecc-*`。

## 🔍 研究 (Research)

借助相关技能了解项目现有流程、规则和背景，不作任何更改。

### 1. 简短

```text
研究项目 <项目路径>：说明其主要流程、适用规则和文档。以只读方式工作，不要进行任何更改。
```

### 2. 常规模板

```text
研究项目 <项目路径> 中的 <范围或流程>；目前尚未明确具体任务。

研究相关组件、项目文档、测试和既定约定。说明实际工作流程、关键依赖和限制，并给出准确的依据文件路径。区分已确认的信息与推测，并列出信息缺口。

不要编辑文件，也不要开始实现。最后提出有助于明确背景的问题。
```

### 3. 详细分步

```text
以只读方式研究项目 <项目路径> 中的 <范围或流程>。

1. 查找本地指引、文档、相关组件和测试。
2. 根据现有代码和仓库数据还原流程；不要把名称或注释当作行为证据。
3. 说明流程的输入、结果、规则、依赖和常见错误。
4. 将文档与实际行为对照，并指出具体不一致之处。
5. 列出研究限制以及缺少的信息。

不要进行任何更改、安装软件包或访问网络。在我提出要求之前，不要提供实现计划。最终以简要流程图的形式呈现结果，并附上事实来源和待解决的问题。
```

## 🧠 分析 (Analysis)

在不编辑项目的前提下，找出所选范围内已证实的问题、缺口和改进机会。

### 1. 简短

```text
分析项目 <项目路径> 中的 <范围或流程>：找出已证实的问题和有价值的改进，用依据支持结论并排列优先级。不要进行任何更改。
```

### 2. 常规模板

```text
根据项目 <项目路径> 中的实际代码、测试和文档，分析 <范围或流程>。

找出缺陷、风险、缺少的检查以及改进机会。对每项结论说明证据、影响、涉及范围、可能收益、复杂度和优先级。另行标注假设和其他可能解释。

以只读方式工作：不要修复发现的问题，也不要安装依赖。最后提出后续操作选项，但不要替我作决定。
```

### 3. 详细分步

```text
对项目 <项目路径> 中的 <范围或流程> 进行分析性审查。除了问题之外，也要寻找切实可行的改进机会。

1. 将分析范围限定在相关模块、本地指引、测试和文档来源内。
2. 在适用时，评估流程的正确性和完整性、边界情况处理、安全性、可访问性及可维护性。
3. 对每项结论提供可核实的证据，并区分事实、解读和假设。
4. 评估影响、可能性、收益、复杂度和依赖项，形成优先级列表。
5. 指出还需要我提供哪些信息或作出哪些决定。

不要编辑文件、运行有副作用的命令、安装依赖或访问网络。最后给出供讨论的建议，而不是直接实施。
```

## 🛠️ 实现 (Implementation)

当已选定具体任务，且适合使用专用技能时使用。先明确验收标准并商定计划。

### 1. 简短

```text
请结合项目 <项目路径> 现有约定，帮助实现 <具体更改>。先提出计划和验证步骤，等待我确认，然后只进行已商定的更改。
```

### 2. 常规模板

```text
在项目 <项目路径> 的 <组件或流程> 中实现 <具体更改>。

研究指引、现有实现和测试。修改前先列出目标行为、涉及文件、验收标准以及适用的技能或方法。等待我确认；如果需求不完整，请先提问。

确认后进行最小范围的更改，验证相关场景，并更新相关文档。未经单独许可，不要添加依赖或访问网络。
```

### 3. 详细分步

```text
在项目 <项目路径> 中实现已商定的更改 <描述>。

预期场景：<列表>。
验收标准：<可验证的条件>。
限制：<兼容性、技术栈、安全性和修改范围>。

1. 研究本地指引、架构、现有模式和测试。
2. 仅针对给定任务选择相关技能，并简要说明其适用方式。
3. 制定计划，列出文件、验证步骤、风险和未知事项。在我确认前不要编辑项目。
4. 商定后进行最小范围的更改，并添加或更新必要的测试。
5. 仅运行相关的本地检查，展示最终 diff 并说明剩余限制。

如果发现需求冲突，或需要执行尚未商定的工作，请暂停并确认下一步。未经单独许可，不要安装软件包或访问网络。
```
