# `/ecc-terminal-ops`

在仓库中以证据为依据地执行命令：运行检查、分析 CI 错误并进行小范围修复，精确记录运行和确认过的内容。

## 简单请求
```text
/ecc-terminal-ops 根据现有日志分析此 CI 错误，并提出安全检查：[日志]
```
## 模板请求
```text
/ecc-terminal-ops
仓库/任务：[背景]
命令或错误：[信息]
获准范围：[只读/明确的本地检查]
先列出命令计划和副作用；不要运行超出约定范围的内容。
```
## 详细请求
```text
/ecc-terminal-ops
需要在仓库[范围]中检查/诊断[任务]。先查看相关文件和可用说明，然后制定最精简的安全本地命令计划，并注明预期副作用。运行命令、写入文件、访问网络、安装软件、修改 Git、push 或 deploy 前，分别就相应操作征求我的确认。准确记录命令和实际退出码/输出；屏蔽机密。未实际执行的检查，不要声称成功。结果：已执行操作、证据、未执行的检查及下一安全步骤。
```
