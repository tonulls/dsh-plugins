# `/ecc-orch-add-feature`

编排新增功能：研究、规划、TDD 实现、验证，并在更改和提交前设置独立检查点。

## 简单请求
```text
/ecc-orch-add-feature 添加 CSV 报告导出。先展示计划并等待我的批准。
```
## 模板请求
```text
/ecc-orch-add-feature 新功能：[描述]。背景/范围：[模块]。验收标准：[列表]。研究项目并提出计划；未经我确认，不要开始实现。提交前需另行确认。
```
## 详细请求
```text
/ecc-orch-add-feature 在[项目/子系统]中实现新功能[描述]。步骤：(1) 研究现有约定和扩展点；(2) 列出未知项，提出包含验收标准的计划，并在批准前暂停；(3) 获批后以测试优先、最小范围实现；(4) 仅运行适当的本地检查；(5) 审查 diff 并报告结果。不要安装依赖、访问网络或部署。只有获得单独明确确认后才提交。报告包括修改文件、检查和剩余风险。
```
