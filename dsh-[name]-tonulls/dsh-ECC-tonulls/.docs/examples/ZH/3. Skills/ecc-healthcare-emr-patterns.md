# `ecc-healthcare-emr-patterns`

**命令：** `/ecc-healthcare-emr-patterns`

**用途：**医疗应用 EMR/EHR 开发实践：临床安全、就诊流程、处方生成、CDSS 集成，以及便于录入医疗数据的 UI。适用于创建 EMR/EHR 功能，例如登记流程、处方和临床数据录入。

## 提示词

### 1. 简短请求

> /ecc-healthcare-emr-patterns 设计安全的医疗记录录入流程。

### 2. 带上下文的模板

> /ecc-healthcare-emr-patterns EMR/EHR 功能：[描述]，用户：[角色]，数据：[类别]。考虑临床安全、无障碍性和人工核验。

### 3. 详细请求

> /ecc-healthcare-emr-patterns 设计 EMR/EHR 场景[场景]：就诊 (encounter) 阶段、记录验证、界面无障碍性，以及必要时的 CDSS 集成。不要使用真实患者数据；明确说明审计和临床人员确认要求。返回流程、安全不变量和测试场景。
