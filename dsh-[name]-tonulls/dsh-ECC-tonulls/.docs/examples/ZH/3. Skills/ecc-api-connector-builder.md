# `/ecc-api-connector-builder`

遵循仓库中现有的集成模式添加 API 连接器或提供方，而不是引入并行架构。

## 提示词示例

### 1. 简短请求
```text
/ecc-api-connector-builder 按照项目中现有集成的模式，为[提供方]添加连接器。先研究本地模式。
```

### 2. 模板请求
```text
/ecc-api-connector-builder 在[项目]中实现[服务/API]集成。参考实现：[路径或名称]。所需操作：[列表]。只修改与连接器相关的文件，不要安装依赖或访问网络；如果模式或契约不明确，请暂停并提出问题。
```

### 3. 详细请求
```text
/ecc-api-connector-builder 为[仓库/模块]创建[提供方]连接器。1) 查找并研究现有连接器：接口、配置、错误、序列化和测试方法。2) 对照本地可用的 API 要求，列出信息缺口；不要臆造端点。3) 按相同风格仅实现集成所需文件；不要修改无关模块、安装软件包或发起网络请求。4) 检查 diff，并说明未运行哪些检查。结果包括：参考实现、修改文件清单、假设和限制。
```
