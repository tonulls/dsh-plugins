# `/ecc-scientific-pkg-gget`

提供可复现的 gget 工作流建议，用于基因组数据库查询、序列检索、类似 BLAST 的检查及生物信息学数据富集。

## 简单请求
```text
/ecc-scientific-pkg-gget 为检索基因[符号/物种]并记录来源，提出 gget 计划。
```
## 模板请求
```text
/ecc-scientific-pkg-gget
任务：[基因/序列/富集]
物种和标识符：[值]
可用数据和环境：[背景]
制定可复现的 gget 计划，并列出所需输入和验证。不要安装软件包。
```
## 详细请求
```text
/ecc-scientific-pkg-gget
计划进行生物信息学查询：[目标]，物种[物种/基因组组装版本]，标识符[列表]。1) 选择适用的 gget 操作并解释参数。2) 说明如何核验物种、参考数据库版本和标识符对应关系。3) 提出如何记录命令、时间、参数和结果以保证可复现性。4) 指出解释限制和预期错误。不要编造结果；未经单独许可，不要安装 CLI/库或发起网络请求。不要包含个人/机密数据。将命令作为草稿提供，并附输入要求、检查项和证据日志模板。
```
