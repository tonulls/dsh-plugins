# `ecc-frontend-a11y`

**命令：** `/ecc-frontend-a11y`

**用途：**React 和 Next.js 无障碍实践：语义化 HTML、ARIA 属性、字段标签、键盘导航、焦点管理和屏幕阅读器支持。适用于创建或检查表单、模态框、下拉菜单、提示框和标签页，修复无障碍问题，或配置键盘与焦点行为。

## 提示词

### 1. 简短请求

> /ecc-frontend-a11y 检查此 React 表单的无障碍性。

### 2. 带上下文的模板

> /ecc-frontend-a11y 组件：[路径]，元素：[表单/模态框/标签页]。检查语义、labels、键盘、焦点和屏幕阅读器；不要修改文件。

### 3. 详细请求

> /ecc-frontend-a11y 对[组件]执行只读审计。检查 HTML/ARIA、字段标签、键盘顺序、焦点管理和屏幕阅读器行为。按严重程度列出缺陷，注明具体位置和修复验证方法；不要编辑文件。
