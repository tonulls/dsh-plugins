# `ecc-finance-billing-ops`

**命令：** `/ecc-finance-billing-ops`

**用途：**基于数据的 ECC 财务流程，涵盖收入、定价、退款、团队账单和实际付费模式核查。适用于汇总销售、比较套餐、诊断重复扣款，或通过代码检查账单，而非提供通用付费建议。

## 提示词

### 1. 简短请求

> /ecc-finance-billing-ops 根据可用数据分析付款差异。

### 2. 带上下文的模板

> /ecc-finance-billing-ops 时间段：[日期]，产品/套餐：[名称]，问题：[收入/退款/重复扣款]。仅使用可用且已确认的信息；不要发起付款或退款。

### 3. 详细请求

> /ecc-finance-billing-ops 对照代码和提供的数据，核实[账单问题]。区分事实与假设，比较金额和时间段，并检查可能的重复项。未经明确同意，不要打开外部系统或执行财务操作。提供计算过程和未知事项。
