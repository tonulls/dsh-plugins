# `/ecc-content-engine`

为各平台创建原生内容体系：帖子、线程、视频脚本、日历，以及适配 X、LinkedIn、TikTok、YouTube 和通讯邮件的原始素材。

## 简单请求

```text
/ecc-content-engine 将我们功能发布公告改写成 LinkedIn 帖子和简短的 X 线程。
```

## 模板请求

```text
/ecc-content-engine
原始材料：[要点/所提供文档的链接]
目标受众：[受众]
目标：[告知/讨论/注册]
平台和格式：[列表]
品牌语气和限制：[描述]
请为每个平台准备符合其格式的不同版本。
```

## 详细请求

```text
/ecc-content-engine 根据[原始材料]为[活动/主题]制定内容体系。受众：[细分群体]，目标：[可衡量结果]，时间段：[日期]，平台：[列表]，品牌语气：[描述/示例]。先提取已确认的核心要点和信息缺口；然后提出内容角度和日历；为每个平台准备原生格式，并制定重新包装原始材料的规则。不要编造事实、指标或评价。不要发布或发送任何内容；未经许可，不要使用外部来源。请提供日历、可用草稿、CTA 以及需要核实的陈述列表。
```
