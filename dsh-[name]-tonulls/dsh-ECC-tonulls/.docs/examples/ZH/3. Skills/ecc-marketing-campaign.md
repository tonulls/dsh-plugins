# `/ecc-marketing-campaign`

**用途：**规划并开展营销活动：受众研究、定位、活动创意、落地页文案、邮件、帖子、广告、短视频脚本和内容计划。适用于协调多渠道产品发布或准备营销材料。

## 简短提示词

```text
/ecc-marketing-campaign 为[产品]在[渠道]上的发布制定活动计划，包括受众、信息和指标。
```

## 模板提示词

```text
/ecc-marketing-campaign
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 规划多渠道产品发布活动。
重点：受众、定位、目标、材料、渠道、日历和可衡量指标。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-marketing-campaign
为 [项目/组件/场景] 执行任务“规划多渠道产品发布活动”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：受众、定位、目标、材料、渠道、日历和可衡量指标。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
