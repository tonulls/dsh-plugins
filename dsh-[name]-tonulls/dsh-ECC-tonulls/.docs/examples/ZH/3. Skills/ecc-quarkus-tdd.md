# `/ecc-quarkus-tdd`

**用途：**Quarkus 3.x LTS 的测试驱动开发实践，采用 JUnit 5、Mockito、REST Assured、Camel 测试和 JaCoCo。适用于为事件驱动服务添加功能、修复缺陷和重构。

## 简短提示词

```text
/ecc-quarkus-tdd 为[Quarkus 场景]制定 test-first 矩阵和 JUnit/REST Assured 示例。
```

## 模板提示词

```text
/ecc-quarkus-tdd
背景：[功能/缺陷、API、项目测试技术栈和行为标准]。
任务：为 [目标组件/结果] 设计 Quarkus 服务的 TDD 验证。
重点：JUnit 5、Mockito、REST Assured、Camel tests、JaCoCo 及更改前后的行为。
限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-quarkus-tdd
为 [目标系统/场景] 执行任务“设计 Quarkus 服务的 TDD 验证”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：JUnit 5、Mockito、REST Assured、Camel tests、JaCoCo 及更改前后的行为。
3. 仅使用项目现有技术栈形成测试集或代码草案；区分建议的检查与实际执行的检查。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
