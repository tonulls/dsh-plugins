# `ecc-golang-testing`

**命令：** `/ecc-golang-testing`

**用途：**Go 测试实践：表驱动测试、子测试、性能基准、模糊测试和覆盖率；以及 TDD 和 Go 惯用写法。适用于编写 Go 测试、性能基准、模糊测试或检查覆盖率。

## 提示词

### 1. 简短请求

> /ecc-golang-testing 为 Go 函数[函数]提出 table-driven 测试。

### 2. 带上下文的模板

> /ecc-golang-testing 包：[名称]，函数：[签名]，预期场景：[列表]。添加子测试并提出适当的 fuzz/benchmark 思路；不要运行代码。

### 3. 详细请求

> /ecc-golang-testing 以 TDD 方式为[包]规划测试：有效/错误输入表、子测试、适用时的 fuzz 和 benchmark，以及边界覆盖。先展示测试代码和命令；未经确认，不要执行命令或编辑文件。
