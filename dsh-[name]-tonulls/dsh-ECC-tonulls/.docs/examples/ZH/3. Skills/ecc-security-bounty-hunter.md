# `/ecc-security-bounty-hunter`

帮助在仓库中寻找可能可利用的漏洞，优先关注可远程触达且适合负责任披露的问题，而不是噪声较大的本地发现。

## 简单请求
```text
/ecc-security-bounty-hunter 对此仓库进行只读分析，寻找严重且可远程触达的漏洞，并说明证据。
```
## 模板请求
```text
/ecc-security-bounty-hunter
仓库范围：[路径/组件]
威胁模型：[可访问接口和边界]
授权模式：仅限静态只读分析
寻找从外部输入到影响结果、且有证据支持的攻击链。不要利用系统、发送请求或修改文件。
```
## 详细请求
```text
/ecc-security-bounty-hunter
仅在授权评估范围内对代码[范围]进行本地只读分析。步骤：识别外部可达入口；追踪数据到敏感操作的路径；检查利用前提和防护屏障；仅对已证实的重大问题排序；为每项准备安全影响说明和可复核的静态代码位置。不要运行 exploit、扫描器、网络请求或针对真实系统的操作；不要提取机密或修改文件。如果核查需要主动测试，暂停并请求明确许可和安全范围。报告：简要结论、附证据及可达条件的发现、误报/未验证假设和限制。
```
