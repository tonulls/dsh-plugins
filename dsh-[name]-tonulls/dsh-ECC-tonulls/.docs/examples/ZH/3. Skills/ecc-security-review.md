# `/ecc-security-review`

使用安全检查清单审查身份验证、用户输入处理、API 构建、机密管理，以及支付或其他敏感功能的实现。

## 简单请求
```text
/ecc-security-review 对此更改进行只读安全审查：[链接/diff]。不要修改文件。
```
## 模板请求
```text
/ecc-security-review
更改/组件：[路径或 diff]
威胁背景：[用户、信任边界]
特别关注：[身份验证/输入/API/支付]
仅进行分析，不作修改：找出已证实的风险并指出代码证据。
```
## 详细请求
```text
/ecc-security-review
以只读方式审计[组件/更改]的安全性。研究信任边界和数据流；根据适用情况检查身份验证/授权、输入验证、机密、API 和敏感操作；追踪每项潜在问题到具体代码，并评估其可达性和影响。不要修改文件、修复发现、运行主动检查、访问网络或输出机密值。每项发现都要注明严重程度、路径/位置、风险场景和安全建议；未证实的疑点应单独标注。最后报告审查范围、限制和修复优先级。
```
