# `/ecc-postgres-patterns`

**用途：**PostgreSQL 实践：查询优化、架构设计、索引和基于 Supabase 建议的安全措施。适用于设计架构、索引和 RLS 策略，或排查缓慢查询。

## 简短提示词

```text
/ecc-postgres-patterns 分析此 PostgreSQL 查询，并提出可验证的优化；不要连接数据库。
```

## 模板提示词

```text
/ecc-postgres-patterns
背景：[SQL/架构/迁移、PostgreSQL 版本、负载示例和匿名化查询计划]。
任务：为 [目标组件/结果] 检查或设计 PostgreSQL 架构、查询、索引或 RLS。
重点：查询计划、索引、数据完整性、访问安全及适用的 Supabase 实践。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-postgres-patterns
为 [目标系统/场景] 执行任务“检查或设计 PostgreSQL 架构、查询、索引或 RLS”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：查询计划、索引、数据完整性、访问安全及适用的 Supabase 实践。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
