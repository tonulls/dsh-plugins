# `/ecc-benchmark`

通过可复现的基线指标测量和比较性能：Core Web Vitals 和页面体积、API 延迟百分位数、构建时间及测试反馈时间。前后结果以 Git 跟踪的 JSON 保存到 `.ecc/benchmarks`。

## 提示词示例

### 1. 简短请求
```text
/ecc-benchmark 为[页面/API/构建]采集可复现的基线，并说明指标和测量条件。不要发布或部署。
```

### 2. 模板请求
```text
/ecc-benchmark 比较[目标]在[更改]前后的性能。环境：[条件]，关键指标：[LCP/INP/CLS/latency/build time]。先检查可用的测量方法；仅当项目已规定该目录和格式时，才将可比较结果保存到 `.ecc/benchmarks`。说明测量限制。
```

### 3. 详细请求
```text
/ecc-benchmark 测量[页面/endpoint/构建]并评估[目标阈值/更改]。1) 记录环境、应用版本、输入数据和方法；不要比较不可比的运行结果。2) 采集适用指标：浏览器端的 LCP、INP、CLS 和页面体积；API 的延迟百分位数；开发流程的构建/测试周期耗时。3) 比较时用相同方式获取基线和更改后数据，并说明噪声和限制。4) 不要部署或执行外部操作。仅按照项目现有结构将 JSON 保存到 `.ecc/benchmarks`。结果包括：条件、测量表、差异及相对于目标的结论。
```
