# `/ecc-energy-procurement`

帮助分析商业设施的电力和天然气采购：费率、峰值功率、供应商 RFP、对冲及可再生能源 PPA/REC。

## 简单请求

```text
/ecc-energy-procurement 比较降低我们仓库峰值功率费用的方案。
```

## 模板请求

```text
/ecc-energy-procurement
设施和地区：[信息]
用量/账单：[不含个人信息的汇总数据]
峰值负荷和时间表：[描述]
费率/合同：[条款]
目标：[降低成本/可再生能源/预算]
请进行初步分析，并指出需要核实的数据。
```

## 详细请求

```text
/ecc-energy-procurement
评估[设施/地区/时间段]的能源供应方案。仅使用提供的用量、费率、峰值和合同条件汇总数据[数据]。如适用，分别分析费率优化和需量费用、固定/指数/block-and-index 方案、供应商 RFP 及 PPA/REC。说明关键假设、价格/负荷敏感性及期限/数量风险；不要将评估表述为保证节省或专业咨询。未经单独确认，不要联系供应商、提交申请或更改合同。结果包括方案比较、所需信息，以及向合格采购/能源专家咨询的问题。
```
