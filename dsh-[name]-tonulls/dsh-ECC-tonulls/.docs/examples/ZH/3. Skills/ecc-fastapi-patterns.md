# `ecc-fastapi-patterns`

**命令：** `/ecc-fastapi-patterns`

**用途：**FastAPI 实践：项目结构、Pydantic v2 架构、依赖注入、异步处理程序、身份验证和授权、事务服务层，以及使用 httpx 和 pytest 的测试。适用于创建或检查 FastAPI 应用、架构、依赖、异步处理程序、身份验证或测试。

## 提示词

### 1. 简短请求

> /ecc-fastapi-patterns 检查此 FastAPI endpoint 的结构。

### 2. 带上下文的模板

> /ecc-fastapi-patterns Endpoint：[路径]，任务：[行为]，架构：[描述]。评估 Pydantic v2、DI、async 和可测试性；提出改进，不要安装软件包。

### 3. 详细请求

> /ecc-fastapi-patterns 研究 FastAPI 中的[路由/模块]。分步检查架构、依赖、异步调用、授权和事务层；随后提出 httpx/pytest 测试。只有在我确认后才修改文件。提供证据链接和计划。
