# `/ecc-benchmark-methodology`

按九项加权维度评估一组确定的竞争者：定位、品牌语气、视觉执行、产品方案包装、证据、企业级准备度、思想领导力、定价和客户痛点。生成评分为 1–5 且有证据依据的竞争者卡片，以及 2×2 痛点图；此步骤位于竞争范围确定之后、报告结构制定之前。

## 提示词示例

### 1. 简短请求
```text
/ecc-benchmark-methodology 按九项标准评估竞争者[列表]。每项评分都提供证据；明确标注数据缺口。
```

### 2. 模板请求
```text
/ecc-benchmark-methodology 为[竞争者/细分市场]制作可比较的卡片。使用定位、品牌语气、视觉执行、产品方案、证据、企业级准备度、思想领导力、定价和客户痛点等标准。来源：[材料]。仅在有依据时使用 1–5 评分；不要靠猜测填补空白。
```

### 3. 详细请求
```text
/ecc-benchmark-methodology 为已选定分析的竞争者集合[列表]准备有证据依据的基准比较。1) 核查比较对象是否为同类公司/产品；如组成可疑，将其列为限制，不要擅自扩充集合。2) 为每个对象收集九项维度的可用证据：定位、品牌语气、视觉工艺、方案包装、证据、企业级准备度、思想领导力、定价和客户痛点。3) 按统一标准给出 1–5 分，每项评分关联具体来源；缺失数据标为未知。4) 绘制 2×2 痛点图并解释坐标轴。格式：竞争者卡片、对比矩阵、图表和方法学限制；本阶段用于评估，不是最终战略报告。
```
