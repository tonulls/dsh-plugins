# `/ecc-cpp-testing`

支持编写和修复 C++ 测试、配置 GoogleTest/CTest、诊断 flaky 测试，以及增加覆盖率或 sanitizer 检查。

## 简单请求

```text
/ecc-cpp-testing 为 C++ 范围解析器添加边界情况测试。
```

## 模板请求

```text
/ecc-cpp-testing
组件：[描述/路径]
测试技术栈：[GoogleTest/CTest/其他]
预期行为：[规则和边界情况]
现有测试：[路径或示例]
先提出测试场景矩阵；商定后只修改必要的测试文件。
```

## 详细请求

```text
/ecc-cpp-testing 需要为使用 [GoogleTest/CTest/配置] 的 C++ 项目覆盖[功能/缺陷]。研究现有约定，为正常、边界及错误输入设计测试；针对缺陷，先创建可复现的回归用例。保持测试确定性，不依赖网络或外部服务；仅在适用时才建议 sanitizer/覆盖率。在修改文件前展示计划；如果需要新依赖或更改构建，请先确认。确认后只修改相关测试/配置文件，并仅运行获准的本地命令。报告：更改位置、场景和检查的实际结果。
```
