# `/ecc-production-audit`

**用途：**仅根据本地证据评估应用的生产就绪情况：发布前、合并后，或回答“生产环境会出现什么问题？”时使用。仓库数据不会发送到外部审计服务。

## 简短提示词

```text
/ecc-production-audit 仅根据本地证据审计[服务]的 production readiness。
```

## 模板提示词

```text
/ecc-production-audit
背景：[服务路径、已更改范围、配置和不含机密的本地日志]。
任务：在发布前或合并后评估本地应用 [目标组件/结果] 的生产就绪情况。
重点：配置和环境、可观测性、迁移、安全、故障模式，以及不向外部审计上传仓库的本地证据。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-production-audit
为 [目标系统/场景] 执行任务“在发布前或合并后评估本地应用的生产就绪情况”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：配置和环境、可观测性、迁移、安全、故障模式，以及不向外部审计上传仓库的本地证据。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
