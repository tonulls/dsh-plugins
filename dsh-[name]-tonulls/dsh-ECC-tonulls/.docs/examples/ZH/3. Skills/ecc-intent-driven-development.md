# `ecc-intent-driven-development`

**命令：** `/ecc-intent-driven-development`

**用途：**在实现之前或过程中，将含糊或影响重大的产品与工程更改转化为明确、可验证的验收标准。适用于澄清功能、定义标准、降低安全/数据/迁移/集成更改的风险、为其他 Agent 准备需求，或检查复杂请求。不适用于小改动、简单修复、主动调试、代码审查，或标准已明确的实现任务，除非明确调用此技能。

## 提示词

### 1. 简短请求

> /ecc-intent-driven-development 帮我把请求转化为可验证的验收标准。

### 2. 带上下文的模板

> /ecc-intent-driven-development 请求：[文本]，用户：[对象]，限制：[列表]。在不实施的情况下，列出问题、范围和标准。

### 3. 详细请求

> /ecc-intent-driven-development 将请求[描述]拆解为可验证的意图。确定用户/结果、范围边界、场景和验收标准；对 security/data/migration/integration 标注风险和未决决策。不要开始实施。返回简短规格说明、问题和可供验证的标准。
