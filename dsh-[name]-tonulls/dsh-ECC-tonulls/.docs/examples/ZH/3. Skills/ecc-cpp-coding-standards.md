# `/ecc-cpp-coding-standards`

帮助依据 C++ Core Guidelines，按照现代、安全且符合惯用法的实践编写、审查和重构 C++。

## 简单请求

```text
/ecc-cpp-coding-standards 检查这段 C++ 代码的内存所有权安全性和惯用性。
```

## 模板请求

```text
/ecc-cpp-coding-standards
语言标准：[C++ 版本]
组件背景：[用途]
代码：[片段或路径]
评估命名、资源所有权、const 正确性、错误处理和可读性；暂时不要编辑文件。
```

## 详细请求

```text
/ecc-cpp-coding-standards
在[组件]背景下，审查[代码片段/文件]，目标 C++ 版本为[版本]。不要修改文件。按顺序检查对象所有权和生命周期、RAII、异常/错误边界、类型和 const 正确性、接口、可读性及与现有风格的一致性。每条意见都要关联具体位置并评估严重程度；没有已证实的必要性时，不要建议大型重构。指出适用的建议、安全的修复方案，以及需要进一步背景才能判断的问题。最后按优先级列出发现并作简短总结，不要声称运行了未经核实的测试。
```
