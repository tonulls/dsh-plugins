# `ecc-frontend-slides`

**命令：** `/ecc-frontend-slides`

**用途：**从头创建富有表现力的动画 HTML 演示文稿，或将 PowerPoint 文件转换为网页格式。适用于准备演示、将 PPT/PPTX 转换为 Web 格式，或为演讲和项目展示创建幻灯片。帮助缺乏设计经验的人通过研究而非随意挑选来确定视觉风格。

## 提示词

### 1. 简短请求

> /ecc-frontend-slides 制定一份关于[主题]的 HTML 演示文稿计划。

### 2. 带上下文的模板

> /ecc-frontend-slides 受众：[对象]，目标：[目的]，时长：[分钟]，源 PPTX：[路径/无]。提出视觉概念和幻灯片结构。

### 3. 详细请求

> /ecc-frontend-slides 为[受众]准备一份关于[主题]的演示文稿。先提出概念和分镜，然后编写每张幻灯片的内容并标注动画重点；如果需要转换 PPTX，请注明假设。未经确认，不要创建或转换文件。请提供计划和缺失材料清单。
