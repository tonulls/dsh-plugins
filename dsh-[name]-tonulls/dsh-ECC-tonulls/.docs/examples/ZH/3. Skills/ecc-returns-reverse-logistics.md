# `/ecc-returns-reverse-logistics`

帮助组织退货流程：退货授权和收件、检查与状态评估、后续处置选择、退款、识别欺诈迹象及保修索赔。

## 简单请求
```text
/ecc-returns-reverse-logistics 为商品退货提出处理流程，包括状态评估和处置选项。
```
## 模板请求
```text
/ecc-returns-reverse-logistics
商品及类别：[描述]
退货原因：[原因]
收货时状态：[事实]
政策/期限：[条款]
帮助选择后续处置并解释决定理由；单独列出未知信息。
```
## 详细请求
```text
/ecc-returns-reverse-logistics
分析退货案例：[商品、原因、日期和脱敏检查事实]。按步骤进行：检查信息是否充分；依据所提供的规则对状态分类；比较处置选项（如适用：重新销售、翻新、降价、报废或退回供应商）；评估经济影响和可能的滥用迹象，但不要作出指控；提出可验证的退款/保修决定。未经单独确认，不要发起退款、报废、联系客户或更改记录。结果：事实、缺失数据、选项、建议和置信度边界。
```
