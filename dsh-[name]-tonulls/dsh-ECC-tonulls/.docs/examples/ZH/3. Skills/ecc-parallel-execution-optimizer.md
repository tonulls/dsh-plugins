# `/ecc-parallel-execution-optimizer`

**用途：**通过将任务拆分为依赖图和并行执行流来加快任务完成速度，提供 lane 矩阵、批量读取和检查、彼此隔离的更改范围（文件、Git worktrees、分支或服务），以及最终验证表。适用于并行工作、多个 Agent、批量工具调用或相互独立的检查，且需确保正确性。

## 简短提示词

```text
/ecc-parallel-execution-optimizer 将[任务]拆分为相互独立的并行阶段，并定义安全的写入边界。
```

## 模板提示词

```text
/ecc-parallel-execution-optimizer
背景：[任务计划、步骤依赖、可能冲突的文件、可用执行者]。
任务：为 [目标组件/结果] 将工作拆分为独立并行阶段，以加快任务执行。
重点：依赖图、lane 矩阵、文件/分支/服务隔离、批量读取和最终验证表。
限制：制定并行 lane 和写入隔离计划；未经同意，不要启动子 Agent 或修改文件。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-parallel-execution-optimizer
为 [目标系统/场景] 执行任务“将工作拆分为独立并行阶段以加快执行”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：依赖图、lane 矩阵、文件/分支/服务隔离、批量读取和最终验证表。
3. 构建依赖图，划分独立 lanes 和写入区域，注明任务间依赖和最终检查；不要开始执行。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：制定并行 lane 和写入隔离计划；未经同意，不要启动子 Agent 或修改文件。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
