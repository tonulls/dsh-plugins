# `/ecc-mybatis-patterns`

**用途：**MyBatis 和 MyBatis-Spring 实践：mapper 设计、XML 和注解中的 SQL、结果映射、动态查询安全、事务、批处理、分页及查询性能。适用于使用 MyBatis、Spring Boot 或遗留 MyBatis 应用开发或检查 Java 数据访问层。

## 简短提示词

```text
/ecc-mybatis-patterns 审查此 MyBatis mapper 及相关 SQL 的安全性、事务和性能。
```

## 模板提示词

```text
/ecc-mybatis-patterns
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 检查 MyBatis 数据访问层。
重点：mapper、SQL/XML/annotations、动态查询安全性、结果映射、事务和分页。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-mybatis-patterns
为 [项目/组件/场景] 执行任务“检查 MyBatis 数据访问层”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：mapper、SQL/XML/annotations、动态查询安全性、结果映射、事务和分页。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
