# `/ecc-codebase-onboarding`

**用途：**研究陌生代码库并创建结构化入门文档：架构图、关键入口点、约定和初始 CLAUDE.md。适用于加入新项目或首次在仓库中配置 Claude Code。

## 简短提示词

```text
/ecc-codebase-onboarding 研究此仓库，并准备一份简洁的入门指南，包含架构图和入口点。
```

## 模板提示词

```text
/ecc-codebase-onboarding
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：帮助新成员熟悉陌生代码库，以实现 [目标或对象]。
重点：架构、entry points、约定、开发命令和经过核实的信息来源。
限制：仅创建或编辑明确指定的结果文件；未经同意，不要添加其他文件。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-codebase-onboarding
为 [项目/组件/场景] 执行任务“帮助新成员熟悉陌生代码库”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：架构、entry points、约定、开发命令和经过核实的信息来源。
3. 按准确指定的格式和位置准备结果；如果未指定路径或许可，请先展示方案并征求写入确认。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅创建或编辑明确指定的结果文件；未经同意，不要添加其他文件。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
