# `/ecc-redis-patterns`

**用途：**Redis 实践：面向生产应用的数据结构、缓存策略、分布式锁、速率限制、pub/sub 消息传递和连接管理。适用于增加这些功能或审查键设计。

## 简短提示词

```text
/ecc-redis-patterns 检查[负载]下的 Redis 键设计和所选数据结构。
```

## 模板提示词

```text
/ecc-redis-patterns
背景：[操作/负载、键设计、TTL、客户端/连接池及观察到的症状]。
任务：为 [目标组件/结果] 检查或设计应用的 Redis 模式。
重点：数据结构、缓存失效、分布式锁、速率限制、pub/sub 和连接管理。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-redis-patterns
为 [目标系统/场景] 执行任务“检查或设计应用的 Redis 模式”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：数据结构、缓存失效、分布式锁、速率限制、pub/sub 和连接管理。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
