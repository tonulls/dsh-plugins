# `/ecc-pytorch-patterns`

**用途：**用于可靠、高效、可复现训练流水线、模型架构和数据加载的 PyTorch 实践与指南。适用于编写或审查训练循环、模型架构和数据加载器，以及排查不可复现的训练运行。

## 简短提示词

```text
/ecc-pytorch-patterns 分析[模型]训练不可复现的原因，并检查 seed、数据和 train loop。
```

## 模板提示词

```text
/ecc-pytorch-patterns
背景：[模型、train loop、环境版本、dataset pipeline 和不可复现的迹象]。
任务：为 [目标组件/结果] 检查 PyTorch 训练流水线或模型。
重点：可复现性、模型架构、数据加载、train/eval loop、指标和实验正确性。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-pytorch-patterns
为 [目标系统/场景] 执行任务“检查 PyTorch 训练流水线或模型”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：可复现性、模型架构、数据加载、train/eval loop、指标和实验正确性。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
