# `/ecc-motion-patterns`

**用途：**可用于发布的 React/Next.js 动画：按钮、模态框、toast、级联效果、页面过渡、退出动画、滚动和布局动画。使用 `motion-foundations` 技能的令牌和弹簧配置。适用于为具体界面元素添加动画。

```text
/ecc-motion-patterns 为 React/Next.js 设计[按钮/模态框/过渡]的无障碍动画。
```
