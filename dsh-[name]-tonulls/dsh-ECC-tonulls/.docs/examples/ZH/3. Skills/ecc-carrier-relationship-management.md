# `/ecc-carrier-relationship-management`

货运承运商组合管理实践：FMCSA 搜索与验证、运价和燃油附加费谈判、RFP 和 routing guide、scorecard、运量分配，以及 truckload、LTL 和 intermodal 业务中的关系续约。

## 简短请求

```text
/ecc-carrier-relationship-management 为我们的 LTL 承运商设计 scorecard 结构，评估准时率、索赔、成本和数据质量。
```

## 模板

```text
/ecc-carrier-relationship-management 协助处理[整车/LTL/intermodal]承运商的[入驻 / RFP / 谈判 / 评估 / 分配 / 续约]。线路/地区：[数据]，运量：[时间段和范围]，服务限制：[条件]。区分已确认数据与假设；不要编造报价或 FMCSA 状态。
```

## 分步请求

```text
/ecc-carrier-relationship-management 为[网络、地区、运输类型]制定[ RFP/组合审查/续约]计划，时间范围为[日期]。目标：[节省成本/可靠性/运力]，限制：[服务、保险、采购政策]。
1. 按线路、运量和 truckload/LTL/intermodal 模式细分需求；列出缺失数据。
2. 对新候选承运商制定核查流程，包括 FMCSA；没有来源和日期时，当前状态应视为未经确认。
3. 制定可比较的 RFP 结构：运价、燃油附加费、accessorials、条件和有效期；不要编造供应商报价。
4. 提出带指标定义和频率的 scorecard（如服务、索赔、成本、偏差）；说明结果如何影响运量分配和 routing guide。
5. 准备谈判重点和续约选项，注明哪些决策需要采购部门批准。

格式：缺少的数据、承运商/标准矩阵、风险和后续步骤计划。未经明确同意，不要签订协议、调整分配或联系承运商。
```
