# `ecc-flutter-dart-code-review`

**命令：** `/ecc-flutter-dart-code-review`

**用途：**与库无关的 Flutter/Dart 代码审查清单：组件实践、状态管理（BLoC、Riverpod、Provider、GetX、MobX、Signals）、Dart 惯用法、性能、无障碍性、安全和整洁架构。适用于审查任何状态管理库下的 Flutter/Dart 代码。

## 提示词

### 1. 简短请求

> /ecc-flutter-dart-code-review 对 Flutter 代码执行只读审查。

### 2. 带上下文的模板

> /ecc-flutter-dart-code-review 文件：[路径]，状态管理：[BLoC/Riverpod/其他]。检查组件、Dart 惯用法、性能、无障碍性和安全性；不要进行更改。

### 3. 详细请求

> /ecc-flutter-dart-code-review 在不编辑文件的情况下审查[更改/PR]。检查组件架构、状态、重绘、无障碍性、安全性和可测试性；只按优先级列出有证据支持的问题，并注明文件/行号、风险和建议。
