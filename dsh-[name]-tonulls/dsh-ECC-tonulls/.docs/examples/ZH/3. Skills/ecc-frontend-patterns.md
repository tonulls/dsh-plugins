# `ecc-frontend-patterns`

**命令：** `/ecc-frontend-patterns`

**用途：**React 和 Next.js 前端开发实践：状态管理、性能和 UI。适用于创建或检查 React/Next.js 组件、状态管理及渲染速度。

## 提示词

### 1. 简短请求

> /ecc-frontend-patterns 提出改进此 React 组件的建议。

### 2. 带上下文的模板

> /ecc-frontend-patterns 组件：[路径]，问题：[状态/渲染/性能]。遵循项目现有模式，不要添加依赖。

### 3. 详细请求

> /ecc-frontend-patterns 在项目背景下研究[组件/页面]。确定状态边界、更新过程和高开销渲染；提出最小改动方案及测试/验证方式。先给计划；未经我同意，不要修改文件。
