# `/ecc-competitive-report-structure`

将已完成评估的竞争者档案汇总为决策报告：市场图谱、层级、比较矩阵、未覆盖市场空间和战略结论。

## 简单请求

```text
/ecc-competitive-report-structure 根据这些竞争者档案，整理一份简短的管理层报告。
```

## 模板请求

```text
/ecc-competitive-report-structure
报告受众：[管理层/董事会]
决策目标：[需要决定什么]
已评分档案：[粘贴数据或注明可用资料]
整理市场图谱、竞争者层级、比较矩阵、市场空白和建议；区分事实与结论。
```

## 详细请求

```text
/ecc-competitive-report-structure
根据提供的已评分档案，为[受众]准备一份有助于决定[问题]的竞争分析报告。1) 检查输入是否完整，并明确列出缺口。2) 按层级整理竞争者并展示市场图谱。3) 将可比指标汇总到矩阵中，不要用猜测填补缺失数据。4) 指出有依据的市场空白及其限制。5) 提出有理由支持的战略选项和团队对齐问题。未经许可，不要从网络收集新数据，也不要修改原始材料。输出摘要、表格、附证据的结论及未知事项清单。
```
