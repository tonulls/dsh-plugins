# `/ecc-dashboard-builder`

帮助围绕运营人员实际问题，在 Grafana、SigNoz 等系统中构建监控面板，而不是只添加装饰性图表。

## 简单请求

```text
/ecc-dashboard-builder 设计一个 Grafana 面板，帮助值班人员快速了解任务队列状态。
```

## 模板请求

```text
/ecc-dashboard-builder
面板用户：[角色]
需要回答的问题：[列表]
可用指标和标签：[列表]
平台：[Grafana/SigNoz/其他]
提出面板、阈值和变量；不要修改运行中的配置。
```

## 详细请求

```text
/ecc-dashboard-builder
为[系统/服务]在[Grafana/SigNoz]上设计运营面板。目标角色：[角色]，决策场景：[事故/日常监控]，可用数据源和指标：[列表]。先将每个运营问题映射到信号，再提出面板、时间范围、变量、分组和阈值，并区分症状与原因。避免虚荣指标和未经证实的 SLO。考虑指标基数规模以及事故期间的可读性。未经明确确认，不要连接数据源、修改仪表板或调用 API。报告包括：布局、面板用途、在数据可用时给出查询/指标、监控缺口和验证标准。
```
