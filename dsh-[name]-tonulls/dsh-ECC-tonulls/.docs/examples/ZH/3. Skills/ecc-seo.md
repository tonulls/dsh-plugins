# `/ecc-seo`

规划并审查搜索可见性改进：技术 SEO、页面优化、结构化数据、Core Web Vitals 和主题关键词地图。

## 简单请求
```text
/ecc-seo 对页面[URL 或文本]进行只读 SEO 审计，并按优先级排列改进建议。
```
## 模板请求
```text
/ecc-seo
网站/页面：[地址或本地文件]
目标和受众：[描述]
地区/语言：[值]
限制：[技术/编辑方面]
提出可验证的改进并解释预期效果；不要发布任何内容。
```
## 详细请求
```text
/ecc-seo
评估[页面/网站]的 SEO，目标为[目标]，受众为[描述]，市场为[地区]。步骤：根据可用数据评估技术可访问性和可索引性；检查结构和页面相关性；依据提供的背景核查 schema/sitemap/robots；有测量数据时评估 Core Web Vitals；建立主题查询地图，不要编造搜索量。区分已确认观察与假设，按优先级列出建议并注明工作量和验证方法。仅审计并提供建议：不要修改文件、DNS、网站元数据或发布内容。未经明确许可，不要扫描外部网站或访问网络。结果包括发现、证据、计划和成功指标。
```
