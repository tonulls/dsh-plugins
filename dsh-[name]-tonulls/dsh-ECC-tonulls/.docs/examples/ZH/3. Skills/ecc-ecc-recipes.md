# `/ecc-ecc-recipes`

根据描述的流程选择合适的 ECC 命令组，提供步骤顺序和停止条件；仅提供建议，不会执行命令。

## 简单请求

```text
/ecc-ecc-recipes 修复回归并验证修复应使用哪些 ECC 命令？
```

## 模板请求

```text
/ecc-ecc-recipes
流程/目标：[需要完成的事项]
项目背景：[任务类型]
限制：[禁止执行的操作]
选择命令组，说明运行顺序和停止条件。只做解释，不执行任何操作。
```

## 详细请求

```text
/ecc-ecc-recipes
将流程[描述]与合适的 ECC command-group recipe 对应起来。明确前置条件和任务类型；提出命令执行顺序，并简述每条命令的用途、依赖项和停止/移交控制点。如果有多个选项，解释取舍及适用范围。这只是参考建议：不要运行命令或执行流程。如果可用目录中没有某条命令/命令系列，请明确指出，不要编造名称。输出推荐顺序、步骤间的转换标准，以及潜在副作用操作所需的确认。
```
