# `/ecc-context-budget`

通过 Codex 或 Claude Code 的内置计数器查看剩余上下文，不扫描文件；只有收到单独请求时才对组件进行静态审计。

## 简单请求

```text
/ecc-context-budget 当前还剩多少上下文？
```

## 模板请求

```text
/ecc-context-budget
模式：[查看当前剩余量 / 明确请求组件静态审计]
环境：[Codex/Claude Code/其他]
如果内置计数器不可用，请说明；未经我的明确请求，不要扫描文件。
```

## 详细请求

```text
/ecc-context-budget
使用 Codex 或 Claude Code 的可用内置计数器检查当前上下文预算。本次检查不要遍历目录、读取源文件或估算文件大小。如果环境没有提供计数器，请说明限制，不要用猜测代替测量。只有在我单独启用审计时：[是/否]，才对所列组件[列表]进行范围受限的静态审查，并说明方法和边界。返回测量值/可用状态、读数时间和来源；如果无法获取，请明确说明原因。
```
