# `ecc-homelab-network-setup`

**命令：** `/ecc-homelab-network-setup`

**用途：**家庭网络和 home lab 的实用规划：网关、交换机、接入点、IP 范围、DHCP 保留、DNS、布线及常见新手错误。适用于规划或配置家庭网络和实验室。

## 提示词

### 1. 简短请求

> /ecc-homelab-network-setup 帮我为[任务]规划家庭网络。

### 2. 带上下文的模板

> /ecc-homelab-network-setup 设备：[gateway/switch/AP]，设备数量/类型：[信息]，IP 范围：[CIDR]。提出 DHCP、DNS 和布线方案；不要更改设置。

### 3. 详细请求

> /ecc-homelab-network-setup 根据[需求]设计家庭网络。明确网关、寻址、DHCP reservations、DNS、Wi-Fi/AP 和布线；检查冲突和常见错误。不要扫描网络或应用配置。提供网络图、检查计划和实施前需确认的问题。
