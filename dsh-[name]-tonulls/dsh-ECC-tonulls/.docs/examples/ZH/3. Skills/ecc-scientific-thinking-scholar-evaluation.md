# `/ecc-scientific-thinking-scholar-evaluation`

依据可重复的评分标准评估科学论文、申请书、综述和方法部分，重点关注证据质量及引文支持情况。

## 简单请求
```text
/ecc-scientific-thinking-scholar-evaluation 评估此研究的方法学，并指出优点和局限：[文本]
```
## 模板请求
```text
/ecc-scientific-thinking-scholar-evaluation
材料：[论文/申请书/章节]
目的和范围：[背景]
标准/评分表：[如有]
评估方法、证据和参考文献是否充分；不要声称材料包含其未提供的信息。
```
## 详细请求
```text
/ecc-scientific-thinking-scholar-evaluation
按结构化标准评估所提供的[科学作品类型]，用于[目的]。1) 简述重构研究问题、主张的结论和设计。2) 按明确的评分标准评估方法学、样本/数据、分析、可复现性和局限性。3) 将每项重要声明与所引证据对照；注明无法根据提供材料核实的引文。4) 将关键问题与改进建议分开。不要修改文档、添加虚构引用，也不要把评估说成专家同行评审。结果包括带理由的评分、优点、优先风险、给作者的问题及评估边界。
```
