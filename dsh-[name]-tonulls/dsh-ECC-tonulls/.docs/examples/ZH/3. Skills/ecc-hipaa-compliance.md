# `ecc-hipaa-compliance`

**命令：** `/ecc-hipaa-compliance`

**用途：**处理与 HIPAA 有关的医疗隐私和安全任务的入口点。适用于明确涉及 HIPAA、PHI 处理、受监管实体、BAA、泄漏准备或美国医疗保健要求的任务。

## 提示词

### 1. 简短请求

> /ecc-hipaa-compliance 为此数据流整理一份 HIPAA 问题清单。

### 2. 带上下文的模板

> /ecc-hipaa-compliance 系统：[描述]，角色：[角色]，PHI 数据：[类别]，司法辖区/背景：美国。这不是法律意见；请标明未知事项。

### 3. 详细请求

> /ecc-hipaa-compliance 在 HIPAA 背景下评估提供的架构：PHI 流、角色/访问权限、audit、BAA 依赖和 breach 准备状况。不要作出法律保证，也不要泄露真实数据；列出应向隐私/安全法律顾问确认的问题，并提出需审批的可验证行动。
