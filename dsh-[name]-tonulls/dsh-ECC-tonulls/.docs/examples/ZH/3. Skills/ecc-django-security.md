# `/ecc-django-security`

执行 Django 安全审查：身份验证和授权、CSRF、SQL 注入、XSS、输入处理及安全部署设置。

## 简单请求

```text
/ecc-django-security 审查 Django view 中的授权和 CSRF 问题；不要修改文件。
```

## 模板请求

```text
/ecc-django-security
路径/片段：[代码]
Django 版本：[版本]
场景和角色：[描述]
信任边界：[数据]
只做静态分析；不要修改文件或运行攻击性测试。
```

## 详细请求

```text
/ecc-django-security
对指定 Django 代码[路径/片段]执行只读审计。不要修改文件、利用漏洞、发起网络请求或更改数据。追踪身份验证和对象级授权、CSRF、用户输入安全处理、ORM/raw SQL、模板输出与 XSS、文件上传及相关生产配置。根据实际数据流和角色进行评估，不要泄露机密。每项意见均注明准确位置、触发条件、影响、严重程度和建议；明确标注不确定事项。最后说明分析覆盖范围、优先发现和供后续验证的安全测试。
```
