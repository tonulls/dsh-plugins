# `/ecc-rust-testing`

帮助编写和诊断 Rust 测试：单元、集成、异步和基于属性的测试，以及按 TDD 方法评估覆盖率。

## 简单请求
```text
/ecc-rust-testing 为此 Rust 函数提出测试，包括边界情况：[代码]
```
## 模板请求
```text
/ecc-rust-testing
待测行为：[描述]
代码/接口：[片段]
当前问题：[错误或覆盖缺口]
环境和使用的测试技术栈：[信息]
制定测试集；没有依据和许可，不要建议新增依赖。
```
## 详细请求
```text
/ecc-rust-testing
需要验证[模块/行为]。先从提供的代码和需求中提取预期契约。然后制定测试：常规情况、边界、错误、异步场景，以及适用时的属性测试。对于缺陷，先展示复现它的测试和确认测试失败的预期方法；最小修复后，再检查测试通过。未经许可，不要修改文件或运行命令；不要安装软件包或访问网络。报告：覆盖的不变量、遗漏的风险、建议的验证命令，以及仅限实际执行的检查结果。
```
