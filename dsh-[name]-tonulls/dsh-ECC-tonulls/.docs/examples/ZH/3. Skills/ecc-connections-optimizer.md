# `/ecc-connections-optimizer`

帮助整理 X 和 LinkedIn 联系人网络：提出取消关注/关注的优先级，并撰写个性化的暖场消息草稿。账户中的更改需另行确认。

## 简单请求

```text
/ecc-connections-optimizer 帮我确定 LinkedIn 人脉中哪些联系人对可持续能源主题最有帮助。
```

## 模板请求

```text
/ecc-connections-optimizer
渠道：[X/LinkedIn]
我当前的目标：[主题或受众]
可用联系人列表：[不含多余个人信息的数据]
我的文风示例：[文本]
提供优先级建议和消息草稿；不要取消关注或发送任何内容。
```

## 详细请求

```text
/ecc-connections-optimizer
帮助我围绕目标[目标]和渠道[X/LinkedIn]调整职业人脉。仅使用我提供或明确允许访问的数据。先定义相关性标准，再根据线索和不确定性对联系人分组；准备保留/移除候选名单，并建议应寻找的新联系人类型。根据示例[示例]，用我的风格撰写几条个性化草稿。不要关注、取消关注、点赞、发消息或执行其他账户操作；任何此类操作前，都必须就具体操作和对象另行征得明确确认。结果包括有依据的建议、存疑案例和未发送的草稿。
```
