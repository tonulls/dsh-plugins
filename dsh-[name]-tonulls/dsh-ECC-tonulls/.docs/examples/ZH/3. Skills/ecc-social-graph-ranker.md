# `/ecc-social-graph-ranker`

对社交关系进行排序，以寻找暖介绍机会，并评估 X 和 LinkedIn 中联系人的中介作用及社交网络缺口。

## 简单请求
```text
/ecc-social-graph-ranker 根据提供的脱敏表格，按[标准]找出最有前景的引荐桥接关系。
```
## 模板请求
```text
/ecc-social-graph-ranker
关系拓展目标：[目标]
图数据：[脱敏节点/边和特征]
标准权重：[值]
为关系排序并解释各因素的作用；不要依据数据之外的信息推断个人情况。
```
## 详细请求
```text
/ecc-social-graph-ranker
根据提供的社交图谱导出数据评估任务[目标]。先澄清数据结构和限制；再为相关性、路径强度和 bridge score 提出透明权重；仅根据提供的信息计算排序；识别覆盖缺口并检查权重敏感性。只使用合法取得的最少必要数据，不要在网络上搜索个人，也不要导出或修改联系人。未经单独确认，不要发送消息、关注或连接。结果：方法和假设、附解释的排序列表、不确定性，以及安全的人工后续步骤建议。
```
