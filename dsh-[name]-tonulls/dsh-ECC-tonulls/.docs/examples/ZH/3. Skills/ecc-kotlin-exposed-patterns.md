# `ecc-kotlin-exposed-patterns`

**命令：** `/ecc-kotlin-exposed-patterns`

**用途：**JetBrains Exposed ORM 实践：DSL 查询、DAO、事务、HikariCP 连接池、Flyway 迁移和 repository 模式。适用于使用 Exposed 的 DSL/DAO 查询、事务、连接池或迁移时。

## 提示词

### 1. 简短请求

> /ecc-kotlin-exposed-patterns 针对场景[场景]优化 Exposed 查询。

### 2. 带上下文的模板

> /ecc-kotlin-exposed-patterns 使用[DSL/DAO]，实体：[描述]，问题：[查询/事务/连接池]。检查 SQL、HikariCP 和迁移；不要运行迁移。

### 3. 详细请求

> /ecc-kotlin-exposed-patterns 研究[模块]中 JetBrains Exposed 的用法。比较 DSL/DAO、事务边界、HikariCP、repository 模式和 Flyway 迁移方案。不要连接数据库或应用迁移。提供具体建议、风险和测试。
