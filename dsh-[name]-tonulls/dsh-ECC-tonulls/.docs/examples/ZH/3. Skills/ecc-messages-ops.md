# `/ecc-messages-ops`

**用途：**基于事实检查消息：阅读对话和私信、帮助查找近期一次性验证码、回复前研究完整线程，并确认核查过哪些消息来源。适用于处理这类消息任务。

## 简短提示词

```text
/ecc-messages-ops 检查此对话并准备回复草稿；不要发送，也不要泄露一次性验证码。
```

## 模板提示词

```text
/ecc-messages-ops
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查所提供的对话，并为 [目标或对象] 准备但不发送回复。
重点：消息的时效性和来源、线程上下文、个人信息和验证代码。
限制：仅处理提供且获准查看的消息；不要发送回复，也不要泄露代码、机密或多余个人信息。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-messages-ops
为 [项目/组件/场景] 执行任务“检查提供的对话并准备但不发送回复”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：消息的时效性和来源、线程上下文、个人信息和验证代码。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅处理提供且获准查看的消息；不要发送回复，也不要泄露代码、机密或多余个人信息。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
