# `ecc-java-coding-standards`

**命令：** `/ecc-java-coding-standards`

**用途：**Spring Boot 和 Quarkus 服务的 Java 标准：命名、不可变性、Optional、Stream API、异常、泛型、CDI、响应式模式和项目结构。自动考虑框架约定。适用于编写或检查 Spring Boot 或 Quarkus Java 服务。

## 提示词

### 1. 简短请求

> /ecc-java-coding-standards 检查 Java 代码是否符合 Spring Boot 约定。

### 2. 带上下文的模板

> /ecc-java-coding-standards 文件：[路径]，框架：[Spring Boot/Quarkus]。检查命名、不可变性、Optional、streams、异常和 CDI/reactive 模式；不要修改。

### 3. 详细请求

> /ecc-java-coding-standards 对[类/更改]进行只读审查。检查 Java 风格、generics、Optional、异常、DI 和框架专属结构。对每项已确认的问题注明位置、影响和修复方案；不要修改文件或添加依赖。
