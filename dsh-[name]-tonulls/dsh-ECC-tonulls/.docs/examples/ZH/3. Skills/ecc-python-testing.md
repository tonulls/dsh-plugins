# `/ecc-python-testing`

**用途：**使用 pytest 和 TDD 的 Python 测试实践：fixtures、mock、参数化和覆盖率要求。适用于编写 pytest 测试、使用 fixtures/mock/参数化或评估覆盖率。

## 简短提示词

```text
/ecc-python-testing 为[函数]提出 pytest 测试：fixtures、参数、错误和边界输入。
```

## 模板提示词

```text
/ecc-python-testing
背景：[函数、预期行为、错误/边界输入和现有测试]。
任务：为 [目标组件/结果] 设计 Python 代码的 pytest 测试。
重点：TDD、适当的 fixtures/mocks/parametrize、重要边界和实际覆盖率。
限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-python-testing
为 [目标系统/场景] 执行任务“为 Python 代码设计 pytest 测试”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：TDD、适当的 fixtures/mocks/parametrize、重要边界和实际覆盖率。
3. 仅使用项目现有技术栈形成测试集或代码草案；区分建议的检查与实际执行的检查。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
