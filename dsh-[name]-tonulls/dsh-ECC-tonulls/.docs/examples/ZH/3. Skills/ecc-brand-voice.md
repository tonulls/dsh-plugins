# `/ecc-brand-voice`

根据真实文本样本（帖子、文章、发布说明、文档或网站）提炼风格档案，并应用于内容、邮件和社交媒体，避免常见的“AI 腔”。

## 简短请求

```text
/ecc-brand-voice 从所附帖子中提炼风格，并重写发布公告，使其符合该语气，而不是通用 AI 文案。
```

## 模板

```text
/ecc-brand-voice 使用以下风格来源：[文本/文件]。根据可观察特征构建档案——词汇、节奏、语气、结构、典型手法和应避免的表达。然后将[材料]改写为适合[渠道和受众]的版本。如果示例中的事实与新材料无关，不要照搬。
```

## 分步请求

```text
/ecc-brand-voice 根据[真实文本清单]创建可复用的[作者/品牌]语气档案。需要为[受众、渠道、目标]准备[邮件/帖子/页面]。
1. 检查样本是否充足且多样；注明其体裁和可能的语气差异。
2. 提炼风格档案，并用实例说明可观察特征：句子长度、词汇、正式程度、节奏、幽默、结构和直接程度。区分已确认内容与假设。
3. 记录应避免的陈词滥调和不受欢迎的风格特征。不要超出所提供的来源模仿个人身份。
4. 为指定渠道准备材料，保留原始事实和长度要求[限制]。
5. 简要说明内容如何符合档案，并列出数据不足之处。

格式：风格档案、成稿、简短自检。不要编造事实，也不要未经单独同意发布或发送文本。
```
