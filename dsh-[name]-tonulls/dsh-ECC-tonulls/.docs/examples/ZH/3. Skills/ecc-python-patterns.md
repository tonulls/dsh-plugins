# `/ecc-python-patterns`

**用途：**Python 惯用法、PEP 8 标准、类型注解，以及可靠、高效、易维护应用的开发实践。适用于编写或检查 Python 代码，尤其关注惯用结构、类型或 PEP 8 时。

## 简短提示词

```text
/ecc-python-patterns 检查此 Python 模块的类型、惯用写法和项目风格一致性。
```

## 模板提示词

```text
/ecc-python-patterns
背景：[Python 文件路径、版本、用途和项目约定]。
任务：为 [目标组件/结果] 检查或设计 Python 代码。
重点：PEP 8、类型提示、Python 惯用法、可读性和稳健性；不要强加未使用的抽象。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-python-patterns
为 [目标系统/场景] 执行任务“检查或设计 Python 代码”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：PEP 8、类型提示、Python 惯用法、可读性和稳健性；不要强加未使用的抽象。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
