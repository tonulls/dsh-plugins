# `/ecc-network-config-validation`

**用途：**在部署前预检路由器和交换机配置：危险命令、重复地址、子网重叠、过时引用、管理平面风险及 IOS 风格的安全要求。适用于部署网络配置之前。

## 简短提示词

```text
/ecc-network-config-validation 检查此路由器配置片段中的危险命令、地址冲突和管理风险；不要应用配置。
```

## 模板提示词

```text
/ecc-network-config-validation
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：在 [目标或对象] 更改前检查路由器或交换机配置。
重点：危险命令、重复 IP、子网重叠、过时引用、管理平面和 IOS 安全。
限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-network-config-validation
为 [项目/组件/场景] 执行任务“在更改前检查路由器或交换机配置”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：危险命令、重复 IP、子网重叠、过时引用、管理平面和 IOS 安全。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
