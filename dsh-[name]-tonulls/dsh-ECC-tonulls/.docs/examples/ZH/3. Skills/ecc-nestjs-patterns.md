# `/ecc-nestjs-patterns`

**用途：**NestJS 架构实践：模块、控制器、providers、DTO 验证、guards、interceptors、配置以及生产级 TypeScript 服务端应用。适用于开发或审查 NestJS 后端。

## 简短提示词

```text
/ecc-nestjs-patterns 审查 NestJS 模块[路径]，重点关注 DTO 验证、guards 和模块边界。
```

## 模板提示词

```text
/ecc-nestjs-patterns
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 NestJS 服务端模块架构。
重点：modules/controllers/providers、DTO 验证、guards、interceptors、配置及服务端边界。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-nestjs-patterns
为 [项目/组件/场景] 执行任务“检查 NestJS 服务端模块架构”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：modules/controllers/providers、DTO 验证、guards、interceptors、配置及服务端边界。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
