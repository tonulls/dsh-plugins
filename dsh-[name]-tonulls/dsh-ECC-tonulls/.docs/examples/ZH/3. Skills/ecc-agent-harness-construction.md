# `/ecc-agent-harness-construction`

设计并改进 Agent 的动作空间：工具集合、工具定义和观察格式，以提高任务成功完成率。

## 提示词示例

### 1. 简短请求
```text
/ecc-agent-harness-construction 分析 Agent 可用的工具，并提出如何精简工具集、让调用结果更易理解。只做分析，不修改代码。
```

### 2. 模板请求
```text
/ecc-agent-harness-construction 评估用于任务[类型]的 Agent harness。研究[工具和观察格式的描述/配置文件]。找出冗余或缺失的动作、含糊的工具定义以及观察信息中的噪声。提出具体更改及预期效果；不要进行任何更改。
```

### 3. 详细请求
```text
/ecc-agent-harness-construction 重新审视仓库或文件 [仓库或文件] 中场景[场景]的 Agent 动作空间。1) 根据源文件记录当前工具、输入/输出和观察格式。2) 查找重复、动作缺口以及妨碍工具选择的歧义。3) 提出最小更改，说明其对任务完成率的影响和风险。4) 不要修改文件，也不要在没有测量的情况下声称有所改进。结果包括：当前方案、附证据的优先问题、目标方案，以及后续评估可验证的假设。
```
