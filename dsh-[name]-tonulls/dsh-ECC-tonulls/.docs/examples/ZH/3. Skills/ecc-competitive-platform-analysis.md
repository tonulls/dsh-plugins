# `/ecc-competitive-platform-analysis`

界定竞争格局范围：确定哪些产品算竞争对手、归属哪个层级，以及应研究哪些来源。这是比较评估前的范围界定阶段。

## 简单请求

```text
/ecc-competitive-platform-analysis 为面向小型分布式团队的任务管理服务确定主要竞争对手。
```

## 模板请求

```text
/ecc-competitive-platform-analysis
产品：[描述和类别]
目标客户：[细分市场和地域]
市场：[范围]
已知替代方案：[列表]
制定纳入标准、分层方法和建议的信息来源。不要把未经证实的假设说成事实。
```

## 详细请求

```text
/ecc-competitive-platform-analysis
为[产品]在[地域/类别]市场界定竞争格局。先明确竞争对手的定义和筛选标准；随后将候选者划分为直接竞争者、相邻竞争者和替代方案，注明各自依据并提出后续研究的信息来源。将缺口和有争议的纳入项单独标注。不要进入评分或战略建议阶段：那是下一步。仅使用可用材料；未经许可不要进行网络搜索。结果包括：样本范围、含层级和理由的候选者表，以及待核实的信息来源/问题列表。
```
