# `/ecc-backend-patterns`

适用于 Node.js、Express 和 Next.js 路由的服务端架构、API、数据访问及数据库优化实践。用于开发或分析这些服务端组件。

## 提示词示例

### 1. 简短请求
```text
/ecc-backend-patterns 根据我们的技术栈，检查处理程序[路径/端点]中的常见后端问题。只做分析。
```

### 2. 模板请求
```text
/ecc-backend-patterns 帮我在[Node.js/Express/Next.js]中实现[服务端功能]。数据背景：[模型/存储]，限制：[列表]。先遵循仓库现有结构和约定；仅允许在[范围]内更改。
```

### 3. 详细请求
```text
/ecc-backend-patterns 分析使用[Node.js、Express 或 Next.js]的项目中[路由/数据访问层]。1) 研究相邻实现，确定实际技术栈和任务边界。2) 检查路由与业务逻辑分离、输入验证、错误处理、数据库查询和潜在性能问题。3) 对每项结论提供证据，并区分缺陷与建议。4) 如果要求实现，只修改完成[任务]所必需的文件，不做无关重构、不安装软件包或执行网络操作；否则保持代码不变。格式：按严重程度列出发现，然后给出有限计划或 diff 总结。
```
