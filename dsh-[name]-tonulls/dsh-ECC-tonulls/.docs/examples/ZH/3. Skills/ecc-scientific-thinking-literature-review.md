# `/ecc-scientific-thinking-literature-review`

帮助开展系统化科学和技术文献综述：制定检索计划、筛选来源、综合结果、核对引文并维护证据日志。

## 简单请求
```text
/ecc-scientific-thinking-literature-review 为[主题]制定文献综述计划和筛选标准。
```
## 模板请求
```text
/ecc-scientific-thinking-literature-review
研究问题：[问题]
领域/日期/语言：[范围]
出版物类型：[标准]
提出检索、筛选和综合策略；区分计划与实际找到的来源。
```
## 详细请求
```text
/ecc-scientific-thinking-literature-review
为问题[问题]准备可复现的综述。步骤：1) 界定范围、定义和纳入/排除标准；2) 针对适用数据库形成检索式，并制定检索记录计划；3) 描述去重以及标题/摘要/全文筛选；4) 确定数据提取字段和证据质量评估方法；5) 提出综合方法和引文核验流程。不要编造来源或结果，也不要把计划说成已完成的检索。仅在获准时使用网络；不要以综述代替医疗决策。结果包括方案、证据表、限制，以及实际核查过的链接/标识符；若未执行检索则明确说明。
```
