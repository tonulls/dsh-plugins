# `ecc-laravel-security`

**命令：** `/ecc-laravel-security`

**用途：**审查 Laravel 身份验证和授权安全、Eloquent 安全操作、CSRF 和 XSS 防护、API 安全及部署设置。

## 提示词

### 1. 简短请求

> /ecc-laravel-security 对此 Laravel 路由执行只读检查，查找授权和不安全输入处理问题。仅展示已确认的风险。

### 2. 带占位符的模板

> /ecc-laravel-security 检查 Laravel 应用的[路由/控制器/模型]，用于场景[场景]。考虑[输入类型、角色、guard/API]。检查适用范围内的访问策略、批量赋值和 Eloquent 查询、CSRF/XSS 及配置。不要修复问题。结果包括发现、证据（文件和行号）、影响、优先级和安全建议；明确标注未知事项。

### 3. 详细分步请求

> /ecc-laravel-security 仅分析 Laravel 组件[路径或功能]的安全性。1) 追踪输入数据从路由到模型及响应的流向。2) 将身份验证与授权分开检查，包括策略和对其他用户对象的访问边界。3) 评估 Eloquent 对不安全赋值/注入的防护、用户数据输出的 XSS、浏览器操作的 CSRF 和 API 专属机制。4) 查看相关的安全环境设置；无证据时不要推断生产环境状态。输出“风险 / 证据 / 影响场景 / 修复”表格，并列出检查缺口。不要修改文件、运行攻击性测试、安装软件或访问网络。
