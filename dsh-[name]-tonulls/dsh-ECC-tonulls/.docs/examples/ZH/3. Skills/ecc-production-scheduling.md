# `/ecc-production-scheduling`

**用途：**离散和批量生产的生产排程、作业排序、生产线平衡、换型优化及瓶颈消除实践，基于 15 年以上经验的生产计划人员知识。涵盖 TOC/drum-buffer-rope、SMED、OEE 分析、故障响应以及与 ERP/MES 的集成。适用于制定生产计划和解决生产问题。

## 简短提示词

```text
/ecc-production-scheduling 为[生产线/订单]制定班次排程，指出瓶颈和换型。
```

## 模板提示词

```text
/ecc-production-scheduling
背景：[订单、生产线产能、期限、班次、换型和生产限制]。
任务：为 [目标组件/结果] 优化生产排程和生产线平衡。
重点：作业排序、产能/班次限制、SMED 换型、OEE/瓶颈、故障及对 ERP/MES 的影响。
限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-production-scheduling
为 [目标系统/场景] 执行任务“优化生产排程和生产线平衡”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：作业排序、产能/班次限制、SMED 换型、OEE/瓶颈、故障及对 ERP/MES 的影响。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
