# `/ecc-mle-workflow`

**用途：**ML 系统开发和运营流程：数据契约、可复现训练、模型评估、部署、监控和回滚。适用于构建、审查或加固超出一次性 notebook 范围的 ML 系统。

## 简短提示词

```text
/ecc-mle-workflow 为[模型类型]设计从数据和训练到评估及监控的可复现 workflow。
```

## 模板提示词

```text
/ecc-mle-workflow
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 设计可复现的 ML 系统开发和运营周期。
重点：数据契约、可复现训练、评估、部署计划、监控和回滚。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-mle-workflow
为 [项目/组件/场景] 执行任务“设计可复现的 ML 系统开发和运营周期”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：数据契约、可复现训练、评估、部署计划、监控和回滚。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
