# `/ecc-logistics-exception-management`

**用途：**货运异常处理实践：延误、货损、丢失、短缺及承运商争议。涵盖升级处理、承运商和运输方式差异、索赔，以及选择赔偿或申诉。适用于解决配送问题、索赔和承运商争议。

## 简短提示词

```text
/ecc-logistics-exception-management 为货物延误和损坏制定处理计划，注明所需证据、升级路径和下一个时限。
```

## 模板提示词

```text
/ecc-logistics-exception-management
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 制定货运异常解决计划。
重点：延误/货损/丢失、证据、升级处理、承运商 SLA 和索赔方案。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-logistics-exception-management
为 [项目/组件/场景] 执行任务“制定货运异常解决计划”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：延误/货损/丢失、证据、升级处理、承运商 SLA 和索赔方案。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
