# `/ecc-make-interfaces-feel-better`

**用途：**运用具体的设计工程技巧改善界面：间距、字体、边框、阴影、动画、点击区域、图标、换行和交互状态。适用于审查或改进用户界面。

## 简短提示词

```text
/ecc-make-interfaces-feel-better 评估此屏幕，并提出若干具体方法以改善视觉和交互清晰度。
```

## 模板提示词

```text
/ecc-make-interfaces-feel-better
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：改善 [目标或对象] 的界面视觉和交互质量。
重点：间距、字体、边框、阴影、动画、点击目标、图标和状态。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-make-interfaces-feel-better
为 [项目/组件/场景] 执行任务“改善界面视觉和交互质量”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：间距、字体、边框、阴影、动画、点击目标、图标和状态。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
