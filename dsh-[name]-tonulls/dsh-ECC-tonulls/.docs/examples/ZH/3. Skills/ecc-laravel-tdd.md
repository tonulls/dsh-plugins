# `ecc-laravel-tdd`

**命令：** `/ecc-laravel-tdd`

**用途：**使用 PHPUnit 或 Pest 开发和修复 Laravel 测试：模型工厂、HTTP 测试、Sanctum 身份验证检查、mock 和覆盖率；也可通过测试推动功能开发。

## 提示词

### 1. 简短请求

> /ecc-laravel-tdd 为此 Laravel HTTP endpoint 编写 Pest 测试，检查成功响应和权限不足时的拒绝，并使用项目现有工厂。

### 2. 带占位符的模板

> /ecc-laravel-tdd 为[功能/endpoint]添加[成功场景、错误、权限]测试。项目使用[PHPUnit/Pest]，工厂为[模型]，身份验证为[Sanctum/其他]。先研究现有约定和测试辅助工具。只修改[路径列表]中的测试文件；未经单独同意，不要安装依赖或更改生产代码。

### 3. 详细分步请求

> /ecc-laravel-tdd 针对 Laravel 中的[描述]进行测试优先开发。1) 找到类似测试、PHPUnit/Pest 配置和工厂；明确可测试行为的边界。2) 制定用例矩阵：有效请求、验证错误、缺少/不足授权、副作用和边界数据。3) 添加最小化且隔离的测试；在测试 endpoint 时优先使用工厂和 HTTP 层；mock 仅用于外部边界。4) 提供验证命令，但非必要/未获同意时不要运行。最后列出修改的文件、覆盖的预期行为和未检查场景。不要修改应用代码、安装软件包或访问网络。
