# `/ecc-customs-trade-compliance`

帮助分析指定司法辖区的海关分类、单证、Incoterms 2020、优惠待遇和关税、制裁限制及海关问询。

## 简单请求

```text
/ecc-customs-trade-compliance 将工业传感器进口到欧盟进行初步关税分类，需要哪些信息？
```

## 模板请求

```text
/ecc-customs-trade-compliance
商品及用途：[规格]
原产国/出口国：[国家]
进口国：[国家]
路线和 Incoterm：[信息]
单证/限制：[已知情况]
请进行初步分析，指出缺失信息以及是否需要官方确认。
```

## 详细请求

```text
/ecc-customs-trade-compliance
分析将商品[技术描述、材料、功能]从[国家]运往[国家/地区]的货运，条件为[Incoterm 2020]，拟采用的海关制度为[描述]。请分步：列出事实和缺失规格；依据适用规则解释可能的分类方法和替代方案；检查所需商业/进口单证及原产地信息；仅依据提供的信息指出潜在限制和 denied-party screening 问题。不要给出最终法律结论，也不要提交报关、付款或问询；未经许可，不要使用网络来源。输出初步评估、置信度、证据、风险，以及需要向海关专家核实的事项。
```
