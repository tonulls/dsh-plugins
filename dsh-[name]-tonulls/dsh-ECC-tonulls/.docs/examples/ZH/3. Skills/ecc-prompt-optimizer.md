# `/ecc-prompt-optimizer`

**用途：**分析提示词草稿、识别目标和缺失背景、选择 ECC 命令/技能/Agent，并给出可直接粘贴的优化版提示词及分析说明。只提供建议，不执行任务。适用于“优化提示词”“改进指令”“重写请求”“帮我写提示词”或“怎样更好地表达请求”等要求。不要用于代码或性能优化。

## 简短提示词

```text
/ecc-prompt-optimizer 重写此提示词草稿：[文本]。先指出缺失背景和合适的 ECC 命令；不要执行任务。
```

## 模板提示词

```text
/ecc-prompt-optimizer
背景：[原始提示词、期望结果、上下文和明确限制]。
任务：改进提示词草稿，为 [目标组件/结果] 准备可直接粘贴的表述。
重点：用户意图、缺失背景、所需限制、ECC command/skill/agent 的选择及简要理由。
限制：仅处理提示词措辞；不要执行原始任务，也不要调用所选 ECC 命令。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-prompt-optimizer
为 [目标系统/场景] 执行任务“改进提示词草稿并准备可直接粘贴的表述”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：用户意图、缺失背景、所需限制、ECC command/skill/agent 的选择及简要理由。
3. 给出改进后的可直接粘贴表述，列出选择的 ECC 命令/技能/角色并解释原因；不要执行原始任务。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅处理提示词措辞；不要执行原始任务，也不要调用所选 ECC 命令。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
