# `/ecc-customer-billing-ops`

帮助处理客户账单流程——订阅、退款、流失、billing portal 访问和套餐——如有可用的已连接账单工具，则可使用这些工具。

## 简单请求

```text
/ecc-customer-billing-ops 帮我查明客户为何看到本月有两笔扣款。
```

## 模板请求

```text
/ecc-customer-billing-ops
客户请求：[不含多余个人信息的文本]
工单标识符：[不含机密]
已知订阅/账单事实：[数据]
需要：[检查状态 / 准备回复 / 评估方案]
先只查看和解释；未经我确认，不要退款、改套餐或取消订阅。
```

## 详细请求

```text
/ecc-customer-billing-ops
分析客户提出的[简述]，主题是[订阅/退款/重复扣款/门户]。仅使用已获准连接的工具和最低限度必要数据；不要索取银行卡信息、密码或令牌。先核查可用事实并区分已确认信息与假设；随后对照账单规则并准备客户回复。任何涉及资金或状态变更的操作（退款、取消、改套餐、给客户发邮件）都必须在获得单独确认后才能执行，确认内容需明确具体对象及金额/文本。若没有已连接的工具或许可，不要访问网络或外部服务。结果包括：已确认事实、疑点、建议的安全下一步和回复草稿。
```
