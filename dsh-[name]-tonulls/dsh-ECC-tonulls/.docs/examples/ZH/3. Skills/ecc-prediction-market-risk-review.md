# `/ecc-prediction-market-risk-review`

**用途：**审查预测市场场景、组合、预言机和交易 Agent 的合规、安全、数据质量、隐私和执行风险。适用于场景获得平台授权、组合数据、API key 或交易规划访问权限之前。

## 简短提示词

```text
/ecc-prediction-market-risk-review 对预测市场 workflow 的数据、执行和隐私风险进行只读审查。
```

## 模板提示词

```text
/ecc-prediction-market-risk-review
背景：[workflow 架构、数据类型、权限和提供的配置]。
任务：检查 [目标组件/结果] 中预测市场、oracle 或交易 Agent 的风险。
重点：合规背景、数据质量、隐私、venue auth/API keys，以及规划/执行边界。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-prediction-market-risk-review
为 [目标系统/场景] 执行任务“检查预测市场 workflow、oracle 或交易 Agent 的风险”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：合规背景、数据质量、隐私、venue auth/API keys，以及规划/执行边界。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
