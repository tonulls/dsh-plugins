# `/ecc-prisma-patterns`

**用途：**TypeScript 后端的 Prisma ORM 实践：架构设计、查询优化、事务和分页；重要陷阱包括 `updateMany` 返回计数而非记录、`$transaction` 超时、`migrate dev` 重置数据库、批量写入时跳过 `@updatedAt`，以及 serverless 连接耗尽。适用于处理 Prisma 架构和查询、事务、迁移及连接限制。

## 简短提示词

```text
/ecc-prisma-patterns 分析 Prisma 查询[片段]，检查事务、分页和 N+1 风险。
```

## 模板提示词

```text
/ecc-prisma-patterns
背景：[Prisma 模型、查询/仓库、数据库、版本及观察到的症状]。
任务：为 [目标组件/结果] 检查 Prisma 架构、查询或后端事务流程。
重点：事务超时、updateMany、迁移行为、serverless 连接限制和实际数据模型。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-prisma-patterns
为 [目标系统/场景] 执行任务“检查 Prisma 架构、查询或后端事务流程”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：事务超时、updateMany、迁移行为、serverless 连接限制和实际数据模型。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
