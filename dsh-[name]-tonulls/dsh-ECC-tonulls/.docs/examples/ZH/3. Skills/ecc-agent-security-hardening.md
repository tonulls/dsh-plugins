# `/ecc-agent-security-hardening`

为处理不可信内容、调用工具、写入文件、管理运行时标识或使用凭据的 Agent 系统提供加固建议。不用于一般 Web 应用安全或攻击性测试。

## 提示词示例

### 1. 简短请求
```text
/ecc-agent-security-hardening 防御性分析此 Agent runtime 的信任边界和工具权限。仅基于已确认的信息给出结论，不做更改或攻击性测试。
```

### 2. 模板请求
```text
/ecc-agent-security-hardening 检查 [Agent runtime/tool gateway/记忆服务]，位置为[路径/描述]。考虑不可信输入、工具调用、workspace 写入、runtime 标识和凭据。只对源文件和配置进行防御性审查；不要运行漏洞利用或修改文件。提供有证据支持的风险和缓解措施。
```

### 3. 详细请求
```text
/ecc-agent-security-hardening 对 [Agent 组件] 进行范围受限的安全分析。1) 根据源文件追踪不可信内容到模型、工具、文件系统和记忆服务的路径。2) 仅在组件相关机制范围内检查权限边界、参数验证、租户隔离、runtime 标识处理和机密保护。3) 不要用攻击性提示测试系统，不要访问外部系统或修改代码。4) 对每项结论注明位置和证据、影响场景、严重程度及具体防护建议；将未知事项标记为未验证。不要将结论泛化到普通 Web 应用安全。
```
