# `/ecc-perl-security`

**用途：**全面 Perl 安全实践：taint mode、输入验证、安全执行进程、参数化 DBI 查询、Web 安全（XSS/SQLi/CSRF）及 perlcritic 安全策略。适用于审查输入处理、进程执行、DBI 查询和 Web 代码。

## 简短提示词

```text
/ecc-perl-security 对 Perl 代码执行只读审计，检查危险输入、进程调用和 SQL。
```

## 模板提示词

```text
/ecc-perl-security
背景：[Perl 代码路径、入口、数据来源和信任边界]。
任务：为 [目标组件/结果] 检查 Perl 代码安全性和不可信数据处理路径。
重点：taint mode、输入验证、安全进程执行、参数化 DBI 查询及适用的 XSS/SQLi/CSRF 风险。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-perl-security
为 [目标系统/场景] 执行任务“检查 Perl 代码和不可信数据处理路径的安全性”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：taint mode、输入验证、安全进程执行、参数化 DBI 查询及适用的 XSS/SQLi/CSRF 风险。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
