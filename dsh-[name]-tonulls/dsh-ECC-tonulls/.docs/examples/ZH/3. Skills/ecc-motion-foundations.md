# `/ecc-motion-foundations`

**用途：**面向 React/Next.js motion/react 的动画令牌、弹簧预设、性能规则、设备适配、无障碍要求和 SSR 安全实践。是其他 motion 技能的基础层。适用于配置动画、reduced motion 或 SSR 安全动画。

## 简短提示词

```text
/ecc-motion-foundations 为 React/Next.js 应用制定基础动画令牌和规则，支持 reduced motion 和 SSR。
```
