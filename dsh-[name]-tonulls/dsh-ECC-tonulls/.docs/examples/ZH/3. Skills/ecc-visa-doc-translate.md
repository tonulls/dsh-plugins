# `/ecc-visa-doc-translate`

帮助识别签证材料图片（银行、工作、收入和养老金证明），并准备英文翻译及原文与译文对照的双语 PDF。

## 简单请求
```text
/ecc-visa-doc-translate 将此证明翻译成英文，并标出无法辨认的部分：[图片]
```
## 模板请求
```text
/ecc-visa-doc-translate
文件类型：[证明]
原文语言：[语言]
用途：签证文件材料包[国家/背景]
输入图片：[路径]
翻译可见文本并保留结构，明确标记存疑片段。不要声称翻译已认证或公证。
```
## 详细请求
```text
/ecc-visa-doc-translate
处理所提供的[证明类型]图片，准备双语材料。先说明你是否能读取图片格式/质量；然后识别文本，保留姓名、日期、金额和结构，不要猜测；翻译成英文，单独标出无法辨认/有歧义的片段，并要求人工复核关键字段。如果有相应功能，生成包含原件和格式化译文的 PDF；不要声称译文已官方认证。未经单独同意，不要将文件上传到网络或保存/发送副本。保护个人和财务信息。结果包括识别后的译文、疑点列表及 PDF 状态（已创建/不可用）。
```
