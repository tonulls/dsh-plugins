# `/ecc-orch-refine-code`

**用途：**协调不改变行为的重构：确认测试通过，在保持行为和检查通过的前提下重组代码，进行代码审查，并仅在用户确认后创建提交。适用于改善代码结构但不改变行为的场景。

## 简短提示词

```text
/ecc-orch-refine-code 为[模块]制定重构计划，保持行为不变且不提交。
```

## 模板提示词

```text
/ecc-orch-refine-code
背景：[模块、当前结构、目标结构、已有测试]。
任务：为[目标组件/结果]规划行为等价重构。
重点：先确保测试通过；重构结构但不改变行为；每步后验证；提交需单独同意。
限制：先准备计划和行为保持标准；未经单独同意，不要修改代码或创建提交。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-orch-refine-code
为 [目标系统/场景] 执行任务“规划行为等价的重构”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：测试先通过、结构调整不改变行为、每一步后进行验证，以及提交需另行同意。
3. 编写分阶段重构计划，并为每阶段制定前后行为验证；不要修改代码。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：先准备计划和行为保持标准；未经单独同意，不要修改代码或创建提交。
按以下格式整理结果：[预期格式]。不要编造事实；若需执行未预期的副作用操作，请暂停并征求同意。
```
