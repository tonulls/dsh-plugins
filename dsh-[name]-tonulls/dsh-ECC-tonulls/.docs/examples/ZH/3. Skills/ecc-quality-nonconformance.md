# `/ecc-quality-nonconformance`

**用途：**受监管制造业的质量控制和不符合项管理（FDA 21 CFR 820、IATF 16949、AS9100）：NCR 流程及处置决策、5 Why/Ishikawa/fault tree/8D 根因分析、CAPA、SPC 解读、AQL 抽样和供应商质量审计。适用于调查不符合项、根因分析、CAPA、SPC 和供应商质量问题。

## 简短提示词

```text
/ecc-quality-nonconformance 分析不符合项[描述]，并准备附证据的 root-cause/CAPA 计划。
```

## 模板提示词

```text
/ecc-quality-nonconformance
背景：[不含敏感信息的 NCR 编号或描述、流程、质量标准和现有测量数据]。
任务：为 [目标组件/结果] 调查制造不符合项并准备 CAPA。
重点：NCR 生命周期/处置、5 Why/Ishikawa/8D、SPC/AQL 和供应商质量；不要作出法律保证。
限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-quality-nonconformance
为 [目标系统/场景] 执行任务“调查制造不符合项并准备 CAPA”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：NCR 生命周期/处置、5 Why/Ishikawa/8D、SPC/AQL 和供应商质量；不要作出法律保证。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
