# `/ecc-ai-first-engineering`

**用途：**为由 AI Agent 编写大量代码的团队设计工程工作模式。适用于配置团队流程、代码审查阶段，以及 Agent 主导代码库的责任规则。

## 简短提示词

```text
/ecc-ai-first-engineering 为由 Agent 编写大量代码的团队，提出工程流程和审查规则。
```

## 模板提示词

```text
/ecc-ai-first-engineering
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为主要由 Agent 编写代码的团队配置工程流程，以实现 [目标或对象]。
重点：代码所有权、review gates、责任划分和 Agent 更改的质量控制。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-ai-first-engineering
为 [项目/组件/场景] 执行任务“为主要由 Agent 编写代码的团队配置工程流程”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：代码所有权、review gates、责任划分和 Agent 更改的质量控制。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
