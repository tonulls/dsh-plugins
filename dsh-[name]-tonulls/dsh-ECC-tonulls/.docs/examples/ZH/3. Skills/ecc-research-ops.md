# `/ecc-research-ops`

基于最新事实开展现状研究，对比备选方案，并结合提供的本地背景形成有证据支持的建议。

## 简单请求
```text
/ecc-research-ops 对比[主题]的当前方案，并提供带来源依据的结论。
```
## 模板请求
```text
/ecc-research-ops
问题：[要查明什么]
背景：[项目/市场/限制]
比较：[选项]
标准：[成本、时效性、风险]
根据可用的最新公开数据给出结论；区分已核实事实和假设。
```
## 详细请求
```text
/ecc-research-ops
研究问题：[问题]。背景和标准：[描述]。按以下步骤执行：1) 明确范围和信息时效日期；2) 列出可核查的问题；3) 收集并比较可用的公开证据和提供的本地背景；4) 标出来源间矛盾、信息缺口和限制；5) 给出建议、备选项和置信度。不要泄露机密，也不要在外部系统中执行操作。仅在网络可用且获准时使用；否则明确指出这一限制。结果：简要摘要、带来源的事实、未知项和建议。
```
