# `/ecc-nasiko-control-plane`

**用途：**通过 ECC 管理实验性 Nasiko CLI 生命周期：只读查看状态；安装固定且经过验证的版本前先 dry-run 并征得用户同意；卸载时核实所有权；明确限制遥测和机密信息。适用于请求安装、检查或卸载 Nasiko CLI，或查询其是否已安装。

## 简短提示词

```text
/ecc-nasiko-control-plane 检查 Nasiko CLI 是否已安装及其版本；暂时不要安装或卸载。
```

## 模板提示词

```text
/ecc-nasiko-control-plane
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 Nasiko CLI 安装状态。
重点：优先只读查看状态、固定且已验证的版本、dry-run、所有权检查，以及安装/卸载的明确同意。
限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-nasiko-control-plane
为 [项目/组件/场景] 执行任务“检查 Nasiko CLI 安装状态”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：优先只读查看状态、固定且已验证的版本、dry-run、所有权检查，以及安装/卸载的明确同意。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
