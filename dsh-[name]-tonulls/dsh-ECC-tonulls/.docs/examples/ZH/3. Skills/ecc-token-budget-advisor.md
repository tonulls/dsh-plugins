# `/ecc-token-budget-advisor`

建议选择回答深度（25%、50%、75% 或 100%），并估算大致 token 用量，然后按选定规模作答。

## 简单请求
```text
/ecc-token-budget-advisor 用简短版本回答问题：[问题]
```
## 模板请求
```text
/ecc-token-budget-advisor
主题：[问题]
期望深度：[25/50/75/100%，或让我选择]
所需格式：[列表/说明/示例]
如果我未指定深度，先评估各方案的篇幅和 token 数，再按选定级别作答。
```
## 详细请求
```text
/ecc-token-budget-advisor
我需要一份关于[主题]的回答，面向[受众/目标]。建议选择 25/50/75/100% 的深度，并估算 token 数以及各方案包含/省略的内容；不要把估算说成精确计数。如果我未指定，请等待我选择。选择后按相应规模作答，同时保留重要限定条件和事实准确性。不要将文本预算与加密/支付 token 混淆。简要注明估算假设。
```
