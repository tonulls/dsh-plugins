# `/ecc-clickhouse-io`

**用途：**ClickHouse 实践：数据库架构、查询优化、分析和数据处理，适用于高性能分析任务。用于编写 ClickHouse 架构和查询，或排查缓慢的分析查询。

## 简短提示词

```text
/ecc-clickhouse-io 分析缓慢的 ClickHouse 查询，并提出可验证的优化方案；不要在数据库中执行更改。
```

## 模板提示词

```text
/ecc-clickhouse-io
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 分析 ClickHouse 架构或缓慢的分析查询。
重点：表模型、键顺序、扫描量、聚合和优化计划。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-clickhouse-io
为 [项目/组件/场景] 执行任务“分析 ClickHouse 架构或缓慢的分析查询”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：表模型、键顺序、扫描量、聚合和优化计划。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
