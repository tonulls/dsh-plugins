# `/ecc-code-tour`

**用途：**创建 CodeTour `.tour` 文件，提供逐步代码导览，并准确关联文件和行号，适配目标受众。可用于新成员入职、架构概览、PR 和 RCA，以及结构化代码讲解。

## 简短提示词

```text
/ecc-code-tour 为新团队成员编写模块[路径]的 CodeTour；先列出导览路线及真实文件链接。
```

## 模板提示词

```text
/ecc-code-tour
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为指定受众准备分步 CodeTour，以实现 [目标或对象]。
重点：真实文件和行号、入口点顺序、清晰的步骤衔接及有效的代码定位。
限制：仅创建或编辑明确指定的结果文件；未经同意，不要添加其他文件。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-code-tour
为 [项目/组件/场景] 执行任务“为指定受众准备分步 CodeTour”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：真实文件和行号、入口点顺序、清晰的步骤衔接及有效定位。
3. 按准确指定的格式和位置准备结果；如果未指定路径或许可，请先展示方案并征求写入确认。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅创建或编辑明确指定的结果文件；未经同意，不要添加其他文件。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
