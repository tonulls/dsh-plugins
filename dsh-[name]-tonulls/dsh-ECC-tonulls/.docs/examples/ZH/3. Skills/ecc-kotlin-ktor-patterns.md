# `ecc-kotlin-ktor-patterns`

**命令：** `/ecc-kotlin-ktor-patterns`

**用途：**Ktor 服务端实践：DSL 路由、插件、身份验证、Koin 依赖注入、kotlinx.serialization、WebSockets，以及通过 `testApplication` 测试。适用于创建 Ktor 服务端，包括路由、插件、身份验证、依赖注入、序列化和测试。

## 提示词

### 1. 简短请求

> /ecc-kotlin-ktor-patterns 为[资源]设计 Ktor route。

### 2. 带上下文的模板

> /ecc-kotlin-ktor-patterns 服务：[描述]，auth：[机制]，格式：[JSON/WebSocket]。按项目当前风格提出 routing DSL、plugins 和 serialization 方案。

### 3. 详细请求

> /ecc-kotlin-ktor-patterns 设计或检查用途为[目标]的 Ktor endpoint。步骤：routing DSL、plugins、auth、Koin DI、kotlinx.serialization、错误处理及 testApplication 测试。考虑现有模式；不要修改文件、安装软件包或访问网络。提供方案结构和可验证的测试用例。
