# `/ecc-orch-pipeline`

说明通用的 Research–Plan–TDD–Review–Commit 受控流程及其检查点；通常通过专用的 `orch-*` 技能使用。

## 简单请求
```text
/ecc-orch-pipeline 解释安全处理小型任务的流程阶段；不要运行任何内容。
```
## 模板请求
```text
/ecc-orch-pipeline 针对任务[描述]列出适用阶段、阶段转换标准和必要的人工确认。仅提供建议，不执行命令或更改。
```
## 详细请求
```text
/ecc-orch-pipeline 分析通用流程如何适用于[任务/orch 操作]。注明规模分类、阶段顺序、适用命令/Agent 的职责、输入/输出和停止条件。明确将计划批准和提交确认列为相互独立的 gate。不要执行任务、修改文件或创建提交。最后提供阶段示意和错误转换的风险。
```
