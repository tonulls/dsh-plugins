# `/ecc-article-writing`

根据提供的范例或品牌指南，以鲜明的作者风格撰写长篇文章、指南、教学材料、通讯刊物及其他长文。

## 提示词示例

### 1. 简短请求
```text
/ecc-article-writing 为[受众]撰写一篇关于[主题]的文章，语气参照所附示例；不要添加未经证实的事实。
```

### 2. 模板请求
```text
/ecc-article-writing 为[受众]准备一份关于[主题]的[材料类型]。目标：[目标]，篇幅：[大致范围]，要点：[列表]，资料来源/语气示例：[材料]。保持来源风格，但不要照抄措辞；标记有争议的事实。
```

### 3. 详细请求
```text
/ecc-article-writing 为[受众]创作一篇关于[主题]的[指南/文章/通讯邮件]，目标为[目标]。1) 研究提供的示例或品牌指南，简要总结其语气、节奏、词汇和应避免的手法。2) 制定结构，明确核心论点和章节逻辑。3) 撰写篇幅为[范围]的连贯文本，仅使用[输入材料]中的事实；不要将未知信息说成事实。4) 检查文本是否符合受众、风格和目标，并去除陈词滥调和重复。格式：标题、导语、章节、结语；文末列出需要核实的陈述。
```
