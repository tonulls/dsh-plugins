# `/ecc-perl-testing`

**用途：**使用 Test2::V0、Test::More、prove 执行器、mock、Devel::Cover 覆盖率工具及 TDD 方法的 Perl 测试实践。适用于编写测试或测量覆盖率。

## 简短提示词

```text
/ecc-perl-testing 使用[Test2::V0/Test::More]为 Perl 函数[名称]制定边界情况测试。
```

## 模板提示词

```text
/ecc-perl-testing
背景：[函数/模块、预期行为、选定测试框架和现有测试]。
任务：为 [目标组件/结果] 使用 Test2::V0 或 Test::More 设计 Perl 测试。
重点：表格化用例、fixtures、mock、负向场景和有依据的覆盖率。
限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-perl-testing
为 [目标系统/场景] 执行任务“使用 Test2::V0 或 Test::More 设计 Perl 测试”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：表格化用例、fixtures、mock、负向场景和有依据的覆盖率。
3. 仅使用项目现有技术栈形成测试集或代码草案；区分建议的检查与实际执行的检查。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：按仓库风格准备测试计划/示例；未经许可，不要运行命令或安装依赖。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
