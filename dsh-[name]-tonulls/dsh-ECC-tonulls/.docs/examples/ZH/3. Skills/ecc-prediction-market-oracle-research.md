# `/ecc-prediction-market-oracle-research`

**用途：**研究预测市场，作为产品、Agent、仪表板和企业分析的数据来源或预言机信号。基于来源分析市场隐含概率、注意事项和集成方案，不提供投资建议。适用于评估此类数据源或信号。

## 简短提示词

```text
/ecc-prediction-market-oracle-research 评估[预测市场]是否适合作为[产品]的信号来源。
```

## 模板提示词

```text
/ecc-prediction-market-oracle-research
背景：[产品问题、关注的市场、可用来源和所需时间范围]。
任务：研究预测市场作为 [目标组件/结果] 的数据来源或信号。
重点：来源和报价质量、市场概率、流动性/偏差、集成限制及不提供投资建议。
限制：使用有依据的来源，区分事实和估算；不要提供投资建议，也不要未经许可采取外部操作。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-prediction-market-oracle-research
为 [目标系统/场景] 执行任务“研究预测市场作为产品的数据来源或信号”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：来源和报价质量、市场概率、流动性/偏差、集成限制及不提供投资建议。
3. 整理结论，注明来源、方法和置信度；不要用编造的数字填补缺口。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：使用有依据的来源，区分事实和估算；不要提供投资建议，也不要未经许可采取外部操作。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
