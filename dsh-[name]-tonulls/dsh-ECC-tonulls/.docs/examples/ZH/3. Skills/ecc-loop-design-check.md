# `/ecc-loop-design-check`

**用途：**设计 Agent 执行循环，并检查是否会陷入无限循环、通过 Goodhart 定律操纵指标，或将错误答案误判为完成。涵盖机器可验证目标、循环类型、“规划—执行—评估”方案及防止失控运行；机制配置详见 `autonomous-loops` skill。适用场景：设计或检查 Agent 循环、诊断循环问题、评估失控风险、确定可验证目标和五类故障。

## 简短提示词

```text
/ecc-loop-design-check 检查此 Agent 循环是否会陷入循环、操纵指标或误报完成。
```

## 模板提示词

```text
/ecc-loop-design-check
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：评估 [目标或对象] 的 Agent 执行循环是否会循环运行，或存在错误的完成标准。
重点：可验证目标、停止标准、Goodhart、重试和失控风险。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-loop-design-check
为 [项目/组件/场景] 执行任务“评估 Agent 执行循环是否会循环运行或使用错误的完成标准”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：可验证目标、停止标准、Goodhart、重试和失控风险。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
