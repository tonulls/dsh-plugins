# `/ecc-uncloud`

帮助通过 `uc` 管理 Uncloud 集群：部署服务、Caddy ingress、静态路由、端口发布、扩缩容、日志、机器和卷。

## 简单请求
```text
/ecc-uncloud 说明如何在不做更改的情况下安全检查 Uncloud 服务[名称]的状态。
```
## 模板请求
```text
/ecc-uncloud
集群/服务：[标识符]
任务：[日志/扩缩容/路由/卷]
获准模式：只读
说明所需的 `uc` 命令及预期效果；未经确认，不要运行命令或更改集群。
```
## 详细请求
```text
/ecc-uncloud
需要对 Uncloud [集群/服务]执行[任务]。先制定计划，并将每条命令分类为只读或会更改状态；注明对可用性、路由、数据/卷的影响以及回滚可能性。未经我针对具体操作单独明确确认，不要执行 deploy、扩缩容、更改 Caddy/端口/机器/卷或删除。不要打印机密，也不要未经许可访问网络。确认后，仅执行已同意的范围，并准确报告命令、结果和状态检查；未获确认时只提供计划。
```
