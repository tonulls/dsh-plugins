# `/ecc-react-native-patterns`

**用途：**React Native 和 Expo 实践：Expo Router 导航、状态分层（服务端、客户端、路由、表单状态）、通过 Zod 和 TanStack Query 获取数据、高性能列表、NativeWind/StyleSheet 样式、原生 API 及安全存储。适用于开发或更改 React Native / Expo 的屏幕、组件、导航和数据层。

## 简短提示词

```text
/ecc-react-native-patterns 检查 Expo 屏幕[路径]：导航、状态、数据获取和 secure storage。
```

## 模板提示词

```text
/ecc-react-native-patterns
背景：[屏幕/模块、Expo Router、state/data layers、设备和问题]。
任务：为 [目标组件/结果] 检查 React Native/Expo 屏幕、导航或数据层。
重点：Expo Router、server/client/route/form state 分层、TanStack Query+Zod、列表、NativeWind 和 secure storage。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```
