# `/ecc-cost-aware-llm-pipeline`

通过按复杂度路由、预算管理、可控重试和提示词缓存，帮助降低 LLM 成本。

## 简单请求

```text
/ecc-cost-aware-llm-pipeline 提出降低 LLM 客服请求分类成本的方法，同时不损失质量。
```

## 模板请求

```text
/ecc-cost-aware-llm-pipeline
当前流程：[任务和模型]
规模和成本：[估算]
质量/延迟要求：[阈值]
可复用前缀：[描述]
提出路由、预算上限、重试和缓存方案；不要调用 API。
```

## 详细请求

```text
/ecc-cost-aware-llm-pipeline
分析 LLM 管道[描述]，目标是在质量要求[指标]、延迟[阈值]和总预算[限制]下减少成本。按复杂度和错误代价划分任务；提出模型选择规则、单次请求/周期的成本上限、可防止成本失控的重试策略，以及 prompt caching 的位置。确定验证节省效果和质量回归所需的测量指标。未经确认，不要向模型/API 发送数据或修改配置。报告中列出当前未知项、目标架构、控制指标、风险和安全的实验计划。
```
