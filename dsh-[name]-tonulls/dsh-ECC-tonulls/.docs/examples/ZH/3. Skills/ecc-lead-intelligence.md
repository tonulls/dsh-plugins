# `ecc-lead-intelligence`

**命令：** `/ecc-lead-intelligence`

**用途：**根据真实用户风格，通过信号、匹配度排序、暖介绍路径搜索，为 email、LinkedIn 和 X 寻找并筛选高价值联系人，准备定向消息。

## 提示词

### 1. 简短请求

> /ecc-lead-intelligence 根据[标准]评估这些潜在客户的匹配度，并提出个性化暖场首条消息；不要发送。

### 2. 带占位符的模板

> /ecc-lead-intelligence 我正在为[产品/方案]寻找[行业、职位、地区]细分市场的联系人。优先信号：[事件/需求]，排除条件：[标准]。仅使用所提供的来源[列表]，根据有依据的匹配度排序并指出缺口。按照示例[材料]的风格准备[邮件/LinkedIn/X]草稿。不要发送，也不要提出未经证实的个人结论。

### 3. 详细分步请求

> /ecc-lead-intelligence 为[方案]和目标画像[ICP]制定潜在客户研究名单。1) 明确纳入/排除标准及所需信号的新鲜度。2) 对每位联系人区分已确认信息与假设，并在可用时标注来源和日期/背景。3) 按透明标准评估匹配度和相对优先级；数据不足时注明，不要凭空填补。4) 如果提供了文本示例，请提取其可观察语气特征，并为 email、LinkedIn 和 X 分别准备简短版本，使用相关的暖场理由。格式：含依据和来源的联系人表格、草稿及未知项清单。不要网络搜索、使用已连接服务，或未经单独许可发送/发布消息。
