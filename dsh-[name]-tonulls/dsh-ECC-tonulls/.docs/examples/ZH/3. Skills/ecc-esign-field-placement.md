# `/ecc-esign-field-placement`

**命令：** `/ecc-esign-field-placement`

**用途：**通过浏览器自动化，在电子签名 Web 编辑器中精确放置签名、日期和文本字段：锁定签名页，在“位置”面板中输入坐标而非拖放，默认仅保存草稿。适用于重复放置字段和分配签署人；发送或签署前必须核实。

## 提示词

### 1. 简短请求

> /ecc-esign-field-placement 在文档中准备签名字段作为草稿，不要发送。

### 2. 带上下文的模板

> /ecc-esign-field-placement 文档：[名称]，页面：[页码]，参与者：[角色]。使用固定坐标准备签名/日期/文本字段的位置，仅保存草稿；任何保存操作前先征得确认。

### 3. 详细请求

> /ecc-esign-field-placement 检查签名页面和收件人对应关系。通过 Location 面板规划字段坐标，不要拖动。保存草稿前暂停；未经单独确认，不要发送或签署。报告字段和不确定事项。
