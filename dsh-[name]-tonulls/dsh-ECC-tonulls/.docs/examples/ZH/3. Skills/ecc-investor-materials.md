# `ecc-investor-materials`

**命令：** `/ecc-investor-materials`

**用途：**创建和更新 pitch deck、单页材料、投资备忘录、加速器申请、财务模型及募资材料。适用于准备投资人文档、预测、资金用途表、里程碑计划和统一融资材料。

## 提示词

### 1. 简短请求

> /ecc-investor-materials 检查投资人 one-pager 的一致性。

### 2. 带上下文的模板

> /ecc-investor-materials 阶段：[轮次]，市场：[描述]，指标：[数据]，目标文档：[类型]。不要编造数字；标出缺口。

### 3. 详细请求

> /ecc-investor-materials 为[轮次]准备/核对[pitch deck/memo/模型]。比较不同材料中的指标、资金用途、里程碑和核心论点；所有未经确认的数值都标记为 placeholders。不要发送或发布材料。先提出结构和所需确认清单，然后提供一致的草稿。
