# `/ecc-automation-audit-ops`

基于事实清点并审计 ECC 自动化之间的重叠：任务、hooks、连接器、MCP 服务器和包装器。帮助在修复前确认哪些正常、失效、重复或缺失。

## 提示词示例

### 1. 简短请求
```text
/ecc-automation-audit-ops 清点此项目的自动化，找出已证实的重复项和故障。暂时不要修复。
```

### 2. 模板请求
```text
/ecc-automation-audit-ops 审计[仓库/范围]：检查[jobs/hooks/connectors/MCP/wrappers]。使用可用的本地配置和状态；区分事实、假设和未知事项。不要进行更改。将结果整理为“组件 — 用途 — 状态 — 证据 — 重叠/缺口”表格。
```

### 3. 详细请求
```text
/ecc-automation-audit-ops 对[项目/范围]进行 evidence-first 自动化审计。1) 确定可用于清点任务、hooks、连接器、MCP 服务器和包装器的信息来源；不要把信息源缺失当作组件不存在的证据。2) 对每个发现的组件记录用途、状态及佐证路径/输出。3) 对照功能，注明确实存在的重复、故障和缺口，并标注置信度。4) 不要修复、运行或重新配置自动化。输出：汇总表、优先发现，以及无法核查的范围。
```
