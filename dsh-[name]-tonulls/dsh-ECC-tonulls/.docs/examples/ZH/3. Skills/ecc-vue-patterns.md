# `/ecc-vue-patterns`

提供 Vue 3 和 Nuxt 实践建议：Composition API、组件架构、响应性、Pinia、Vue Router 和 SSR。

## 简单请求
```text
/ecc-vue-patterns 为场景[描述]提出使用 Composition API 的 Vue 组件方案，并正确管理状态。
```
## 模板请求
```text
/ecc-vue-patterns
技术栈和版本：[Vue/Nuxt/Pinia]
组件或问题：[描述]
代码/限制：[片段]
根据当前项目，针对响应性、状态和路由提供符合惯用模式的方案。
```
## 详细请求
```text
/ecc-vue-patterns
设计/检查 Vue 3/Nuxt [版本] 中的[功能]。1) 确定组件边界和状态所有权。2) 检查 Composition API 与响应性的正确用法，包括副作用。3) 论证是否需要 Pinia，或局部状态是否足够。4) 在适用时分析路由、SSR/hydration 和性能。5) 提出可测试场景。未经明确许可，不要修改文件、安装软件包、访问网络或发布更改。结果：推荐结构/草案、风险、假设和验证计划。
```
