# `/ecc-council`

组织围绕存在歧义的选择进行讨论，引入四种不同视角以揭示权衡并支持有依据的决策。

## 简单请求

```text
/ecc-council 帮我在单体架构和将服务拆成两个组件之间作出选择。
```

## 模板请求

```text
/ecc-council
决策：[问题]
选项：[A、B、其他]
标准和限制：[时间、预算、风险]
背景：[事实]
请以结构化方式讨论不同立场，并给出有条件的建议。
```

## 详细请求

```text
/ecc-council
需要作出的决策：[问题]。请结合背景[事实]和限制[时间/成本/安全/可逆性]，评估选项[列表]。让四种立场分别阐述各方案的支持理由、风险及有力反对意见；随后按标准进行比较，区分事实和假设，并给出决策或说明哪些条件变化会改变倾向。不要执行任何操作或修改系统：这里只需要分析。最后简要总结决策、待解决问题和安全的后续验证。
```
