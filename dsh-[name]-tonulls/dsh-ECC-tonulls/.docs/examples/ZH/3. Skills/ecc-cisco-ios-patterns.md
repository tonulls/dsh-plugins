# `/ecc-cisco-ios-patterns`

**用途：**Cisco IOS 和 IOS-XE 检查实践：状态查看命令、配置层级、wildcard 掩码、ACL 放置、接口状态以及变更窗口中的安全验证。用于读取、编写和检查配置，或规划变更窗口。

## 简短提示词

```text
/ecc-cisco-ios-patterns 检查提供的 Cisco IOS/XE 配置片段，并标出风险点；不要对设备进行任何更改。
```

## 模板提示词

```text
/ecc-cisco-ios-patterns
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：检查 [目标或对象] 的 Cisco IOS/IOS-XE 配置，或制定安全的变更窗口计划。
重点：show 命令、配置层级、wildcard ACL、接口和验证/回滚计划。
限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-cisco-ios-patterns
为 [项目/组件/场景] 执行任务“检查 Cisco IOS/IOS-XE 配置或制定安全的变更窗口计划”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：show 命令、配置层级、wildcard ACL、接口和验证/回滚计划。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
