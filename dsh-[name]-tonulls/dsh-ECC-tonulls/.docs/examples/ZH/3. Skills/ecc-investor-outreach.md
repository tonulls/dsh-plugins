# `ecc-investor-outreach`

**命令：** `/ecc-investor-outreach`

**用途：**为融资准备冷邮件、暖介绍文案、follow-up、进展更新和投资者沟通。适用于向天使投资人、VC、战略投资者和加速器发送简短且个性化的信息。

## 提示词

### 1. 简短请求

> /ecc-investor-outreach 为[公司]写一封简短的投资人邮件。

### 2. 带上下文的模板

> /ecc-investor-outreach 投资人：[姓名/基金]，阶段：[轮次]，联系原因：[熟人介绍/首次联系]，已验证要点：[数据]。不要编造关系或指标。

### 3. 详细请求

> /ecc-investor-outreach 为投资人[简介]撰写关于[公司]的个性化[冷邮件/引荐/follow-up]。只使用提供的事实，语气[风格]，不超过[长度限制]。准备主题和正文；未经许可，不要发送或搜索网络信息。标注需要确认的字段。
