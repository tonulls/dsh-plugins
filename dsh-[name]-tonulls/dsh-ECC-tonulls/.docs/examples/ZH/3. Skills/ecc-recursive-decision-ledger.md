# `/ecc-recursive-decision-ledger`

**用途：**执行多轮迭代（“Prime Gauss”风格的递归提示词），并维护不可变的决策日志，记录尝试、评分、一致性检查和晋级条件。递归式置信度不会自动授权真实交易、部署或破坏性操作。适用于多轮迭代、决策评估流程、多维空间搜索、随机优化、集成对比，以及保留证据的递归推理。

## 简短提示词

```text
/ecc-recursive-decision-ledger 为一系列实验创建可见 ledger，并制定停止标准；不要执行任何操作。
```

## 模板提示词

```text
/ecc-recursive-decision-ledger
背景：[实验目标、选项、评估标准、迭代次数上限和禁止操作]。
任务：为 [目标组件/结果] 组织多轮 rollouts，并维护 append-only 决策日志。
重点：记录 trial/marks/coherence、证据链、晋级 gate，以及禁止自动批准交易、部署或破坏性操作。
限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-recursive-decision-ledger
为 [目标系统/场景] 执行任务“组织多轮 rollouts 并维护 append-only 决策日志”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：trial/marks/coherence 记录、证据链、晋级 gate，以及禁止自动批准交易、部署或破坏性操作。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：制定计划和验证标准；不要修改代码、数据、排期或外部系统。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
