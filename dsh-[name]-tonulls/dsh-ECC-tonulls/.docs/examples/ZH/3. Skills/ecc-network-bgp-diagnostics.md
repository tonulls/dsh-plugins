# `/ecc-network-bgp-diagnostics`

**用途：**无需更改配置的 BGP 诊断实践：邻居状态、路由交换、前缀策略、AS path 分析和安全证据采集。适用于 BGP 邻居不可达、路由缺失或检查策略及 AS path。

## 简短提示词

```text
/ecc-network-bgp-diagnostics 根据这些诊断输出，查明 BGP 邻居不可达或路由缺失的原因；不要修改配置。
```

## 模板提示词

```text
/ecc-network-bgp-diagnostics
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：根据提供的数据诊断 [目标或对象] 的 BGP 问题。
重点：邻居状态、路由交换、前缀策略、AS path 和证据采集；仅限诊断。
限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-network-bgp-diagnostics
为 [项目/组件/场景] 执行任务“根据提供的数据诊断 BGP 问题”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：邻居状态、路由交换、前缀策略、AS path 和证据采集；仅限诊断。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：仅进行诊断；不要更改设备、配置或外部状态；如需主动检查，先征求许可。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
