# `/ecc-accessibility`

依据 WCAG 2.2 AA，为 Web、iOS 和 Android 设计、实现并审计无障碍界面：语义、键盘、焦点、对比度、目标尺寸和屏幕阅读器。

## 提示词示例

### 1. 简短请求
```text
/ecc-accessibility 检查注册表单的无障碍性：键盘导航、字段标签和可见焦点。只做分析，不要修改文件。
```

### 2. 模板请求
```text
/ecc-accessibility 审计 [Web/iOS/Android] 上的[屏幕/组件]。背景：[路径或描述]。检查语义和标签、焦点顺序、对比度以及屏幕阅读器支持。不要进行任何更改；列出已确认的问题并排列优先级。
```

### 3. 详细请求
```text
/ecc-accessibility 审计[平台]上的组件[名称]是否符合适用的 WCAG 2.2 AA 要求。1) 仅研究与该组件相关的材料。2) 检查角色/标签、键盘场景、焦点管理、对比度和交互目标尺寸；不要做未经证实的结论。3) 不要修改文件或启动外部服务。4) 报告包括：发现、证据/位置、对用户的影响、严重程度和具体建议；另行注明未检查的标准。
```
