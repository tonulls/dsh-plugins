# `/ecc-coding-standards`

**用途：**适用于不同项目的基础代码约定：命名、可读性、不可变性和质量检查。特定实践请使用更详细的前端或后端技能。如果没有适用于具体框架的技能，可用此技能评估代码质量或命名。

## 简短提示词

```text
/ecc-coding-standards 检查修改后的代码是否符合基本的可读性、命名和不可变性标准；不要重复框架专属规则。
```

## 模板提示词

```text
/ecc-coding-standards
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：当没有更具体的 framework 技能时，为 [目标或对象] 检查代码的基础约定。
重点：命名、可读性、不可变性和一致的质量标准。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-coding-standards
为 [项目/组件/场景] 执行任务“在没有更具体的 framework 技能时检查代码的基础约定”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：命名、可读性、不可变性和一致的质量标准。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
