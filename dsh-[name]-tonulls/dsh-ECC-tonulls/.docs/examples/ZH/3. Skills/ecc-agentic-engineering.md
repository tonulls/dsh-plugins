# `/ecc-agentic-engineering`

组织由 Agent 执行的工程工作：从评估开始，拆解任务，并结合模型成本分配工作。适用于规划和执行 Agent 端到端开发。

## 提示词示例

### 1. 简短请求
```text
/ecc-agentic-engineering 将任务[简述]拆分为可验证的 Agent 执行阶段，并建议哪些阶段用较小模型就足够、哪些需要更强模型。暂时只做规划。
```

### 2. 模板请求
```text
/ecc-agentic-engineering 为[仓库]中的[目标]制定 eval-first 计划。验收标准：[标准]；限制：[文件/更改/时限/成本]。将工作拆分为相互独立的阶段，并为每阶段注明输入、输出、验证方式和适用的模型等级。在确认前不要执行任何操作。
```

### 3. 详细请求
```text
/ecc-agentic-engineering 规划[功能/结果]的端到端 Agent 实现。1) 首先制定可验证的成功标准和最小 eval，不要假设任务已完成。2) 研究指定仓库范围，将工作拆解为有明确依赖、产物和验收点的阶段。3) 为每阶段建议满足需求的最小模型等级，并解释质量/成本权衡；没有数据时，不要声称具体价格。4) 将更改限制在[允许范围]；未经单独同意，不要安装依赖、访问网络或部署。5) 每阶段完成后先验证再继续；如遇歧义或失败，请暂停并报告。结果格式：标准/eval、阶段、任务和模型分配、限制、风险和停止条件。
```
