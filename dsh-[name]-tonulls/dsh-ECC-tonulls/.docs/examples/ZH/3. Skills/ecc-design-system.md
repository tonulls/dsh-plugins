# `/ecc-design-system`

从现有界面提取设计令牌，并制定有依据的样式系统及 HTML 预览；也可从多个维度审计视觉一致性。

## 简单请求

```text
/ecc-design-system 审计页面的视觉一致性，找出重复使用的颜色和间距。
```

## 模板请求

```text
/ecc-design-system
UI 范围：[页面/组件]
样式和组件路径：[列表]
目标：[提取设计系统 / 执行审计]
品牌限制：[描述]
先只做分析，不要修改文件；请提出设计令牌、理由和一致性问题。
```

## 详细请求

```text
/ecc-design-system
研究[界面部分]以创建或审计设计系统。不要修改文件。识别现有颜色、字体、间距和阴影；将其整理为建议的设计令牌和 CSS custom properties；以简洁 DESIGN.md 的风格说明理由，并按相关视觉维度评估界面。指出不一致状态和模板化设计，但避免缺乏依据的主观评价。提出交互式 HTML 预览应包含的内容；未经确认，不要创建预览。不要添加依赖，也不要采集/发布数据。结果包括：清点结果、令牌、评估、优先级和实施计划。
```
