# `/ecc-blender-motion-state-inspection`

帮助在 Blender 中检查角色、骨骼绑定、姿势、动画重定向、地面接触、注视/运动方向以及模型动作匹配情况。单张截图往往不足以完成此类检查；请求应明确需要比较的状态和特征。

## 简短请求

```text
/ecc-blender-motion-state-inspection 检查角色走路时滑步的原因：对比各帧脚部姿势、地面接触和骨骼绑定运动。
```

## 模板

```text
/ecc-blender-motion-state-inspection 检查[文件或集合]中的[角色/场景/动画]。疑似问题：[姿势/重定向/接触/方向错误]。检查帧范围[起—止]、源骨骼绑定[描述]和目标骨骼绑定[描述]。提供可观察的原因及准确的帧/对象，不要仅凭单张图像猜测。
```

## 分步请求

```text
/ecc-blender-motion-state-inspection 诊断场景[文件/场景]中[症状]，帧范围[帧]，角色[对象]，骨骼绑定[对象]。
1. 确认场景数据和检查方式是否可用；如果无法访问 Blender 或帧状态，明确列出缺失信息。
2. 追踪关键帧[注明]上的姿势和骨骼变换；另行检查 root motion 和角色朝向。
3. 如果源和目标骨骼绑定均可访问，比较重定向时的骨骼/轴线映射和比例。
4. 通过脚相对地面及相邻帧的运动检查地面接触；区分实际接触和单帧中的视觉重合。
5. 提出可验证的原因和最小修复方案；除非明确要求，不要修改场景。

格式：注明帧和对象名称的观察结果；将假设与已确认事实分开；列出可能原因和下一项检查。不要声称检查了不可访问的状态。
```
