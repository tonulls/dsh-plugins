# `/ecc-rust-patterns`

提供 Rust 惯用且安全的实现方法：所有权与借用、错误处理、trait 和并发。

## 简单请求
```text
/ecc-rust-patterns 检查这段 Rust 代码中的所有权问题和惯用写法：[代码]
```
## 模板请求
```text
/ecc-rust-patterns
任务：[要实现什么]
背景和 Rust 版本：[信息]
片段/限制：[代码、接口]
提出安全方案，并解释所有权、错误处理和权衡。未经我同意，不要添加依赖。
```
## 详细请求
```text
/ecc-rust-patterns
需要在 Rust [版本/背景] 中实现[功能描述]。1) 研究提供的代码和契约。2) 确定所有权模型和可变性边界。3) 提出符合惯用写法的类型、错误和 trait 设计。4) 仅在相关时考虑并发和性能。5) 展示方案和可测试的边界情况。不要修改文件、安装软件包或访问网络。进行任何更改前，先提出计划并请求确认。报告中列出假设、安全风险和设计理由。
```
