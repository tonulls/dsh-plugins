# `/ecc-regex-vs-llm-structured-text`

帮助设计低成本的结构化文本混合解析方案：用正则表达式提取常见数据，通过置信度评分识别歧义案例，仅将 LLM 作为异常情况的验证器。

## 简单请求

```text
/ecc-regex-vs-llm-structured-text 设计发票解析方案：常见字段用 regex，评估置信度并处理歧义情况。
```

## 模板请求

```text
/ecc-regex-vs-llm-structured-text
文档类型：[发票/表单/收据/表格]
所需字段：[列表]
输入示例：[脱敏片段]
成本和准确度限制：[数值]
提出 regex-first 流程、置信度评分，以及将个别案例交由 LLM 处理的标准。不要使用真实个人数据或机密。
```

## 详细请求

```text
/ecc-regex-vs-llm-structured-text
为[文档类型]中的字段[列表]设计数据提取计划。分步处理：
1. 记录输入格式、表示形式变体和正确性标准。
2. 将字段划分为可用正则表达式提取的字段和需要上下文解读的字段。
3. 设计 regex-first 提取和标准化，不要引入未经示例确认的假设。
4. 提出置信度评分、人工复核阈值，以及仅将边界案例交由 LLM 处理的方案。
5. 定义测试示例、准确率/召回率指标、成本指标和错误处理规则。
限制：不要向网络或第三方服务发送数据；不要使用真实个人数据；不要安装软件或更改项目。先给出设计方案，再说明假设、风险和验证计划。
```
