# `ecc-fsharp-testing`

**命令：** `/ecc-fsharp-testing`

**用途：**F# 测试实践：xUnit、FsUnit、Unquote、通过 FsCheck 进行属性测试，以及集成测试组织。适用于使用 xUnit、FsUnit、Unquote 或 FsCheck 编写 F# 测试。

## 提示词

### 1. 简短请求

> /ecc-fsharp-testing 为这个 F# 函数推荐测试。

### 2. 带上下文的模板

> /ecc-fsharp-testing 函数：[名称]，行为：[预期]，项目使用：[xUnit/FsUnit/Unquote/FsCheck]。提出示例和属性测试。

### 3. 详细请求

> /ecc-fsharp-testing 为 F# 模块[模块]制定测试策略。确定 unit/integration 边界，提供 xUnit/FsUnit/Unquote 示例及 FsCheck 属性测试，并涵盖边界情况。未经许可，不要运行命令或修改文件；请输出测试用例矩阵和代码示例。
