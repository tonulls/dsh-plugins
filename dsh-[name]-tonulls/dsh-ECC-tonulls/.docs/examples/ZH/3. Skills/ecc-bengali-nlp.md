# `/ecc-bengali-nlp`

用于孟加拉语 (Bangla) 文本处理：Unicode 规范化、文字识别、分词、合字序列的正确处理，以及 AI 应用中的 NLP 特性。

## 简短请求

```text
/ecc-bengali-nlp 检查孟加拉语字符串分词：考虑 Unicode 规范化和合字，并提出测试用例。
```

## 模板

```text
/ecc-bengali-nlp 分析用于孟加拉语文本处理的[模块/代码片段]。输入：[示例，包括混合文本]。需要：[规范化 / 文字识别 / 分词 / 其他]。保留对语言有意义的差异；不要假定字节、码点和用户感知字符彼此等同。
```

## 分步请求

```text
/ecc-bengali-nlp 分析[路径/函数]中 Bengali/Bangla 的处理管道，用于场景[搜索/分类/生成]。
1. 追踪输入编码和规范化；说明哪些 Unicode 转换适用，以及哪些转换可能扭曲数据。
2. 用具体示例检查孟加拉文识别和混合字符串：[示例]。
3. 评估分词及对合字、符号和边界的处理；没有示例依据时，不要断言语言学处理正确与否。
4. 提出精简的回归用例集和预期行为标准。

结果为“输入 / 观察到的问题 / 预期行为”表格、优先级和最小修复计划。如果只要求审查，不要修改。实施时仅修改相关文件；未经单独同意，不要安装软件包、访问网络或部署。
```
