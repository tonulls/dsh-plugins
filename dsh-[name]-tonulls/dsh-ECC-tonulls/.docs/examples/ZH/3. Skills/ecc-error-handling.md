# `/ecc-error-handling`

**命令：** `/ecc-error-handling`

**用途：**TypeScript、Python 和 Go 中的可靠错误处理实践：类型化错误、错误处理边界、重试和熔断器 (circuit breaker)、清晰易懂的用户提示。适用于设计错误类型、重试、熔断器或故障提示。

## 提示词

### 1. 简短请求

> /ecc-error-handling 分析此模块中的错误处理。

### 2. 带上下文的模板

> /ecc-error-handling 语言：[TypeScript/Python/Go]，模块：[路径]，故障：[症状]。提出类型化处理方式和易懂的用户提示。

### 3. 详细请求

> /ecc-error-handling 研究场景[场景]中[路径]的错误处理。检查错误边界、重试和 circuit breaker；不要修改文件。提供按优先级排列的结论、安全计划和示例。
