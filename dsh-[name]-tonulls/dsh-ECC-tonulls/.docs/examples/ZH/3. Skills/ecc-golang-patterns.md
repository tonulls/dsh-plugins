# `ecc-golang-patterns`

**命令：** `/ecc-golang-patterns`

**用途：**编写可靠、高效且易维护应用程序的 Go 惯用实践和约定。适用于编写或检查 Go 代码，尤其重视惯用结构和约定时。

## 提示词

### 1. 简短请求

> /ecc-golang-patterns 检查这段 Go 代码是否符合惯用写法。

### 2. 带上下文的模板

> /ecc-golang-patterns 路径：[文件]，背景：[用途]。评估结构、错误处理、接口和可读性；不要修改。

### 3. 详细请求

> /ecc-golang-patterns 对 Go 模块[路径]执行只读审查。检查惯用结构、数据所有权、错误处理、接口和可维护性；区分实际问题与风格偏好，并给出具体建议。不要进行更改。
