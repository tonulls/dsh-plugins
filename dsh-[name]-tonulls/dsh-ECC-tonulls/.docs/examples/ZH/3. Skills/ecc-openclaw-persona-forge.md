# `/ecc-openclaw-persona-forge`

为 OpenClaw Agent 创建人格概念：身份、`SOUL.md` 草稿、角色边界、名称和头像文本提示。只有在有获准的图像生成工具时才生成图像。

## 简单请求

```text
/ecc-openclaw-persona-forge 为家庭图书馆构思一个友好的 OpenClaw 助手。
```

## 模板请求

```text
/ecc-openclaw-persona-forge 创建 OpenClaw 人格：Agent 用途为[用途]，沟通对象为[受众]，期望语气为[语气]，重要限制为[边界]。准备身份设定、SOUL.md、名称和头像文本提示。未经我单独确认，不要创建文件或图像。
```

## 详细请求

```text
/ecc-openclaw-persona-forge 为[场景]设计 OpenClaw 角色。
1. 澄清缺失的偏好；不要编造关于所有者的事实。
2. 提出定位、个性和名称。
3. 准备 SOUL.md 草稿，明确角色和行为边界。
4. 编写独立的头像文本提示，保持统一视觉理念。
5. 展示所有内容供确认。未经我明确同意，不要修改现有文件、启动图像生成或连接外部服务。
最后列出假设和问题。
```
