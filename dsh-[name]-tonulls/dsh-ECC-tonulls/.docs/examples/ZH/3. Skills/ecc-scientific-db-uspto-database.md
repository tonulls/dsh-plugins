# `/ecc-scientific-db-uspto-database`

帮助构建可复核的 USPTO 官方数据检索：专利记录、通过 TSDR 查询商标、权利转让记录，以及可复现的知识产权研究日志。

## 简单请求
```text
/ecc-scientific-db-uspto-database 告诉我如何在 USPTO 官方系统中核查商标[名称]的记录。
```
## 模板请求
```text
/ecc-scientific-db-uspto-database
检索类型：[专利/商标/转让]
名称或标识符：[数据]
范围和核查日期：[参数]
制定官方来源检索计划和结果记录日志；提供法律结论时须注明限制。
```
## 详细请求
```text
/ecc-scientific-db-uspto-database
为[对象/标识符]制定可复现的核查流程。步骤：确认记录类型和拼写变体；指出适用的 USPTO 官方界面（PatentSearch、TSDR、转让数据等）；构建查询并定义记录字段；说明如何核对标识符、状态、日期和相关文件；指出时效性限制及匹配结果歧义。不要提交申请或修改记录。仅在我许可后执行网络访问；不要泄露机密。报告应区分已确认记录与相似匹配，并提供链接/核查时间，或如未执行检索则如实说明。
```
