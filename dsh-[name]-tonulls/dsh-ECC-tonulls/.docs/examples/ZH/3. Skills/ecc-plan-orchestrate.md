# `/ecc-plan-orchestrate`

**用途：**读取计划文档，将其拆分为步骤并分类；按照已记录的参数格式，为每一步生成包含标识符和范围的可直接使用的 ECC slash 命令。仅生成命令，不执行它们，也不声称控制命令内部执行。如果某条命令不支持计划范围，则不包含该步骤。适用于为多阶段计划匹配命令。

## 简短提示词

```text
/ecc-plan-orchestrate 将此计划拆分为准确的 ECC slash 命令，但不要执行。
```

## 模板提示词

```text
/ecc-plan-orchestrate
背景：[计划路径或文本、任务限制和允许的命令]。
任务：拆分多步计划，并为 [目标组件/结果] 的每阶段匹配有文档说明的 ECC 命令。
重点：依赖关系、步骤 ID 和范围、命令支持的参数格式，以及无法传递范围时安全拒绝。
限制：仅生成可直接粘贴的步骤/命令；不要调用，也不要声称已执行。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-plan-orchestrate
为 [目标系统/场景] 执行任务“拆分多步计划并为每阶段匹配有文档说明的 ECC 命令”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：依赖关系、步骤 ID 和范围、命令支持的参数格式，以及无法传递范围时安全拒绝。
3. 对每一步注明准确的有文档依据的调用和范围；若命令不能限定步骤范围，不要纳入并注明阻碍。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅生成可直接粘贴的步骤/命令；不要调用，也不要声称已执行。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
