# `/ecc-orch-build-mvp`

将 MVP 设计或规格拆分为垂直切片，并通过检查和检查点组织逐步构建。

## 简单请求
```text
/ecc-orch-build-mvp 根据所附规格制定第一个可运行切片计划，并等待我的批准。
```
## 模板请求
```text
/ecc-orch-build-mvp 规格：[路径/文本]。目标受众：[受众]。MVP 应包含：[最小场景]。拆分为垂直切片并提出第一个切片；计划获批前不要修改文件。
```
## 详细请求
```text
/ecc-orch-build-mvp 使用[规格]作为需求来源。1) 提取使用场景、限制和未知项。2) 将 MVP 拆分为相互独立且有验收标准的垂直切片。3) 展示计划并暂停等待确认。获批后逐个实现切片，并用可用的本地测试和更改审查进行验证。未经单独许可，不要安装软件包、访问网络、部署或提交。报告：已完成切片、检查结果、缺口和下一步。
```
