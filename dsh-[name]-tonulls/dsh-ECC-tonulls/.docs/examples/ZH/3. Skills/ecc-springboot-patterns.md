# `/ecc-springboot-patterns`

提供 Spring Boot 架构建议，涵盖 REST API、分层服务、数据访问、缓存、异步处理和日志记录。

## 简单请求
```text
/ecc-springboot-patterns 为[任务]提出 Spring Boot endpoint 结构，并分离 controller 和 service。
```
## 模板请求
```text
/ecc-springboot-patterns
Java/Spring 版本：[值]
功能或 API：[描述]
当前架构：[层级/代码]
限制：[数据库、事务、负载]
请提出符合现有项目风格的方案并说明权衡。
```
## 详细请求
```text
/ecc-springboot-patterns
为使用[Java 和 Spring Boot 版本]的项目设计[功能]。1) 将方案与当前包结构和约定对照。2) 定义 REST 契约、验证、服务边界和事务。3) 仅在确有依据时分析数据访问、缓存/异步处理。4) 描述错误处理和安全日志记录。5) 列出测试场景和风险。未经我确认，不要修改文件、添加依赖或连接外部服务。结果：建议结构/代码草案、理由、假设和验证方式。
```
