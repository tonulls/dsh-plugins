# `/ecc-perl-patterns`

**用途：**现代 Perl 5.36+ 的惯用实践和约定，用于构建可靠、易维护的应用。适用于编写或检查现代 Perl 5.36+ 代码。

## 简短提示词

```text
/ecc-perl-patterns 检查此 Perl 5.36+ 模块是否符合惯用写法、可读性要求，并查找常见错误。
```

## 模板提示词

```text
/ecc-perl-patterns
背景：[Perl 文件路径、模块用途、Perl 版本和项目现有风格]。
任务：为 [目标组件/结果] 检查或设计现代 Perl 代码。
重点：模块结构、Perl 5.36+ 惯用法、错误处理、类型/签名和仓库约定。
限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
格式：[简要结论、证据/理由、风险和下一步]。
```

## 详细提示词

```text
/ecc-perl-patterns
为 [目标系统/场景] 执行任务“检查或设计现代 Perl 代码”。
1. 明确目标、范围、初始信息和结果标准；列出缺失背景。
2. 仅研究与请求相关的材料并核查：模块结构、Perl 5.36+ 惯用法、错误处理、类型/签名和仓库约定。
3. 根据事实提出发现或备选方案，注明风险、验证标准和未解决问题；不要应用任何更改。
4. 根据给定标准检查结论，注明证据、假设和未核实事项。

限制：仅分析；不要修改文件或数据，也不要运行外部/破坏性检查。
按以下格式整理结果：[预期格式]。不要编造事实；如需执行未预期的副作用操作，请暂停并征求同意。
```
