# `/ecc-mcp-dependency-review`

**用途：**在批准或启动 CI 之前，静态检查 MCP 配置中可变的软件包引用；不启动发现的 MCP 服务器。适用于检查 `.mcp.json` 以及 Cursor、VS Code、Claude、Windsurf 等环境中的仓库 MCP 设置。

## 简短提示词

```text
/ecc-mcp-dependency-review 静态审计 `.mcp.json` 和 MCP 配置中的可变引用及风险；不要启动服务器。
```

## 模板提示词

```text
/ecc-mcp-dependency-review
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 静态检查 MCP 配置中的可变依赖。
重点：软件包引用、版本固定、脚本和 install hooks、信任边界；不要启动 MCP 服务器。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-mcp-dependency-review
为 [项目/组件/场景] 执行任务“静态检查 MCP 配置中的可变依赖”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：软件包引用、版本固定、脚本和 install hooks、信任边界；不要启动 MCP 服务器。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
