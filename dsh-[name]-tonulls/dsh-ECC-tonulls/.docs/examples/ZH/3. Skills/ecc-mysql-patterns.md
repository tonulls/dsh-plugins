# `/ecc-mysql-patterns`

**用途：**生产级服务端应用的 MySQL 和 MariaDB 实践：架构、查询、索引、事务、复制和连接池。适用于设计架构与索引，或诊断查询延迟、事务和副本问题。

## 简短提示词

```text
/ecc-mysql-patterns 分析缓慢的 MySQL/MariaDB 查询，并结合事务提出索引方案。
```

## 模板提示词

```text
/ecc-mysql-patterns
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：为 [目标或对象] 分析 MySQL/MariaDB 架构或查询延迟。
重点：架构、索引、事务、复制、连接池和查询延迟。
限制：只读；不要修改文件，也不要运行主动或外部检查。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-mysql-patterns
为 [项目/组件/场景] 执行任务“分析 MySQL/MariaDB 架构或查询延迟”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：架构、索引、事务、复制、连接池和查询延迟。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：只读；不要修改文件，也不要运行主动或外部检查。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
