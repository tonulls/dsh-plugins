# `/ecc-agent-eval`

**用途：**根据用户任务的成功率、成本、耗时和稳定性，比较 Claude Code、Aider、Codex 等编码 Agent。用于选择 Agent，或依据可衡量指标评估其配置更改。

## 简短提示词

```text
/ecc-agent-eval 制定一个公平的比较方案，用相同任务和指标评估两个 coding agents。
```

## 模板提示词

```text
/ecc-agent-eval
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：针对 [目标或对象]，用相同的用户任务比较 coding agents。
重点：成功率、成本、耗时、稳定性、一致的条件和测量限制。
限制：提供建议，不应用更改、不发送消息，也不进行发布。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-agent-eval
为 [项目/组件/场景] 执行任务“用相同的用户任务比较 coding agents”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：成功率、成本、耗时、稳定性、一致的条件和测量限制。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：提供建议，不应用更改、不发送消息，也不进行发布。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
