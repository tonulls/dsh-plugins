# `/ecc-email-ops`

在相应邮件工具可用时，帮助根据实际信息整理邮件、准备邮件内容、核实发送状态并安全跟进。

## 简单请求

```text
/ecc-email-ops 汇总项目相关的未读邮件，并建议优先回复哪些；不要发送任何内容。
```

## 模板请求

```text
/ecc-email-ops
目标：[整理收件箱/准备回复/核实发送状态]
文件夹或时间段：[范围]
筛选标准：[主题/发件人]
回复风格：[描述]
先说明检查了哪些来源；未经我确认，不要发送邮件。
```

## 详细请求

```text
/ecc-email-ops
在[文件夹/日期/发件人]范围内处理邮件任务[目标]。仅使用明确可用的邮件工具，列出实际核查的来源，不要声称检查了其他内容。先按主题和紧急程度对邮件分组，再依据收件人及事实背景准备回复草稿。不要泄露一次性验证码/机密，不要打开链接，也不要未经单独确认执行发送/归档/删除/移动邮件等操作；确认时需明确具体操作。若工具支持，请核查已发送邮件的实际状态，以便跟进。结果包括：核查来源、摘要、草稿和未解决问题；任何操作都须在确认后执行。
```
