# `/ecc-prompt-caching-strategy`

**用途：**提高 LLM 提示词缓存的重复命中率，以降低 API 成本和延迟。分析提示词结构，识别可缓存和不可缓存部分，并提出有利于缓存复用的更改。适用于询问提示词缓存、命中率、降低 LLM 成本、节省 token，以及 OpenAI、Anthropic 等供应商的缓存。不要将其用于改进单条提示词质量或通用基础设施缓存。

## 简短提示词

```text
/ecc-prompt-caching-strategy 找出如何提高此 LLM 提示词的 cache-hit，同时不改变其含义。
```
