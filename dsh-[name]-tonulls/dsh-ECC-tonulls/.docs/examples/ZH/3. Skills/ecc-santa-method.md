# `/ecc-santa-method`

组织两位审查者按照同一标准进行独立对抗性审查，安排修复和复审循环；若分歧仍未解决，则升级给人工处理。

## 简单请求
```text
/ecc-santa-method 发布前按事实、风险和合规性独立审查此文本：[文本]
```
## 模板请求
```text
/ecc-santa-method
材料：[文本/更改]
用途和受众：[背景]
验收标准：[标准]
进行两次独立审查，并报告所有强制标准是否通过。不要发布或修改任何内容。
```
## 详细请求
```text
/ecc-santa-method
需要判断[材料/更改]是否适合[发布/上线]。标准：[评分表]，关键声明：[列表]。安排两次独立审查，使用相同标准；保留评分差异，对照支持证据，只提出必要修正，并在应用修正后复审。不要发布、部署或修改文件；任何外部副作用都需我另行确认。限制循环次数；如有分歧或证据不足，暂停并交由人工决策。报告：结论、两轮结果、按严重程度分类的意见、未解决问题及升级条件。
```
