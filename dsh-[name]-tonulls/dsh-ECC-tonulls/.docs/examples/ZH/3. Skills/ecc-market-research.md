# `/ecc-market-research`

**用途：**开展市场研究、竞争分析、投资验证和行业分析，注明来源并提供决策所需结论。适用于评估市场规模、比较竞争者、研究基金和技术，或为商业决策开展研究。

## 简短提示词

```text
/ecc-market-research 评估[细分市场]对[决策]的意义，并区分已确认信息与估算。
```

## 模板提示词

```text
/ecc-market-research
背景：[项目路径 / 片段 / 系统 / 症状]。
任务：研究市场和竞争环境，为 [目标或对象] 的商业问题决策提供依据。
重点：来源、市场规模/细分、竞争者比较、假设和可验证的结论。
限制：区分已核实的事实与估算，注明来源；只有在外部搜索可用且获准时才进行搜索。
结果格式：[简要结论、依据、优先级和后续步骤]。
```

## 详细提示词

```text
/ecc-market-research
为 [项目/组件/场景] 执行任务“研究市场和竞争环境，为商业问题决策提供依据”。
1. 记录初始信息、工作范围和结果标准；列出缺少的信息。
2. 仅研究与任务相关的背景并检查：来源、市场规模/细分、竞争者比较、假设和可验证结论。
3. 提出结论和后续步骤；不要应用更改，也不要把假设说成事实。
4. 根据标准核对结果，提供证据并区分已确认的结论和假设。

限制：区分已核实的事实与估算，注明来源；只有在外部搜索可用且获准时才进行搜索。
报告应注明结论、重要发现/操作、未检查部分、风险和安全的后续步骤。
```
