# `/ecc-brand-discovery`

通过结构化访谈创建或重新定义品牌：八个模块涵盖目标、定位、受众、个性、语气、叙事和创始人张力。访谈可跨多个会话继续，保存回答并汇总为 `90_SYNTHESIS.md`。

## 简短请求

```text
/ecc-brand-discovery 通过访谈明确新工作室品牌的定位，并为品牌手册准备基础材料。
```

## 模板

```text
/ecc-brand-discovery 帮助[创建/重新定义]面向[市场/受众]的品牌[名称/项目]。从[模块或全新访谈]开始，每次提出一个有实质意义的问题，并通过追问深入了解。将我的原话与分析结论分开保存；如果在项目中开展，请先建议笔记保存位置，不要直接写入文件。
```

## 分步请求

```text
/ecc-brand-discovery 针对品牌[名称/项目]进行多阶段访谈。目标：[新品牌 / 重新定位 / 为设计师或作者准备简报]。
1. 检查是否已有保存的回答；继续访谈时不要重复询问已确认的信息，并指出尚未完成的模块。
2. 依次访谈目标、定位、受众、个性、语气、叙事和创始人张力（以及访谈规定的其他主题）。可以追问“为什么？”或提出投射性问题，但不要用自己的猜测代替回答。
3. 每阶段结束时简要总结所听到的内容，请我确认或纠正有争议的结论。未商定保存位置前，不要将材料写入磁盘。
4. 完成商定的模块后，将结论整理为 `90_SYNTHESIS.md`，区分事实和引述与解读。

结果：已完成/未完成的模块、已确认的品牌表述、矛盾点和最终品牌手册。如果信息不足，请继续提问，不要编造内容来填补缺口。
```
