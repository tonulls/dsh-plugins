# `/ecc-command-build-fix`

**用途：**确定项目使用的构建系统，分步诊断构建和类型错误，并以最小、安全的更改修复。只使用已可用的工具；不安装或下载依赖。

## 提示词示例

### 1. 简短请求

```text
/ecc-command-build-fix 找出并以最小更改修复当前构建错误。只使用已安装的工具；不要安装依赖。
```

### 2. 带上下文的请求

```text
/ecc-command-build-fix
项目[路径或模块名称]的构建失败并报错。检查构建系统和本地可用命令，然后按文件分析错误，并逐个进行最小修复。

范围：[目录/模块]。不要更改架构或此范围外的文件。不要安装或下载软件包。如果缺少所需工具、尝试三次后错误仍存在，或需要大范围更改，请停止并说明原因；继续此类更改前先征求确认。
```

### 3. 详细请求

```text
/ecc-command-build-fix
修复[项目或目标模块]的构建/类型错误。按阶段处理：
1. 根据项目文件确定构建系统，仅选择已安装的本地验证命令。
2. 执行验证，并按文件归类错误信息；注明错误初始数量。
3. 对每个错误研究上下文并找到根因，在[获准范围]内提出/实施最小修复。每次修复后重新验证，并检查是否引入新错误。
4. 如果缺少工具/依赖、尝试三次后错误仍未解决、修复造成更多错误、涉及架构或超出范围，则停止。不要安装、下载或执行网络操作。删除数据、发布或其他重大副作用前，须另行征求确认。
5. 最后报告更改及路径、重复验证结果、剩余/新增错误（如有）和安全的后续步骤。

未经我事先同意，不要进行无关重构，也不要修改指定范围外的文件。
```
