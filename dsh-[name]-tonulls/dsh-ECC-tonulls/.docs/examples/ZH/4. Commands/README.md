# ECC 命令示例

本节提供 [commands 软件包](../../../../packages/commands/README.md) 中三条命令的调用示例。在 DSH 普通消息中输入 `/ecc-组件名称`，然后描述任务和限制。命令会为当前 DSH Agent 提供操作指引。

这里只列出目录中的 `entries` 条目；每个组件都有单独文件，其中包含三个级别的提示词。

| 组件 | 简要用途 | 提示词示例 |
| --- | --- | --- |
| `/ecc-command-build-fix` | 确定项目构建系统，分阶段以最小且安全的更改修复构建和类型错误。 | [三个提示词](ecc-command-build-fix.md) |
| `/ecc-command-test-coverage` | 分析测试覆盖率、识别缺口，并添加所需测试以达到目标阈值。 | [三个提示词](ecc-command-test-coverage.md) |
| `/ecc-command-update-docs` | 根据脚本、架构、路由和公开导出等权威来源同步文档。 | [三个提示词](ecc-command-update-docs.md) |

**合计：**3 项；缺少的示例文件：0。
