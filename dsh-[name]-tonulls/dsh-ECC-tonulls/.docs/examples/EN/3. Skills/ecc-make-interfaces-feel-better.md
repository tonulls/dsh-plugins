# `/ecc-make-interfaces-feel-better`

**Purpose:** Applies concrete design-engineering techniques to improve interfaces: spacing, typography, borders, shadows, animation, hit areas, icons, text wrapping, and interaction states. Use when reviewing or refining a user interface.

## Short Prompt
```text
/ecc-make-interfaces-feel-better Assess this screen and suggest several concrete improvements to visual and interactive clarity.
```

## Template Prompt
```text
/ecc-make-interfaces-feel-better
Context: [project path / snippet / system / symptom].
Task: improve visual and interactive interface quality for [goal or subject].
Focus: spacing, typography, borders, shadows, animation, hit targets, icons, and states.
Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Output format: [brief conclusion, evidence, priorities, and next steps].
```

## Detailed Prompt
```text
/ecc-make-interfaces-feel-better
Perform the task “improve visual and interactive interface quality” for [project/component/scenario].
1. Record baseline information, scope, and success criteria; list missing information.
2. Study only relevant context and assess spacing, typography, borders, shadows, animation, hit targets, icons, and states.
3. Form conclusions and next steps without applying changes or presenting assumptions as facts.
4. Compare results with criteria, cite evidence, and distinguish confirmed conclusions from assumptions.

Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Include outcome, important findings/actions, unverified areas, risks, and safe next steps.
```
