# `/ecc-dart-flutter-patterns`

Helps create and review Flutter/Dart code: null safety, immutable state, async behavior, widget architecture, BLoC/Riverpod/Provider, GoRouter, Dio, errors, and tests.

## Simple Request

```text
/ecc-dart-flutter-patterns How can I safely manage loading and display state for a list in Flutter?
```

## Template Request

```text
/ecc-dart-flutter-patterns
Flutter/Dart versions: [versions]
Current state management: [BLoC/Riverpod/Provider/other]
Task: [widget/navigation/network/state]
Code and constraints: [snippet/description]
Suggest an idiomatic solution compatible with the current architecture.
```

## Detailed Request

```text
/ecc-dart-flutter-patterns Analyze implementation of [feature] in a Flutter/Dart application [versions]. Consider current approach [BLoC/Riverpod/Provider], routing [GoRouter/other], and network layer [Dio/other]. Check null safety, immutable state, widget lifecycle, async errors/cancellation, separation of UI and logic, accessibility, and testability. Suggest specific changes and tests while preserving existing conventions. Do not add dependencies, make network requests, or edit files before approval. Result: recommended structure, snippets, risks, and test matrix.
```
