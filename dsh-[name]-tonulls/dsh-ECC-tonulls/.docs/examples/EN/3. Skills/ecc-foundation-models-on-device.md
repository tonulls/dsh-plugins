# ecc-foundation-models-on-device

**Command:** `/ecc-foundation-models-on-device`

**Purpose:** Apple's FoundationModels framework for running large language models on device: text generation, guided generation with @Generable, tool calling, and snapshot streaming on iOS 26+. Use when adding these capabilities to iOS 26+ applications.

## Prompts

### 1. Short Request
> /ecc-foundation-models-on-device Sketch on-device generation for iOS 26+ using FoundationModels.

### 2. Template with Context
> /ecc-foundation-models-on-device App: [description], scenario: [generation/tools/streaming]. Suggest a data model with @Generable and handling of limited availability, without network APIs.

### 3. Detailed Request
> /ecc-foundation-models-on-device Design feature [scenario] using Apple FoundationModels for iOS 26+. Break it into availability checks, guided generation/@Generable, tool calling or snapshot streaming if needed, failure handling, and tests. Do not modify the project without approval; note platform limitations.
