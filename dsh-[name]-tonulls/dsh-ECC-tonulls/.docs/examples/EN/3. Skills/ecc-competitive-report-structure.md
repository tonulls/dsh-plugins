# `/ecc-competitive-report-structure`

Combines already evaluated competitor profiles into a decision-making report: market map, tiers, comparison matrix, open niches, and strategic conclusions.

## Simple Request

```text
/ecc-competitive-report-structure Turn these competitor profiles into a concise report for leadership.
```

## Template Request

```text
/ecc-competitive-report-structure
Report audience: [leadership/board]
Decision goal: [what needs to be decided]
Scored profiles: [paste data or identify available materials]
Create a market map, competitor tiers, comparison matrix, open niches, and recommendations; distinguish facts from conclusions.
```

## Detailed Request

```text
/ecc-competitive-report-structure Based on the supplied scored profiles, prepare a competitive report for [audience] to help decide [question]. 1) Check input completeness and explicitly list gaps. 2) Group competitors by tier and show a landscape map. 3) Summarize comparable dimensions in a matrix without guessing missing data. 4) Identify confirmed open niches and their limitations. 5) Provide justified strategic options and questions for team alignment. Do not gather new information from the web without approval or change source materials. Output a summary, tables, evidence-linked conclusions, and a list of unknowns.
```
