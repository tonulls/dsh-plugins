# ecc-frontend-a11y

**Command:** `/ecc-frontend-a11y`

**Purpose:** Accessibility practices for React and Next.js: semantic HTML, ARIA attributes, field labels, keyboard navigation, focus management, and screen-reader support. Use when building/reviewing forms, modals, dropdowns, tooltips, and tabs, fixing accessibility findings, or configuring keyboard and focus behavior.

## Prompts

### 1. Short Request
> /ecc-frontend-a11y Review the accessibility of this React form.

### 2. Template with Context
> /ecc-frontend-a11y Component: [path], elements: [form/modal/tabs]. Check semantics, labels, keyboard, focus, and screen reader; do not modify files.

### 3. Detailed Request
> /ecc-frontend-a11y Conduct a read-only audit of [component]. Check HTML/ARIA, field labels, keyboard order, focus management, and screen-reader behavior. Report defects by severity with exact locations and remediation checks; do not edit files.
