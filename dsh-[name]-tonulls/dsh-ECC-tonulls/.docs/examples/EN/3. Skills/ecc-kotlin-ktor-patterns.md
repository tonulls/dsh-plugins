# ecc-kotlin-ktor-patterns

**Command:** `/ecc-kotlin-ktor-patterns`

**Purpose:** Ktor server practices: DSL routing, plugins, authentication, Koin dependency injection, kotlinx.serialization, WebSockets, and testing with `testApplication`. Use when creating Ktor servers involving routing, plugins, auth, dependency injection, serialization, or tests.

## Prompts

### 1. Short Request
> /ecc-kotlin-ktor-patterns Design a Ktor route for [resource].

### 2. Template with Context
> /ecc-kotlin-ktor-patterns Service: [description], auth: [mechanism], format: [JSON/WebSocket]. Suggest routing DSL, plugins, and serialization consistent with project style.

### 3. Detailed Request
> /ecc-kotlin-ktor-patterns Design or review Ktor endpoint [purpose]. Phases: routing DSL, plugins, auth, Koin DI, kotlinx.serialization, errors, and testApplication tests. Follow existing patterns; do not modify files, install packages, or access the network. Return solution structure and verifiable test cases.
