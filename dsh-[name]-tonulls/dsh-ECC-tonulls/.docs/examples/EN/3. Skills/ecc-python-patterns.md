# `/ecc-python-patterns`

**Purpose:** Python idioms, PEP 8 standards, type annotations, and practices for reliable, efficient, maintainable applications. Use when writing or reviewing Python code where idiomatic structure, typing, or PEP 8 matter.

## Short Prompt
```text
/ecc-python-patterns Review this Python module for typing, idioms, and consistency with project style.
```

## Template Prompt
```text
/ecc-python-patterns
Context: [Python file path, version, purpose, and project conventions].
Task: review or design Python code for [target component/outcome].
Focus: PEP 8, type hints, Python idioms, readability, and robustness without imposing unused abstractions.
Constraints: Analysis only: do not modify files/data or run external/destructive checks.
Format: [brief result, evidence/rationale, risks, and next step].
```

## Detailed Prompt
```text
/ecc-python-patterns
Perform the task “review or design Python code” for [target system/scenario].
1. Clarify goal, scope, baseline information, and success criteria; list missing context.
2. Study only relevant materials and assess PEP 8, type hints, Python idioms, readability, and robustness without imposing unused abstractions.
3. State findings or options with facts, risks, verification criteria, and unresolved questions; apply nothing.
4. Check conclusions against criteria and cite evidence, assumptions, and unknowns.

Constraints: Analysis only: do not modify files/data or run external/destructive checks.
Use output format [expected format]. Do not invent facts; stop and request approval before any unplanned side effect.
```
