# ecc-homelab-network-setup

**Command:** `/ecc-homelab-network-setup`

**Purpose:** Practical planning for home networks and homelabs: gateways, switches, access points, IP ranges, DHCP reservations, DNS, cabling, and common beginner mistakes. Use when planning or configuring a home network or lab.

## Prompts

### 1. Short Request
> /ecc-homelab-network-setup Help plan a home network for [task].

### 2. Template with Context
> /ecc-homelab-network-setup Equipment: [gateway/switch/AP], devices: [number/types], IP range: [CIDR]. Suggest DHCP, DNS, and cabling without changing settings.

### 3. Detailed Request
> /ecc-homelab-network-setup Design a home network for [needs]. Clarify gateway, addressing, DHCP reservations, DNS, Wi-Fi/AP, and cabling; check for conflicts and common mistakes. Do not scan the network or apply configurations. Return a diagram, verification plan, and questions to resolve before implementation.
