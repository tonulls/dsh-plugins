# `/ecc-scientific-db-uspto-database`

Structures verifiable searches of official USPTO data: patent records, trademarks through TSDR, assignment records, and a reproducible IP research log.

## Simple Request
```text
/ecc-scientific-db-uspto-database Explain how to check trademark record [name] in official USPTO systems.
```

## Template Request
```text
/ecc-scientific-db-uspto-database
Search type: [patent/trademark/assignment]
Name or identifier: [data]
Scope and check date: [parameters]
Create an official-source search plan and a log of results to record; avoid unqualified legal conclusions.
```

## Detailed Request
```text
/ecc-scientific-db-uspto-database Prepare a reproducible check for [subject/identifiers]. Steps: clarify record type and spelling variants; identify appropriate official USPTO interfaces (PatentSearch, TSDR, assignment data, as applicable); formulate queries and fields to record; describe verification of identifier, status, dates, and related documents; note recency limitations and ambiguous matches. Do not file applications or change records. Make network requests only with my approval; do not disclose confidential information. The report must distinguish confirmed records from similar matches and provide links/check time, or honestly state that the search was not run.
```
