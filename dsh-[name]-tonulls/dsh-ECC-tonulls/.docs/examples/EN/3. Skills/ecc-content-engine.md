# `/ecc-content-engine`

Creates platform-native content systems: posts, threads, video scripts, calendars, and adaptations of source material for X, LinkedIn, TikTok, YouTube, and newsletters.

## Simple Request

```text
/ecc-content-engine Turn our feature launch announcement into a LinkedIn post and a short thread for X.
```

## Template Request

```text
/ecc-content-engine
Source material: [key points/link to supplied document]
Target audience: [who]
Goal: [inform/discuss/register]
Platforms and formats: [list]
Tone and brand constraints: [description]
Prepare distinct versions suited to each platform's format.
```

## Detailed Request

```text
/ecc-content-engine Develop a content system for [campaign/topic] based on [source material]. Audience: [segments], goal: [measurable outcome], period: [dates], platforms: [list], brand voice: [description/examples]. First identify confirmed key messages and gaps; then suggest content angles and a calendar; prepare separate native formats for each platform and rules for repackaging the source. Do not invent facts, metrics, or testimonials. Do not publish or send anything; do not use external sources without approval. Present the calendar, finished drafts, CTAs, and claims requiring verification.
```
