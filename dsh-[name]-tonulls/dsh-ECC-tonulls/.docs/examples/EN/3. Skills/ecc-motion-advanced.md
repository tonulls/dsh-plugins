# `/ecc-motion-advanced`

**Purpose:** Advanced Motion techniques for React/Next.js: drag, gestures, text animation, SVG path drawing, custom hooks, imperative sequences (`useAnimate`), loading indicators, and API selection. Requires `motion-foundations`. Use to implement these animations.

## Short Prompt
```text
/ecc-motion-advanced Suggest an implementation of a drag gesture and animation sequence for [component] using Motion.
```

## Template Prompt
```text
/ecc-motion-advanced
Context: [project path / snippet / system / symptom].
Task: design a complex Motion animation in React/Next.js for [goal or subject].
Focus: drag/gestures, useAnimate sequences, SVG/text animation, loading states, and selected API.
Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Output format: [brief conclusion, evidence, priorities, and next steps].
```
