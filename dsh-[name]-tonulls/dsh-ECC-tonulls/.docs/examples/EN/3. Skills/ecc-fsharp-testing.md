# ecc-fsharp-testing

**Command:** `/ecc-fsharp-testing`

**Purpose:** F# testing practices: xUnit, FsUnit, Unquote, property testing with FsCheck, and integration-test organization. Use when writing F# tests with xUnit, FsUnit, Unquote, or FsCheck.

## Prompts

### 1. Short Request
> /ecc-fsharp-testing Suggest tests for this F# function.

### 2. Template with Context
> /ecc-fsharp-testing Function: [name], behavior: [expected], project uses [xUnit/FsUnit/Unquote/FsCheck]. Suggest examples and properties.

### 3. Detailed Request
> /ecc-fsharp-testing Develop a test strategy for [module] in F#. Define unit/integration boundaries, xUnit/FsUnit/Unquote examples, and FsCheck properties; include edge cases. Do not run commands or modify files without approval; provide a case matrix and code examples.
