# ecc-growth-log

**Command:** `/ecc-growth-log`

**Purpose:** Keep a growth log by capturing reusable lessons from completed work—the root cause, transferable rule, and recognizable signal—instead of a diary-like recap. Use a 4–8 sentence template and merge duplicates. Apply after a complex task, debugging, failure, or rollback, during progress reviews, or when asked about lessons learned.

## Prompts

### 1. Short Request
> /ecc-growth-log Draft a growth-log entry for a completed task.

### 2. Template with Context
> /ecc-growth-log Task: [what happened], root cause: [if known], lesson: [observation]. Write 4–8 sentences covering cause, transferable rule, and recognizable signal; avoid a diary-style recap.

### 3. Detailed Request
> /ecc-growth-log Based on [task/incident], prepare a growth-log entry. First extract the evidenced root cause, then the generalizable rule and early-warning signal; check for duplicates in supplied notes. Do not record secrets or modify the log file without approval. Return ready-to-use text of 4–8 sentences.
