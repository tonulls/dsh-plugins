# `/ecc-production-scheduling`

**Purpose:** Production planning, sequencing, line balancing, changeover optimization, and bottleneck resolution for discrete and batch manufacturing, based on scheduler experience of 15+ years. Includes TOC/drum-buffer-rope, SMED, OEE analysis, disruption response, and ERP/MES interaction. Use for production scheduling and manufacturing problem-solving.

## Short Prompt
```text
/ecc-production-scheduling Create a shift schedule plan for [line/order], noting bottlenecks and changeovers.
```
