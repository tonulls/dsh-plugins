# `/ecc-benchmark-methodology`

Evaluates an agreed competitor set across nine weighted dimensions—positioning, voice, visual execution, offer packaging, evidence, enterprise readiness, thought leadership, pricing, and customer tensions. Produces evidence-backed scorecards rated 1–5 and a 2×2 tension map; follows competitor scoping and precedes report structuring.

## Prompt Examples

### 1. Short Request
```text
/ecc-benchmark-methodology Score competitors [list] against nine criteria. Provide evidence for every score; explicitly mark data gaps.
```

### 2. Template Request
```text
/ecc-benchmark-methodology Create comparable scorecards for [competitors/segment]. Use criteria for positioning, voice, visual execution, offer, evidence, enterprise readiness, thought leadership, pricing, and customer tensions. Sources: [materials]. Apply a 1–5 scale only with justification; do not fill gaps by guessing.
```

### 3. Detailed Request
```text
/ecc-benchmark-methodology Prepare an evidence-anchored benchmark of the [competitors] set already selected for analysis. 1) Check that the comparison covers comparable companies/products; flag questionable composition as a limitation and do not expand the set unilaterally. 2) Gather available evidence for each participant across nine dimensions: positioning, voice, visual craft, offer packaging, evidence, enterprise readiness, thought leadership, pricing, and customer tensions. 3) Score 1–5 using one rubric and tie every score to a specific source; mark unavailable data as unknown. 4) Build a 2×2 tension map and explain its axes. Format: competitor cards, comparison matrix, map, and methodological limitations; this is the evaluation stage, not a final strategic report.
```
