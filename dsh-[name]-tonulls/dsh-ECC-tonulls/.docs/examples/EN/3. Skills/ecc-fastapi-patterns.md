# ecc-fastapi-patterns

**Command:** `/ecc-fastapi-patterns`

**Purpose:** FastAPI practices: project structure, Pydantic v2 schemas, dependency injection, async handlers, authentication/authorization, transactional service layers, and tests with httpx and pytest. Use when creating or reviewing FastAPI apps, schemas, dependencies, async handlers, authentication, or tests.

## Prompts

### 1. Short Request
> /ecc-fastapi-patterns Review the structure of this FastAPI endpoint.

### 2. Template with Context
> /ecc-fastapi-patterns Endpoint: [path], task: [behavior], schemas: [description]. Assess Pydantic v2, DI, async, and testability; suggest changes without installing packages.

### 3. Detailed Request
> /ecc-fastapi-patterns Study [route/module] in FastAPI. In phases, check schemas, dependencies, async calls, authorization, and transaction layer; then suggest httpx/pytest tests. Modify files only after my approval. Provide evidence references and a plan.
