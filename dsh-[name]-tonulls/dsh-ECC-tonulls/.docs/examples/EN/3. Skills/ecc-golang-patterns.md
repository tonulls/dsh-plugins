# ecc-golang-patterns

**Command:** `/ecc-golang-patterns`

**Purpose:** Idiomatic Go practices and conventions for reliable, efficient, maintainable applications. Use when writing or reviewing Go code where idiomatic structure and conventions matter.

## Prompts

### 1. Short Request
> /ecc-golang-patterns Check whether this Go code is idiomatic.

### 2. Template with Context
> /ecc-golang-patterns Path: [file], context: [purpose]. Assess structure, error handling, interfaces, and readability without edits.

### 3. Detailed Request
> /ecc-golang-patterns Conduct a read-only review of Go module [path]. Check idiomatic structure, data ownership, errors, interfaces, and maintainability; distinguish issues from preferences and provide specific recommendations. Change nothing.
