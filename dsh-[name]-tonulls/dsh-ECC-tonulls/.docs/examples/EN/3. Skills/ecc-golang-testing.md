# ecc-golang-testing

**Command:** `/ecc-golang-testing`

**Purpose:** Go testing practices: table-driven tests, subtests, benchmarks, fuzzing, and coverage; TDD and idiomatic Go. Use when writing Go tests, benchmarks, fuzz tests, or checking coverage.

## Prompts

### 1. Short Request
> /ecc-golang-testing Suggest table-driven tests for [Go function].

### 2. Template with Context
> /ecc-golang-testing Package: [name], function: [signature], expected cases: [list]. Add subtests and suitable fuzz/benchmark ideas; do not run code.

### 3. Detailed Request
> /ecc-golang-testing Plan TDD tests for [package]: table of valid/invalid inputs, subtests, fuzzing and benchmarks where appropriate, and boundary coverage. Show test code and commands first; do not execute them or edit files without approval.
