# ecc-error-handling

**Command:** `/ecc-error-handling`

**Purpose:** Reliable error-handling practices in TypeScript, Python, and Go: typed errors, error boundaries, retries and circuit breakers, and user-friendly failure messages. Use when designing error types, retries, circuit breakers, or failure messages.

## Prompts

### 1. Short Request
> /ecc-error-handling Analyze error handling in this module.

### 2. Template with Context
> /ecc-error-handling Language: [TypeScript/Python/Go], module: [path], failure: [symptom]. Suggest typed handling and a clear user-facing message.

### 3. Detailed Request
> /ecc-error-handling Study errors in [path] for scenario [scenario]. Check error boundaries, retries, and circuit breakers; do not modify files. Provide prioritized findings, a safe plan, and examples.
