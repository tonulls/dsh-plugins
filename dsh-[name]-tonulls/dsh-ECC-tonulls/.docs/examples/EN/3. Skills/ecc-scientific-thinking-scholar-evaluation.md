# `/ecc-scientific-thinking-scholar-evaluation`

Evaluates scientific papers, proposals, reviews, and methodology sections against a repeatable rubric, focusing on evidence quality and citation support.

## Simple Request
```text
/ecc-scientific-thinking-scholar-evaluation Evaluate the methodology of this study for strengths and limitations: [text]
```
## Template Request
```text
/ecc-scientific-thinking-scholar-evaluation
Material: [paper/proposal/section]
Purpose and field: [context]
Criteria/rubric: [if available]
Assess the soundness of methods, evidence, and citations; do not attribute information absent from the material.
```
## Detailed Request
```text
/ecc-scientific-thinking-scholar-evaluation Conduct a structured evaluation of the supplied [type of scholarly work] for [purpose]. 1) Briefly reconstruct the question, stated conclusions, and design. 2) Assess methodology, sample/data, analysis, reproducibility, and limitations using the specified rubric. 3) Match each significant claim to its supporting evidence; identify citations that cannot be verified from the supplied material. 4) Separate critical concerns from improvement recommendations. Do not modify the document, add fabricated citations, or present this as expert peer review. Result: scores with rationale, strengths, priority risks, questions for the author, and evaluation boundaries.
```
