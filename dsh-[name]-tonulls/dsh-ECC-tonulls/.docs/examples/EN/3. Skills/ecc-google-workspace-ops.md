# ecc-google-workspace-ops

**Command:** `/ecc-google-workspace-ops`

**Purpose:** Work with Google Drive, Docs, Sheets, and Slides as one environment for plans, trackers, presentations, and shared documents. Use for searching, summarizing, editing, moving, and cleaning Google Workspace without low-level tool calls.

## Prompts

### 1. Short Request
> /ecc-google-workspace-ops Find documents about [topic] and briefly summarize them.

### 2. Template with Context
> /ecc-google-workspace-ops Goal: [search/summarize/edit], folder: [name], document: [name]. For any changes, prepare a draft and request approval before applying them.

### 3. Detailed Request
> /ecc-google-workspace-ops Help with Google Workspace task [description] in [Drive/Docs/Sheets/Slides]. First identify needed materials and suggest a plan. Do not delete, move, share, or modify documents without precise approval; report what was found and proposed edits.
