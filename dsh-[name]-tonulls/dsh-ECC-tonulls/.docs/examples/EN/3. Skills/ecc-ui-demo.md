# `/ecc-ui-demo`

Creates a video demonstration of a web application using Playwright: WebM recording with visible cursor, smooth pacing, and walkthrough/tutorial styling.

## Simple Request
```text
/ecc-ui-demo Prepare a demo script for interface [page/feature]; do not record anything without my approval.
```
## Template Request
```text
/ecc-ui-demo
Application and authorized address: [local environment/URL]
Scenario and audience: [steps]
Window/resolution: [values]
Suggest a WebM recording plan using available Playwright; do not log into real accounts or submit data.
```
## Detailed Request
```text
/ecc-ui-demo I need a demonstration of [feature] for [audience]. First agree on the scenario, authorized environment, and test data; then list safe browser steps, cursor/pause points, and criteria for a finished WebM video. Do not install Playwright or access the network without approval; do not use real credentials, submit forms/emails/payments, or modify server data. Begin recording or interacting with the interface only after separate approval. Report: actual scenario coverage, output path, limitations, and any skipped steps.
```
