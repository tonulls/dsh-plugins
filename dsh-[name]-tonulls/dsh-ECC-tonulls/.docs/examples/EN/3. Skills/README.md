# ECC Skills Examples

This section contains examples for all 236 skills in the [skills package](../../../../packages/skills/README.md). In a regular DSH message, enter `/ecc-component-name`, then describe the task and constraints. The skill is explicitly loaded into the current DSH Agent and runs in the context of the current project.

Only entries from the catalog's `entries` are listed; each component has a separate file with three prompt levels.
