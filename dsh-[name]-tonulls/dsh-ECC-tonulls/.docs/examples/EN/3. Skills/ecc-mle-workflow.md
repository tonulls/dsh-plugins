# `/ecc-mle-workflow`

**Purpose:** Develops and operates ML systems: data contracts, reproducible training, model evaluation, deployment, monitoring, and rollback. Use when building, reviewing, or strengthening ML systems beyond one-off notebooks.

## Short Prompt
```text
/ecc-mle-workflow Design a reproducible workflow for a [type] model, from data and training through evaluation and monitoring.
```

## Template Prompt
```text
/ecc-mle-workflow
Context: [project path / snippet / system / symptom].
Task: design a reproducible ML system development and operations cycle for [goal or subject].
Focus: data contracts, reproducible training, evaluation, deployment plan, monitoring, and rollback.
Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Output format: [brief conclusion, evidence, priorities, and next steps].
```

## Detailed Prompt
```text
/ecc-mle-workflow
Perform the task “design a reproducible ML system development and operations cycle” for [project/component/scenario].
1. Record baseline information, scope, and success criteria; list missing information.
2. Study only relevant context and assess data contracts, reproducible training, evaluation, deployment plan, monitoring, and rollback.
3. Form conclusions and next steps without applying changes or presenting assumptions as facts.
4. Compare results with criteria, cite evidence, and distinguish confirmed conclusions from assumptions.

Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Include outcome, important findings/actions, unverified areas, risks, and safe next steps.
```
