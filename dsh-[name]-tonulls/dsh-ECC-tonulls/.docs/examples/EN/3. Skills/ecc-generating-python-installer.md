# ecc-generating-python-installer

**Command:** `/ecc-generating-python-installer`

**Purpose:** Create commercial Python installers for Windows: extreme Nuitka compilation, dist-size reduction, DLL footprint analysis, and Inno Setup packaging for the smallest, fastest installers. Use when releasing a Python application as a minimal, fast-starting Windows installer; not for simply converting a script to an exe. Triggers: extreme Nuitka optimization, commercial Python packaging, extreme Python compilation, dist reduction, DLL analysis, minimal installer, fast startup, commercial-grade packaging.

## Prompts

### 1. Short Request
> /ecc-generating-python-installer Assess a plan for a minimal Windows installer for a Python application.

### 2. Template with Context
> /ecc-generating-python-installer Application: [description], target Windows versions: [versions], size/startup constraints: [values]. Consider Nuitka, DLLs, and Inno Setup; do not install tools.

### 3. Detailed Request
> /ecc-generating-python-installer Create a packaging plan for [application] as a compact Windows installer using Nuitka and Inno Setup. Step by step, assess dependencies/DLLs, dist size, startup time, and result verification. Do not run builds, install packages, or download anything without my approval. Return measurable criteria and risks.
