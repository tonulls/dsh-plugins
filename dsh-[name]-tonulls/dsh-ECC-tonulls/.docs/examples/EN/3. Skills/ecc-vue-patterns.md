# `/ecc-vue-patterns`

Suggests Vue 3 and Nuxt practices: Composition API, component architecture, reactivity, Pinia, Vue Router, and SSR.

## Simple Request
```text
/ecc-vue-patterns Suggest a Composition API component for [scenario] with correct state management.
```
## Template Request
```text
/ecc-vue-patterns
Stack and versions: [Vue/Nuxt/Pinia]
Component or issue: [description]
Code/constraints: [snippets]
Suggest an idiomatic approach to reactivity, state, and routing suited to the current project.
```
## Detailed Request
```text
/ecc-vue-patterns Design/review [feature] in Vue 3/Nuxt [versions]. 1) Define component boundaries and state ownership. 2) Check correct use of Composition API and reactivity, including side effects. 3) Justify whether Pinia is needed or local state is sufficient. 4) Analyze routing, SSR/hydration, and performance as applicable. 5) Suggest testable scenarios. Do not modify files, install packages, access the network, or publish changes without explicit approval. Result: recommended structure/sketch, risks, assumptions, and verification plan.
```
