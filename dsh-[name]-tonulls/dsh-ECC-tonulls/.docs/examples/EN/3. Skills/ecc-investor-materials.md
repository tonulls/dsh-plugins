# ecc-investor-materials

**Command:** `/ecc-investor-materials`

**Purpose:** Create and update pitch decks, one-pagers, investor memos, accelerator applications, financial models, and fundraising materials. Use for investor documents, forecasts, use-of-funds tables, milestone plans, and consistency across fundraising materials.

## Prompts

### 1. Short Request
> /ecc-investor-materials Review the consistency of an investor one-pager.

### 2. Template with Context
> /ecc-investor-materials Stage: [stage], market: [description], metrics: [data], target document: [type]. Do not invent figures; mark gaps.

### 3. Detailed Request
> /ecc-investor-materials Prepare/reconcile [pitch deck/memo/model] for [round]. Compare metrics, use of funds, milestones, and claims across materials; mark all unsubstantiated values as placeholders. Do not send or publish materials. First suggest a structure and list required confirmations, then produce a consistent draft.
