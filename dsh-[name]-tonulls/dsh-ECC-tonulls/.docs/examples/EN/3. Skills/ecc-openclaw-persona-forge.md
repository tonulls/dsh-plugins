# `/ecc-openclaw-persona-forge`

Creates an OpenClaw agent persona concept: identity, `SOUL.md` draft, role boundaries, name, and text prompt for an avatar. An image is generated only when an authorized generation tool is available.

## Simple Request

```text
/ecc-openclaw-persona-forge Invent a friendly OpenClaw assistant for a home library.
```

## Template Request

```text
/ecc-openclaw-persona-forge Create an OpenClaw persona: agent purpose — [purpose], audience — [who interacts], desired tone — [tone], important constraints — [boundaries]. Prepare identity, SOUL.md, a name, and an avatar text prompt. Do not create files or images without my separate approval.
```

## Detailed Request

```text
/ecc-openclaw-persona-forge Develop an OpenClaw character for [scenario].
1. Clarify missing preferences; do not invent facts about the owner.
2. Suggest positioning, character, and name.
3. Prepare a SOUL.md draft with role and explicit behavioral boundaries.
4. Formulate a separate text prompt for an avatar, following one consistent visual concept.
5. Present everything for review. Do not modify existing files, generate an image, or connect external services without my explicit approval.
List assumptions and questions at the end.
```
