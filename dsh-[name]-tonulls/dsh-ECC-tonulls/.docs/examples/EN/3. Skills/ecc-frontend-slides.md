# ecc-frontend-slides

**Command:** `/ecc-frontend-slides`

**Purpose:** Create expressive animated HTML presentations from scratch or convert PowerPoint files. Use for presentations, PPT/PPTX-to-web conversion, talks, and project demos. Helps people without design experience choose a visual style based on research rather than arbitrary selection.

## Prompts

### 1. Short Request
> /ecc-frontend-slides Create a plan for an HTML presentation about [topic].

### 2. Template with Context
> /ecc-frontend-slides Audience: [who], goal: [goal], duration: [minutes], source PPTX: [path/none]. Suggest a visual concept and slide structure.

### 3. Detailed Request
> /ecc-frontend-slides Prepare a presentation on [topic] for [audience]. First suggest a concept and storyboard, then content for each slide and animation accents; state assumptions if PPTX conversion is needed. Do not create or convert files without approval. Present the plan and list missing materials.
