# `/ecc-seo`

Plans and reviews search visibility improvements: technical SEO, page optimization, structured data, Core Web Vitals, and topic maps.

## Simple Request
```text
/ecc-seo Conduct a read-only SEO audit of page [URL or text] and prioritize improvements.
```
## Template Request
```text
/ecc-seo
Website/pages: [URLs or local files]
Goal and audience: [description]
Region/language: [values]
Constraints: [technical/editorial]
Suggest verifiable improvements and explain expected impact; do not publish anything.
```
## Detailed Request
```text
/ecc-seo Assess SEO for [pages/site] with goal [goal], audience [description], market [region]. Steps: technical accessibility and indexability based on available data; structure and on-page relevance; schema/sitemap/robots correctness based on supplied context; Core Web Vitals if measurements exist; topic query map without inventing search volumes. Separate substantiated observations from hypotheses and prioritize findings by effort and verification method. Audit and recommendations only: do not change files, DNS, site metadata, or publish. Do not scan external sites or access the network without explicit approval. Result: findings, evidence, plan, and success metrics.
```
