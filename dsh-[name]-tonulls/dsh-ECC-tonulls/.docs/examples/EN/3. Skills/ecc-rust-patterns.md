# `/ecc-rust-patterns`

Suggests idiomatic and safe Rust approaches: ownership and borrowing, error handling, traits, and concurrency.

## Simple Request
```text
/ecc-rust-patterns Review this Rust snippet for ownership issues and idiomatic style: [code]
```

## Template Request
```text
/ecc-rust-patterns
Task: [what to implement]
Context and Rust version: [data]
Snippet/constraints: [code, interfaces]
Suggest a safe approach, explaining ownership, errors, and trade-offs. Do not add dependencies without my approval.
```

## Detailed Request
```text
/ecc-rust-patterns Implement [feature description] in Rust [version/context]. 1) Study the supplied code and contracts. 2) Determine ownership model and mutability boundaries. 3) Suggest idiomatic type, error, and trait design. 4) Consider concurrency and performance only where significant. 5) Show a solution and testable edge cases. Do not modify files, install packages, or access the network. Before any changes, present a plan and request approval. Report assumptions, security risks, and rationale for the design.
```
