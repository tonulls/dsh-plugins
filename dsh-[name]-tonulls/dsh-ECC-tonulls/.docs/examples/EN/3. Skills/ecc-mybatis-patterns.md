# `/ecc-mybatis-patterns`

**Purpose:** MyBatis and MyBatis-Spring practices: mapper design, SQL in XML and annotations, result mapping, dynamic-query security, transactions, batch processing, pagination, and query performance. Use for developing or reviewing Java data access with MyBatis, Spring Boot, or legacy MyBatis applications.

## Short Prompt
```text
/ecc-mybatis-patterns Review this MyBatis mapper and related SQL for security, transactions, and performance.
```
