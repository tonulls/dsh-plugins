# `/ecc-perl-testing`

**Purpose:** Perl testing practices with Test2::V0, Test::More, prove, mocks, Devel::Cover coverage, and TDD methodology. Use when writing tests or measuring coverage.

## Short Prompt
```text
/ecc-perl-testing Write tests for Perl function [name] using [Test2::V0/Test::More], including edge cases.
```

## Template Prompt
```text
/ecc-perl-testing
Context: [function/module, expected behavior, chosen test framework, and existing tests].
Task: design Perl tests with Test2::V0 or Test::More for [target component/outcome].
Focus: table-driven cases, fixtures, mocks, negative scenarios, and justified coverage.
Constraints: Prepare a test plan/examples in repository style; do not run commands or install dependencies without approval.
Format: [brief result, evidence/rationale, risks, and next step].
```

## Detailed Prompt
```text
/ecc-perl-testing
Perform the task “design Perl tests with Test2::V0 or Test::More” for [target system/scenario].
1. Clarify goal, scope, baseline information, and success criteria; list missing context.
2. Study only relevant materials and assess table-driven cases, fixtures, mocks, negative scenarios, and justified coverage.
3. Form a test suite or code sketch using only the stack already in the project; distinguish proposed checks from those actually run.
4. Check conclusions against criteria and cite evidence, assumptions, and unknowns.

Constraints: Prepare a test plan/examples in repository style; do not run commands or install dependencies without approval.
Use output format [expected format]. Do not invent facts; stop and request approval before any unplanned side effect.
```
