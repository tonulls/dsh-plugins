# `/ecc-scientific-thinking-literature-review`

Helps conduct a systematic review of scientific and technical literature: search plan, source selection, synthesis, citation verification, and evidence log.

## Simple Request
```text
/ecc-scientific-thinking-literature-review Create a literature review plan on [topic] with selection criteria.
```
## Template Request
```text
/ecc-scientific-thinking-literature-review
Research question: [question]
Fields/dates/languages: [scope]
Publication types: [criteria]
Suggest a search, screening, and synthesis strategy; distinguish the plan from sources actually found.
```
## Detailed Request
```text
/ecc-scientific-thinking-literature-review Prepare a reproducible review of question [question]. Steps: 1) define scope, terms, and inclusion/exclusion criteria; 2) formulate searches for suitable databases and a search-registration plan; 3) describe deduplication and title/abstract/full-text screening; 4) define extracted fields and evidence-quality assessment; 5) suggest synthesis and citation-verification methods. Do not invent sources or results, or present a plan as a completed search. Use the network only with approval; a review is not a substitute for medical decisions. Result: protocol, evidence table, limitations, and list of verified links/identifiers—or a note that no search was performed.
```
