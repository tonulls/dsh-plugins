# ecc-frontend-patterns

**Command:** `/ecc-frontend-patterns`

**Purpose:** Frontend development practices for React and Next.js: state management, performance, and UI. Use when creating or reviewing React/Next.js components, state, and rendering speed.

## Prompts

### 1. Short Request
> /ecc-frontend-patterns Suggest improvements to this React component.

### 2. Template with Context
> /ecc-frontend-patterns Component: [path], issue: [state/rendering/performance]. Follow existing project patterns and do not add dependencies.

### 3. Detailed Request
> /ecc-frontend-patterns Study [component/page] in project context. Identify state boundaries, updates, and expensive renders; suggest a minimal-change approach, then tests/verification. Show a plan first; do not modify files before my approval.
