# `/ecc-article-writing`

Creates in-depth articles, guides, educational materials, newsletters, and other long-form content in a distinct authorial voice based on supplied examples or a brand guide.

## Prompt Examples

### 1. Short Request
```text
/ecc-article-writing Write an article about [topic] for [audience] in the tone of the attached example; do not add unverified facts.
```

### 2. Template Request
```text
/ecc-article-writing Prepare [content type] about [topic] for [audience]. Goal: [goal], length: [approximate], key points: [list], sources/voice examples: [materials]. Preserve the sources' style without copying their wording; flag disputed facts.
```

### 3. Detailed Request
```text
/ecc-article-writing Create a [guide/article/newsletter email] about [topic] for [audience] with goal [goal]. 1) Study the provided examples or brand guidance and briefly derive voice characteristics: tone, rhythm, vocabulary, and techniques to avoid. 2) Create an outline with a clear thesis and logical sections. 3) Write a cohesive piece of [range] using only facts from [source materials]; do not present unknowns as facts. 4) Check fit for the audience, voice, and goal; remove clichés and repetition. Format: headline, lead, sections, conclusion; after the text, list claims that need verification.
```
