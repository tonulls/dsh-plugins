# ecc-healthcare-emr-patterns

**Command:** `/ecc-healthcare-emr-patterns`

**Purpose:** EMR/EHR development practices for healthcare applications: clinical safety, intake workflows, prescription creation, CDSS integration, and accessible interfaces for entering medical data. Use when creating EMR/EHR features such as intake, prescriptions, and clinical data entry.

## Prompts

### 1. Short Request
> /ecc-healthcare-emr-patterns Sketch a safe workflow for entering a medical record.

### 2. Template with Context
> /ecc-healthcare-emr-patterns EMR/EHR feature: [description], user: [role], data: [categories]. Account for clinical safety, accessibility, and human review.

### 3. Detailed Request
> /ecc-healthcare-emr-patterns Design EMR/EHR scenario [scenario]: encounter stages, record validation, interface accessibility, and CDSS integration if needed. Do not use real patient data; specify audit requirements and clinician sign-off. Return workflow, safety invariants, and test scenarios.
