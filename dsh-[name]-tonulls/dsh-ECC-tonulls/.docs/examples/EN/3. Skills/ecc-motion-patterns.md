# `/ecc-motion-patterns`

**Purpose:** Production-ready React/Next.js animations: buttons, modals, toasts, stagger effects, page transitions, exit animations, scroll, and layout. Uses tokens and springs from `motion-foundations`. Use to animate specific interface elements.

## Short Prompt
```text
/ecc-motion-patterns Design an accessible animation for a [button/modal/transition] in React/Next.js.
```

## Template Prompt
```text
/ecc-motion-patterns
Context: [project path / snippet / system / symptom].
Task: prepare a production-ready UI animation pattern for [goal or subject].
Focus: button/modal/toast/page transitions, shared motion tokens, exit behavior, and accessibility.
Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Output format: [brief conclusion, evidence, priorities, and next steps].
```

## Detailed Prompt
```text
/ecc-motion-patterns
Perform the task “prepare a production-ready UI animation pattern” for [project/component/scenario].
1. Record baseline information, scope, and success criteria; list missing information.
2. Study only relevant context and assess button/modal/toast/page transitions, shared motion tokens, exit behavior, and accessibility.
3. Form conclusions and next steps without applying changes or presenting assumptions as facts.
4. Compare results with criteria, cite evidence, and distinguish confirmed conclusions from assumptions.

Constraints: Provide recommendations; do not apply changes, send messages, or publish.
Include outcome, important findings/actions, unverified areas, risks, and safe next steps.
```
