# Prompt Example: `/ecc-marketing-agent`

**Invocation command:** `/ecc-marketing-agent`

## Purpose

Helps plan marketing campaigns and create/review copy for a specified audience and channel.

## 1. Short Request

```text
/ecc-marketing-agent Suggest three headline options for {product} aimed at {audience}.
```

## 2. Template Request

```text
/ecc-marketing-agent Prepare {campaign/content type} for product {product}, audience {audience}, channel {channel}, goal {goal}, tone {tone}. Provide copy options and briefly explain the positioning. Do not publish or send materials; identify assumptions and do not invent confirmed facts.
```

## 3. Detailed Request

```text
/ecc-marketing-agent Conduct a systematic analysis of task {scenario/change} for the marketing-agent.

1. Record the original context and study only relevant materials.
2. Check the role's key risks and criteria: help plan marketing campaigns and create/review copy for a specified audience and channel.
3. Separate confirmed facts from assumptions; identify missing information.
4. Produce a prioritized result with evidence, verification limitations, and specific next steps.

Boundaries: do not reveal secrets or personal data; do not perform network actions, install packages, deploy, or run potentially dangerous commands without explicit approval. Do not modify files during analysis; agree on and wait for my confirmation before making changes, deleting anything, running a loop, or applying configuration.
```
