# ECC Command Examples

This section contains examples for the three commands in the [commands package](../../../../packages/commands/README.md). In a regular DSH message, enter `/ecc-component-name`, then describe the task and constraints. The command provides instructions to the current DSH Agent.

Only entries from the catalog's `entries` are listed; each component has a separate file with three prompt levels.

| Component | Purpose | Prompt examples |
| --- | --- | --- |
| `/ecc-command-build-fix` | Identify the project's build system, diagnose build/type errors step by step, and fix them with minimal safe changes. | [Three prompts](ecc-command-build-fix.md) |
| `/ecc-command-test-coverage` | Analyze test coverage, identify gaps, and add missing tests to reach a specified threshold. | [Three prompts](ecc-command-test-coverage.md) |
| `/ecc-command-update-docs` | Synchronize documentation with sources of truth such as scripts, schemas, routes, and exported interfaces. | [Three prompts](ecc-command-update-docs.md) |

**Total:** 3 entries; missing example files: 0.
