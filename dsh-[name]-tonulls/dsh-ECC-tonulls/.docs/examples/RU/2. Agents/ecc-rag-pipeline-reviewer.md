# Пример промта: `/ecc-rag-pipeline-reviewer`

**Команда вызова:** `/ecc-rag-pipeline-reviewer`

## Назначение

Проверяет RAG-конвейер: качество retrieval, стратегию chunking, embeddings и достаточность оценки. Только анализ.

## 1. Короткий запрос

```text
/ecc-rag-pipeline-reviewer Оцени retrieval-качество RAG по описанию {конвейер} и данным {метрики}; ничего не меняй.
```

## 2. Шаблонный запрос

```text
/ecc-rag-pipeline-reviewer Оцени RAG-систему {описание/дифф} для запросов {тип запросов}; корпус и метрики {данные}. Проверь разбиение, retrieval/reranking, embeddings и eval-набор на репрезентативность. Не обращайся к внешней сети и не меняй код/индекс; укажи доказательства, пробелы и приоритетные эксперименты.
```

## 3. Подробный запрос

```text
/ecc-rag-pipeline-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для rag-pipeline-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: качество retrieval, стратегию chunking, embeddings и достаточность оценки. Только анализ.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
