# Пример промта: `/ecc-performance-optimizer`

**Команда вызова:** `/ecc-performance-optimizer`

## Назначение

Ищет узкие места производительности, включая алгоритмы, память, рендеринг и размер bundle, и предлагает оптимизации.

## 1. Короткий запрос

```text
/ecc-performance-optimizer Найди вероятное узкое место в сценарии {сценарий} по метрикам {данные}.
```

## 2. Шаблонный запрос

```text
/ecc-performance-optimizer Изучи медленный сценарий {сценарий} в {компонент}, ожидаемое и текущее время {метрики}. Сначала установи вероятное узкое место по имеющимся данным, предложи измеримый план и варианты оптимизации с риском регрессии. Не меняй файлы и не запускай тяжёлое профилирование без подтверждения.
```

## 3. Подробный запрос

```text
/ecc-performance-optimizer Проведи последовательный анализ задачи {сценарий/изменение} для performance-optimizer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Ищет узкие места производительности, включая алгоритмы, память, рендеринг и размер bundle, и предлагает оптимизации.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
