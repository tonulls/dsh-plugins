# Пример промта: `/ecc-ruby-reviewer`

**Команда вызова:** `/ecc-ruby-reviewer`

## Назначение

Проверяет Ruby/Rails-код на идиоматичность, безопасность Active Record, Rails security defaults и качество RSpec/Minitest. Только review.

## 1. Короткий запрос

```text
/ecc-ruby-reviewer Проведи read-only review Ruby/Rails-изменений {путь}.
```

## 2. Шаблонный запрос

```text
/ecc-ruby-reviewer Проведи read-only review {пути/дифф} Ruby/Rails для {сценарий}. Проверь Active Record на безопасные запросы и N+1, Rails-защиты, обработку ошибок и релевантные тесты. Укажи уверенные дефекты с файлом/строкой и рекомендацией; не меняй код.
```

## 3. Подробный запрос

```text
/ecc-ruby-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для ruby-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет Ruby/Rails-код на идиоматичность, безопасность Active Record, Rails security defaults и качество RSpec/Minitest. Только review.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
