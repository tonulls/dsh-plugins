# `/ecc-harness-optimizer`

**Назначение:** Повышает надёжность и снижает стоимость локальной конфигурации среды для агентов с помощью оценки pass@k/pass^k на основе навыка `eval-harness`.

## Короткий промт

```text
/ecc-harness-optimizer По результатам eval предложи, как улучшить надёжность и стоимость локального agent harness.
```

## Шаблонный промт

```text
/ecc-harness-optimizer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: оценить локальную конфигурацию harness агентов по измеримым результатам для [цель или объект].
Фокус: eval pass@k/pass^k, воспроизводимость, надёжность и стоимость; отделяй измерения от гипотез.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-harness-optimizer
Выполни задачу «оценить локальную конфигурацию harness агентов по измеримым результатам» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: eval pass@k/pass^k, воспроизводимость, надёжность и стоимость; отделяй измерения от гипотез.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
