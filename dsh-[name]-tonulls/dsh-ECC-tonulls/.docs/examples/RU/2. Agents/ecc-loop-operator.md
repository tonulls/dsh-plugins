# Пример промта: `/ecc-loop-operator`

**Команда вызова:** `/ecc-loop-operator`

## Назначение

Помогает безопасно наблюдать за автономным циклом агентов, находить остановки и повторные сбои, определять условия паузы и восстановления.

## 1. Короткий запрос

```text
/ecc-loop-operator Оцени, не остановился ли безопасно цикл {идентификатор}, по имеющимся checkpoint.
```

## 2. Шаблонный запрос

```text
/ecc-loop-operator Оцени состояние цикла {название/идентификатор} по доступным журналам и контрольным точкам. Без запуска, остановки или изменения цикла укажи прогресс, признаки застоя, бюджет/повторы, quality gates, baseline и rollback; предложи безопасное следующее действие.
```

## 3. Подробный запрос

```text
/ecc-loop-operator Проведи последовательный анализ задачи {сценарий/изменение} для loop-operator.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Помогает безопасно наблюдать за автономным циклом агентов, находить остановки и повторные сбои, определять условия паузы и восстановления.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
