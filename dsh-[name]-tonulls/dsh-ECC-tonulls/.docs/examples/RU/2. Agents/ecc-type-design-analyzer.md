# Пример промта: `/ecc-type-design-analyzer`

**Команда вызова:** `/ecc-type-design-analyzer`

## Назначение

Анализирует дизайн типов: инкапсуляцию, выражение инвариантов, практическую полезность и их принудительное соблюдение.

## 1. Короткий запрос

```text
/ecc-type-design-analyzer Проанализируй инварианты типов в {путь}; не изменяй код.
```

## 2. Шаблонный запрос

```text
/ecc-type-design-analyzer Оцени типы {файлы/фрагмент} в предметной области {контекст}. Для каждого ключевого типа проверь, какие недопустимые состояния он допускает, выражены ли инварианты в API и кто может нарушить их. Предложи альтернативы с компромиссами; код не меняй.
```

## 3. Подробный запрос

```text
/ecc-type-design-analyzer Проведи последовательный анализ задачи {сценарий/изменение} для type-design-analyzer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: инкапсуляцию, выражение инвариантов, практическую полезность и их принудительное соблюдение.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
