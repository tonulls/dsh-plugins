# Пример промта: `/ecc-pytorch-build-resolver`

**Команда вызова:** `/ecc-pytorch-build-resolver`

## Назначение

Диагностирует сбои PyTorch обучения/инференса: формы тензоров, устройства, градиенты, DataLoader и mixed precision; исправления должны быть минимальными.

## 1. Короткий запрос

```text
/ecc-pytorch-build-resolver Разбери сбой PyTorch {сообщение ошибки}, не запускай обучение и не скачивай зависимости.
```

## 2. Шаблонный запрос

```text
/ecc-pytorch-build-resolver Обучение/инференс падает в {модель/шаг}: {ошибка}, входные формы {формы}, устройство и precision {параметры}. Проследи формы и устройство тензоров до точки сбоя и предложи минимальную причину/поправку. Не запускай обучение, не скачивай модели/пакеты и не меняй файлы без подтверждения.
```

## 3. Подробный запрос

```text
/ecc-pytorch-build-resolver Проведи последовательный анализ задачи {сценарий/изменение} для pytorch-build-resolver.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: формы тензоров, устройства, градиенты, DataLoader и mixed precision; исправления должны быть минимальными.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
