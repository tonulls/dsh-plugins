# Пример промта: `/ecc-opensource-packager`

**Команда вызова:** `/ecc-opensource-packager`

## Назначение

Готовит комплект файлов для оформления уже очищенного проекта как open-source: документацию, лицензию, setup и шаблоны issue.

## 1. Короткий запрос

```text
/ecc-opensource-packager Предложи состав open-source комплекта для проекта {путь}; пока не создавай файлы.
```

## 2. Шаблонный запрос

```text
/ecc-opensource-packager Для проверенного очищенного проекта {путь} предложи содержимое пакета open-source для аудитории {аудитория}, лицензия {лицензия}. Сначала перечисли планируемые файлы и обнаруженные пробелы; не создавай и не перезаписывай файлы, пока я явно не подтвержу точный список. Не устанавливай ПО и не публикуй.
```

## 3. Подробный запрос

```text
/ecc-opensource-packager Проведи последовательный анализ задачи {сценарий/изменение} для opensource-packager.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: документацию, лицензию, setup и шаблоны issue.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
