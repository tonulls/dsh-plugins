# `/ecc-fsharp-reviewer` — примеры промтов

## Назначение

Экспертно проверяет F# на функциональные идиомы, безопасность типов, pattern matching, computation expressions и производительность.

## Короткий запрос

```text
/ecc-fsharp-reviewer Проверь {файл/diff} на дефекты F#: типы, pattern matching, вычислительные выражения и производительность. Ничего не меняй.
```

## Шаблонный запрос

```text
/ecc-fsharp-reviewer Проведи read-only ревью {модуль/изменение} в {путь}. Проверь выражение инвариантов типами, полноту сопоставлений с образцом, корректность computation expressions, идиоматичность и значимые узкие места. Укажи подтверждённые находки с местом, последствием и рекомендацией.
```

## Подробный запрос

```text
/ecc-fsharp-reviewer Проанализируй изменение {описание} в F#-проекте {путь}, с учётом назначения {контекст}.
1. Проследи преобразования данных и проверь, насколько типы и конструкции ограничивают недопустимые состояния.
2. Проверь pattern matching на неполные или неверные ветви и корректность обработки ошибок.
3. Рассмотри computation expressions и побочные эффекты в контексте используемого кода, не предполагая неизвестной семантики.
4. Отмечай производительность только при конкретном основании; отделяй риск от стилевого предпочтения.

Формат: находки по серьёзности (файл/строка, сценарий, эффект, рекомендация), затем проверенные области и неизвестные факты. Только анализ: не редактируй исходники и не устанавливай пакеты, не обращайся к сети и не выполняй деплой без согласия.
```
