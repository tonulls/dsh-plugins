# `/ecc-django-build-resolver`

**Назначение:** Диагностирует и минимально исправляет ошибки pip/Poetry, конфликты миграций, импорта и конфигурации Django, а также сбои `collectstatic`. Используйте при ошибках настройки или запуска Django.

## Короткий промт

```text
/ecc-django-build-resolver Разбери ошибку запуска Django и внеси минимальное исправление в указанной области. Не устанавливай зависимости.
```

## Шаблонный промт

```text

Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: диагностировать и минимально устранить сбой настройки или запуска Django для [цель или объект].
Фокус: ошибки pip/Poetry, импорта, конфигурации, миграций и collectstatic.
Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```
