# `/ecc-conversation-analyzer`

**Назначение:** Анализирует расшифровки диалогов и выявляет поведение, которое следует предотвращать хуками. Вызывается командой `/hookify` без аргументов.

## Короткий промт

```text
/ecc-conversation-analyzer Проанализируй эту расшифровку и выдели повторяющееся поведение, которое можно предотвращать хуком. Сам hook не создавай.
```

## Шаблонный промт

```text
/ecc-conversation-analyzer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: найти повторяющиеся модели поведения в расшифровке диалога и оценить, стоит ли предотвращать их хуком для [цель или объект].
Фокус: наблюдаемые фрагменты, повторяемость, ложные срабатывания и минимальное условие для будущего hook.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-conversation-analyzer
Выполни задачу «найти повторяющиеся модели поведения в расшифровке диалога и оценить, стоит ли предотвращать их хуком» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: наблюдаемые фрагменты, повторяемость, ложные срабатывания и минимальное условие для будущего hook.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
