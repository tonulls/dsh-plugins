# Пример промта: `/ecc-swift-reviewer`

**Команда вызова:** `/ecc-swift-reviewer`

## Назначение

Проверяет Swift-код на protocol-oriented design, value semantics, ARC, Swift Concurrency и идиоматичность. Не меняет файлы.

## 1. Короткий запрос

```text
/ecc-swift-reviewer Проведи read-only review Swift-изменений {путь}.
```

## 2. Шаблонный запрос

```text
/ecc-swift-reviewer Сделай read-only review изменений {файлы/дифф} Swift в контексте {сценарий}. Проверь value/reference semantics, циклы ARC, конкурентность и изоляцию акторов, API-дизайн и обработку ошибок. Укажи только конкретные находки с местом, влиянием и рекомендацией.
```

## 3. Подробный запрос

```text
/ecc-swift-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для swift-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет Swift-код на protocol-oriented design, value semantics, ARC, Swift Concurrency и идиоматичность. Не меняет файлы.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
