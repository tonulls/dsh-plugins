# `/ecc-docs-lookup` — примеры промтов

## Назначение

Отвечает на вопросы по использованию библиотек, фреймворков и API, опираясь на актуальную документацию через Context7 MCP; приводит применимые примеры кода.

## Короткий запрос

```text
/ecc-docs-lookup Как в {библиотека и версия} выполнить {задача}? Приведи пример и укажи ограничения по документации.
```

## Шаблонный запрос

```text
/ecc-docs-lookup Найди актуальную документацию для {API/фреймворк}, версия {версия или неизвестна}. Объясни {конкретный вопрос}, покажи минимальный пример для {язык/окружение}. Отдели подтверждённое источником от предположений; если версия не определена, уточни применимость.
```

## Подробный запрос

```text
/ecc-docs-lookup Разбери вопрос {вопрос} для {библиотека/API}, используемая версия {версия}, контекст проекта {среда и ограничения}.
1. Найди относящиеся к вопросу актуальные материалы документации через Context7 MCP.
2. Уточни, какие положения зависят от версии; не подменяй отсутствующую информацию догадками.
3. Дай решение и компактный пример, согласованный с указанной средой.
4. Перечисли важные ограничения, типичные ошибки и альтернативу, если документация её описывает.

Формат: краткий ответ, пример, пояснение по шагам, ссылки/названия использованных разделов и оговорки. Не меняй проектные файлы и не утверждай, что проверил код исполнением.
```
