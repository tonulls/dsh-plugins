# Пример промта: `/ecc-planner`

**Команда вызова:** `/ecc-planner`

## Назначение

Разрабатывает структурированный план сложной функции, архитектурного изменения или рефакторинга до начала реализации.

## 1. Короткий запрос

```text
/ecc-planner Составь этапный план для {функция}; код не меняй.
```

## 2. Шаблонный запрос

```text
/ecc-planner Составь план для {цель} в проекте {контекст}. Ограничения: {совместимость/сроки/объём}. Разбей на этапы, укажи затрагиваемые области, зависимости, риски и проверяемые критерии завершения. Не реализуй план и не меняй файлы.
```

## 3. Подробный запрос

```text
/ecc-planner Проведи последовательный анализ задачи {сценарий/изменение} для planner.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Разрабатывает структурированный план сложной функции, архитектурного изменения или рефакторинга до начала реализации.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
