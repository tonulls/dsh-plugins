# `/ecc-gan-planner` — примеры промтов

## Назначение

Преобразует краткую идею в продуктовую спецификацию: описывает функции, спринты, критерии оценки и направление дизайна.

## Короткий запрос

```text
/ecc-gan-planner Разверни идею «{идея}» в спецификацию с функциями, этапами и проверяемыми критериями приёмки.
```

## Шаблонный запрос

```text
/ecc-gan-planner Составь спецификацию для {продукт/аудитория} на основе идеи {идея}. Включи приоритетные функции, границы MVP, этапы/спринты, критерии оценки и направление дизайна. Отдели заданные вводные от предположений и вопросов.
```

## Подробный запрос

```text
/ecc-gan-planner Преобразуй идею {краткое описание} в спецификацию продукта для {целевая аудитория}, учитывая {платформа, ограничения, сроки}.
1. Сформулируй проблему, пользователей и желаемые результаты, не добавляя неизвестных фактов о рынке.
2. Разложи функции на MVP и последующие этапы; для каждой отметь ценность и зависимости.
3. Опиши пользовательские потоки и направление дизайна достаточно конкретно для реализации, без неподтверждённых визуальных требований.
4. Разбей работу на последовательные спринты/этапы с измеримыми результатами.
5. Определи критерии оценки и приёмки, позволяющие evaluator проверить результат; укажи порог только если он задан или обоснован явно.

Формат: краткое резюме, аудитория/цели, scope и вне scope, функции, этапы, критерии оценки, предположения и открытые вопросы. Только планирование: не меняй код, не устанавливай пакеты, не обращайся к сети и не выполняй деплой.
```
