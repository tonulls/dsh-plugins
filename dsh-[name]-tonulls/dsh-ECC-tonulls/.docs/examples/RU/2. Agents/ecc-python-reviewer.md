# Пример промта: `/ecc-python-reviewer`

**Команда вызова:** `/ecc-python-reviewer`

## Назначение

Проверяет Python-код на PEP 8, идиоматичность, аннотации типов, безопасность и производительность. Не редактирует файлы.

## 1. Короткий запрос

```text
/ecc-python-reviewer Проведи read-only review Python-кода {путь}; укажи только реальные находки.
```

## 2. Шаблонный запрос

```text
/ecc-python-reviewer Проведи read-only review {файлы/дифф} Python-кода для {назначение}. Проверь типы, обработку ошибок, безопасность границ ввода и эффективность; отдели реальные дефекты от стиля. Укажи только подтверждённые находки с местом и рекомендацией, не меняя файлы.
```

## 3. Подробный запрос

```text
/ecc-python-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для python-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет Python-код на PEP 8, идиоматичность, аннотации типов, безопасность и производительность. Не редактирует файлы.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
