# Пример промта: `/ecc-rust-reviewer`

**Команда вызова:** `/ecc-rust-reviewer`

## Назначение

Проверяет Rust-код на владение, lifetimes, обработку ошибок, применение unsafe и идиоматичность. Файлы не меняет.

## 1. Короткий запрос

```text
/ecc-rust-reviewer Проверь Rust-изменения {путь} на ownership и ошибки; не меняй файлы.
```

## 2. Шаблонный запрос

```text
/ecc-rust-reviewer Проведи read-only review Rust-изменений {файлы/дифф}, особенно участка {модуль}. Оцени корректность владения/lifetimes, ошибки и panic, unsafe-блоки и конкурентность. Дай находки с контекстом, серьёзностью и рекомендацией; не переписывай код.
```

## 3. Подробный запрос

```text
/ecc-rust-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для rust-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет Rust-код на владение, lifetimes, обработку ошибок, применение unsafe и идиоматичность. Файлы не меняет.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
