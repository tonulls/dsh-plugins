# `/ecc-go-build-resolver` — примеры промтов

## Назначение

Устраняет ошибки сборки и компиляции Go, замечания `go vet` и линтеров минимальными изменениями, не превращая диагностику в архитектурный рефакторинг.

## Короткий запрос

```text
/ecc-go-build-resolver Разбери ошибку Go: {вывод/команда}. Найди первопричину и исправь минимально, не расширяя область изменений.
```

## Шаблонный запрос

```text
/ecc-go-build-resolver В {путь проекта} устрани {ошибка go build/go vet/линтера}, вывод: {текст}. Сначала проверь модуль и затронутый код; исправляй только причину сбоя минимальным diff. Не обновляй зависимости и объясни результат разрешённой проверки.
```

## Подробный запрос

```text
/ecc-go-build-resolver Восстанови сборку Go-проекта {путь} после ошибки {команда и полный вывод}.
1. Найди затронутые пакеты и проследи сообщение до исходной причины, отделяя каскадные ошибки.
2. Проверь согласованность типов, импортов и используемых API; для vet/линтера оцени, является ли предупреждение следствием реального дефекта.
3. Внеси минимальную локальную правку, не меняя архитектуру и публичное поведение без необходимости.
4. Запусти только разрешённую команду проверки {команда}; если она недоступна/запрещена, не выдавай исправление за проверенное.

Формат: первопричина, изменённые файлы и обоснование, выполненная проверка и её точный результат, оставшиеся ошибки. Не устанавливай пакеты, не обращайся к сети и не выполняй деплой без согласия; не изменяй несвязанные файлы.
```
