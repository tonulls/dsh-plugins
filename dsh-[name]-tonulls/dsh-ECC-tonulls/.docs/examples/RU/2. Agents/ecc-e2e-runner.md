# `/ecc-e2e-runner` — примеры промтов

## Назначение

Создаёт, поддерживает и запускает E2E-сценарии критичных пользовательских потоков; предпочитает Vercel Agent Browser, с Playwright как запасным вариантом, и помогает разбирать нестабильные тесты и артефакты.

## Короткий запрос

```text
/ecc-e2e-runner Проверь E2E-сценарий {поток} в {приложение}. Сначала определи существующие средства и сообщи, что можно безопасно выполнить.
```

## Шаблонный запрос

```text
/ecc-e2e-runner Для {путь/приложение} покрой поток {начало → ожидаемый результат}. Используй имеющиеся в проекте Vercel Agent Browser или Playwright, не добавляй зависимости. Укажи предусловия, проверки, нестабильные места и нужные артефакты; запускай тест только если это разрешено.
```

## Подробный запрос

```text
/ecc-e2e-runner Подготовь E2E-покрытие сценария {сценарий} для {окружение/URL}.
1. Изучи существующую тестовую инфраструктуру, доступные команды и уже описанные пользовательские пути.
2. Выбери поддерживаемый инструмент (предпочтительно Vercel Agent Browser, иначе Playwright) только если он уже доступен.
3. Сформулируй шаги, наблюдаемые проверки и данные, не зависящие от нестабильных деталей интерфейса.
4. При нестабильном тесте отдели дефект приложения от flaky-поведения и предложи карантин только при обосновании.
5. Запусти только явно разрешённый тест; перечисли созданные артефакты, если они реально получены.

Формат: инфраструктура, сценарий и assertions, изменения тестов, фактический результат и ограничения. Не устанавливай пакеты, не обращайся к сети и не запускай деплой без согласия; без запущенного приложения не заявляй о проверке живого потока.
```
