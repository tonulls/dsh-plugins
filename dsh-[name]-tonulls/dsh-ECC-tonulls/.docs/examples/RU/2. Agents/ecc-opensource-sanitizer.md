# Пример промта: `/ecc-opensource-sanitizer`

**Команда вызова:** `/ecc-opensource-sanitizer`

## Назначение

Проверяет публичную копию на секреты, персональные данные, внутренние ссылки и опасные файлы и выдаёт PASS/FAIL/PASS-WITH-WARNINGS. Только анализ.

## 1. Короткий запрос

```text
/ecc-opensource-sanitizer Проверь публичную копию {путь} на утечки и выдай краткий статус, не меняя файлы.
```

## 2. Шаблонный запрос

```text
/ecc-opensource-sanitizer Проведи read-only проверку подготовленной копии {путь} перед публикацией. Не раскрывай найденные значения секретов/PII; укажи файл и безопасный контекст, категорию, серьёзность. Проверь внутренние ссылки и опасные файлы, сформируй PASS/FAIL/PASS-WITH-WARNINGS с ограничениями проверки. Не исправляй файлы.
```

## 3. Подробный запрос

```text
/ecc-opensource-sanitizer Проведи последовательный анализ задачи {сценарий/изменение} для opensource-sanitizer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет публичную копию на секреты, персональные данные, внутренние ссылки и опасные файлы и выдаёт PASS/FAIL/PASS-WITH-WARNINGS. Только анализ.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
