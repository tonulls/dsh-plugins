# Пример промта: `/ecc-php-reviewer`

**Команда вызова:** `/ecc-php-reviewer`

## Назначение

Проверяет PHP-код на PSR-12, корректность типов, безопасные паттерны Eloquent, уязвимости и производительность. Только замечания, без правок.

## 1. Короткий запрос

```text
/ecc-php-reviewer Проведи read-only review PHP-изменений {путь} на безопасность и типы.
```

## 2. Шаблонный запрос

```text
/ecc-php-reviewer Сделай read-only review PHP-изменений {пути/дифф} в контексте {функция/фреймворк}. Проверь PSR-12, типы, Eloquent-запросы, безопасность ввода и производительность. Для каждой уверенной находки дай файл/строку, риск и вариант исправления; не меняй код.
```

## 3. Подробный запрос

```text
/ecc-php-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для php-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет PHP-код на PSR-12, корректность типов, безопасные паттерны Eloquent, уязвимости и производительность. Только замечания, без правок.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
