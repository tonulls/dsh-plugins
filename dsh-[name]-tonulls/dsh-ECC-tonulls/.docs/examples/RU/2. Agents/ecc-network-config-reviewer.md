# Пример промта: `/ecc-network-config-reviewer`

**Команда вызова:** `/ecc-network-config-reviewer`

## Назначение

Проверяет конфигурации маршрутизаторов и коммутаторов на безопасность, корректность, устаревшие ссылки и рискованные команды. Только анализ, без изменений.

## 1. Короткий запрос

```text
/ecc-network-config-reviewer Проверь этот конфиг сети только для чтения и перечисли рискованные настройки: {путь}.
```

## 2. Шаблонный запрос

```text
/ecc-network-config-reviewer Выполни read-only проверку конфигурации {устройство/файл}, контекст {планируемое изменение}. Найди ошибки, небезопасные настройки, устаревшие ссылки и опасные команды окна работ. Не подключайся к устройствам и ничего не применяй; дай находки по серьёзности, доказательства и безопасные рекомендации.
```

## 3. Подробный запрос

```text
/ecc-network-config-reviewer Проведи последовательный анализ конфигурации {устройство/файл} перед изменением {цель/окно работ}.

1. Определи платформу и область проверки по предоставленному контексту; не подключайся к устройству.
2. Проверь корректность и безопасность настроек, устаревшие ссылки и команды, способные прервать управление или трафик.
3. Для каждого вывода приведи фрагмент/место, возможное влияние и уверенность; отделяй факты от предположений.
4. Сформируй приоритетный список рисков, недостающих проверок и безопасных рекомендаций до окна работ.
5. Заверши краткой оценкой готовности и ограничениями анализа.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
