# `/ecc-django-reviewer`

**Назначение:** Проверяет код Django: корректность ORM, шаблоны DRF, безопасность миграций, настройки защиты и готовность к эксплуатации. Используйте для изменений в проектах Django.

## Короткий промт

```text
/ecc-django-reviewer Проведи read-only ревью этого Django-изменения: проверь ORM/DRF, миграции и безопасность.
```

## Шаблонный промт

```text
/ecc-django-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить изменение приложения Django для [цель или объект].
Фокус: ORM/DRF, безопасность, миграции, настройки и готовность к production.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-django-reviewer
Выполни задачу «проверить изменение приложения Django» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: ORM/DRF, безопасность, миграции, настройки и готовность к production.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
