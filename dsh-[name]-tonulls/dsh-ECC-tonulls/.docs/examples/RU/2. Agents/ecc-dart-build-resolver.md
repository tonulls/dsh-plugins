# `/ecc-dart-build-resolver`

**Назначение:** Диагностирует и минимально исправляет ошибки `dart analyze`, сборки Flutter, конфликтов зависимостей pub и `build_runner`. Используйте при сбоях сборки Dart/Flutter.

## Короткий промт

```text
/ecc-dart-build-resolver Разбери ошибки dart analyze и сборки Flutter; исправь только подтверждённую причину, не устанавливая пакеты.
```

## Шаблонный промт

```text
/ecc-dart-build-resolver
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: минимально исправить ошибки анализа или сборки Dart/Flutter для [цель или объект].
Фокус: вывод dart analyze/Flutter, конфликт pub/build_runner и подтверждённая первопричина.
Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-dart-build-resolver
Выполни задачу «минимально исправить ошибки анализа или сборки Dart/Flutter» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: вывод dart analyze/Flutter, конфликт pub/build_runner и подтверждённая первопричина.
3. Внеси минимальную правку только после подтверждения первопричины и повтори подходящую локальную проверку.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
