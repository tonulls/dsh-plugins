# Пример промта: `/ecc-seo-specialist`

**Команда вызова:** `/ecc-seo-specialist`

## Назначение

Аудирует техническое SEO, on-page метаданные, structured data, Core Web Vitals и карту контента/ключевых слов.

## 1. Короткий запрос

```text
/ecc-seo-specialist Составь технический SEO-чеклист для {страница}; не делай сетевых запросов.
```

## 2. Шаблонный запрос

```text
/ecc-seo-specialist Проведи SEO-аудит {сайт/страницы} по доступным локальным материалам: цель {цель}, аудитория {аудитория}. Проверь метаданные, structured data, sitemap/robots, Core Web Vitals и соответствие контента запросам. Не делай сетевых запросов и не меняй сайт; обозначь непроверяемое и приоритезируй рекомендации.
```

## 3. Подробный запрос

```text
/ecc-seo-specialist Проведи последовательный анализ задачи {сценарий/изменение} для seo-specialist.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Аудирует техническое SEO, on-page метаданные, structured data, Core Web Vitals и карту контента/ключевых слов.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
