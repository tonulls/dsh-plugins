# `/ecc-bengali-reviewer` — примеры промтов

## Назначение

Проверяет код, который обрабатывает бенгальский (Bangla) текст: корректность Unicode и нормализации, работу с письменностью и практики интернационализации. Применяйте к конкретным путям и сценариям с бенгальскими данными.

## 1. Короткий запрос

```text
/ecc-bengali-reviewer Проверь обработку бенгальского текста в форме поиска на ошибки Unicode и локализации. Только анализ, код не меняй.
```

## 2. Шаблонный запрос

```text
/ecc-bengali-reviewer Проведи проверку {файлы/модуль} в проекте {стек}. Сценарии: {ввод, хранение, поиск, отображение бенгальского текста}. Проверь Unicode-нормализацию, операции над строками и локализацию. Для замечаний укажи файл/строки, пример входа и наблюдаемое последствие; не меняй файлы.
```

## 3. Подробный запрос

```text
/ecc-bengali-reviewer Проведи read-only проверку обработки бенгальского (Bangla) текста в {путь или модуль}. Контекст: {где поступают данные и как используются}; ожидаемые сценарии: {сортировка, поиск, ввод, отображение, хранение}.

1. Найди места, где текст декодируется, нормализуется, сравнивается, разбивается или преобразуется; проследи путь данных от ввода до вывода.
2. Проверь, не предполагает ли код, что один видимый знак равен одному кодовому элементу; оцени корректность Unicode-нормализации и операций с комбинируемыми знаками для фактического сценария.
3. Проверь формирование, хранение, поиск и отображение Bangla, включая локализационные допущения. Не утверждай проблему без конкретного контрпримера или подтверждаемого риска.
4. Сопоставь наблюдения с относящимися к ним тестами, если они есть; не создавай и не запускай дополнительные тесты без разрешения.

Выведи сначала подтверждённые проблемы с приоритетом, точными местами, примером текста/условием и исправлением; затем потенциальные риски, проверенные области и пробелы. Код не изменяй, зависимости не устанавливай, сеть и деплой не используй.
```
