# Пример промта: `/ecc-silent-failure-hunter`

**Команда вызова:** `/ecc-silent-failure-hunter`

## Назначение

Ищет молча скрытые ошибки, проглоченные исключения, опасные fallback-ветви и отсутствие передачи ошибок. Только review.

## 1. Короткий запрос

```text
/ecc-silent-failure-hunter Найди места, где ошибки в {путь} могут быть скрыты; не меняй код.
```

## 2. Шаблонный запрос

```text
/ecc-silent-failure-hunter Проведи read-only анализ {файлы/дифф}, проследи отказные пути для {операция}. Найди пустые catch, игнорируемые результаты, маскирующие fallback и потерю error propagation. Укажи сценарий сбоя, место, последствия и безопасное исправление; не меняй файлы.
```

## 3. Подробный запрос

```text
/ecc-silent-failure-hunter Проведи последовательный анализ задачи {сценарий/изменение} для silent-failure-hunter.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Ищет молча скрытые ошибки, проглоченные исключения, опасные fallback-ветви и отсутствие передачи ошибок. Только review.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
