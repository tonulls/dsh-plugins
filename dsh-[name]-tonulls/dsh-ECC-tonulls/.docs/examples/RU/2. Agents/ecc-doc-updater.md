# `/ecc-doc-updater` — примеры промтов

## Назначение

Обновляет документацию и карты кодовой базы по фактическому состоянию проекта; может работать с README, руководствами и `docs/CODEMAPS/*` в заданных пределах.

## Короткий запрос

```text
/ecc-doc-updater Обнови документацию {путь/раздел} по изменениям {функция}. Сверь утверждения с кодом и не выходи за указанный раздел.
```

## Шаблонный запрос

```text
/ecc-doc-updater Приведи в соответствие {документ или карта} с реализацией {функция/модуль}. Проверь связанные исходники {пути}, сохрани стиль проекта, укажи изменённые файлы и неподтверждённые детали. Изменяй только {разрешённые пути}; не редактируй другие документы.
```

## Подробный запрос

```text
/ecc-doc-updater Документируй изменение {описание} для {аудитория}.
1. Изучи относящиеся к нему исходники и текущие документы; отдели факты от предположений.
2. Определи, какие страницы или карты кодовой базы действительно устарели.
3. Обнови только {разрешённые файлы}, сохраняя структуру и терминологию проекта; не создавай обещаний о неподтверждённых возможностях.
4. Проверь ссылки, команды и соответствие описания реализации.

В ответе перечисли файлы, суть правок и оставшиеся пробелы. Не меняй код и файлы вне разрешённого объёма; без согласия не устанавливай зависимости, не обращайся к сети и не выполняй деплой.
```
