# Пример промта: `/ecc-typescript-reviewer`

**Команда вызова:** `/ecc-typescript-reviewer`

## Назначение

Проверяет TypeScript/JavaScript на безопасность типов, асинхронность, безопасность Node/web и идиоматичность. Только отчёт, без правок.

## 1. Короткий запрос

```text
/ecc-typescript-reviewer Проведи read-only review TS/JS-изменений {путь}.
```

## 2. Шаблонный запрос

```text
/ecc-typescript-reviewer Проведи read-only review {файлы/дифф} TS/JS приложения {Node/web}. Проверь границы типов и валидацию внешних данных, async-ошибки/гонки, безопасность и идиоматичность. Не меняй файлы; перечисли находки с точными местами, доказательством, серьёзностью и рекомендацией.
```

## 3. Подробный запрос

```text
/ecc-typescript-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для typescript-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет TypeScript/JavaScript на безопасность типов, асинхронность, безопасность Node/web и идиоматичность. Только отчёт, без правок.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
