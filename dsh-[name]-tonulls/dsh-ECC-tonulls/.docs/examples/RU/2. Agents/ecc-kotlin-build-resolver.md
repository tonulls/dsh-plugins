# Пример промта: `/ecc-kotlin-build-resolver`

**Команда вызова:** `/ecc-kotlin-build-resolver`

## Назначение

Находит и минимально устраняет ошибки сборки/компиляции Kotlin и Gradle.

## 1. Короткий запрос

```text
/ecc-kotlin-build-resolver Помоги найти причину ошибки Kotlin/Gradle: {вставьте сообщение ошибки}.
```

## 2. Шаблонный запрос

```text
/ecc-kotlin-build-resolver В проекте {модуль} падает {команда_сборки} с ошибкой: {текст_ошибки}. Найдите первопричину в Kotlin/Gradle-конфигурации и предложите минимальное исправление. Не устанавливайте зависимости и не запускайте сеть; перед изменением файлов или выполнением изменяющих команд запросите подтверждение.
```

## 3. Подробный запрос

```text
/ecc-kotlin-build-resolver Проведи последовательный анализ задачи {сценарий/изменение} для kotlin-build-resolver.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Находит и минимально устраняет ошибки сборки/компиляции Kotlin и Gradle.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
