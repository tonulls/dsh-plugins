# Пример промта: `/ecc-network-troubleshooter`

**Команда вызова:** `/ecc-network-troubleshooter`

## Назначение

Диагностирует симптомы сети по уровням OSI, используя только наблюдаемые данные и формируя доказательное резюме первопричины.

## 1. Короткий запрос

```text
/ecc-network-troubleshooter Помоги диагностировать {симптом} без изменений сетевых настроек.
```

## 2. Шаблонный запрос

```text
/ecc-network-troubleshooter Разбери проблему {симптом} на {сегмент/устройство}; начало {время}, известные изменения {изменения}, результаты проверок {данные}. Иди от физического/канального уровня к DNS/маршрутизации/политикам, не меняй конфигурацию и не сканируй сеть. Отдели факты от гипотез и укажи безопасные проверки.
```

## 3. Подробный запрос

```text
/ecc-network-troubleshooter Проведи последовательный анализ задачи {сценарий/изменение} для network-troubleshooter.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Диагностирует симптомы сети по уровням OSI, используя только наблюдаемые данные и формируя доказательное резюме первопричины.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
