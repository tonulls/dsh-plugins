# Пример промта: `/ecc-mle-reviewer`

**Команда вызова:** `/ecc-mle-reviewer`

## Назначение

Проводит review production ML/MLOps: контракты данных, pipelines, воспроизводимость, оценки, serving, мониторинг и rollback. Файлы не меняет.

## 1. Короткий запрос

```text
/ecc-mle-reviewer Проверь изменения ML-pipeline на воспроизводимость и риски serving; не редактируй файлы.
```

## 2. Шаблонный запрос

```text
/ecc-mle-reviewer Сделай read-only review изменений {пути/дифф} в ML-компоненте {описание}. Проверь согласованность train/serve, воспроизводимость, утечки данных, метрики offline/online, мониторинг и откат. Приведи только обоснованные находки с доказательствами и приоритетом.
```

## 3. Подробный запрос

```text
/ecc-mle-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для mle-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: контракты данных, pipelines, воспроизводимость, оценки, serving, мониторинг и rollback. Файлы не меняет.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
