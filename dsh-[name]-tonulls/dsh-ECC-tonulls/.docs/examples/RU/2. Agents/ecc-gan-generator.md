# `/ecc-gan-generator` — примеры промтов

## Назначение

Реализует функции по предоставленной спецификации, затем учитывает обратную связь evaluator и повторяет улучшения до указанного порога качества. Сам порог должен быть определён пользователем или спецификацией.

## Короткий запрос

```text
/ecc-gan-generator Реализуй {функция} по {спецификация}; учитывай {оценка/обратная связь}. Меняй только относящиеся к задаче файлы.
```

## Шаблонный запрос

```text
/ecc-gan-generator В проекте {путь} выполни итерацию по спецификации {ссылка/текст} и оценке {feedback}. Исправь приоритетные несоответствия в пределах {разрешённые области}, затем перечисли правки и критерии, которые остались неподтверждёнными. Не расширяй объём самостоятельно.
```

## Подробный запрос

```text
/ecc-gan-generator Реализуй {функциональность} в {проект} по спецификации {спецификация} и замечаниям evaluator {отчёт}.
1. Сопоставь замечания с критериями спецификации; при конфликте или неоднозначности явно обозначь её, не придумывая требований.
2. Выбери минимальный набор изменений в пределах {разрешённые файлы/поведение}; не затрагивай несвязанные функции.
3. Внеси изменения, ориентируясь на приоритеты и порог качества {явно заданный порог}; не заявляй о достижении без соответствующих данных оценки.
4. Выполни только разрешённые проверки из {команды/ограничения}; сообщи фактический результат.
5. Составь краткий отчёт, который evaluator сможет проверить в следующем цикле.

Формат: изменения по критериям, файлы, проверки и результат, остаточные риски/вопросы. Не устанавливай зависимости, не обращайся к сети и не выполняй деплой без отдельного согласия.
```
