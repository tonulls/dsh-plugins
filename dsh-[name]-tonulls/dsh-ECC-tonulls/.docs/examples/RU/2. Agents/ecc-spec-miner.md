# Пример промта: `/ecc-spec-miner`

**Команда вызова:** `/ecc-spec-miner`

## Назначение

Извлекает из существующего кода поведенческие требования и инварианты для OpenSpec с привязкой к сущностям и тестам.

## 1. Короткий запрос

```text
/ecc-spec-miner Извлеки требования и инварианты capability {название} из {путь}; не создавай файлы.
```

## 2. Шаблонный запрос

```text
/ecc-spec-miner Извлеки спецификации существующего поведения capability {название} из {пути}. Сопоставь код и тесты; оформи требования и инварианты с сущностями, механизмом обеспечения, стабильным id и test anchors. Не додумывай отсутствующее поведение; сначала покажи результат в ответе и не создавай spec.md без подтверждения.
```

## 3. Подробный запрос

```text
/ecc-spec-miner Проведи последовательный анализ задачи {сценарий/изменение} для spec-miner.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Извлекает из существующего кода поведенческие требования и инварианты для OpenSpec с привязкой к сущностям и тестам.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
