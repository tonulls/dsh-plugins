# Пример промта: `/ecc-refactor-cleaner`

**Команда вызова:** `/ecc-refactor-cleaner`

## Назначение

Ищет неиспользуемый и дублирующийся код для безопасной очистки и консолидации; удаления требуют подтверждения.

## 1. Короткий запрос

```text
/ecc-refactor-cleaner Найди кандидатов на удаление в {область}, но не удаляй и не меняй файлы.
```

## 2. Шаблонный запрос

```text
/ecc-refactor-cleaner Проанализируй область {папки/модули} на неиспользуемый код и дубли. Учитывай динамические импорты, публичные API и генерацию. Сначала представь кандидатов с доказательствами и риском ложного срабатывания; не запускай установку инструментов и не удаляй/меняй файлы без моего подтверждения.
```

## 3. Подробный запрос

```text
/ecc-refactor-cleaner Проведи последовательный анализ задачи {сценарий/изменение} для refactor-cleaner.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Ищет неиспользуемый и дублирующийся код для безопасной очистки и консолидации; удаления требуют подтверждения.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
