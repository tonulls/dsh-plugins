# `/ecc-healthcare-reviewer`

**Назначение:** Проверяет код медицинских приложений: клиническая безопасность, точность CDSS, защита PHI и целостность медицинских данных. Специализируется на EMR/EHR и системах поддержки клинических решений.

## Короткий промт

```text
/ecc-healthcare-reviewer Проведи read-only ревью медицинского изменения на клинические риски, PHI и целостность данных; не включай реальные данные пациентов в ответ.
```

## Шаблонный промт

```text
/ecc-healthcare-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить медицинское приложение на риски безопасности и целостности для [цель или объект].
Фокус: клиническая безопасность, корректность CDSS, защита PHI и целостность EMR/EHR.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-healthcare-reviewer
Выполни задачу «проверить медицинское приложение на риски безопасности и целостности» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: клиническая безопасность, корректность CDSS, защита PHI и целостность EMR/EHR.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
