# Пример промта: `/ecc-network-architect`

**Команда вызова:** `/ecc-network-architect`

## Назначение

Проектирует архитектуру корпоративной или многоплощадочной сети по требованиям, оборудованию и ограничениям.

## 1. Короткий запрос

```text
/ecc-network-architect Предложи безопасную схему сети для {число} рабочих мест и {число} площадок.
```

## 2. Шаблонный запрос

```text
/ecc-network-architect Составь проект сети для {площадки/число пользователей}, требования {сервисы/доступность}, ограничения {бюджет/оборудование/компетенции}. Опиши топологию, сегментацию, маршрутизацию, отказоустойчивость и этапы миграции с проверкой и откатом. Ничего не меняй в реальной сети и не обращайся к ней.
```

## 3. Подробный запрос

```text
/ecc-network-architect Проведи последовательный анализ задачи {сценарий/изменение} для network-architect.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проектирует архитектуру корпоративной или многоплощадочной сети по требованиям, оборудованию и ограничениям.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
