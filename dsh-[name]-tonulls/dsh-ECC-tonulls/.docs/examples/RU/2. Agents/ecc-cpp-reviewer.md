# `/ecc-cpp-reviewer`

**Назначение:** Проверяет код C++: безопасность памяти, современные идиомы языка, конкурентность и производительность. Используйте для изменений в проектах C++.

## Короткий промт

```text
/ecc-cpp-reviewer Проведи read-only ревью этого изменения C++: ищи прежде всего риски памяти и конкурентности.
```

## Шаблонный промт

```text
/ecc-cpp-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить изменение C++ на ошибки и риски для [цель или объект].
Фокус: владение и время жизни памяти, UB, конкурентность, современные идиомы и производительность.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-cpp-reviewer
Выполни задачу «проверить изменение C++ на ошибки и риски» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: владение и время жизни памяти, UB, конкурентность, современные идиомы и производительность.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
