# Пример промта: `/ecc-kotlin-reviewer`

**Команда вызова:** `/ecc-kotlin-reviewer`

## Назначение

Проверяет Kotlin/Android/KMP-код: идиомы, корутины/Flow, Compose, архитектурные границы и типичные Android-риски. Только сообщает находки, файлы не меняет.

## 1. Короткий запрос

```text
/ecc-kotlin-reviewer Проверь Kotlin-код на ошибки корутин и Compose; ничего не меняй.
```

## 2. Шаблонный запрос

```text
/ecc-kotlin-reviewer Проведи read-only review {изменённые_файлы_или_дифф} для {Android/KMP/Compose}. Проверь отмену корутин, Flow, lifecycle, Compose-перерисовки и границы модулей; сообщай лишь уверенные проблемы с местом, обоснованием и исправлением.
```

## 3. Подробный запрос

```text
/ecc-kotlin-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для kotlin-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: идиомы, корутины/Flow, Compose, архитектурные границы и типичные Android-риски. Только сообщает находки, файлы не меняет.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
