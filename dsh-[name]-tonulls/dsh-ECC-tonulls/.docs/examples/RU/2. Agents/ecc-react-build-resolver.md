# Пример промта: `/ecc-react-build-resolver`

**Команда вызова:** `/ecc-react-build-resolver`

## Назначение

Находит и устраняет минимальными изменениями сбои сборки React: JSX/TSX, гидратация, границы server/client, типы и настройки bundler.

## 1. Короткий запрос

```text
/ecc-react-build-resolver Разбери ошибку сборки React {лог}; не устанавливай пакеты.
```

## 2. Шаблонный запрос

```text
/ecc-react-build-resolver Сборка React-проекта {Vite/webpack/Next.js/иной} завершается ошибкой {лог}. Найди первопричину в изменённых файлах и предложи минимальное исправление. Не устанавливай пакеты и не обращайся к сети; перед правкой или командами с побочными эффектами запроси подтверждение.
```

## 3. Подробный запрос

```text
/ecc-react-build-resolver Проведи последовательный анализ задачи {сценарий/изменение} для react-build-resolver.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: JSX/TSX, гидратация, границы server/client, типы и настройки bundler.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
