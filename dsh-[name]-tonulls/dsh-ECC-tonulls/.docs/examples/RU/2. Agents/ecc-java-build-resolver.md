# `/ecc-java-build-resolver`

**Назначение:** Диагностирует и минимально исправляет ошибки сборки, компиляции и зависимостей Java/Maven/Gradle; распознаёт Spring Boot и Quarkus. Используйте при сбоях Java-сборки.

## Короткий промт

```text
/ecc-java-build-resolver Разбери ошибку сборки Java/Maven/Gradle и предложи минимальное исправление; не скачивай и не устанавливай зависимости.
```

## Шаблонный промт

```text
/ecc-java-build-resolver
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: диагностировать и минимально исправить ошибку Java/Maven/Gradle для [цель или объект].
Фокус: ошибки компиляции и зависимостей, выбранный Spring Boot/Quarkus-контекст и доступные локальные проверки.
Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-java-build-resolver
Выполни задачу «диагностировать и минимально исправить ошибку Java/Maven/Gradle» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: ошибки компиляции и зависимостей, выбранный Spring Boot/Quarkus-контекст и доступные локальные проверки.
3. Внеси минимальную правку только после подтверждения первопричины и повтори подходящую локальную проверку.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
