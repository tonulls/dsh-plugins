# `/ecc-go-reviewer`

**Назначение:** Проверяет код Go: идиоматичность, конкурентность, обработка ошибок и производительность. Используйте для изменений в проектах Go.

## Короткий промт

```text
/ecc-go-reviewer Проведи read-only ревью этого изменения Go, уделяя внимание конкурентности и обработке ошибок.
```

## Шаблонный промт

```text
/ecc-go-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить изменение Go для [цель или объект].
Фокус: идиоматичность, конкурентность, обработка ошибок и горячие пути производительности.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-go-reviewer
Выполни задачу «проверить изменение Go» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: идиоматичность, конкурентность, обработка ошибок и горячие пути производительности.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
