# `/ecc-gan-evaluator` — примеры промтов

## Назначение

Оценивает работающее приложение через Playwright по заданной шкале/рубрике и формирует предметную обратную связь для Generator. Требует доступного запущенного приложения.

## Короткий запрос

```text
/ecc-gan-evaluator Оцени запущенное приложение {URL/среда} по критериям {рубрика}; проверь указанный поток {сценарий} и сообщи наблюдаемые результаты.
```

## Шаблонный запрос

```text
/ecc-gan-evaluator Проведи оценку живого приложения {адрес или способ доступа} по рубрике {критерии/порог}. Проверь пути {сценарии}, используй Playwright только при доступности. Для каждой оценки укажи наблюдение и доказательство; в конце подготовь конкретную обратную связь Generator. Не меняй приложение.
```

## Подробный запрос

```text
/ecc-gan-evaluator Оцени запущенную версию {приложение/адрес} как итерацию GAN Harness.
1. Уточни доступность приложения и критерии из {спецификация/рубрика}; не приписывай ему отсутствующие требования.
2. Через Playwright пройди сценарии {основные пользовательские пути}; фиксируй только реально наблюдаемое поведение.
3. Оцени каждый критерий по {шкала/порог}, приводя подтверждение, серьёзность проблемы и влияние на пользователя.
4. Подготовь Generator приоритизированный список корректировок, привязанный к критериям.

Формат: таблица «критерий — оценка — доказательства — пробелы», итог против порога и отдельный список обратной связи. Если приложение недоступно или критерии не заданы, обозначь это и не выдумывай баллы. Не редактируй приложение, не устанавливай зависимости, не обращайся к сети и не деплой без согласия.
```
