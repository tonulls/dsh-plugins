# Пример промта: `/ecc-swift-build-resolver`

**Команда вызова:** `/ecc-swift-build-resolver`

## Назначение

Диагностирует Swift/Xcode-сборки, ошибки компиляции, SPM и code signing с минимальными исправлениями.

## 1. Короткий запрос

```text
/ecc-swift-build-resolver Разбери ошибку Swift/Xcode {лог}, не скачивая зависимости и не меняя signing.
```

## 2. Шаблонный запрос

```text
/ecc-swift-build-resolver Сборка {swift build / Xcode scheme} для {проект} падает с {ошибка}. Определи, относится ли причина к Swift, Xcode, SPM или signing, и предложи минимальное исправление. Не скачивай зависимости, не меняй signing-настройки и файлы без подтверждения.
```

## 3. Подробный запрос

```text
/ecc-swift-build-resolver Проведи последовательный анализ задачи {сценарий/изменение} для swift-build-resolver.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Диагностирует Swift/Xcode-сборки, ошибки компиляции, SPM и code signing с минимальными исправлениями.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
