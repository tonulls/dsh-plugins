# Пример промта: `/ecc-marketing-agent`

**Команда вызова:** `/ecc-marketing-agent`

## Назначение

Помогает планировать маркетинговые кампании и создавать/проверять тексты для заданной аудитории и канала.

## 1. Короткий запрос

```text
/ecc-marketing-agent Придумай три варианта заголовка для {продукт} для аудитории {аудитория}.
```

## 2. Шаблонный запрос

```text
/ecc-marketing-agent Подготовь {тип кампании/материала} для продукта {продукт}, аудитория {аудитория}, канал {канал}, цель {цель}, тон {тон}. Дай варианты текста и кратко объясни позиционирование. Не публикуй и не отправляй материалы; отметь предположения и не выдумывай подтверждённые факты.
```

## 3. Подробный запрос

```text
/ecc-marketing-agent Проведи последовательный анализ задачи {сценарий/изменение} для marketing-agent.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Помогает планировать маркетинговые кампании и создавать/проверять тексты для заданной аудитории и канала.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
