# Пример промта: `/ecc-rust-build-resolver`

**Команда вызова:** `/ecc-rust-build-resolver`

## Назначение

Минимально диагностирует и исправляет ошибки сборки Rust, borrow checker и Cargo.toml.

## 1. Короткий запрос

```text
/ecc-rust-build-resolver Разбери ошибку cargo {лог} и предложи минимальную причину без добавления зависимостей.
```

## 2. Шаблонный запрос

```text
/ecc-rust-build-resolver Команда {cargo check/build/test} в crate {имя} завершается ошибкой {лог}. Проследи типы, владение/заимствования и конфигурацию Cargo, предложи узкое исправление. Не добавляй зависимости, не выполняй сетевые действия и не меняй файлы без подтверждения.
```

## 3. Подробный запрос

```text
/ecc-rust-build-resolver Проведи последовательный анализ задачи {сценарий/изменение} для rust-build-resolver.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Минимально диагностирует и исправляет ошибки сборки Rust, borrow checker и Cargo.toml.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
