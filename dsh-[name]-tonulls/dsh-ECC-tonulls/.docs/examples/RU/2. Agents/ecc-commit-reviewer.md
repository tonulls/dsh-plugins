# `/ecc-commit-reviewer`

**Назначение:** Проверяет подготовленные изменения и предлагает сообщение коммита в формате Conventional Commits с учётом фактических норм истории репозитория. Используйте перед коммитом или для проверки его сообщения.

## Короткий промт

```text
/ecc-commit-reviewer Проверь staged diff и предложи точное сообщение Conventional Commits. Ничего не коммить.
```

## Шаблонный промт

```text
/ecc-commit-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить подготовленные изменения и составить сообщение Conventional Commits для [цель или объект].
Фокус: staged diff, фактические соглашения истории репозитория, type/scope/summary и соответствие сообщения изменениям.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-commit-reviewer
Выполни задачу «проверить подготовленные изменения и составить сообщение Conventional Commits» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: staged diff, фактические соглашения истории репозитория, type/scope/summary и соответствие сообщения изменениям.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
