# `/ecc-database-reviewer`

**Назначение:** Эксперт по PostgreSQL: оптимизация запросов, проектирование схем, безопасность и производительность. Используйте при работе с SQL и миграциями, а также при диагностике БД; учитывает практики Supabase.

## Короткий промт

```text
/ecc-database-reviewer Проверь этот PostgreSQL-запрос или миграцию на корректность, безопасность и производительность; ничего не выполняй в БД.
```

## Шаблонный промт

```text
/ecc-database-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить запрос, схему или миграцию PostgreSQL для [цель или объект].
Фокус: корректность SQL, планы запросов, индексы, целостность, безопасность и применимые практики Supabase.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-database-reviewer
Выполни задачу «проверить запрос, схему или миграцию PostgreSQL» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: корректность SQL, планы запросов, индексы, целостность, безопасность и применимые практики Supabase.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
