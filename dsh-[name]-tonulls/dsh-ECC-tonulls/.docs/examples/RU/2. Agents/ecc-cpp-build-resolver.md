# `/ecc-cpp-build-resolver`

**Назначение:** Диагностирует и минимально исправляет ошибки сборки C++/CMake, компоновки и шаблонов. Используйте, когда сборка C++ завершается с ошибкой.

## Короткий промт

```text
/ecc-cpp-build-resolver Разбери текущую ошибку сборки C++/CMake и исправь подтверждённую причину минимально. Зависимости не устанавливай.
```

## Шаблонный промт

```text
/ecc-cpp-build-resolver
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: диагностировать и минимально исправить ошибку сборки C++/CMake для [цель или объект].
Фокус: первопричина ошибки компиляции/линковки/шаблонов, минимальный diff и локальная проверка.
Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-cpp-build-resolver
Выполни задачу «диагностировать и минимально исправить ошибку сборки C++/CMake» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: первопричина ошибки компиляции/линковки/шаблонов, минимальный diff и локальная проверка.
3. Внеси минимальную правку только после подтверждения первопричины и повтори подходящую локальную проверку.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Вноси только минимальные изменения в [разрешённая область], используя уже доступные локальные инструменты; ничего не устанавливай и не скачивай. Остановись и запроси подтверждение для широкого изменения.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
