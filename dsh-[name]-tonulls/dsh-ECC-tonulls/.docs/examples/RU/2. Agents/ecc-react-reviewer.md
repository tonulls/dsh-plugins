# Пример промта: `/ecc-react-reviewer`

**Команда вызова:** `/ecc-react-reviewer`

## Назначение

Проверяет React/JSX на корректность hooks, производительность рендеринга, server/client-границы, доступность и безопасность. Без изменений файлов.

## 1. Короткий запрос

```text
/ecc-react-reviewer Проведи read-only review React-изменений {путь}, ничего не редактируя.
```

## 2. Шаблонный запрос

```text
/ecc-react-reviewer Сделай read-only review React-изменений {файлы/дифф} в сценарии {поведение}. Проверь hooks, лишние рендеры, границы server/client, доступность и React-специфичные риски безопасности. Приведи только конкретные находки с местом, влиянием и рекомендацией; файлы не меняй.
```

## 3. Подробный запрос

```text
/ecc-react-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для react-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет React/JSX на корректность hooks, производительность рендеринга, server/client-границы, доступность и безопасность. Без изменений файлов.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
