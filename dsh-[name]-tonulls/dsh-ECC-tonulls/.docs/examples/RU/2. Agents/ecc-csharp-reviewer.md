# `/ecc-csharp-reviewer`

**Назначение:** Проверяет код C# и .NET: соглашения платформы, асинхронность, безопасность, nullable-типы и производительность. Используйте для изменений в проектах C#.

## Короткий промт

```text
/ecc-csharp-reviewer Проведи read-only ревью изменения C#/.NET с фокусом на async, nullable и безопасность.
```

## Шаблонный промт

```text
/ecc-csharp-reviewer
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить изменение C#/.NET для [цель или объект].
Фокус: корректность async, nullable reference types, безопасность и соглашения платформы.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-csharp-reviewer
Выполни задачу «проверить изменение C#/.NET» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: корректность async, nullable reference types, безопасность и соглашения платформы.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
