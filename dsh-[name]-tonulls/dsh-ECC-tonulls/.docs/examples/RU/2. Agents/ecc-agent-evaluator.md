# `/ecc-agent-evaluator`

Оценивает готовый ответ агента по пяти осям: точность, полнота, ясность, применимость и краткость. Нужен именно разбор уже выполненной нетривиальной задачи, а не выполнение новой.

## Короткий запрос

```text
/ecc-agent-evaluator Оцени предыдущий ответ по пяти осям. Подкрепи оценки наблюдаемыми примерами и предложи самые важные улучшения.
```

## Шаблон

```text
/ecc-agent-evaluator Оцени результат задачи «[краткое описание задачи]».
Ответ агента: [вставьте ответ]
Контекст и ограничения: [что требовалось, критерии приемки]
Поставь оценки точности, полноты, ясности, применимости и краткости; приведи обоснования и конкретные улучшения. Не додумывай факты, которых нет в контексте.
```

## Подробный запрос

```text
/ecc-agent-evaluator Проведи проверяемую оценку результата.
1. Сопоставь ответ с исходной задачей и перечисли подтвержденные факты отдельно от предположений.
2. Оцени пять осей: точность, полнота, ясность, применимость, краткость. Для каждой дай балл по шкале 1–5 и короткое доказательное объяснение.
3. Отметь существенные пропуски, противоречия и потенциально вводящие в заблуждение утверждения; не считай отсутствие сведений ошибкой без основания.
4. Предложи до трех приоритетных улучшений.
Формат: сначала итоговая оценка, затем таблица «ось / балл / свидетельство», далее замечания и рекомендации. Анализируй только этот ответ: [вставьте ответ]. Критерии задачи: [вставьте критерии].
```
