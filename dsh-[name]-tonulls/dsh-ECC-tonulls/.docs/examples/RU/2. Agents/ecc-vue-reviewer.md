# Пример промта: `/ecc-vue-reviewer`

**Команда вызова:** `/ecc-vue-reviewer`

## Назначение

Проверяет Vue-код на корректность Composition API и реактивности, архитектуру компонентов, безопасность шаблонов и производительность. Без правок.

## 1. Короткий запрос

```text
/ecc-vue-reviewer Проверь Vue-изменения {путь} на реактивность и шаблонную безопасность; без правок.
```

## 2. Шаблонный запрос

```text
/ecc-vue-reviewer Сделай read-only review Vue-изменений {файлы/дифф} в компоненте {сценарий}; учти используемые Pinia/Router/Nuxt. Проверь Composition API, реактивные зависимости, template escaping, жизненный цикл и производительность. Укажи только подтверждённые проблемы с местом и способом исправления; не меняй файлы.
```

## 3. Подробный запрос

```text
/ecc-vue-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для vue-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Проверяет Vue-код на корректность Composition API и реактивности, архитектуру компонентов, безопасность шаблонов и производительность. Без правок.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
