# Пример промта: `/ecc-pr-test-analyzer`

**Команда вызова:** `/ecc-pr-test-analyzer`

## Назначение

Оценивает полноту и полезность тестового покрытия PR с акцентом на поведение и предотвращение реальных регрессий.

## 1. Короткий запрос

```text
/ecc-pr-test-analyzer Проверь, какие важные поведения PR {ссылка/номер} не покрыты тестами; файлы не меняй.
```

## 2. Шаблонный запрос

```text
/ecc-pr-test-analyzer Проведи read-only анализ тестового покрытия PR {номер/дифф} относительно поведения {изменение}. Найди непроверенные сценарии, слабые assertions и тесты, не ловящие вероятные баги. Сопоставь каждую рекомендацию с требованием/риском; файлы и тесты не меняй.
```

## 3. Подробный запрос

```text
/ecc-pr-test-analyzer Проведи последовательный анализ задачи {сценарий/изменение} для pr-test-analyzer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: Оценивает полноту и полезность тестового покрытия PR с акцентом на поведение и предотвращение реальных регрессий.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
