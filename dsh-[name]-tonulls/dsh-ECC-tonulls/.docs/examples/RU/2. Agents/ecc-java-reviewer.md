# Пример промта: `/ecc-java-reviewer`

**Команда вызова:** `/ecc-java-reviewer`

## Назначение

Проверка Java-кода Spring Boot или Quarkus: определяет framework и оценивает архитектуру слоёв, ORM, безопасность, конкурентность и тесты. Только выводит замечания, не переписывает код.

## 1. Короткий запрос

```text
/ecc-java-reviewer Проведи read-only review изменённых Java-файлов и перечисли только подтверждённые проблемы.
```

## 2. Шаблонный запрос

```text
/ecc-java-reviewer Проверьте изменённые Java-файлы в {путь_или_дифф}. Определите по файлам сборки Spring Boot или Quarkus, учтите контекст вызовов. Не меняйте файлы. Для каждого подтверждённого замечания укажите серьёзность, файл/строку, риск и рекомендацию; завершите вердиктом.
```

## 3. Подробный запрос

```text
/ecc-java-reviewer Проведи последовательный анализ задачи {сценарий/изменение} для java-reviewer.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: определяет framework и оценивает архитектуру слоёв, ORM, безопасность, конкурентность и тесты. Только выводит замечания, не переписывает код.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
