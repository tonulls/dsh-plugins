# `/ecc-a11y-architect`

Проектирует и проверяет доступность веб- и нативных интерфейсов по WCAG 2.2: компоненты, дизайн-системы и инклюзивность.

## Простой запрос

```text
/ecc-a11y-architect Проверь доступность формы регистрации по WCAG 2.2 и перечисли главные проблемы. Ничего не меняй.
```

## Шаблонный запрос

```text
/ecc-a11y-architect Оцени доступность [экран/компонент] в [путь/описание]. Контекст пользователей: [аудитория]; платформы: [web/native]. Проверь семантику, клавиатурную навигацию, фокус и обратную связь. Только анализ, файлы не изменять; приводи подтверждения и приоритеты.
```

## Подробный запрос

```text
/ecc-a11y-architect Проведи аудит доступности [компонент/поток] для [платформа] с ориентиром на WCAG 2.2.
1. Изучи относящиеся к нему компоненты и состояния.
2. Проверь семантику, управление клавиатурой/фокусом, доступные имена, ошибки и адаптацию к вспомогательным технологиям.
3. Для каждого вывода укажи доказательство, затронутый сценарий и предполагаемую серьёзность; неизвестное пометь как требующее ручной проверки.
4. Предложи исправления и порядок работ, не редактируя файлы.
Отчёт: краткий итог, список находок, соответствующие критерии, рекомендации и ограничения проверки. Не запускай сеть или дополнительные инструменты без моего разрешения.
```
