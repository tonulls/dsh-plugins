# `/ecc-fastapi-reviewer` — примеры промтов

## Назначение

Проводит предметное ревью FastAPI: корректность async-кода и внедрения зависимостей, схемы Pydantic, безопасность, качество OpenAPI, тестирование и готовность к эксплуатации. Это анализ, не внесение правок.

## Короткий запрос

```text
/ecc-fastapi-reviewer Проведи только ревью FastAPI-кода {пути/diff}; проверь async, зависимости, схемы и безопасность. Ничего не меняй.
```

## Шаблонный запрос

```text
/ecc-fastapi-reviewer Проверь {endpoint/модуль} в {путь или diff}. Оцени корректность async-вызовов, dependency injection, Pydantic-валидацию, авторизацию, ошибки и OpenAPI-контракт. Приводи только подтверждённые находки с приоритетом, файлом/строкой, сценарием риска и рекомендацией; изменения не вноси.
```

## Подробный запрос

```text
/ecc-fastapi-reviewer Выполни read-only ревью FastAPI-изменения {diff/путь}, особенно для сценария {назначение endpoint}.
1. Проследи маршрут запроса и зависимости: порядок исполнения, блокирующие операции в async-контексте, жизненный цикл ресурсов и обработку ошибок.
2. Проверь Pydantic-схемы и границы доверия: валидацию входа/выхода, утечки полей, авторизацию и чувствительные данные.
3. Оцени HTTP-коды, контракт OpenAPI и наличие тестовых проверок существенного поведения.
4. Выдавай только конкретные дефекты или риски, подтверждаемые кодом; не представляй предпочтение стиля как баг.

Формат: находки по убыванию серьёзности (приоритет, файл/строка, условие воспроизведения, последствия, рекомендация), затем проверенные области и пробелы. Только анализ: не редактируй код; не устанавливай зависимости, не обращайся к сети и не выполняй деплой без согласия.
```
