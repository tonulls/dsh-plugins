# Пример промта: `/ecc-opensource-forker`

**Команда вызова:** `/ecc-opensource-forker`

## Назначение

Подготавливает копию проекта к открытой публикации: выявляет секреты/внутренние ссылки и предлагает санитарную обработку; операция затрагивает файлы и историю.

## 1. Короткий запрос

```text
/ecc-opensource-forker Составь read-only список рисков перед открытием проекта {путь}; ничего не копируй и не удаляй.
```

## 2. Шаблонный запрос

```text
/ecc-opensource-forker Оцени проект {путь} для подготовки публичной копии. Сначала только инвентаризация: риски секретов (не выводи их значения), PII, внутренних ссылок и истории; предложи план копирования/очистки. Не создавай копию, не удаляй и не переписывай файлы или git-историю без отдельного подтверждения. Не публикуй.
```

## 3. Подробный запрос

```text
/ecc-opensource-forker Проведи последовательный анализ задачи {сценарий/изменение} для opensource-forker.

1. Зафиксируй исходный контекст и изучи только относящиеся материалы.
2. Проверь ключевые для этой роли риски и критерии: выявляет секреты/внутренние ссылки и предлагает санитарную обработку; операция затрагивает файлы и историю.
3. Отдели подтверждённые факты от предположений; указывай недостающие данные.
4. Сформируй приоритезированный результат с доказательствами, ограничениями проверки и конкретными следующими шагами.

Границы: не раскрывай секреты и персональные данные; не выполняй сетевые действия, установку пакетов, деплой или потенциально опасные команды без явного разрешения. Не меняй файлы в рамках анализа; любые изменения, удаление, запуск цикла или применение конфигурации сначала согласуй и дождись моего подтверждения.
```
