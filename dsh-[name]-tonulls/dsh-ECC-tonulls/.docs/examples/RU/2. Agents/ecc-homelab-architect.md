# `/ecc-homelab-architect`

**Назначение:** Проектирует домашние и небольшие лабораторные сети по списку оборудования, целям и опыту оператора; предлагает безопасные поэтапные изменения и план отката.

## Короткий промт

```text
/ecc-homelab-architect По этому инвентарю оборудования предложи безопасный план сети для homelab с этапами и откатом.
```

## Шаблонный промт

```text
/ecc-homelab-architect
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: спроектировать безопасную домашнюю или небольшую лабораторную сеть для [цель или объект].
Фокус: инвентарь оборудования, цели и опыт оператора, поэтапные изменения и проверяемый откат.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-homelab-architect
Выполни задачу «спроектировать безопасную домашнюю или небольшую лабораторную сеть» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: инвентарь оборудования, цели и опыт оператора, поэтапные изменения и проверяемый откат.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
