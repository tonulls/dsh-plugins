# Примеры команд ECC

В этом разделе — примеры вызова трёх команд из пакета [commands](../../../../packages/commands/README.md). В обычном сообщении DSH укажите `/ecc-имя-компонента`, затем опишите задачу и ограничения. Команда задаёт инструкции для текущего Agent DSH.

Перечислены только записи `entries` каталога; для каждого компонента есть отдельный файл с тремя уровнями промта.

| Компонент | Краткое назначение | Примеры промтов |
| --- | --- | --- |
| `/ecc-command-build-fix` | Определяет систему сборки проекта и поэтапно исправляет ошибки сборки и типов минимальными безопасными изменениями. | [Три промта](ecc-command-build-fix.md) |
| `/ecc-command-test-coverage` | Анализирует покрытие тестами, выявляет пробелы и создаёт недостающие тесты для достижения заданного порога. | [Три промта](ecc-command-test-coverage.md) |
| `/ecc-command-update-docs` | Синхронизирует документацию с источниками истины: скриптами, схемами, маршрутами и экспортируемыми интерфейсами. | [Три промта](ecc-command-update-docs.md) |

**Итого:** 3 записей; отсутствующих файлов примеров: 0.
