# `dsh-ecc-agents` — режимы работы и примеры промтов

**Назначение:** включить или выключить автоматический выбор ролевых инструкций ECC Agents для текущей сессии. Переключатель доступен только пользователю и не запускает отдельного агента. Если конкретная задача ещё не сформулирована, начните с Исследования, затем перейдите к Анализу; Реализацию используйте для выбранного изменения. Эти три заголовка обозначают тип последующего запроса, а не дополнительные команды переключения.

Чтобы включить подбор, отправьте отдельным прямым сообщением пользователя:

```text
/dsh-ecc-agents on
```

Не добавляйте к команде задачу. После подтверждения выберите один шаблон ниже и отправьте его отдельным следующим сообщением. Чтобы выключить подбор, отправьте отдельно:

```text
/dsh-ecc-agents off
```

Явные вызовы `/ecc-*` остаются доступны и при выключенном автоподборе.
