# Примеры переключателей ECC Bundle

В этом разделе — четыре пользовательских переключателя из umbrella bundle. Они включают или выключают **автоматический выбор** соответствующей группы ECC-компонентов для текущей сессии DSH и доступны только пользователю.

Команду переключения отправляйте отдельным прямым сообщением пользователя — ровно в указанном виде, без кавычек и дополнительного текста. После подтверждения режима отправьте задачу следующим сообщением. Переключатели не создают отдельного агента и не отключают явный вызов `/ecc-*`.

| Переключатель | Назначение | Примеры |
| --- | --- | --- |
| `/dsh-ecc-agents on\|off` | Автоматический выбор ролевых инструкций ECC Agents в этой сессии. | [Три режима, девять промтов](<dsh-ecc-agents.md>) |
| `/dsh-ecc-skills on\|off` | Автоматический выбор ECC Skills в этой сессии. | [Три режима, девять промтов](<dsh-ecc-skills.md>) |
| `/dsh-ecc-commands on\|off` | Автоматический выбор проверенных ECC Commands в этой сессии. | [Три режима, девять промтов](<dsh-ecc-commands.md>) |
| `/dsh-ecc-tonulls on\|off` | Автоматический выбор всех включённых ECC-компонентов в этой сессии. `off` выключает все три группы. | [Три режима, девять промтов](<dsh-ecc-tonulls.md>) |

Индивидуальный переключатель можно использовать после `/dsh-ecc-tonulls on|off`, чтобы изменить режим только одной группы. Подробности bundle — в [README пакета](<../../../../packages/dsh-ecc-tonulls-en/README.md>).
