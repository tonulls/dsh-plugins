# ecc-kotlin-testing

Команда: `/ecc-kotlin-testing`

Подсказывает практики тестирования Kotlin через Kotest, MockK, корутины, property-based tests и Kover.

### Короткий запрос
```text
/ecc-kotlin-testing Напиши тесты для [Kotlin-функция/класс] на Kotest.
```

### Шаблонный запрос
```text
/ecc-kotlin-testing Подготовь тестовую стратегию для [компонент]. Используем [Kotest/MockK], поведение: [сценарии], зависимости: [описание]. Учти асинхронность [если есть] и предложи проверки покрытия.
```

### Подробный запрос
```text
/ecc-kotlin-testing Для [компонент] сначала выдели контракт и граничные случаи, затем составь набор тестов Kotest: успешные сценарии, ошибки, граничные значения и свойства. Для coroutine-кода укажи детерминированную проверку времени и отмены; MockK применяй только к внешним зависимостям. Опиши запуск и интерпретацию Kover. Не меняй файлы и не устанавливай зависимости. Верни структуру тестов, примеры и пробелы покрытия.
```
