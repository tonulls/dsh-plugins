# ecc-java-coding-standards

**Команда:** `/ecc-java-coding-standards`

**Назначение:** Стандарты Java для сервисов Spring Boot и Quarkus: именование, неизменяемость, Optional, Stream API, исключения, обобщённые типы, CDI, реактивные шаблоны и структура проекта. Автоматически учитывает соглашения фреймворка. Используйте при написании или проверке Java-сервиса Spring Boot или Quarkus.

## Промты

### 1. Короткий запрос

> /ecc-java-coding-standards Проверь Java-код на соответствие конвенциям Spring Boot.

### 2. Шаблон с контекстом

> /ecc-java-coding-standards Файл: [путь], фреймворк: [Spring Boot/Quarkus]. Оцени naming, immutability, Optional, streams, exceptions и CDI/reactive паттерны без правок.

### 3. Подробный запрос

> /ecc-java-coding-standards Сделай read-only обзор [класс/изменение]. Проверь Java стиль, generics, Optional, исключения, DI и framework-specific структуру. Для каждого подтверждённого замечания укажи место, эффект и исправление; не меняй файлы и не добавляй зависимости.
