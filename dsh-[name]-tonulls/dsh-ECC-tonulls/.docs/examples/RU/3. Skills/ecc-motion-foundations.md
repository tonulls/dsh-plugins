# `/ecc-motion-foundations`

**Назначение:** Токены анимации, пресеты пружин, правила производительности, адаптация к устройствам, требования доступности и безопасность SSR для React / Next.js с motion/react. Базовый слой для остальных motion-навыков. Используйте при настройке анимаций, reduced motion или безопасной для SSR анимации.

## Короткий промт

```text
/ecc-motion-foundations Составь базовые токены и правила анимации для приложения React/Next.js с поддержкой reduced motion и SSR.
```
