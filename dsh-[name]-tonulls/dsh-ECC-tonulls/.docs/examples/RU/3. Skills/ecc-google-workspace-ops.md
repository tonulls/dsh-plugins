# ecc-google-workspace-ops

**Команда:** `/ecc-google-workspace-ops`

**Назначение:** Работайте с Google Drive, Docs, Sheets и Slides как с единой средой для планов, трекеров, презентаций и общих документов. Используйте для поиска, обобщения, редактирования, переноса и очистки Google Workspace без низкоуровневых вызовов инструментов.

## Промты

### 1. Короткий запрос

> /ecc-google-workspace-ops Найди документы по [тема] и кратко опиши их.

### 2. Шаблон с контекстом

> /ecc-google-workspace-ops Цель: [поиск/сводка/редактирование], папка: [название], документ: [название]. Для любых изменений подготовь черновик и запроси подтверждение перед применением.

### 3. Подробный запрос

> /ecc-google-workspace-ops Помоги с Google Workspace задачей: [описание] в [Drive/Docs/Sheets/Slides]. Сначала определи нужные материалы и предложи план. Не удаляй, не перемещай, не делись и не изменяй документы без точного подтверждения; отчитайся о найденном и предложенных правках.
