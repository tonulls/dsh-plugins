# `/ecc-scientific-db-uspto-database`

Структурирует проверяемый поиск официальных данных USPTO: патентные записи, товарные знаки через TSDR, назначения прав и воспроизводимый журнал IP-исследования.

## Простой запрос
```text
/ecc-scientific-db-uspto-database Подскажи, как проверить запись товарного знака [название] в официальных системах USPTO.
```
## Шаблонный запрос
```text
/ecc-scientific-db-uspto-database
Тип поиска: [патент/товарный знак/переуступка]
Название или идентификатор: [данные]
Область и дата проверки: [параметры]
Составь план поиска по официальным источникам и журнал фиксируемых результатов; не делай юридических выводов без оговорок.
```
## Подробный запрос
```text
/ecc-scientific-db-uspto-database
Подготовь воспроизводимую проверку [объект/идентификаторы]. Этапы: уточни тип записи и варианты написания; укажи подходящие официальные интерфейсы USPTO (PatentSearch, TSDR, данные о назначениях — по применимости); сформируй запросы и поля фиксации; опиши сверку идентификатора, статуса, дат и связанных документов; отметь ограничения актуальности и неоднозначность совпадений. Не подавай заявлений и не изменяй записи. Сетевые обращения выполняй только после моего разрешения; не раскрывай конфиденциальные сведения. Отчет отделяет подтвержденные записи от похожих совпадений и указывает ссылки/время проверки либо честно сообщает, что поиск не запускался.
```
