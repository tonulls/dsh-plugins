# `/ecc-parallel-execution-optimizer`

**Назначение:** Ускоряет выполнение задачи, разбивая её на граф зависимостей и параллельные потоки с матрицей потоков, пакетным чтением и проверками, изолированными областями изменений (файлы, рабочие деревья Git, ветки или сервисы) и итоговой таблицей проверок. Используйте для параллельной работы, нескольких агентов, пакетных вызовов инструментов или независимых проверок без потери корректности.

## Короткий промт

```text
/ecc-parallel-execution-optimizer Разложи [задача] на независимые параллельные этапы с безопасными границами записи.
```

## Шаблонный промт

```text
/ecc-parallel-execution-optimizer
Контекст: [план задачи, зависимости между шагами, файлы с возможными пересечениями, доступные исполнители].
Задача: ускорить выполнение задачи разбиением на независимые параллельные этапы для [целевой компонент/результат].
Фокус: граф зависимостей, lane matrix, изоляция файлов/веток/сервисов, батчинг чтений и финальная таблица проверок.
Ограничения: Составь план параллельных lane и изоляции записи; не запускай субагентов и не меняй файлы без согласования.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-parallel-execution-optimizer
Выполни задачу «ускорить выполнение задачи разбиением на независимые параллельные этапы» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: граф зависимостей, lane matrix, изоляция файлов/веток/сервисов, батчинг чтений и финальная таблица проверок.
3. Построй dependency graph, выдели независимые lanes и зоны записи, укажи межзадачные зависимости и финальные проверки; исполнение не запускай.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Составь план параллельных lane и изоляции записи; не запускай субагентов и не меняй файлы без согласования.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
