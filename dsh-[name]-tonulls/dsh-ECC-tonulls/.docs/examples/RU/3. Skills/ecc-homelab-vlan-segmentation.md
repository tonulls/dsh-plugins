# ecc-homelab-vlan-segmentation

**Команда:** `/ecc-homelab-vlan-segmentation`

**Назначение:** Разделяйте домашнюю сеть на VLAN для IoT, гостей, доверенных устройств и серверов с UniFi, pfSense/OPNsense и MikroTik: настройка транковых портов, правил межсетевого экрана и беспроводных сетей SSID. Используйте при сегментации сети на этих платформах.

## Промты

### 1. Короткий запрос

> /ecc-homelab-vlan-segmentation Предложи план VLAN для IoT и гостевых устройств.

### 2. Шаблон с контекстом

> /ecc-homelab-vlan-segmentation Платформа: [UniFi/pfSense/OPNsense/MikroTik], VLAN сейчас: [описание], устройства: [категории]. Сформируй изоляцию и правила на высоком уровне.

### 3. Подробный запрос

> /ecc-homelab-vlan-segmentation Спроектируй сегментацию для [trusted/IoT/guest/server] на [платформа]. Укажи VLAN, trunk/SSID mapping и минимальные firewall flows; сначала только анализ конфигурации. Не меняй роутер/фаервол и не отключай доступ; опиши тесты, порядок применения и rollback, запроси подтверждение перед любым изменением.
