# `/ecc-agent-runtime-gateway-smoke-test`

Проверяет связность локального API агента, временного gateway-туннеля и callback удалённой песочницы с помощью задачи без инструментов, после чего восстанавливает исходное подключение приложения.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-agent-runtime-gateway-smoke-test Подготовь безопасный план smoke-проверки локального API, временного gateway и callback песочницы. Пока ничего не подключай и не запускай.
```

### 2. Шаблонный запрос
```text
/ecc-agent-runtime-gateway-smoke-test Проверь связность в [локальная среда]: API [адрес/способ проверки], временный gateway [доступный механизм], callback [песочница]. Используй только безынструментную задачу. Зафиксируй исходное подключение; не раскрывай туннель наружу и не меняй конфигурацию без согласия. Представь шаги, критерии успеха и восстановления.
```

### 3. Подробный запрос
```text
/ecc-agent-runtime-gateway-smoke-test Выполни smoke-проверку цепочки локальный API агента → временный gateway-туннель → callback удалённой песочницы. 1) До действий зафиксируй текущую конфигурацию подключения и способ её точного восстановления. 2) Проверь наличие разрешённого локального API и механизма временного туннеля; не устанавливай ПО и не обращайся к сети без моего согласия. 3) Используй только задачу, не требующую вызова инструментов, и проверь получение callback. 4) Не отправляй реальные данные и не оставляй туннель активным. 5) Восстанови исходное подключение и сообщи, удалось ли это подтвердить. Формат отчёта: предпосылки, каждый результат проверки, ошибки/непроверенные звенья, состояние после восстановления. Если требуется внешний доступ или небезопасное изменение — остановись и запроси разрешение.
```
