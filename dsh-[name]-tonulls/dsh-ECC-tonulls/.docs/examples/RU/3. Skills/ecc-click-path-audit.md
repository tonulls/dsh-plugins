# `/ecc-click-path-audit`

**Назначение:** Проследите полный цикл изменения состояния для каждой кнопки или точки взаимодействия. Найдите ошибки, когда функции по отдельности работают, но взаимно отменяются, дают неверный результат или оставляют пользовательский интерфейс в несогласованном состоянии. Используйте, если систематическая отладка не выявила причину жалоб на кнопки, или после крупного рефакторинга общих хранилищ состояния.

## Короткий промт

```text
/ecc-click-path-audit Проследи путь изменения состояния для этих кнопок и найди сценарии, где действия отменяют друг друга или ломают UI.
```

## Шаблонный промт

```text
/ecc-click-path-audit
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проследить полный цикл изменения состояния UI для каждой точки взаимодействия для [цель или объект].
Фокус: обработчики кнопок, store/state transitions, побочные эффекты и рассинхронизация интерфейса.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-click-path-audit
Выполни задачу «проследить полный цикл изменения состояния UI для каждой точки взаимодействия» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: обработчики кнопок, store/state transitions, побочные эффекты и рассинхронизация интерфейса.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
