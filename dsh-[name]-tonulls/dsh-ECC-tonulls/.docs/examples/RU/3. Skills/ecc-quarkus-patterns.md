# `/ecc-quarkus-patterns`

**Назначение:** Архитектурные практики Quarkus 3.x LTS с Camel для обмена сообщениями, проектирования REST API, сервисов CDI, доступа к данным через Panache и асинхронной обработки. Используйте для бэкендов Java Quarkus с событийной архитектурой, особенно при работе с Camel или Panache.

## Короткий промт

```text
/ecc-quarkus-patterns Проверь структуру Quarkus-сервиса с [Camel/Panache] и предложи улучшения без правок.
```
