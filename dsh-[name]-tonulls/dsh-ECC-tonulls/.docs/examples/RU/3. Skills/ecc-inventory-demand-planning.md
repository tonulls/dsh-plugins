# ecc-inventory-demand-planning

**Команда:** `/ecc-inventory-demand-planning`

**Назначение:** Практики планирования спроса для розницы с несколькими точками: выбор метода прогноза, сегментация ABC/XYZ, оптимизация страхового запаса и точки заказа, оценка эффекта промо и спада после него, сезонных переходов и сроков уценки. Используйте для прогнозирования спроса, пополнения, промо и оптимизации запасов.

## Промты

### 1. Короткий запрос

> /ecc-inventory-demand-planning Оцени точки заказа для ассортимента.

### 2. Шаблон с контекстом

> /ecc-inventory-demand-planning Магазины: [число], SKU: [группа], спрос/срок поставки: [данные], сезонность: [описание]. Предложи метод прогноза и неизвестные.

### 3. Подробный запрос

> /ecc-inventory-demand-planning Подготовь план спроса для [категория/локации]. Сегментируй ABC/XYZ, выбери прогнозный подход, оцени safety stock/reorder point и влияние промо/сезона по предоставленным данным. Не делай закупочных заказов и не меняй системы. Верни допущения, расчёты, рекомендации и проверки.
