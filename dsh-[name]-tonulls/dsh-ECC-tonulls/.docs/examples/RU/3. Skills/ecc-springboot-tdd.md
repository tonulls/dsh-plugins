# `/ecc-springboot-tdd`

Помогает вести разработку Spring Boot через тесты: JUnit 5, Mockito, MockMvc, Testcontainers и JaCoCo по применимости.

## Простой запрос
```text
/ecc-springboot-tdd Составь тесты JUnit для сценария [поведение] в этом Spring Boot сервисе.
```
## Шаблонный запрос
```text
/ecc-springboot-tdd
Изменение/дефект: [описание]
Код и контракт: [фрагменты]
Стек тестов: [JUnit/Mockito/MockMvc/Testcontainers]
Сначала предложи тест, который фиксирует ожидаемое поведение, затем минимальную реализацию и регрессионные проверки.
```
## Подробный запрос
```text
/ecc-springboot-tdd
Реализуй задачу [описание] для Spring Boot с TDD. Этапы: извлеки критерии приемки и границы поведения; предложи тесты JUnit 5 для happy path, валидации, ошибок и интеграционных контрактов; сначала зафиксируй ожидаемый красный тест; затем минимально реализуй изменение; повторно проверь и рефакторь без изменения поведения. Используй Mockito/MockMvc/Testcontainers только где уместно и уже доступно. Не устанавливай зависимости и не меняй файлы без моего подтверждения; тестовые команды запускай только с разрешения. Итог: связь критериев с тестами, фактически выполненные проверки и оставшиеся пробелы.
```
