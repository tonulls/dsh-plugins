# `/ecc-coding-standards`

**Назначение:** Базовые соглашения о коде для разных проектов: именование, читаемость, неизменяемость и проверка качества. Для специфичных практик используйте подробные навыки клиентской и серверной частей. Применяйте при оценке качества или именования, если подходящего навыка для конкретного фреймворка нет.

## Короткий промт

```text
/ecc-coding-standards Проверь изменённый код на базовые стандарты читаемости, именования и неизменяемости; не дублируй правила специфичного фреймворка.
```

## Шаблонный промт

```text
/ecc-coding-standards
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить код на базовые соглашения, когда нет более узкого framework-навыка для [цель или объект].
Фокус: именование, читаемость, неизменяемость и единообразные критерии качества.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-coding-standards
Выполни задачу «проверить код на базовые соглашения, когда нет более узкого framework-навыка» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: именование, читаемость, неизменяемость и единообразные критерии качества.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
