# `/ecc-postgres-patterns`

**Назначение:** Практики PostgreSQL: оптимизация запросов, проектирование схем, индексация и безопасность на основе рекомендаций Supabase. Используйте при проектировании схем, индексов и политик RLS либо при медленных запросах.

## Короткий промт

```text
/ecc-postgres-patterns Разбери этот PostgreSQL-запрос и предложи проверяемую оптимизацию без подключения к БД.
```

## Шаблонный промт

```text
/ecc-postgres-patterns
Контекст: [SQL/схема/миграция, версия PostgreSQL, пример нагрузки и обезличенный план запроса].
Задача: проверить или спроектировать PostgreSQL-схему, запросы, индексы или RLS для [целевой компонент/результат].
Фокус: план запроса, индексы, целостность данных, безопасность доступа и применимые практики Supabase.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-postgres-patterns
Выполни задачу «проверить или спроектировать PostgreSQL-схему, запросы, индексы или RLS» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: план запроса, индексы, целостность данных, безопасность доступа и применимые практики Supabase.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
