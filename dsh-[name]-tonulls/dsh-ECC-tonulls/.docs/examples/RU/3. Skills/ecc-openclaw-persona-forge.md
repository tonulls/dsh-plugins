# `/ecc-openclaw-persona-forge`

Создаёт концепцию личности OpenClaw-агента: идентичность, черновик `SOUL.md`, границы роли, имя и текстовый запрос для аватара. Изображение создаётся только при наличии разрешённого инструмента генерации.

## Простой запрос

```text
/ecc-openclaw-persona-forge Придумай дружелюбного OpenClaw-помощника для домашней библиотеки.
```

## Шаблонный запрос

```text
/ecc-openclaw-persona-forge Создай личность OpenClaw: задача агента — [назначение], аудитория — [кто общается], желаемый тон — [тон], важные ограничения — [границы]. Подготовь идентичность, SOUL.md, имя и текстовый промт аватара. Не создавай файл и изображение без моего отдельного подтверждения.
```

## Подробный запрос

```text
/ecc-openclaw-persona-forge Разработай персонажа OpenClaw для [сценарий].
1. Уточни недостающие предпочтения; не выдумывай факты о владельце.
2. Предложи позиционирование, характер и имя.
3. Подготовь черновик SOUL.md с ролью и явными границами поведения.
4. Сформулируй отдельный текстовый запрос для аватара, соблюдая единую визуальную идею.
5. Покажи всё на согласование. Не изменяй существующие файлы, не запускай генерацию изображения и не подключай внешние сервисы без моего явного подтверждения.
В конце перечисли допущения и вопросы.
```
