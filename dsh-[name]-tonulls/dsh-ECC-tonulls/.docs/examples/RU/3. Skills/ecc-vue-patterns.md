# `/ecc-vue-patterns`

Подсказывает практики Vue 3 и Nuxt: Composition API, архитектуру компонентов, реактивность, Pinia, Vue Router и SSR.

## Простой запрос
```text
/ecc-vue-patterns Предложи Composition API вариант компонента Vue для [сценарий] с корректным управлением состоянием.
```
## Шаблонный запрос
```text
/ecc-vue-patterns
Стек и версии: [Vue/Nuxt/Pinia]
Компонент или проблема: [описание]
Код/ограничения: [фрагменты]
Подскажи идиоматичное решение по реактивности, состоянию и маршрутизации, подходящее текущему проекту.
```
## Подробный запрос
```text
/ecc-vue-patterns
Спроектируй/проверь [функцию] в Vue 3/Nuxt [версии]. 1) Определи границы компонентов и владение состоянием. 2) Проверь корректное использование Composition API и реактивности, включая побочные эффекты. 3) Обоснуй, нужен ли Pinia или достаточно локального состояния. 4) Разбери маршрутизацию, SSR/hydration и производительность по применимости. 5) Предложи тестируемые сценарии. Не меняй файлы, не устанавливай пакеты, не подключай сеть и не публикуй изменения без явного разрешения. Итог: рекомендуемая структура/эскиз, риски, допущения и план проверки.
```
