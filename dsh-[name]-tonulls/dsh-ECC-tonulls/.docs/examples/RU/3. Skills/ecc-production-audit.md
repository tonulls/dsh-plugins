# `/ecc-production-audit`

**Назначение:** Оценивает готовность приложений к рабочей эксплуатации по локальным данным: перед запуском, после слияния и в ответ на вопрос «что сломается в рабочей среде?». Данные репозитория не отправляются во внешний сервис аудита.

## Короткий промт

```text
/ecc-production-audit Проведи аудит готовности [сервис] к production только по локальным доказательствам.
```

## Шаблонный промт

```text
/ecc-production-audit
Контекст: [путь к сервису, изменённые области, конфиги и локальные логи без секретов].
Задача: оценить production readiness локального приложения до релиза или после merge для [целевой компонент/результат].
Фокус: конфигурация и окружение, наблюдаемость, миграции, безопасность, failure modes и локальные доказательства без выгрузки репозитория во внешний аудит.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-production-audit
Выполни задачу «оценить production readiness локального приложения до релиза или после merge» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: конфигурация и окружение, наблюдаемость, миграции, безопасность, failure modes и локальные доказательства без выгрузки репозитория во внешний аудит.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
