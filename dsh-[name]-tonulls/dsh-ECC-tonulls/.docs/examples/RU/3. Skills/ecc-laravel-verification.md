# ecc-laravel-verification

**Команда:** `/ecc-laravel-verification`

**Назначение:** Поэтапная проверка Laravel-проекта перед слиянием или выпуском: окружение, линтеры, статический анализ, тесты и покрытие, security-сканирование и готовность к развертыванию.

## Промты

### 1. Короткий запрос

> /ecc-laravel-verification Составь read-only план проверки этого Laravel PR перед merge: окружение, lint, анализ, тесты, безопасность и открытые риски. Ничего не запускай и не разворачивай.

### 2. Шаблон с заполнителями

> /ecc-laravel-verification Подготовь проверку Laravel-проекта [путь/ветка] перед [merge/release]. Известные команды: [команды или «найди в конфигурации»], целевое покрытие [порог/не задано], ограничения окружения [описание]. Сверь доступные настройки lint/static analysis/tests/security, предложи безопасный порядок и критерии PASS/FAIL. Не устанавливай зависимости и не запускай destructive-команды; любые проверки, затрагивающие данные или окружение, только после согласования.

### 3. Подробный поэтапный запрос

> /ecc-laravel-verification Проведи предварительный аудит готовности Laravel-изменения [описание/PR] без выполнения проверок. 1) Определи по конфигурации проекта необходимые версии PHP/Laravel и доступность локальных инструментов, не устанавливая недостающие. 2) Составь упорядоченные этапы: форматирование/lint, статический анализ, тесты с фактически заданными целями покрытия, security-проверки, миграции и конфигурация. 3) Для каждого этапа укажи точную команду только если она подтверждена файлами репозитория, побочные эффекты и условие остановки при сбое. 4) Отдельно обозначь deployment readiness как оценку, а не разрешение на deploy. Вывод: таблица «этап / основание / команда / критерий / риск», затем блокеры и отсутствующие сведения. Только анализ: не запускай команды, не меняй файлы, не устанавливай пакеты, не ходи в сеть и не выполняй deploy.
