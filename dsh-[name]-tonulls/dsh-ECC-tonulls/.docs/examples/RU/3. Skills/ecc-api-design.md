# `/ecc-api-design`

Проектирование и анализ REST API: имена ресурсов, HTTP-статусы, пагинация, фильтрация, формат ошибок, версионирование и ограничения частоты запросов.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-api-design Проверь дизайн REST-эндпоинта [метод и путь]: ресурсы, статусы и ошибки. Только анализ, код не меняй.
```

### 2. Шаблонный запрос
```text
/ecc-api-design Спроектируй REST API для [сценарий] в [система]. Клиенты: [клиенты]; ожидаемый объём/ограничения: [данные]. Предложи пути, методы, пагинацию и ошибки; явно обозначь неизвестные требования.
```

### 3. Подробный запрос
```text
/ecc-api-design Проведи ревью контракта [эндпоинты/спецификация] для [задача]. 1) Определи ресурсы и операции по предоставленным требованиям. 2) Для каждого маршрута укажи метод, путь, вход/выход и подходящие статусы. 3) Проверь пагинацию, фильтры, единый формат ошибок, версионирование и rate limiting там, где это уместно. 4) Сверь совместимость с существующими клиентами, если их контракты доступны. Не меняй код и не придумывай требования. Результат: таблица маршрутов, замечания с обоснованием и вопросы для уточнения.
```
