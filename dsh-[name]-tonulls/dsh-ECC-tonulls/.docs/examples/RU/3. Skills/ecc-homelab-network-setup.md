# ecc-homelab-network-setup

**Команда:** `/ecc-homelab-network-setup`

**Назначение:** Практическое планирование домашней сети и домашней лаборатории: шлюзы, коммутаторы, точки доступа, диапазоны IP, резервации DHCP, DNS, кабели и типичные ошибки новичков. Используйте при планировании или настройке домашней сети и лаборатории.

## Промты

### 1. Короткий запрос

> /ecc-homelab-network-setup Помоги спланировать домашнюю сеть для [задача].

### 2. Шаблон с контекстом

> /ecc-homelab-network-setup Оборудование: [gateway/switch/AP], устройства: [число/типы], IP-диапазон: [CIDR]. Предложи DHCP, DNS и кабельную схему без изменения настроек.

### 3. Подробный запрос

> /ecc-homelab-network-setup Спроектируй домашнюю сеть для [потребности]. Уточни шлюз, адресацию, DHCP reservations, DNS, Wi-Fi/AP и кабели; проверь конфликты и простые ошибки. Не сканируй сеть и не применяй конфиги. Верни схему, план проверки и вопросы перед реализацией.
