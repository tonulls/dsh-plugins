# ecc-kotlin-patterns

Команда: `/ecc-kotlin-patterns`

Помогает писать и проверять идиоматичный Kotlin: null-безопасность, корутины и DSL.

### Короткий запрос
```text
/ecc-kotlin-patterns Проверь этот Kotlin-код на идиоматичность и небезопасную работу с null: [фрагмент]
```

### Шаблонный запрос
```text
/ecc-kotlin-patterns Помоги спроектировать Kotlin-компонент для [задача]. Контекст: [версия Kotlin/платформа], ограничения [производительность/совместимость]. Предложи идиоматичную структуру, типы и обработку ошибок; отметь решения по null-безопасности и корутинам, если применимо.
```

### Подробный запрос
```text
/ecc-kotlin-patterns Разбери задачу [описание] для проекта [контекст и версия Kotlin]. 1) Определи подходящие идиомы и структуру. 2) Покажи минимальный пример кода с безопасной обработкой null и ошибок. 3) Если есть асинхронность, объясни выбор coroutine scope и отмену. 4) Укажи компромиссы и потенциальные антипаттерны. Не меняй файлы и не запускай команды. В отчёте дай рекомендации, пример и список допущений.
```
