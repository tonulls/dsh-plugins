# `/ecc-competitive-report-structure`

Собирает уже оценённые карточки конкурентов в отчёт для принятия решений: карту рынка, уровни, сравнительную матрицу, свободные ниши и стратегические выводы.

## Простой запрос

```text
/ecc-competitive-report-structure Собери из этих профилей конкурентов краткий отчёт для руководства.
```

## Шаблонный запрос

```text
/ecc-competitive-report-structure
Аудитория отчёта: [руководство/совет]
Цель решения: [что нужно решить]
Профили с оценками: [вставьте данные или укажите доступные материалы]
Оформи карту рынка, уровни конкурентов, матрицу сравнения, свободные ниши и рекомендации; отдели факты от выводов.
```

## Подробный запрос

```text
/ecc-competitive-report-structure
На основе предоставленных оценённых профилей подготовь конкурентный отчёт для [аудитория], который поможет решить [вопрос]. 1) Проверь полноту входных данных и явно перечисли пробелы. 2) Сгруппируй конкурентов по уровням и покажи карту ландшафта. 3) Сведи сопоставимые измерения в матрицу, не подменяя отсутствующие данные догадками. 4) Выдели подтверждённые свободные ниши и их ограничения. 5) Дай обоснованные стратегические варианты и вопросы для выравнивания команды. Не собирай новые данные из сети без разрешения и не меняй исходные материалы. Выведи резюме, таблицы, выводы с привязкой к доказательствам и перечень неизвестного.
```
