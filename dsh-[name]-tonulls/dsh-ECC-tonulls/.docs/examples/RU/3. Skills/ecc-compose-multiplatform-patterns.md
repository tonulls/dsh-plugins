# `/ecc-compose-multiplatform-patterns`

Помогает проектировать и реализовывать UI на Compose Multiplatform и Jetpack Compose в KMP: состояние, навигацию, темы, производительность и платформенные особенности.

## Простой запрос

```text
/ecc-compose-multiplatform-patterns Подскажи, как организовать состояние экрана каталога в Compose Multiplatform.
```

## Шаблонный запрос

```text
/ecc-compose-multiplatform-patterns
Проект: [KMP-платформы и версии]
Экран/функция: [описание]
Текущая архитектура состояния: [описание или фрагменты]
Предложи подход к состоянию, навигации и разделению общего и платформенного UI с учётом существующих соглашений.
```

## Подробный запрос

```text
/ecc-compose-multiplatform-patterns
Разбери задачу [экран или изменение] в KMP-приложении для [Android/iOS/desktop/web; версии]. Изучи предоставленные файлы и принятые в репозитории паттерны. По шагам: определи владельца состояния и поток событий; предложи структуру composable и навигацию; укажи, что безопасно вынести в общий модуль, а что оставить платформенным; проверь доступность, recomposition и потенциальные узкие места; предложи проверяемые тесты. Не добавляй зависимости и не изменяй файлы без моего подтверждения. В отчёте дай рекомендуемую схему, компромиссы, затронутые места и тестовые сценарии.
```
