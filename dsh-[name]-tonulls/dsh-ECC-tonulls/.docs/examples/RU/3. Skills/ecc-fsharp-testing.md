# ecc-fsharp-testing

**Команда:** `/ecc-fsharp-testing`

**Назначение:** Практики тестирования F#: xUnit, FsUnit, Unquote, проверка свойств с FsCheck и организация интеграционных тестов. Используйте при написании F#-тестов с xUnit, FsUnit, Unquote или FsCheck.

## Промты

### 1. Короткий запрос

> /ecc-fsharp-testing Подскажи тесты для этой F# функции.

### 2. Шаблон с контекстом

> /ecc-fsharp-testing Функция: [имя], поведение: [ожидаемое], проект использует [xUnit/FsUnit/Unquote/FsCheck]. Предложи примеры и свойства.

### 3. Подробный запрос

> /ecc-fsharp-testing Разработай стратегию тестирования [модуль] на F#. Определи unit/integration границы, xUnit/FsUnit/Unquote примеры и свойства FsCheck, включи крайние случаи. Не запускай команды и не меняй файлы без разрешения; выведи матрицу кейсов и код-примеры.
