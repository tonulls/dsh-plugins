# `/ecc-django-tdd`

Помогает вести Django/DRF-разработку через тесты с pytest-django, factory_boy и моками, включая TDD и проверку покрытия.

## Простой запрос

```text
/ecc-django-tdd Напиши pytest-django тесты для DRF-эндпоинта, который фильтрует заказы по статусу.
```

## Шаблонный запрос

```text
/ecc-django-tdd
Функция/эндпоинт: [описание]
Ожидаемые правила: [список]
Текущий pytest-django setup: [фрагменты]
Фабрики и аутентификация: [что уже есть]
Составь тестовую матрицу и следуй стилю репозитория; не устанавливай пакеты.
```

## Подробный запрос

```text
/ecc-django-tdd
Реализуй тестирование [функция/дефект] в Django/DRF проекте через существующий pytest-django стек. Сначала определи наблюдаемое поведение и напиши план тестов: успешные сценарии, валидация, права доступа, пустые/граничные данные и ошибки. Используй имеющиеся factory_boy фабрики и моки только на внешних границах; для дефекта зафиксируй регрессию до исправления реализации. Не вызывай реальные внешние API и не меняй данные вне изолированной тестовой БД. Новые зависимости/конфигурацию согласуй заранее. После подтверждения меняй только необходимые тестовые и, если явно поручено, производственные файлы; запусти выбранные локальные тесты и сообщи фактические результаты.
```
