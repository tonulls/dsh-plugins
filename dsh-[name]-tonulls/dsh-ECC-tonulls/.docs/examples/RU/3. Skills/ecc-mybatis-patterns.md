# `/ecc-mybatis-patterns`

**Назначение:** Практики MyBatis и MyBatis-Spring: проектирование mapper, SQL в XML и аннотациях, сопоставление результатов, безопасность динамических запросов, транзакции, пакетная обработка, пагинация и производительность запросов. Используйте для разработки или проверки Java-доступа к данным с MyBatis, Spring Boot или унаследованными приложениями на MyBatis.

## Короткий промт

```text
/ecc-mybatis-patterns Проведи ревью этого MyBatis mapper и связанного SQL на безопасность, транзакции и производительность.
```

