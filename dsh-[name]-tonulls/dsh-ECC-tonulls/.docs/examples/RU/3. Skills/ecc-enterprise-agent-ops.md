# `/ecc-enterprise-agent-ops`

Помогает управлять эксплуатацией долгоживущих агентных систем: жизненным циклом, наблюдаемостью, ограничениями полномочий, kill switch и контролируемыми rollout/rollback.

## Простой запрос

```text
/ecc-enterprise-agent-ops Составь чек-лист мониторинга и безопасной остановки production-флота агентов.
```

## Шаблонный запрос

```text
/ecc-enterprise-agent-ops
Среда запуска: [PM2/systemd/контейнеры]
Число и роль агентов: [описание]
Доступные логи/метрики/трейсы: [перечень]
Политика полномочий и kill switch: [описание]
Сделай read-only оценку; не останавливай процессы и не выполняй rollout.
```

## Подробный запрос

```text
/ecc-enterprise-agent-ops
Оцени эксплуатационные контроли для агентного сервиса [система] на [PM2/systemd/контейнерной платформе]. Проверь предложенный lifecycle (start/pause/stop/restart), логи/метрики/трейсы, минимальные safety scopes и проверяемый kill switch, audit trail, rollout/rollback gates и метрики успеха/стоимости. Выяви пробелы мониторинга и инцидентный сценарий; предложи критерии остановки и восстановление. Не выполняй команды управления, не меняй конфигурацию, не деплой и не обращайся к сети без отдельного явного подтверждения. Отчёт: риски по приоритету, необходимая телеметрия, безопасная схема изменения и план проверки/отката.
```
