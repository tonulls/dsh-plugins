# `/ecc-scientific-thinking-literature-review`

Помогает провести систематизированный обзор научной и технической литературы: план поиска, отбор источников, синтез результатов, проверка цитирования и журнал свидетельств.

## Простой запрос
```text
/ecc-scientific-thinking-literature-review Составь план обзора литературы по теме [тема] с критериями отбора.
```
## Шаблонный запрос
```text
/ecc-scientific-thinking-literature-review
Исследовательский вопрос: [вопрос]
Области/даты/языки: [границы]
Типы публикаций: [критерии]
Предложи стратегию поиска, скрининга и синтеза; отделяй план от фактически найденных источников.
```
## Подробный запрос
```text
/ecc-scientific-thinking-literature-review
Подготовь воспроизводимый обзор по вопросу [вопрос]. Этапы: 1) задай рамки, определения и критерии включения/исключения; 2) сформируй поисковые запросы по подходящим базам и план регистрации поиска; 3) опиши дедупликацию и скрининг заголовков/аннотаций/полных текстов; 4) задай извлекаемые поля и оценку качества доказательств; 5) предложи метод синтеза и проверки цитат. Не выдумывай источники или результаты, не выдавай план за выполненный поиск. Сеть используй только с разрешения; медицинские решения не подменяй обзором. Итог: протокол, таблица доказательств, ограничения и список проверенных ссылок/идентификаторов либо отметка, что поиск не выполнялся.
```
