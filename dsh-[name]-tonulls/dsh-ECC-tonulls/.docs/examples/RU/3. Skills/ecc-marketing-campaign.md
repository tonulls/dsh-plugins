# `/ecc-marketing-campaign`

**Назначение:** Планирует и проводит маркетинговые кампании: изучение аудитории, позиционирование, идея кампании, тексты лендинга, письма, публикации, объявления, короткие видеосценарии и контент-планы. Используйте для координации запуска продукта на нескольких каналах или подготовки маркетинговых материалов.

## Короткий промт

```text
/ecc-marketing-campaign Составь план кампании для запуска [продукт] на [каналы] с аудиторией, сообщениями и метриками.
```

## Шаблонный промт

```text
/ecc-marketing-campaign
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: спланировать кампанию запуска продукта на нескольких каналах для [цель или объект].
Фокус: аудитория, позиционирование, цель, материалы, каналы, календарь и измеримые метрики.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-marketing-campaign
Выполни задачу «спланировать кампанию запуска продукта на нескольких каналах» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: аудитория, позиционирование, цель, материалы, каналы, календарь и измеримые метрики.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
