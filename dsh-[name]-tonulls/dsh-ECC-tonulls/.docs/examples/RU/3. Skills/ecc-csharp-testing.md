# `/ecc-csharp-testing`

Предлагает практики тестирования C#/.NET с xUnit, FluentAssertions, моками, интеграционными тестами и организованной структурой тестов.

## Простой запрос

```text
/ecc-csharp-testing Напиши xUnit-тесты для проверки обработки пустого списка заказов.
```

## Шаблонный запрос

```text
/ecc-csharp-testing
Компонент: [тип/метод]
Ожидаемое поведение: [правила]
Текущий стек тестов: [xUnit, FluentAssertions, библиотеки моков]
Граничные случаи: [список]
Предложи структуру тестов и не устанавливай пакеты.
```

## Подробный запрос

```text
/ecc-csharp-testing
Разработай тестовое покрытие для [функция] в .NET проекте с [xUnit/FluentAssertions/моки]. Сверься с существующей структурой. Сформируй сценарии успеха, граничных значений и ошибок; отдели unit-уровень от интеграционных проверок, моки используй только для внешних границ и сделай тесты детерминированными. Если требуется пакет или изменение проекта, сначала запроси разрешение и предложи вариант без него. Не обращайся к внешним системам и не изменяй производственное поведение без отдельного запроса. После согласования внеси ограниченные изменения и запусти только локальный тестовый набор; отчитайся о командах и фактическом результате.
```
