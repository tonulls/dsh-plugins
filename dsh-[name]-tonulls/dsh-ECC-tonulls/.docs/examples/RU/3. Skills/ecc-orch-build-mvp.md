# `/ecc-orch-build-mvp`

Преобразует дизайн или спецификацию MVP в вертикальные срезы и организует последовательную сборку с проверками и контрольными точками.

## Простой запрос
```text
/ecc-orch-build-mvp По приложенной спецификации составь план первого рабочего среза и дождись моего одобрения.
```
## Шаблонный запрос
```text
/ecc-orch-build-mvp Спецификация: [путь/текст]. Целевая аудитория: [аудитория]. MVP должен включать [минимальный сценарий]. Разбей на вертикальные срезы и предложи первый; не меняй файлы до одобрения плана.
```
## Подробный запрос
```text
/ecc-orch-build-mvp Используй [спецификацию] как источник требований. 1) Извлеки сценарии, ограничения и неизвестное. 2) Разложи MVP на независимые вертикальные срезы с критериями приёмки. 3) Покажи план и остановись до подтверждения. После подтверждения выполняй срезы по одному, проверяя каждый доступными локальными тестами и обзором изменений. Не устанавливай пакеты, не обращайся к сети, не деплой и не коммить без отдельного разрешения. Отчёт: завершённые срезы, проверки, пробелы и следующий шаг.
```
