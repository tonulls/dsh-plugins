# `/ecc-benchmark-optimization-loop`

Помогает ускорить программу через ограниченный измеряемый цикл: сначала фиксируется базовый уровень, затем проверяются варианты с одной гипотезой за раз, каждый проходит проверку корректности, а лучший безопасный вариант сопровождается воспроизводимыми командами.

## Короткий запрос

```text
/ecc-benchmark-optimization-loop Найди и измеримо устрани главную причину медленной обработки очереди задач. Сначала зафиксируй базовые метрики; корректность важнее скорости.
```

## Шаблон

```text
/ecc-benchmark-optimization-loop Оптимизируй [компонент/операцию] в [путь или модуль]. Симптом: [наблюдаемая задержка/пропускная способность/стоимость]. Цель: [числовой порог]. Ограничения: [память, совместимость, бюджет времени]. Для каждого варианта — одна гипотеза, одинаковая методика замера и проверка корректности; не продвигай вариант, если результаты нестабильны или поведение меняется.
```

## Поэтапный запрос

```text
/ecc-benchmark-optimization-loop Ускорь [конкретный сценарий]. Работай ограниченным циклом:
1. Определи входные данные и воспроизводимую команду; сними baseline (время/пропускная способность и разброс) без изменения кода.
2. Найди вероятное узкое место и сформулируй несколько независимых гипотез. Меняй за итерацию только одну причину.
3. Для каждого варианта повтори одинаковый benchmark и correctness gate; отклоняй ускорение, которое нарушает результаты, инварианты либо лимит ресурсов [указать].
4. Остановись после [N] вариантов, при достижении цели [метрика] или если данные недостаточны. Без согласия не устанавливай зависимости, не обращайся к сети и не разворачивай изменения.

Вывод: baseline и методика; таблица «гипотеза / изменение / метрики / корректность»; выбранный вариант либо вывод, что безопасного выигрыша не найдено; воспроизводимые команды и ограничения измерений. Меняй код только если явно поручено; иначе представь план.
```
