# `/ecc-swiftui-patterns`

Подсказывает архитектуру SwiftUI: состояние с `@Observable`, композицию представлений, навигацию и оптимизацию производительности UI.

## Простой запрос
```text
/ecc-swiftui-patterns Предложи, как разделить состояние и представления SwiftUI для экрана [описание].
```
## Шаблонный запрос
```text
/ecc-swiftui-patterns
Экран и сценарии: [описание]
Текущие View/модель: [код]
Целевые iOS/macOS версии: [версии]
Нужны рекомендации по @Observable, навигации и композиции с учетом текущего проекта.
```
## Подробный запрос
```text
/ecc-swiftui-patterns
Проанализируй экран [описание] в приложении для [платформа/версия]. Этапы: определить владельца состояния и поток обновлений; предложить @Observable и границы моделей; разложить View на композиционные части; описать навигацию и передачу зависимостей; оценить потенциальные лишние перерисовки и доступность по имеющимся данным. Не меняй файлы, не добавляй пакеты и не выполняй сетевые/публикационные действия. Выдай рекомендуемую структуру, эскиз SwiftUI, компромиссы и конкретные проверки поведения/производительности.
```
