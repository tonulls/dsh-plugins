# `/ecc-change-impact`

Перед изменением кода, данных, интерфейсов или правил выполняет доказательный анализ влияния: пути вызовов, схемы, API-контракты, тесты, документация/ADR, миграция, развёртывание и откат. После реализации сопоставляет прогноз с фактическим diff.

## Короткий запрос

```text
/ecc-change-impact Оцени blast radius переименования поля пользователя в публичном API и перечисли безопасную последовательность до любых изменений.
```

## Шаблон

```text
/ecc-change-impact Проанализируй изменение [описание] в [модуль/файлы]. Риск/контекст: [миграция, auth, публичный контракт и т. п.]. До реализации проследи зависимости и затронутые данные, интерфейсы, тесты и документацию; предложи rollout/rollback. Сейчас только анализ, код не менять.
```

## Поэтапный запрос

```text
/ecc-change-impact Проведи impact analysis изменения [точное описание] в [границы]. Особое внимание: [схема данных / auth / публичный интерфейс / межмодульные зависимости].
1. Исследуй фактические call paths и места чтения/записи; для каждого вывода приведи проверяемый путь/символ или обозначь пробел доказательств.
2. Оцени совместимость данных и схемы, API/event contracts, потребителей, тесты и governance-документы (README/ADR и др.).
3. Перед изменением предложи последовательность, включая expand-contract или миграцию при необходимости, окна несовместимости, наблюдаемость, rollout и откат.
4. Если реализация отдельно одобрена, после неё сопоставь прогноз с фактическим diff: отмечай неожиданные затронутые компоненты и незакрытые пункты. Не выполняй миграцию/деплой.

Результат: карта влияния, доказательства и уверенность, риски по приоритету, план проверки/отката. Для запроса review — только анализ, никаких исправлений. Установка пакетов, сеть и деплой запрещены без отдельного согласия.
```
