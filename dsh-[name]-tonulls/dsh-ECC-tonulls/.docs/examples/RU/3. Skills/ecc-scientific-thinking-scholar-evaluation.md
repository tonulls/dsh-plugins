# `/ecc-scientific-thinking-scholar-evaluation`

Оценивает научные работы, заявки, обзоры и методологические разделы по повторяемой рубрике, уделяя внимание качеству доказательств и поддержке цитат.

## Простой запрос
```text
/ecc-scientific-thinking-scholar-evaluation Оцени методологию этого исследования по сильным сторонам и ограничениям: [текст]
```
## Шаблонный запрос
```text
/ecc-scientific-thinking-scholar-evaluation
Материал: [работа/заявка/раздел]
Цель и область: [контекст]
Критерии/рубрика: [если есть]
Оцени обоснованность методов, доказательств и ссылок; не приписывай материалу отсутствующие сведения.
```
## Подробный запрос
```text
/ecc-scientific-thinking-scholar-evaluation
Проведи структурированную оценку предоставленного [типа научной работы] для [назначение]. 1) Кратко восстанови вопрос, заявленные выводы и дизайн. 2) Оцени методологию, выборку/данные, анализ, воспроизводимость и ограничения по явно заданной рубрике. 3) Сопоставь каждое существенное утверждение с приведенной опорой; обозначь цитаты, которые нельзя проверить по предоставленному материалу. 4) Раздели критические замечания и рекомендации по улучшению. Не меняй документ, не добавляй вымышленных ссылок и не выдавай оценку за рецензирование специалистом. Итог: баллы с обоснованием, сильные стороны, приоритетные риски, вопросы автору и границы оценки.
```
