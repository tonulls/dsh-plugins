# `/ecc-mysql-patterns`

**Назначение:** Практики MySQL и MariaDB для серверных приложений в рабочей среде: схемы, запросы, индексы, транзакции, репликация и пулы подключений. Используйте при проектировании схем и индексов или диагностике задержек запросов, транзакций и реплик.

## Короткий промт

```text
/ecc-mysql-patterns Разбери медленный запрос MySQL/MariaDB и предложи варианты индексации с учётом транзакций.
```

## Шаблонный промт

```text
/ecc-mysql-patterns
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: разобрать схему или задержку запроса MySQL/MariaDB для [цель или объект].
Фокус: схема, индексы, транзакции, репликация, connection pools and query latency.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-mysql-patterns
Выполни задачу «разобрать схему или задержку запроса MySQL/MariaDB» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: схема, индексы, транзакции, репликация, connection pools and query latency.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
