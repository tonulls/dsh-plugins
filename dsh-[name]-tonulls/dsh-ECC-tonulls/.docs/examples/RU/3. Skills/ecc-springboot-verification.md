# `/ecc-springboot-verification`

Проводит поэтапную проверку Spring Boot: Maven/Gradle build, статический анализ SpotBugs/PMD/Checkstyle, тесты и покрытие, проверки зависимостей/секретов и ревью diff.

## Простой запрос
```text
/ecc-springboot-verification Подготовь отчет готовности этого Spring Boot изменения; сначала проверь доступные проверки, ничего не меняй.
```
## Шаблонный запрос
```text
/ecc-springboot-verification
Изменение: [ветка/дифф]
Сборщик: [Maven/Gradle]
Критерии покрытия/релиза: [условия]
Проведи доступные фазы проверки, не устанавливая инструменты и не исправляя файлы без подтверждения; укажи, что реально запускалось.
```
## Подробный запрос
```text
/ecc-springboot-verification
Подготовь проверяемый readiness-отчет для Spring Boot изменения [описание]. Сначала выясни доступные команды и границы среды. Затем по фазам: сборка Maven/Gradle; SpotBugs, PMD, Checkstyle; unit и доступные Testcontainers-тесты с JaCoCo; безопасный анализ зависимостей и утечек секретов без вывода значений; просмотр diff. Не подключайся к сети, не устанавливай инструменты, не запускай deploy и не меняй файлы без отдельного разрешения. Если команда требует внешней БД, секретов или изменяет состояние — остановись и запроси подтверждение. В отчете для каждой фазы укажи PASS/FAIL/BLOCKED/NOT RUN, точную команду и фактический результат, ограничения и общую оценку готовности.
```
