# `/ecc-perl-patterns`

**Назначение:** Идиоматические практики и соглашения современного Perl 5.36+ для надёжных приложений, удобных в сопровождении. Используйте при написании или проверке современного кода Perl 5.36+.

## Короткий промт

```text
/ecc-perl-patterns Проверь этот Perl 5.36+ модуль на идиоматичность, читаемость и типичные ошибки.
```

## Шаблонный промт

```text
/ecc-perl-patterns
Контекст: [путь к Perl-файлу, назначение модуля, версия Perl и существующий стиль проекта].
Задача: проверить или спроектировать современный Perl-код для [целевой компонент/результат].
Фокус: структура модулей, идиомы Perl 5.36+, обработка ошибок, типизация/сигнатуры и соглашения репозитория.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-perl-patterns
Выполни задачу «проверить или спроектировать современный Perl-код» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: структура модулей, идиомы Perl 5.36+, обработка ошибок, типизация/сигнатуры и соглашения репозитория.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
