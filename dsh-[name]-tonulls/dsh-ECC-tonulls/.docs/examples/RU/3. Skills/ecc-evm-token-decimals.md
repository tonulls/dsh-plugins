# ecc-evm-token-decimals

**Команда:** `/ecc-evm-token-decimals`

**Назначение:** Предотвращайте незаметные ошибки десятичных разрядов в EVM-сетях: получение decimals во время выполнения, кэширование с учётом сети, расхождение точности bridged-токенов и безопасная нормализация для ботов, панелей и DeFi-инструментов. Используйте при работе с суммами токенов в разных EVM-сетях или при ошибке на порядки величины в балансе, цене либо переводе.

## Промты

### 1. Короткий запрос

> /ecc-evm-token-decimals Проверь, почему сумма токена отображается неверно.

### 2. Шаблон с контекстом

> /ecc-evm-token-decimals Сеть: [chain], токен: [адрес/символ], наблюдаемая сумма: [значение]. Разбери decimals, кэширование по сети и нормализацию без транзакций.

### 3. Подробный запрос

> /ecc-evm-token-decimals Проанализируй расчёт суммы в [файл/функция] для токена [адрес] на сетях [список]. Проверь runtime decimals, bridged precision и ключи кэша; никаких обращений в сеть и транзакций без разрешения. Верни причины, безопасное исправление и тест-кейсы.
