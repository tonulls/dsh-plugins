# ecc-fastapi-patterns

**Команда:** `/ecc-fastapi-patterns`

**Назначение:** Практики FastAPI: структура проекта, схемы Pydantic v2, внедрение зависимостей, асинхронные обработчики, аутентификация и авторизация, транзакционные сервисные слои, тесты с httpx и pytest. Используйте при создании или проверке приложений FastAPI, схем, зависимостей, асинхронных обработчиков, аутентификации или тестов.

## Промты

### 1. Короткий запрос

> /ecc-fastapi-patterns Проверь структуру этого FastAPI endpoint.

### 2. Шаблон с контекстом

> /ecc-fastapi-patterns Endpoint: [путь], задача: [поведение], схемы: [описание]. Оцени Pydantic v2, DI, async и тестируемость; предложи изменения, не устанавливая пакеты.

### 3. Подробный запрос

> /ecc-fastapi-patterns Изучи [маршрут/модуль] в FastAPI. По этапам проверь схемы, зависимости, async-вызовы, авторизацию и транзакционный слой; затем предложи тесты httpx/pytest. Меняй файлы только после моего подтверждения. Дай ссылки на доказательства и план.
