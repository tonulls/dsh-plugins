# ecc-lead-intelligence

**Команда:** `/ecc-lead-intelligence`

**Назначение:** Поиск и квалификация ценных контактов с помощью сигналов, ранжирования соответствия, поиска тёплого пути и подготовки адресных сообщений для email, LinkedIn и X на основе реального стиля пользователя.

## Промты

### 1. Короткий запрос

> /ecc-lead-intelligence Помоги оценить этих потенциальных клиентов по соответствию [критериям] и предложи персональный тёплый первый контакт; не отправляй сообщения.

### 2. Шаблон с заполнителями

> /ecc-lead-intelligence Ищу контакты для [продукт/предложение] в сегменте [отрасль, роль, регион]. Приоритетные сигналы: [события/потребности], исключения: [критерии]. Используй только предоставленные источники [список], ранжируй по обоснованному соответствию и укажи пробелы. Подготовь черновик для [email/LinkedIn/X] в стиле примеров [материалы]. Никаких отправок и неподтверждённых персональных выводов.

### 3. Подробный поэтапный запрос

> /ecc-lead-intelligence Сформируй исследовательский список лидов для [предложение] и целевого профиля [ICP]. 1) Зафиксируй критерии включения/исключения и свежесть требуемых сигналов. 2) Для каждого контакта отдели подтверждённые сведения от предположений, укажи источник и дату/контекст, если они доступны. 3) Оцени соответствие и взаимный приоритет по прозрачным критериям; отметь, когда данных недостаточно, не заполняй пробелы догадками. 4) Если предоставлены примеры текстов, выдели наблюдаемые особенности голоса и подготовь отдельные короткие варианты для email, LinkedIn и X с релевантным тёплым поводом. Формат: таблица контактов с обоснованием и источниками, затем черновики и список неизвестного. Не ищи данные в сети, не используй подключённые сервисы и не отправляй/не публикуй сообщения без отдельного разрешения.
