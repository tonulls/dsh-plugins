# `/ecc-agent-architecture-audit`

**Назначение:** Комплексная диагностика приложений с агентами и LLM: аудит 12-слойного стека на регрессии обёрток, загрязнение памяти, ошибки работы с инструментами, скрытые циклы исправления и сбои отображения. Выдаёт выводы по степени серьёзности и исправления с приоритетом кода. Для разработчиков агентных приложений, автономных циклов и функций на базе LLM. Используйте при неизвестном источнике сбоя агента/LLM или перед выпуском стека.

## Короткий промт

```text
/ecc-agent-architecture-audit Диагностируй, почему [агент/LLM-функция] ведёт себя неверно; найди вероятный слой сбоя и подтверди его фактами.
```

## Шаблонный промт

```text
/ecc-agent-architecture-audit
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: найти слой, вызывающий сбой приложения с агентом или LLM для [цель или объект].
Фокус: 12 слоёв стека, регрессии обёрток, загрязнение памяти, дисциплина работы с инструментами, скрытые циклы повторов/исправлений и ошибки отображения.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-agent-architecture-audit
Выполни задачу «найти слой, вызывающий сбой приложения с агентом или LLM» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: 12 слоёв стека, регрессии обёрток, загрязнение памяти, дисциплина работы с инструментами, скрытые циклы повторов/исправлений и ошибки отображения.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
