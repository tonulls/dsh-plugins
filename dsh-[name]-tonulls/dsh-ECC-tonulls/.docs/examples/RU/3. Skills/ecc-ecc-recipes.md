# `/ecc-ecc-recipes`

Подбирает подходящую группу ECC-команд для описанного процесса, с порядком шагов и условием остановки; только консультирует и не исполняет команды.

## Простой запрос

```text
/ecc-ecc-recipes Какие ECC-команды использовать, чтобы исправить регрессию и проверить исправление?
```

## Шаблонный запрос

```text
/ecc-ecc-recipes
Процесс/цель: [что нужно сделать]
Контекст проекта: [тип задачи]
Ограничения: [что нельзя выполнять]
Подбери группу команд, порядок запуска и условие остановки. Только объясни — ничего не выполняй.
```

## Подробный запрос

```text
/ecc-ecc-recipes
Сопоставь процесс [описание] с подходящей ECC command-group recipe. Уточни исходные условия и тип задачи; предложи последовательность команд с кратким назначением каждой, зависимостями и точкой остановки/передачи контроля. Если существует несколько вариантов, объясни выбор и границы применимости. Это только справочная рекомендация: не запускай команды и не выполняй сам процесс. Если команда/семейство недоступны в доступном каталоге, обозначь это вместо выдумывания имени. Выведи рекомендуемый порядок, критерии перехода между шагами и нужные подтверждения для потенциальных побочных действий.
```
