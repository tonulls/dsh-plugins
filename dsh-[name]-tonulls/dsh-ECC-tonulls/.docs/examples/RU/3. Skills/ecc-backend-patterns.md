# `/ecc-backend-patterns`

Практики серверной архитектуры, API, доступа к данным и оптимизации БД для Node.js, Express и маршрутов Next.js. Применяется при разработке или анализе этих серверных компонентов.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-backend-patterns Проверь обработчик [путь/эндпоинт] на типичные проблемы backend для нашего стека. Только анализ.
```

### 2. Шаблонный запрос
```text
/ecc-backend-patterns Помоги реализовать [серверная функция] в [Node.js/Express/Next.js]. Контекст данных: [модель/хранилище], ограничения: [список]. Сначала следуй текущей структуре и соглашениям репозитория; разрешены изменения только в [объём].
```

### 3. Подробный запрос
```text
/ecc-backend-patterns Проанализируй [маршрут/слой доступа к данным] в проекте на [Node.js, Express или Next.js]. 1) Изучи соседние реализации и установи фактический стек и границы задачи. 2) Проверь разделение маршрута и логики, валидацию входа, обработку ошибок, запросы к БД и возможные проблемы производительности. 3) Для каждого вывода приведи доказательство и отдели дефект от рекомендации. 4) Если просят реализацию — меняй только файлы, необходимые для [задача], без несвязанных рефакторингов, установки пакетов и сетевых действий; иначе оставь код без изменений. Формат: находки по серьёзности, затем ограниченный план или diff-итог.
```
