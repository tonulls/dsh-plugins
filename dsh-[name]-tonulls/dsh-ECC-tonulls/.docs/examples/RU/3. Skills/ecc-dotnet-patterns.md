# `/ecc-dotnet-patterns`

Помогает писать и проверять идиоматичный C#/.NET-код: организацию, dependency injection, async/await и практики поддержки надёжных приложений.

## Простой запрос

```text
/ecc-dotnet-patterns Проверь, корректно ли обработаны отмена и исключения в этом async .NET методе.
```

## Шаблонный запрос

```text
/ecc-dotnet-patterns
Целевая версия .NET/C#: [версии]
Компонент: [описание]
Код: [фрагмент или путь]
Требования: [производительность/совместимость]
Предложи идиоматичный вариант с учётом DI и async; сначала только review.
```

## Подробный запрос

```text
/ecc-dotnet-patterns
Разбери [компонент] для [версия .NET/C#]. Сопоставь решение с текущим стилем проекта. Проверь ответственность типов и DI lifetime, асинхронность и передачу CancellationToken, управление ресурсами, исключения и контракты ошибок, nullability и читаемость. Отметь где полезны изменения, а где абстракция будет избыточна. Не редактируй файлы, не добавляй пакеты и не выполняй внешние вызовы без моего подтверждения. Предложи компактный вариант кода, тестовые сценарии и потенциальные миграционные риски; явно отдели факты от предположений.
```
