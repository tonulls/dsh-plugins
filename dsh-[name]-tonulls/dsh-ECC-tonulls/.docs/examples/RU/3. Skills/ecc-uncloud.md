# `/ecc-uncloud`

Помогает управлять кластером Uncloud через `uc`: развертывание сервисов, Caddy ingress, статические маршруты, публикация портов, масштабирование, журналы, машины и тома.

## Простой запрос
```text
/ecc-uncloud Объясни, как безопасно проверить состояние сервиса Uncloud [имя] без изменений.
```
## Шаблонный запрос
```text
/ecc-uncloud
Кластер/сервис: [идентификатор]
Задача: [логи/масштаб/маршрут/том]
Разрешенный режим: только чтение
Опиши нужные команды `uc` и ожидаемый эффект; не запускай их и не меняй кластер без подтверждения.
```
## Подробный запрос
```text
/ecc-uncloud
Нужно выполнить [задача] для Uncloud [кластер/сервис]. Сначала составь план и классифицируй каждую команду как чтение или изменение состояния; укажи влияние на доступность, маршрутизацию, данные/тома и возможность отката. Не выполняй deploy, масштабирование, изменение Caddy/портов, машин, томов или удаление без моего отдельного явного подтверждения конкретного действия. Не печатай секреты и не обращайся к сети без разрешения. После подтверждения выполняй только согласованный объем и отчитайся точными командами, результатами и проверкой состояния; без подтверждения предоставь только план.
```
