# `/ecc-workspace-surface-audit`

Проводит аудит активного репозитория, MCP-серверов, плагинов, коннекторов, env-поверхностей и конфигурации harness, затем рекомендует подходящие ECC-навыки, hooks, agents и рабочие процессы.

## Простой запрос
```text
/ecc-workspace-surface-audit Проведи read-only инвентаризацию текущего репозитория и доступных интеграций; секреты не выводи.
```
## Шаблонный запрос
```text
/ecc-workspace-surface-audit
Репозиторий и цель: [контекст]
Доступные конфигурации: [пути/поверхности]
Ограничения: только чтение
Инвентаризируй фактически доступные компоненты и предложи релевантные ECC-возможности; не считывай значения секретов и не меняй настройки.
```
## Подробный запрос
```text
/ecc-workspace-surface-audit
Помоги оценить настройку harness для [репозиторий/цель] в режиме read-only. Поэтапно: изучи только доступные конфигурации и структуру проекта; составь перечень MCP, plugins, connectors, env-поверхностей и локальных workflow, отличая обнаруженное от предположительного; проверь доступность без вывода credential-значений; сопоставь реальные потребности с ECC skills/hooks/agents и предложи приоритеты. Не подключайся к внешним системам, не меняй файлы/настройки, не устанавливай компоненты и не включай секреты в отчет. Любое активное подключение или изменение требует моего отдельного разрешения. Результат: инвентарь с доказательствами, пробелы, рекомендации и ограничения проверки.
```
