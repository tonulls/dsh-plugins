# `/ecc-agent-security-hardening`

Рекомендации по защите агентных систем, которые обрабатывают недоверенный контент, вызывают инструменты, записывают файлы, управляют идентификаторами выполнения или работают с учётными данными. Не предназначен для общей безопасности веб-приложений или атакующего тестирования.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-agent-security-hardening Проведи защитный анализ границ доверия и прав инструментов этого agent runtime. Только выводы по подтверждённым данным, без изменений и атакующего тестирования.
```

### 2. Шаблонный запрос
```text
/ecc-agent-security-hardening Проверь [agent runtime/tool gateway/сервис памяти] в [путь/описание]. Рассмотри недоверенный ввод, вызовы инструментов, запись в workspace, runtime-идентификаторы и учётные данные. Только защитный обзор исходников и конфигурации; не запускай эксплойты и не меняй файлы. Выдай риски с доказательствами и мерами снижения.
```

### 3. Подробный запрос
```text
/ecc-agent-security-hardening Выполни ограниченный анализ безопасности [агентного компонента]. 1) По исходникам проследи путь недоверенного содержимого до модели, инструментов, файловой системы и сервисов памяти. 2) Проверь границы полномочий, валидацию аргументов, изоляцию арендаторов, обработку идентификаторов выполнения и защиту секретов — только в пределах относящихся к компоненту механизмов. 3) Не тестируй систему атакующими запросами, не обращайся к внешним системам и не меняй код. 4) Для каждого вывода укажи место и доказательство, сценарий воздействия, серьёзность и конкретную защитную рекомендацию; неизвестное пометь как непроверенное. Не обобщай выводы на безопасность обычного веб-приложения.
```
