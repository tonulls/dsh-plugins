# `/ecc-code-tour`

**Назначение:** Создавайте файлы CodeTour `.tour` — пошаговые обзоры с реальными привязками к файлам и строкам, адаптированные для целевой аудитории. Для адаптации новых участников, обзора архитектуры, PR и RCA, а также структурированных объяснений работы кода.

## Короткий промт

```text
/ecc-code-tour Составь CodeTour по модулю [путь] для нового участника команды; сначала перечисли маршрут и ссылки на реальные файлы.
```

## Шаблонный промт

```text
/ecc-code-tour
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: подготовить пошаговый CodeTour для заданной аудитории для [цель или объект].
Фокус: реальные файлы и строки, последовательность точек входа, понятные переходы и актуальные привязки.
Ограничения: Создавай или редактируй только явно указанный файл результата; не добавляй другие файлы без согласия.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-code-tour
Выполни задачу «подготовить пошаговый CodeTour для заданной аудитории» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: реальные файлы и строки, последовательность точек входа, понятные переходы и актуальные привязки.
3. Подготовь результат в точно указанном формате и месте; если путь/разрешение не заданы, сначала покажи проект и запроси подтверждение на запись.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Создавай или редактируй только явно указанный файл результата; не добавляй другие файлы без согласия.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
