# ecc-kotlin-ktor-patterns

**Команда:** `/ecc-kotlin-ktor-patterns`

**Назначение:** Практики серверов Ktor: DSL-маршрутизация, плагины, аутентификация, внедрение зависимостей Koin, kotlinx.serialization, WebSockets и тестирование через `testApplication`. Используйте при создании Ktor-сервера: маршрутизация, плагины, аутентификация, внедрение зависимостей, сериализация и тесты.

## Промты

### 1. Короткий запрос

> /ecc-kotlin-ktor-patterns Спроектируй Ktor route для [ресурс].

### 2. Шаблон с контекстом

> /ecc-kotlin-ktor-patterns Сервис: [описание], auth: [механизм], формат: [JSON/WebSocket]. Предложи routing DSL, plugins и serialization по текущему стилю проекта.

### 3. Подробный запрос

> /ecc-kotlin-ktor-patterns Спроектируй или проверь Ktor endpoint [назначение]. Этапы: routing DSL, plugins, auth, Koin DI, kotlinx.serialization, ошибки и testApplication тесты. Учитывай существующие паттерны; не меняй файлы, не устанавливай пакеты и не открывай сеть. Верни структуру решения и проверяемые тест-кейсы.
