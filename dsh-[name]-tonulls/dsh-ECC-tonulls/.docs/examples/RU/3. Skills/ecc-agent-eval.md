# `/ecc-agent-eval`

**Назначение:** Сравнение агентов для разработки (Claude Code, Aider, Codex и др.) на пользовательских задачах по доле успешного выполнения, стоимости, времени и стабильности. Используйте при выборе агента или оценке изменений его конфигурации по измеримым метрикам.

## Короткий промт

```text
/ecc-agent-eval Составь план честного сравнения двух coding agents на одинаковом наборе задач и метриках.
```

## Шаблонный промт

```text
/ecc-agent-eval
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: сравнить coding agents на одинаковых пользовательских задачах для [цель или объект].
Фокус: процент успеха, стоимость, время, стабильность, одинаковые условия и ограничения измерений.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-agent-eval
Выполни задачу «сравнить coding agents на одинаковых пользовательских задачах» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: процент успеха, стоимость, время, стабильность, одинаковые условия и ограничения измерений.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
