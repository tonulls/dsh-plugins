# `/ecc-security-bounty-hunter`

Помогает искать в репозитории потенциально эксплуатируемые уязвимости, уделяя приоритет удаленно достижимым проблемам, пригодным для ответственного сообщения, а не шумным локальным находкам.

## Простой запрос
```text
/ecc-security-bounty-hunter Проведи read-only анализ этого репозитория на серьезные удаленно достижимые уязвимости и опиши доказательства.
```
## Шаблонный запрос
```text
/ecc-security-bounty-hunter
Область репозитория: [пути/компоненты]
Модель угроз: [доступный интерфейс и границы]
Разрешенный режим: только статический read-only анализ
Ищи подтверждаемые цепочки от внешнего ввода к воздействию. Не эксплуатируй систему, не отправляй запросы и не меняй файлы.
```
## Подробный запрос
```text
/ecc-security-bounty-hunter
Проведи только локальный read-only анализ кода [область] в рамках авторизованной оценки. Этапы: определить внешне достижимые входы; проследить путь данных до чувствительных операций; проверить предпосылки эксплуатации и защитные барьеры; ранжировать только доказанные существенные находки; для каждой подготовить безопасное описание влияния и воспроизводимые статические указатели на код. Не запускай эксплойты, сканеры, сетевые запросы или действия против реальных систем; не извлекай секреты и не изменяй файлы. Если проверка требует активного тестирования — остановись и запроси явное разрешение и безопасную область. Отчет: краткий итог, находки с доказательствами и условиями достижимости, ложноположительные/непроверенные гипотезы, ограничения.
```
