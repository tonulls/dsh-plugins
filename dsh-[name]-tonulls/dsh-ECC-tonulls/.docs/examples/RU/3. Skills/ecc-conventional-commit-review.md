# `/ecc-conventional-commit-review`

Проверяет staged-изменения и предлагает подходящее сообщение коммита в формате Conventional Commits с корректными типом, областью и длиной. Не выполняет коммит.

## Простой запрос

```text
/ecc-conventional-commit-review Проверь staged-изменения и предложи сообщение коммита.
```

## Шаблонный запрос

```text
/ecc-conventional-commit-review
Проверь только уже staged diff.
Контекст изменения: [цель]
Предложи тип, scope и краткое Conventional Commit сообщение; ничего не добавляй в индекс и не коммить.
```

## Подробный запрос

```text
/ecc-conventional-commit-review
Проанализируй только текущие staged-изменения и сопоставь их с контекстом [описание задачи]. Определи единый смысл изменения, подходящий тип Conventional Commits и узкий scope; проверь длину/ясность subject и необходимость body или breaking-change footer. Если staged diff смешивает независимые задачи или данных недостаточно, отметь это вместо выдуманного контекста. Не изменяй файлы, staging area или историю Git; не создавай коммит. Выведи краткое обоснование и один рекомендуемый вариант сообщения, при необходимости альтернативу.
```
