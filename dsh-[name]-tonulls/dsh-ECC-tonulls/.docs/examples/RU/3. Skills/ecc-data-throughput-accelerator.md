# `/ecc-data-throughput-accelerator`

Находит узкое место в крупных загрузках, backfill, ETL и синхронизации, сравнивает варианты и требует доказательства полноты строк и временных меток.

## Простой запрос

```text
/ecc-data-throughput-accelerator Найди, почему наш backfill таблицы событий идёт слишком медленно, не жертвуя полнотой данных.
```

## Шаблонный запрос

```text
/ecc-data-throughput-accelerator
Пайплайн: [ingest/ETL/export/backfill]
Текущие объёмы и время: [измерения]
Источник и назначение: [системы]
Ограничения целостности/окна: [условия]
Доступные журналы/метрики: [описание]
Сначала предложи безопасное измерение узкого места; не запускай массовые операции.
```

## Подробный запрос

```text
/ecc-data-throughput-accelerator
Оптимизируй производительность [поток данных] при условии нулевой потери и недублирования данных. Начни с базовой линии и разложения времени по этапам, определив метрики и ограниченный тестовый объём. Для каждого варианта укажи одну гипотезу, измеримый выигрыш и корректностный gate; сравни скорость только среди вариантов, прошедших gate. В доказательстве учти число строк, диапазон временных меток, пропуски/дубликаты и повторный запуск. Не запускай backfill, запись, экспорт, сеть или изменение production без отдельного разрешения и плана отката. Предоставь метод измерения, результаты (если реально получены), расчёт учёта данных, лучший безопасный вариант и дальнейшие шаги.
```
