# ecc-hermes-imports

**Команда:** `/ecc-hermes-imports`

**Назначение:** Преобразуйте локальные процессы оператора Hermes в проверенные навыки ECC и артефакты выпуска пакета. Используйте для подготовки процесса Hermes к открытому использованию без раскрытия личного содержимого рабочей области, учётных данных и локальных путей.

## Промты

### 1. Короткий запрос

> /ecc-hermes-imports Подготовь безопасную санитарную проверку Hermes workflow.

### 2. Шаблон с контекстом

> /ecc-hermes-imports Workflow: [название/путь], назначение: [описание]. Удали из предлагаемого экспорта локальные пути, состояние workspace и секреты; пока только план.

### 3. Подробный запрос

> /ecc-hermes-imports Проверь локальный Hermes workflow для переиспользуемого ECC skill. Этапы: определить зависимость от окружения, обезличить примеры, удалить credentials/private state/local paths, сформировать манифест артефактов. Не публикуй и не копируй секреты; сначала покажи diff-план и запроси согласие перед записью.
