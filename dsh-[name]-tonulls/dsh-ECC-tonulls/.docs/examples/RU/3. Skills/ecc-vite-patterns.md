# `/ecc-vite-patterns`

Подсказывает практики Vite: конфигурация и плагины, HMR, переменные окружения, proxy, SSR, library mode, предварительная обработка зависимостей и оптимизация сборки.

## Простой запрос
```text
/ecc-vite-patterns Разбери причину этой проблемы Vite config/HMR и предложи диагностику: [описание]
```
## Шаблонный запрос
```text
/ecc-vite-patterns
Версия Vite и стек: [данные]
Задача/ошибка: [описание]
vite.config.ts и связанные фрагменты: [код]
Предложи совместимое решение и проверки; не меняй конфигурацию и не устанавливай плагины без согласия.
```
## Подробный запрос
```text
/ecc-vite-patterns
Проанализируй задачу Vite: [HMR/proxy/SSR/library mode/build]. Этапы: изучи текущую конфигурацию и версии; определи релевантные настройки и взаимодействия; предложи минимальный вариант; учти секретность env-переменных и различие dev/build; составь проверки ожидаемого результата и регрессий. Не выводи значения секретов, не подключай сеть и не добавляй/устанавливай плагины без отдельного разрешения. Не изменяй файлы до утверждения плана. В отчете дай причину, рекомендуемый конфиг-фрагмент, совместимость, проверки и риски.
```
