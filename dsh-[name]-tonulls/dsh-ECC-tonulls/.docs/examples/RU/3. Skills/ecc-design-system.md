# `/ecc-design-system`

Извлекает из существующего интерфейса дизайн-токены и оформляет систему стилей с обоснованием и HTML-превью либо проводит аудит визуальной согласованности по нескольким измерениям.

## Простой запрос

```text
/ecc-design-system Проведи аудит визуальной согласованности страниц и найди повторяющиеся цвета и отступы.
```

## Шаблонный запрос

```text
/ecc-design-system
Область UI: [страницы/компоненты]
Пути к стилям и компонентам: [список]
Цель: [извлечь систему / провести аудит]
Ограничения бренда: [описание]
Сначала только анализ, файлы не меняй; предложи токены, rationale и проблемы консистентности.
```

## Подробный запрос

```text
/ecc-design-system
Исследуй [часть интерфейса] для создания или аудита дизайн-системы. Файлы не изменяй. Выяви существующие цвета, типографику, интервалы и тени; сгруппируй их в предложенные токены и CSS custom properties; обоснуй решения в стиле краткого DESIGN.md и оцени интерфейс по релевантным визуальным измерениям. Отметь несогласованные состояния и типовые шаблонные решения без необоснованной субъективности. Предложи содержание интерактивного HTML-превью, но не создавай его без подтверждения. Не добавляй зависимости и не снимай/публикуй данные. Итог: инвентаризация, токены, оценка, приоритеты и план внедрения.
```
