# ecc-healthcare-cdss-patterns

**Команда:** `/ecc-healthcare-cdss-patterns`

**Назначение:** Практики разработки систем поддержки принятия клинических решений (CDSS): проверка взаимодействий лекарств и дозировок, клинические шкалы (NEWS2, qSOFA), классификация важности предупреждений и интеграция в процессы EMR. Используйте при создании таких систем.

## Промты

### 1. Короткий запрос

> /ecc-healthcare-cdss-patterns Оцени безопасность клинического правила CDSS.

### 2. Шаблон с контекстом

> /ecc-healthcare-cdss-patterns Сценарий: [взаимодействие/доза/шкала], популяция: [описание], источник правила: [источник]. Укажи клинические допущения и необходимость валидации специалистом.

### 3. Подробный запрос

> /ecc-healthcare-cdss-patterns Проанализируй дизайн CDSS для [сценарий]. Проверь входные данные, единицы измерения, severity alert, ложные срабатывания и интеграцию рабочего процесса. Не делай клинических рекомендаций пациенту; требуй проверки квалифицированным специалистом и валидированных источников. Выдай риски и план тестирования.
