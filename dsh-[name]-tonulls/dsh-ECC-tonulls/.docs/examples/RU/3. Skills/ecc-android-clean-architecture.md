# `/ecc-android-clean-architecture`

Помогает структурировать Android- и Kotlin Multiplatform-проекты по Clean Architecture: модули, границы зависимостей, UseCase, Repository и слой данных.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-android-clean-architecture Оцени структуру Android-модулей [путь/описание] на соблюдение границ Clean Architecture. Пока только анализ.
```

### 2. Шаблонный запрос
```text
/ecc-android-clean-architecture Предложи архитектуру для [функция] в Android/KMP-проекте [стек]. Текущие модули: [список]. Опиши направление зависимостей и ответственность UseCase, Repository и data-слоя; не создавай файлы.
```

### 3. Подробный запрос
```text
/ecc-android-clean-architecture Разбери организацию [функция/модуль] в [Android или KMP, используемые технологии]. 1) Сначала изучи существующие модули и соглашения, не предполагай структуру. 2) Проследи поток данных от UI к источнику данных и обратно. 3) Отметь нарушения границ, лишние зависимости и места для UseCase/Repository только при наличии оснований. 4) Предложи целевую структуру и безопасную последовательность перехода. Не меняй файлы. Выведи схему модулей, обоснование и риски; раздели факты и рекомендации.
```
