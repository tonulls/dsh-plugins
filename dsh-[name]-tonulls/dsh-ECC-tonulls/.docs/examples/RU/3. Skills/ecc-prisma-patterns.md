# `/ecc-prisma-patterns`

**Назначение:** Практики Prisma ORM для бэкендов TypeScript: проектирование схем, оптимизация запросов, транзакции и пагинация; важные ловушки — `updateMany` возвращает количество, а не записи, тайм-ауты `$transaction`, сброс БД командой `migrate dev`, пропуск `@updatedAt` при массовой записи и исчерпание подключений в serverless. Используйте при работе со схемами и запросами Prisma, транзакциями, миграциями и лимитами подключений.

## Короткий промт

```text
/ecc-prisma-patterns Разбери Prisma-запрос [фрагмент] и проверь транзакции, пагинацию и риск N+1.
```
