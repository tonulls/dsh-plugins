# `/ecc-orch-refine-code`

**Назначение:** Координирует рефакторинг без изменения поведения: проверяет прохождение тестов, перестраивает код, сохраняя поведение и успешные проверки, проводит проверку кода и создаёт коммит после подтверждения пользователя. Используйте, когда нужно улучшить структуру, не меняя поведение.

## Короткий промт

```text
/ecc-orch-refine-code Подготовь план рефакторинга [модуль], сохраняя поведение и без коммита.
```

## Шаблонный промт

```text
/ecc-orch-refine-code
Контекст: [модуль, текущая структура, желаемая структура, имеющиеся тесты].
Задача: спланировать поведенчески-эквивалентный рефакторинг для [целевой компонент/результат].
Фокус: сначала зелёные тесты, структура без изменения поведения, проверка после каждого шага и отдельное согласование коммита.
Ограничения: Сначала подготовь план и критерии сохранения поведения; код не меняй и коммит не создавай без отдельного согласия.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-orch-refine-code
Выполни задачу «спланировать поведенчески-эквивалентный рефакторинг» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: сначала зелёные тесты, структура без изменения поведения, проверка после каждого шага и отдельное согласование коммита.
3. Составь поэтапный план рефакторинга с проверками поведения до и после каждого этапа; не меняй код.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Сначала подготовь план и критерии сохранения поведения; код не меняй и коммит не создавай без отдельного согласия.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
