# ecc-generating-python-installer

**Команда:** `/ecc-generating-python-installer`

**Назначение:** Создание коммерческих Python-установщиков для Windows: экстремальная компиляция Nuitka, уменьшение dist, анализ объёма DLL и упаковка Inno Setup для самых компактных и быстрых установщиков. Используйте, когда Python-приложение нужно выпустить как минимальный быстро запускающийся Windows-установщик; не для простой конвертации скрипта в exe. Триггеры: экстремальная оптимизация Nuitka, коммерческая упаковка Python, экстремальная компиляция Python, уменьшение dist, анализ DLL, минимальный установщик, быстрый запуск, коммерческий стиль упаковки.

## Промты

### 1. Короткий запрос

> /ecc-generating-python-installer Оцени план минимального Windows-инсталлятора Python-приложения.

### 2. Шаблон с контекстом

> /ecc-generating-python-installer Приложение: [описание], целевая Windows: [версии], ограничения размера/старта: [значения]. Рассмотри Nuitka, DLL и Inno Setup, не устанавливай инструменты.

### 3. Подробный запрос

> /ecc-generating-python-installer Составь план упаковки [приложение] в компактный Windows installer с Nuitka и Inno Setup. По шагам оцени зависимости/DLL, размер dist, время старта и проверку результата. Не запускай сборку, установку пакетов или загрузки без моего согласия. Верни измеримые критерии и риски.
