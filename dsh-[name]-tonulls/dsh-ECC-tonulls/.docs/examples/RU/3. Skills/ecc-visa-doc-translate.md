# `/ecc-visa-doc-translate`

Помогает распознать изображения визовых документов (банковские, трудовые, доходные и пенсионные справки) и подготовить англоязычный перевод с двуязычным PDF, где оригинал сопоставлен с переводом.

## Простой запрос
```text
/ecc-visa-doc-translate Подготовь английский перевод этой справки и отметь неразборчивые места: [изображение]
```
## Шаблонный запрос
```text
/ecc-visa-doc-translate
Тип документа: [справка]
Язык оригинала: [язык]
Цель: пакет визовых документов [страна/контекст]
Входное изображение: [путь]
Переведи видимый текст, сохрани структуру, явно пометь сомнительные фрагменты. Не выдумывай удостоверение или заверение перевода.
```
## Подробный запрос
```text
/ecc-visa-doc-translate
Обработай предоставленное изображение [тип справки] для подготовки двуязычного материала. Сначала сообщи, можешь ли прочитать формат/качество; затем распознай текст, сохрани имена, даты, суммы и структуру без догадок; переведи на английский, отдельно пометь неразборчивые/неоднозначные фрагменты и попроси ручную сверку критичных полей. Если доступна соответствующая возможность, сформируй PDF с оригиналом и форматированным переводом; не утверждай, что перевод официально заверен. Не загружай документ в сеть и не сохраняй/рассылай копии без отдельного согласия. Защищай персональные и финансовые сведения. Итог: распознанный перевод, список сомнений и статус PDF (создан/недоступен).
```
