# `/ecc-santa-method`

Организует независимую состязательную проверку двумя рецензентами по одной рубрике, цикл исправления и повторной проверки, а при неразрешенном расхождении — эскалацию человеку.

## Простой запрос
```text
/ecc-santa-method Независимо проверь этот текст перед публикацией по фактам, рискам и соответствию требованиям: [текст]
```
## Шаблонный запрос
```text
/ecc-santa-method
Материал: [текст/изменение]
Назначение и аудитория: [контекст]
Рубрика приемки: [критерии]
Проведи две независимые проверки и сообщи, пройдены ли все обязательные критерии. Ничего не публикуй и не меняй.
```
## Подробный запрос
```text
/ecc-santa-method
Нужно принять решение о готовности [материал/изменение] к [публикации/релизу]. Критерии: [рубрика], критические утверждения: [перечень]. Организуй два независимых прохода по одинаковым критериям, сохрани различия в оценках, сопоставь подтверждающие свидетельства, предложи только необходимые исправления и повторную проверку после их применения. Не публикуй, не развертывай и не меняй файлы; любой внешний побочный эффект требует моего отдельного подтверждения. Ограничь число циклов и остановись для решения человека при разногласии или нехватке доказательств. Отчет: вердикт, результаты обоих проходов, замечания по серьезности, нерешенные вопросы и условие эскалации.
```
