# `/ecc-database-migrations`

Помогает проектировать безопасные и обратимые миграции БД: expand-contract, индексы без блокировок, пакетные backfill и практики для распространённых миграционных инструментов.

## Простой запрос

```text
/ecc-database-migrations Как переименовать большую PostgreSQL-колонку без простоя приложения?
```

## Шаблонный запрос

```text
/ecc-database-migrations
База и инструмент: [PostgreSQL/Prisma/Drizzle/Kysely/Django/golang-migrate]
Текущая схема и объём: [описание]
Изменение: [колонка/индекс/данные]
Ограничения доступности и отката: [условия]
Предложи этапы безопасной миграции; ничего не запускай на общей/production БД.
```

## Подробный запрос

```text
/ecc-database-migrations
Составь план изменения [схема/данные] для [СУБД, версия, инструмент], таблица содержит примерно [объём], приложение должно оставаться доступным. Рассмотри expand-contract, совместимость старых и новых версий приложения, конкурентное создание индекса, пакетный backfill и контроль прогресса. Укажи, какие шаги обратимы, а где rollback требует компенсирующей миграции; перечисли блокировки и критерии остановки. Не применяй миграцию, не подключайся к базе и не меняй файлы без подтверждения. Сначала выдай план, SQL/эскиз при необходимости, предварительные проверки, мониторинг и пошаговый rollback; отметь, какие сведения нужно проверить в staging.
```
