# `/ecc-verification-loop`

Проводит шестифазную проверку работы сессии Claude Code: сборка, типизация, lint, тесты с покрытием, поиск утечек безопасности и просмотр diff, завершая отчетом PASS/FAIL.

## Простой запрос
```text
/ecc-verification-loop Проверь готовность текущего изменения и выдай отчет по фазам; не меняй файлы.
```
## Шаблонный запрос
```text
/ecc-verification-loop
Изменение/дифф: [область]
Критерии проекта: [сборка, тесты, покрытие]
Разрешенные проверки: [перечень]
Сначала сообщи план и побочные эффекты; секреты не выводи, изменения не вноси.
```
## Подробный запрос
```text
/ecc-verification-loop
Проверь выполненную работу [описание] перед PR. Сначала выяви доступные команды и согласуй план. Проведи фазы: build; type check; lint; тесты и покрытие; безопасный поиск подозрительных секретов без печати значений; review diff. Не исправляй файлы, не устанавливай зависимости и не обращайся к сети без моего отдельного разрешения. Команды с изменением состояния, внешней БД или секретами не запускай без подтверждения. Для каждой фазы укажи PASS/FAIL/BLOCKED/NOT RUN, фактически выполненную команду и доказательство; итоговый вердикт учитывает пропущенные проверки и не заявляет PASS без полного подтверждения.
```
