# `/ecc-accessibility`

Проектирование, реализация и аудит доступного интерфейса по WCAG 2.2 AA для Web, iOS и Android: семантика, клавиатура, фокус, контраст, размеры целей и экранные дикторы.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-accessibility Проверь доступность формы регистрации: клавиатурная навигация, подписи полей и видимый фокус. Только анализ, файлы не менять.
```

### 2. Шаблонный запрос
```text
/ecc-accessibility Проведи аудит [экрана/компонента] в [Web/iOS/Android]. Контекст: [путь или описание]. Проверь семантику и подписи, порядок фокуса, контраст и работу со скринридером. Ничего не изменяй; перечисли подтверждённые проблемы и приоритеты.
```

### 3. Подробный запрос
```text
/ecc-accessibility Выполни аудит доступности компонента [название] в [платформа] на соответствие применимым требованиям WCAG 2.2 AA. 1) Изучи только относящиеся к компоненту материалы. 2) Проверь роли/метки, клавиатурные сценарии, управление фокусом, контраст и размер интерактивных целей; не делай неподтверждённых выводов. 3) Не меняй файлы и не запускай внешние сервисы. 4) Отчёт: находка, доказательство/место, влияние на пользователя, серьёзность и конкретная рекомендация; отдельно укажи непроверенные критерии.
```
