# `/ecc-clickhouse-io`

**Назначение:** Практики ClickHouse: схемы БД, оптимизация запросов, аналитика и обработка данных для высокопроизводительных аналитических задач. Используйте при написании схем и запросов ClickHouse или при медленных аналитических запросах.

## Короткий промт

```text
/ecc-clickhouse-io Разбери медленный запрос ClickHouse и предложи проверяемые варианты оптимизации без выполнения изменений в БД.
```

## Шаблонный промт

```text
/ecc-clickhouse-io
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: разобрать схему или медленный аналитический запрос ClickHouse для [цель или объект].
Фокус: модель таблиц, порядок ключей, объём сканирования, агрегации и план оптимизации.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-clickhouse-io
Выполни задачу «разобрать схему или медленный аналитический запрос ClickHouse» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: модель таблиц, порядок ключей, объём сканирования, агрегации и план оптимизации.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
