# ecc-hipaa-compliance

**Команда:** `/ecc-hipaa-compliance`

**Назначение:** Точка входа для задач конфиденциальности и безопасности в здравоохранении, связанных с HIPAA. Используйте, если задача явно касается HIPAA, обработки PHI, регулируемых организаций, BAA, готовности к утечке или требований здравоохранения США.

## Промты

### 1. Короткий запрос

> /ecc-hipaa-compliance Составь список HIPAA-вопросов для этого потока данных.

### 2. Шаблон с контекстом

> /ecc-hipaa-compliance Система: [описание], роли: [роли], данные PHI: [категории], юрисдикция/контекст: США. Это не юридическое заключение; выдели неизвестные.

### 3. Подробный запрос

> /ecc-hipaa-compliance Оцени предоставленную архитектуру в контексте HIPAA: PHI поток, роли/доступ, audit, BAA-зависимости и breach posture. Не делай юридических заверений и не раскрывай реальные данные; отметь вопросы для privacy/security counsel и предложи проверяемые действия, требующие одобрения.
