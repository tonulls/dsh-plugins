# `/ecc-network-config-validation`

**Назначение:** Предварительная проверка конфигурации маршрутизаторов и коммутаторов: опасные команды, повторяющиеся адреса, пересечение подсетей, устаревшие ссылки, риски плоскости управления и требования безопасности в стиле IOS. Используйте перед развёртыванием сетевой конфигурации.

## Короткий промт

```text
/ecc-network-config-validation Проверь этот фрагмент конфигурации маршрутизатора на опасные команды, конфликты адресов и риски управления; не применяй его.
```

## Шаблонный промт

```text
/ecc-network-config-validation
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить конфигурацию маршрутизатора или коммутатора перед изменениями для [цель или объект].
Фокус: dangerous commands, duplicate IPs, subnet overlaps, stale references, management-plane and IOS security.
Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-network-config-validation
Выполни задачу «проверить конфигурацию маршрутизатора или коммутатора перед изменениями» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: dangerous commands, duplicate IPs, subnet overlaps, stale references, management-plane and IOS security.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
