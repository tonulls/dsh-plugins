# `/ecc-ralphinho-rfc-pipeline`

**Назначение:** Разбивает RFC на граф выполнения для нескольких агентов: делит работу на единицы с зависимостями и тестами приёмки, организует исследование, планирование, реализацию, тестирование и проверку каждой единицы, затем объединяет изменения через очередь с перебазированием веток и итоговой проверкой системы. Используйте для крупных функций, выполнения RFC несколькими агентами и управления очередями слияния.

## Короткий промт

```text
/ecc-ralphinho-rfc-pipeline Разбей RFC [путь] на work units с зависимостями и acceptance tests; pipeline только спланируй.
```

## Шаблонный промт

```text
/ecc-ralphinho-rfc-pipeline
Контекст: [RFC, ограничения на файлы/ветки, независимые work units и проверяемые критерии].
Задача: спроектировать multi-agent DAG исполнения RFC по независимым work units для [целевой компонент/результат].
Фокус: декомпозиция, зависимости, критерии приёмки, исследование/реализация/тесты/ревью и gated merge queue.
Ограничения: Сформируй только готовые к вставке шаги/команды; не вызывай их и не заявляй, что они выполнены.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-ralphinho-rfc-pipeline
Выполни задачу «спроектировать multi-agent DAG исполнения RFC по независимым work units» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: декомпозиция, зависимости, критерии приёмки, исследование/реализация/тесты/ревью и gated merge queue.
3. Для каждого шага укажи точный документированный вызов и scope; если команда не может передать границы шага — не включай её и обозначь блокер.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Сформируй только готовые к вставке шаги/команды; не вызывай их и не заявляй, что они выполнены.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
