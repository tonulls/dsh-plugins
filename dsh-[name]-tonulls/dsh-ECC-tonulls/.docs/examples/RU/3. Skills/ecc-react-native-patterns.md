# `/ecc-react-native-patterns`

**Назначение:** Практики React Native и Expo: навигация Expo Router, разделение состояния (серверное, клиентское, маршрутное, состояние формы), загрузка данных TanStack Query с Zod, производительные списки, стилизация NativeWind/StyleSheet, нативные API и безопасное хранилище. Используйте при разработке или изменении экранов, компонентов, навигации и слоёв данных React Native / Expo.

## Короткий промт

```text
/ecc-react-native-patterns Проверь Expo-экран [путь]: навигация, состояние, загрузка данных и secure storage.
```
