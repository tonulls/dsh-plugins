# `/ecc-scientific-db-pubmed-database`

Помогает формировать запросы к PubMed/NCBI E-utilities, искать биомедицинскую литературу, находить записи по PMID, получать цитаты и планировать мониторинг.

## Простой запрос
```text
/ecc-scientific-db-pubmed-database Подбери стратегию поиска PubMed по теме [тема] и объясни ключевые термины запроса.
```
## Шаблонный запрос
```text
/ecc-scientific-db-pubmed-database
Вопрос: [исследовательский вопрос]
Популяция/вмешательство/исход: [если применимо]
Период и языки: [ограничения]
Подготовь воспроизводимый PubMed-запрос и критерии отбора; не выдумывай найденные статьи.
```
## Подробный запрос
```text
/ecc-scientific-db-pubmed-database
Для вопроса [вопрос] подготовь поиск PubMed: 1) разложи вопрос на понятия и MeSH/синонимы; 2) составь и объясни запрос с полями и датой; 3) задай критерии включения/исключения и процедуру отбора; 4) опиши получение PMID и библиографических данных; 5) обозначь ограничения полноты. Не делай медицинских рекомендаций и не раскрывай персональные данные. Не выполняй сетевые запросы без разрешения; если доступ к PubMed недоступен, выдай только воспроизводимый план. Итог — запрос, критерии, поля журнала поиска и список фактически проверенных записей с PMID/ссылками либо явная отметка, что поиск не выполнялся.
```
