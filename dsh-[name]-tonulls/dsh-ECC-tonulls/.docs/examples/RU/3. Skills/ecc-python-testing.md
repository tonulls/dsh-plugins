# `/ecc-python-testing`

**Назначение:** Практики тестирования Python с pytest и TDD: фикстуры, моки, параметризация и требования к покрытию. Используйте при написании тестов pytest, работе с фикстурами, моками, параметризацией или покрытием.

## Короткий промт

```text
/ecc-python-testing Предложи pytest для [функция]: фикстуры, параметры, ошибки и граничные входы.
```

## Шаблонный промт

```text
/ecc-python-testing
Контекст: [функция, ожидаемое поведение, ошибочные/краевые входы и существующие тесты].
Задача: спроектировать pytest-тесты для Python-кода для [целевой компонент/результат].
Фокус: TDD, подходящие fixtures/mocks/parametrize, важные границы и фактическое покрытие.
Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-python-testing
Выполни задачу «спроектировать pytest-тесты для Python-кода» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: TDD, подходящие fixtures/mocks/parametrize, важные границы и фактическое покрытие.
3. Сформируй набор тестов или эскиз кода, используя только уже имеющийся в проекте стек; отдели предложенные проверки от реально выполненных.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
