# `/ecc-scientific-pkg-gget`

Подсказывает воспроизводимые сценарии gget для запросов к геномным базам, поиска последовательностей, BLAST-подобных проверок и обогащения биоинформатических данных.

## Простой запрос
```text
/ecc-scientific-pkg-gget Предложи gget-план для поиска гена [символ/вид] и фиксации источников.
```
## Шаблонный запрос
```text
/ecc-scientific-pkg-gget
Задача: [ген/последовательность/обогащение]
Организм и идентификаторы: [значения]
Доступные данные и среда: [контекст]
Составь воспроизводимый план gget и перечисли необходимые входы и проверки. Не устанавливай пакет.
```
## Подробный запрос
```text
/ecc-scientific-pkg-gget
Планирую биоинформатический запрос: [цель], организм [вид/сборка], идентификаторы [список]. 1) Выбери подходящие операции gget и объясни аргументы. 2) Укажи проверку вида, версии ссылочной базы и соответствия идентификаторов. 3) Предложи фиксацию команд, времени, параметров и результата для воспроизводимости. 4) Обозначь ограничения интерпретации и ожидаемые ошибки. Не придумывай результаты, не устанавливай CLI/библиотеки и не выполняй сетевые обращения без отдельного разрешения. Не включай персональные/секретные данные. Верни команды как черновик, входные требования, контрольные проверки и шаблон журнала доказательств.
```
