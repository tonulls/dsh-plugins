# `/ecc-agent-introspection-debugging`

Помогает воспроизводимо разбирать сбои запуска агента: зафиксировать наблюдения, локализовать причину, выполнить ограниченное восстановление и оформить отчёт самоанализа вместо слепого повтора.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-agent-introspection-debugging Разбери последний сбой агента по имеющимся логам: сначала зафиксируй симптомы и предполагаемый слой отказа, не запускай повторно.
```

### 2. Шаблонный запрос
```text
/ecc-agent-introspection-debugging Исследуй сбой запуска [идентификатор/время] в [среда]. Используй только доступные [логи, трассировки, входные данные]. Воспроизведение разрешено только [условия/нет]. Раздели подтверждённые факты и гипотезы, предложи ограниченное восстановление без изменений файлов.
```

### 3. Подробный запрос
```text
/ecc-agent-introspection-debugging Проведи структурированную диагностику сбоя агента [идентификатор]. 1) Сохрани доступные факты запуска: задачу, последовательность действий, ответы инструментов и точку отказа; не раскрывай секреты. 2) Сопоставь симптомы с возможными слоями, отделяя доказанное от предположений. 3) Не делай автоматический retry и не меняй код или настройки. 4) Если для проверки нужно повторное выполнение или побочный эффект, остановись и запроси согласие. Итог: краткая временная шкала, воспроизводимые условия, вероятная причина с доказательствами, безопасный следующий шаг и отчёт самоанализа.
```
