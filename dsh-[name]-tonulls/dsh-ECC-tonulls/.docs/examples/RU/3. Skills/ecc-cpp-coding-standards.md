# `/ecc-cpp-coding-standards`

Помогает писать, проверять и рефакторить C++ по современным безопасным и идиоматичным практикам, опираясь на C++ Core Guidelines.

## Простой запрос

```text
/ecc-cpp-coding-standards Проверь этот C++ фрагмент на безопасность владения памятью и идиоматичность.
```

## Шаблонный запрос

```text
/ecc-cpp-coding-standards
Стандарт языка: [версия C++]
Контекст компонента: [назначение]
Код: [фрагмент или путь]
Оцени именование, владение ресурсами, const-корректность, ошибки и читаемость; пока не редактируй файлы.
```

## Подробный запрос

```text
/ecc-cpp-coding-standards
Проведи review [фрагмент/файлы] в контексте [компонент], целевая версия C++ — [версия]. Файлы не меняй. Последовательно проверь владение и время жизни объектов, RAII, границы исключений/ошибок, типы и const-корректность, интерфейсы, читаемость и соответствие существующему стилю. Привязывай каждое замечание к конкретному месту и оценивай серьёзность; не предлагай крупный рефакторинг без доказанной необходимости. Укажи применимые рекомендации, безопасный вариант исправления и вопросы, требующие контекста. Заверши приоритетным списком находок и кратким резюме без заявления о запуске непроверенных тестов.
```
