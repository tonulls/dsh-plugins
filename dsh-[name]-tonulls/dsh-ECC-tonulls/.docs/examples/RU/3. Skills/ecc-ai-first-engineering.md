# `/ecc-ai-first-engineering`

**Назначение:** Модель инженерной работы для команд, где ИИ-агенты создают значительную часть кода. Используйте при настройке процессов команды, этапов проверки кода и правил ответственности для кодовой базы, написанной преимущественно агентами.

## Короткий промт

```text
/ecc-ai-first-engineering Предложи процесс разработки и правила ревью для команды, где существенную часть кода пишут агенты.
```

## Шаблонный промт

```text
/ecc-ai-first-engineering
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: настроить инженерный процесс команды, где большую часть кода создают агенты для [цель или объект].
Фокус: владение кодом, review gates, ответственность и контроль качества агентных изменений.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-ai-first-engineering
Выполни задачу «настроить инженерный процесс команды, где большую часть кода создают агенты» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: владение кодом, review gates, ответственность и контроль качества агентных изменений.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
