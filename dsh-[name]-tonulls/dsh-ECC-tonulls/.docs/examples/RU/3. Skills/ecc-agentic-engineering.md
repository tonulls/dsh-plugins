# `/ecc-agentic-engineering`

Организует инженерную работу, выполняемую агентами: начинает с оценки, декомпозирует задачу и маршрутизирует работу с учётом стоимости моделей. Подходит для планирования и выполнения сквозной разработки агентами.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-agentic-engineering Разбей задачу [краткое описание] на проверяемые этапы для агентного выполнения и предложи, где достаточно простой модели, а где нужна более сильная. Пока только план.
```

### 2. Шаблонный запрос
```text
/ecc-agentic-engineering Подготовь eval-first план для [цель] в [репозиторий]. Критерии приёмки: [критерии]; ограничения: [файлы/изменения/срок/стоимость]. Разложи работу на независимые этапы, укажи входы, выходы, проверку и подходящий уровень модели для каждого. Ничего не выполняй до подтверждения.
```

### 3. Подробный запрос
```text
/ecc-agentic-engineering Спланируй сквозную агентную реализацию [функция/результат]. 1) Сначала сформулируй проверяемые критерии успеха и минимальный eval, не предполагая, что задача уже выполнена. 2) Изучи заданную область репозитория и раздели работу на этапы с явными зависимостями, артефактами и точками приёмки. 3) Для каждого этапа предложи минимально достаточный класс модели и объясни компромисс качества/стоимости; не утверждай конкретную цену без данных. 4) Ограничь изменения [разрешённая область], не устанавливай зависимости, не используй сеть и не выполняй деплой без отдельного согласия. 5) После каждого этапа предусмотрена проверка перед продолжением; при неоднозначности или провале остановись и доложи. Формат результата: критерии/eval, этапы, распределение задач и моделей, ограничения, риски и стоп-условия.
```
