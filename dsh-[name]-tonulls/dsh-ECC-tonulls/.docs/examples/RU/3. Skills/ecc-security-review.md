# `/ecc-security-review`

Применяет контрольный список безопасности при аутентификации, обработке пользовательского ввода, создании API, работе с секретами и реализации платежных или иных чувствительных функций.

## Простой запрос
```text
/ecc-security-review Проведи read-only security review этого изменения: [ссылка/дифф]. Файлы не меняй.
```
## Шаблонный запрос
```text
/ecc-security-review
Изменение/компонент: [пути или дифф]
Контекст угроз: [пользователи, границы доверия]
Особое внимание: [аутентификация/ввод/API/платежи]
Только анализ без правок: найди подтвержденные риски и укажи доказательства в коде.
```
## Подробный запрос
```text
/ecc-security-review
Проведи аудит безопасности [компонент/изменение] в режиме только чтения. Изучи границы доверия и потоки данных; проверь аутентификацию/авторизацию, валидацию ввода, секреты, API и чувствительные операции по применимости; проследи каждую потенциальную проблему до конкретного кода и оцени достижимость и последствия. Не меняй файлы, не исправляй находки, не запускай активные проверки, не обращайся к сети и не выводи значения секретов. Для каждой находки укажи серьезность, путь/место, сценарий риска и безопасную рекомендацию; неподтвержденные подозрения пометь отдельно. Заверши отчетом о проверенном охвате, ограничениях и приоритетах устранения.
```
