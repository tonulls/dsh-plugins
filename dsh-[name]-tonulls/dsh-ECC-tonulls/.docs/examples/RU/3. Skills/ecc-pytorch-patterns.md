# `/ecc-pytorch-patterns`

**Назначение:** Практики и рекомендации PyTorch для надёжных, эффективных и воспроизводимых конвейеров обучения, архитектур моделей и загрузки данных. Используйте при написании или проверке циклов обучения, архитектур и загрузчиков данных, а также для устранения невоспроизводимых запусков.

## Короткий промт

```text
/ecc-pytorch-patterns Разбери невоспроизводимое обучение [модель] и проверь seed, данные и train loop.
```

## Шаблонный промт

```text
/ecc-pytorch-patterns
Контекст: [модель, train loop, версии окружения, dataset pipeline и признаки невоспроизводимости].
Задача: проверить PyTorch training pipeline или модель для [целевой компонент/результат].
Фокус: воспроизводимость, архитектура модели, data loading, train/eval loop, метрики и корректность эксперимента.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-pytorch-patterns
Выполни задачу «проверить PyTorch training pipeline или модель» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: воспроизводимость, архитектура модели, data loading, train/eval loop, метрики и корректность эксперимента.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
