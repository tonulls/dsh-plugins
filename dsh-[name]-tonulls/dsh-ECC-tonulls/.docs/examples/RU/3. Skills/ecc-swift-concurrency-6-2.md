# `/ecc-swift-concurrency-6-2`

Объясняет подходы Swift 6.2 Approachable Concurrency: выполнение в одном потоке по умолчанию, явный фоновый вынос через `@concurrent` и изолированные conformances.

## Простой запрос
```text
/ecc-swift-concurrency-6-2 Разбери эту ошибку MainActor изоляции в Swift 6.2 и предложи безопасный вариант: [код/ошибка]
```
## Шаблонный запрос
```text
/ecc-swift-concurrency-6-2
Код/операция: [фрагмент]
Диагностика компилятора: [текст без чувствительных данных]
Версии Swift и целевые платформы: [значения]
Объясни, где нужен @concurrent или изоляция, и не предлагай бесконтрольное снятие проверок.
```
## Подробный запрос
```text
/ecc-swift-concurrency-6-2
Проанализируй переход [модуля/функции] на модель Swift 6.2. Сначала определи текущие actor isolation и владельцев состояния; затем выясни, что должно остаться на MainActor, а какая CPU/IO работа может быть явно вынесена через @concurrent; оцени Sendable и isolated conformances; предложи минимальный безопасный дизайн и сценарии проверки гонок. Не используй unsafe-обходы лишь для подавления диагностики. Не меняй файлы, не устанавливай инструменты и не запускай сборку без согласия. Итог: разбор причин, эскиз исправления, совместимость и проверки.
```
