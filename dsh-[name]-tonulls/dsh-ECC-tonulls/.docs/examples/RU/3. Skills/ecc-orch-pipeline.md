# `/ecc-orch-pipeline`

Описывает общий управляемый конвейер Research–Plan–TDD–Review–Commit и его контрольные точки; обычно используется через специализированные `orch-*` навыки.

## Простой запрос
```text
/ecc-orch-pipeline Объясни этапы конвейера для безопасной небольшой задачи; ничего не запускай.
```
## Шаблонный запрос
```text
/ecc-orch-pipeline Для задачи [описание] покажи подходящие фазы, критерии перехода и необходимые человеческие подтверждения. Только консультация, без выполнения команд и изменений.
```
## Подробный запрос
```text
/ecc-orch-pipeline Разбери, как общий конвейер применим к [задаче/операции orch]. Укажи классификацию размера, последовательность фаз, роли подходящих команд/агентов, входы/выходы и условия остановки. Отдельно обозначь одобрение плана и подтверждение коммита как независимые шлюзы. Не исполняй работу, не меняй файлы и не создавай коммит. Заверши схемой этапов и рисками неверного перехода.
```
