# `/ecc-orch-add-feature`

Оркестрирует добавление новой возможности: исследование, план, TDD-реализация, проверка и отдельные контрольные точки перед изменениями и коммитом.

## Простой запрос
```text
/ecc-orch-add-feature Добавь экспорт отчёта в CSV. Сначала покажи план и дождись моего одобрения.
```
## Шаблонный запрос
```text
/ecc-orch-add-feature Новая возможность: [описание]. Контекст/область: [модули]. Критерии приёмки: [список]. Исследуй проект и предложи план; не начинай реализацию до моего подтверждения. Коммит не создавай без отдельного подтверждения.
```
## Подробный запрос
```text
/ecc-orch-add-feature Реализуй новую функцию [описание] в [проект/подсистема]. Этапы: (1) изучи текущие соглашения и точки расширения; (2) перечисли неизвестное и предложи план с критериями приёмки; остановись до одобрения; (3) после одобрения реализуй тестами сначала и минимальным объёмом; (4) запусти только подходящие локальные проверки; (5) проведи обзор diff и сообщи результаты. Не устанавливай зависимости, не используй сеть и не выполняй деплой. Коммит — только после отдельного явного подтверждения. В отчёте укажи изменённые файлы, проверки и остаточные риски.
```
