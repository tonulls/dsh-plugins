# `/ecc-orch-fix-defect`

Оркестрирует исправление дефекта через воспроизводящий регрессионный тест, исправление до зелёного результата и обзор.

## Простой запрос
```text
/ecc-orch-fix-defect Исправь ошибку: фильтр теряет записи на границе диапазона. Сначала воспроизведи её тестом.
```
## Шаблонный запрос
```text
/ecc-orch-fix-defect Симптом: [что не так]. Шаги воспроизведения: [шаги]. Ожидалось: [результат], фактически: [результат]. Область: [модуль]. Не коммить без отдельного подтверждения.
```
## Подробный запрос
```text
/ecc-orch-fix-defect Разбери дефект [описание]. 1) Исследуй соответствующий код и найди способ локального воспроизведения. 2) Добавь регрессионный тест, который сначала подтверждает сбой. 3) Исправь минимально, не расширяя область задачи. 4) Запусти нужные локальные проверки и проверь diff. Не устанавливай зависимости, не обращайся к сети и не выполняй деплой. Перед коммитом остановись для отдельного разрешения. Отчёт: причина, исправление, тесты и оставшиеся неопределённости.
```
