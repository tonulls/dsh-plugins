# ecc-healthcare-eval-harness

**Команда:** `/ecc-healthcare-eval-harness`

**Назначение:** Система оценки безопасности пациентов при выпуске медицинских приложений: автоматические проверки точности CDSS, утечек PHI, целостности клинических процессов и соответствия интеграций. Блокирует выпуск при нарушениях безопасности. Используйте, когда выпуск зависит от таких проверок.

## Промты

### 1. Короткий запрос

> /ecc-healthcare-eval-harness Составь safety-gate тесты для медицинского релиза.

### 2. Шаблон с контекстом

> /ecc-healthcare-eval-harness Приложение: [описание], CDSS: [функции], интеграции: [перечень]. Определи проверки точности, PHI и целостности workflow; без запуска деплоя.

### 3. Подробный запрос

> /ecc-healthcare-eval-harness Определи автоматизированный eval harness для релиза [система]. По блокам опиши CDSS accuracy, утечки PHI, workflow integrity и интеграционное соответствие; задай блокирующие критерии и безопасные синтетические fixtures. Ничего не развёртывай и не используй реальные PHI. Дай pass/fail отчётный формат.
