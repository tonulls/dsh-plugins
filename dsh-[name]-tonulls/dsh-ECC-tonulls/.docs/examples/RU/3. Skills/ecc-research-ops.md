# `/ecc-research-ops`

Проводит исследование текущего состояния на основе свежих фактов, сопоставляет варианты и формирует рекомендацию с доказательствами, учитывая предоставленный локальный контекст.

## Простой запрос
```text
/ecc-research-ops Сравни актуальные варианты [тема] и дай вывод с подтверждающими источниками.
```
## Шаблонный запрос
```text
/ecc-research-ops
Вопрос: [что выяснить]
Контекст: [проект/рынок/ограничения]
Сравнить: [варианты]
Критерии: [стоимость, актуальность, риски]
Подготовь вывод по доступным свежим публичным данным; отделяй проверенные факты от предположений.
```
## Подробный запрос
```text
/ecc-research-ops
Исследуй вопрос: [вопрос]. Контекст и критерии: [описание]. Выполни этапы: 1) уточни область и дату актуальности; 2) составь перечень проверяемых вопросов; 3) собери и сопоставь доступные публичные свидетельства и предоставленный локальный контекст; 4) отметь противоречия, пробелы и ограничения источников; 5) сформулируй рекомендацию с альтернативами и уверенностью. Не раскрывай секреты и не выполняй действия во внешних системах. Сеть используй только если доступна и разрешена; иначе явно укажи это ограничение. Итог: краткое резюме, факты с источниками, неизвестное, рекомендация.
```
