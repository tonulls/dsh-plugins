# `/ecc-test-collaboration`

Инвентаризирует тестовые активы и связывает требования, бизнес-правила, риски, дефекты и межсервисные контракты со стабильными TEST-ID и исполняемыми свидетельствами проекта.

## Простой запрос
```text
/ecc-test-collaboration Проведи read-only анализ пробелов тестирования для требований [перечень]. Файлы не меняй.
```
## Шаблонный запрос
```text
/ecc-test-collaboration
Область и требования: [описание]
Существующий реестр/TESTS.md: [путь или содержимое]
Риски/дефекты: [список]
Сопоставь требования с имеющимися тестами и классифицируй пробелы; не создавай и не редактируй файлы.
```
## Подробный запрос
```text
/ecc-test-collaboration
Проведи аудит тестовых активов [область] строго read-only. Найди в доступном контексте требования, бизнес-правила, известные дефекты и границы потребитель/поставщик; сопоставь их со стабильными TEST-ID и существующими исполняемыми тестами/реестром; классифицируй unit, integration, contract, E2E и smoke; оцени необходимость каждого теста и недоказанные области. Не меняй файлы, не запускай тесты и не добавляй TEST-ID без моего подтверждения. Отчет: карта трассируемости, пробелы по риску, дубли/устаревшие проверки, рекомендуемые действия и ограничения доказательств.
```
