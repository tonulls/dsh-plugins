# `/ecc-quarkus-tdd`

**Назначение:** Разработка через тестирование для Quarkus 3.x LTS с JUnit 5, Mockito, REST Assured, тестированием Camel и JaCoCo. Используйте при добавлении функций, исправлении ошибок и рефакторинге событийных сервисов.

## Короткий промт

```text
/ecc-quarkus-tdd Составь test-first матрицу и примеры JUnit/REST Assured для [Quarkus-сценарий].
```

## Шаблонный промт

```text
/ecc-quarkus-tdd
Контекст: [функция/дефект, API, тестовый стек проекта и критерии поведения].
Задача: спроектировать TDD-проверки для Quarkus-сервиса для [целевой компонент/результат].
Фокус: JUnit 5, Mockito, REST Assured, Camel tests, JaCoCo и поведение до/после изменения.
Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-quarkus-tdd
Выполни задачу «спроектировать TDD-проверки для Quarkus-сервиса» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: JUnit 5, Mockito, REST Assured, Camel tests, JaCoCo и поведение до/после изменения.
3. Сформируй набор тестов или эскиз кода, используя только уже имеющийся в проекте стек; отдели предложенные проверки от реально выполненных.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
