# ecc-frontend-slides

**Команда:** `/ecc-frontend-slides`

**Назначение:** Создавайте выразительные анимированные HTML-презентации с нуля или преобразуйте файлы PowerPoint. Используйте для подготовки презентации, конвертации PPT/PPTX в веб-формат или создания слайдов для выступления и презентации проекта. Помогает людям без дизайнерского опыта выбрать визуальный стиль на основе исследования, а не произвольного выбора.

## Промты

### 1. Короткий запрос

> /ecc-frontend-slides Составь план HTML-презентации о [тема].

### 2. Шаблон с контекстом

> /ecc-frontend-slides Аудитория: [кто], цель: [цель], длительность: [минуты], исходный PPTX: [путь/нет]. Предложи визуальную концепцию и структуру слайдов.

### 3. Подробный запрос

> /ecc-frontend-slides Подготовь презентацию на тему [тема] для [аудитория]. Сначала предложи концепцию и раскадровку, затем содержание каждого слайда и анимационные акценты; если нужен конверт PPTX, укажи допущения. Не создавай и не конвертируй файлы без подтверждения. Представь план и список недостающих материалов.
