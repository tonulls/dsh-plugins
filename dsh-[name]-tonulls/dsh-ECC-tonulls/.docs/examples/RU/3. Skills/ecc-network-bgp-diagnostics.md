# `/ecc-network-bgp-diagnostics`

**Назначение:** Практики диагностики BGP без изменения конфигурации: состояние соседей, обмен маршрутами, политики префиксов, анализ AS path и безопасный сбор доказательств. Используйте при недоступности BGP-соседа, отсутствии маршрутов или проверке политик и AS path.

## Короткий промт

```text
/ecc-network-bgp-diagnostics По этим выводам диагностики найди причину недоступности BGP-соседа или отсутствующих маршрутов; конфигурацию не меняй.
```

## Шаблонный промт

```text
/ecc-network-bgp-diagnostics
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: диагностировать проблему BGP по предоставленным данным для [цель или объект].
Фокус: neighbor state, route exchange, prefix policy, AS path and evidence collection; diagnostics only.
Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-network-bgp-diagnostics
Выполни задачу «диагностировать проблему BGP по предоставленным данным» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: neighbor state, route exchange, prefix policy, AS path and evidence collection; diagnostics only.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
