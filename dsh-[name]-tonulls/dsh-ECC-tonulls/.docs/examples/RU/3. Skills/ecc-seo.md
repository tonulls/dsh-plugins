# `/ecc-seo`

Планирует и проверяет улучшения поисковой видимости: техническое SEO, оптимизацию страниц, структурированные данные, Core Web Vitals и карту ключевых тем.

## Простой запрос
```text
/ecc-seo Проведи read-only SEO-аудит страницы [URL или текст] и расставь улучшения по приоритету.
```
## Шаблонный запрос
```text
/ecc-seo
Сайт/страницы: [адреса или локальные файлы]
Цель и аудитория: [описание]
Регион/язык: [значения]
Ограничения: [технические/редакционные]
Предложи проверяемые улучшения и объясни ожидаемый эффект; ничего не публикуй.
```
## Подробный запрос
```text
/ecc-seo
Оцени SEO для [страницы/сайта] с целью [цель], аудитория [описание], рынок [регион]. Этапы: техническая доступность и индексируемость по доступным данным; структура и on-page релевантность; корректность schema/sitemap/robots по предоставленному контексту; Core Web Vitals, если есть измерения; карта тематических запросов без выдумывания объемов. Раздели подтвержденные наблюдения и гипотезы, составь приоритетный список с трудоемкостью и способом проверки. Только аудит и рекомендации: не меняй файлы, DNS, метаданные сайта и не публикуй. Не сканируй внешний сайт и не обращайся к сети без явного разрешения. Итог: находки, доказательства, план и метрики успеха.
```
