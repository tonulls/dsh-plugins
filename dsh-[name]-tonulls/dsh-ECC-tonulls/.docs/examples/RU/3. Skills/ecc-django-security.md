# `/ecc-django-security`

Проводит обзор безопасности Django: аутентификации и авторизации, CSRF, SQL injection, XSS, обработки ввода и настроек безопасного развёртывания.

## Простой запрос

```text
/ecc-django-security Проведи review Django view на ошибки авторизации и CSRF; файлы не меняй.
```

## Шаблонный запрос

```text
/ecc-django-security
Путь/фрагмент: [код]
Версия Django: [версия]
Сценарий и роли: [описание]
Границы доверия: [данные]
Выполни только статический анализ; не меняй файлы и не запускай атакующие проверки.
```

## Подробный запрос

```text
/ecc-django-security
Проведи read-only аудит указанного Django-кода: [пути/фрагменты]. Файлы не меняй; не выполняй эксплуатацию уязвимостей, сетевые запросы или изменение данных. Проследи аутентификацию и объектную авторизацию, CSRF, безопасную обработку пользовательского ввода, ORM/raw SQL, шаблонный вывод и XSS, загрузки файлов и релевантные production-настройки. Учитывай реальные потоки данных и роли, не выводи секреты. Каждое замечание снабди точным местом, условием проявления, влиянием, серьёзностью и рекомендацией; явно отмечай неопределённость. В конце укажи покрытие анализа, приоритетные находки и безопасные тесты для последующей проверки.
```
