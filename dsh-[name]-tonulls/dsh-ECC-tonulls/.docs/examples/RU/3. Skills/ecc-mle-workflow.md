# `/ecc-mle-workflow`

**Назначение:** Процесс разработки и эксплуатации ML-систем: контракты данных, воспроизводимое обучение, оценка моделей, развёртывание, мониторинг и откат. Используйте при создании, проверке или усилении ML-систем, выходящих за рамки разовых ноутбуков.

## Короткий промт

```text
/ecc-mle-workflow Спроектируй воспроизводимый workflow для модели [тип] от данных и обучения до оценки и мониторинга.
```

## Шаблонный промт

```text
/ecc-mle-workflow
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: спроектировать воспроизводимый цикл разработки и эксплуатации ML-системы для [цель или объект].
Фокус: контракты данных, воспроизводимое обучение, оценка, деплой-план, мониторинг и rollback.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-mle-workflow
Выполни задачу «спроектировать воспроизводимый цикл разработки и эксплуатации ML-системы» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: контракты данных, воспроизводимое обучение, оценка, деплой-план, мониторинг и rollback.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
