# `/ecc-product-lens`

**Назначение:** Проверяет обоснование продукта до начала разработки с помощью четырёх видов анализа: диагностики в стиле YC с итоговым `PRODUCT-BRIEF.md` и рекомендацией запускать или нет, оценки основателем сигналов соответствия продукта рынку, анализа пути пользователя и времени до ценности, а также приоритизации ICE. Используйте для проверки продуктового направления, выбора функций, оценки запуска или превращения идеи в бриф.

## Короткий промт

```text
/ecc-product-lens Проверь идею [описание]: кому нужна, какое время до ценности и что должно быть go/no-go.
```

## Шаблонный промт

```text
/ecc-product-lens
Контекст: [идея/продукт, целевые пользователи, текущий путь пользователя и доступные сигналы].
Задача: проверить продуктовое обоснование до начала разработки для [целевой компонент/результат].
Фокус: проблема и сегмент, признаки product-market fit, user journey/time-to-value, приоритизация ICE и критерии go/no-go.
Ограничения: Подготовь аналитический документ в ответе; не создавай файлы и не начинай реализацию без согласия.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-product-lens
Выполни задачу «проверить продуктовое обоснование до начала разработки» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: проблема и сегмент, признаки product-market fit, user journey/time-to-value, приоритизация ICE и критерии go/no-go.
3. Сформулируй целевую capability/spec с инвариантами, интерфейсами, acceptance criteria и открытыми решениями; отдели факты от гипотез.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Подготовь аналитический документ в ответе; не создавай файлы и не начинай реализацию без согласия.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
