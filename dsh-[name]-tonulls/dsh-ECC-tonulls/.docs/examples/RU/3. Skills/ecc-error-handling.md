# ecc-error-handling

**Команда:** `/ecc-error-handling`

**Назначение:** Практики надёжной обработки ошибок в TypeScript, Python и Go: типизированные ошибки, границы обработки ошибок, повторы и автоматические выключатели (circuit breaker), понятные пользователю сообщения. Используйте при проектировании типов ошибок, повторов, автоматических выключателей или сообщений о сбоях.

## Промты

### 1. Короткий запрос

> /ecc-error-handling Разбери обработку ошибок в этом модуле.

### 2. Шаблон с контекстом

> /ecc-error-handling Язык: [TypeScript/Python/Go], модуль: [путь], сбой: [симптом]. Предложи типизированную обработку и понятное сообщение пользователю.

### 3. Подробный запрос

> /ecc-error-handling Изучи ошибки в [путь] для сценария [сценарий]. Проверь границы ошибок, повторы и circuit breaker; не меняй файлы. Дай приоритетные выводы, безопасный план и примеры.
