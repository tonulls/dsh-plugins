# `/ecc-connections-optimizer`

Помогает пересмотреть сеть контактов X и LinkedIn: предлагает приоритеты для удаления/подписки и составляет персональные черновики тёплых сообщений. Изменения в аккаунтах требуют отдельного подтверждения.

## Простой запрос

```text
/ecc-connections-optimizer Помоги определить, какие контакты в моей сети LinkedIn наиболее полезны для темы устойчивой энергетики.
```

## Шаблонный запрос

```text
/ecc-connections-optimizer
Канал: [X/LinkedIn]
Мои текущие цели: [темы или аудитория]
Доступный список контактов: [данные без лишней персональной информации]
Примеры моего стиля: [тексты]
Составь рекомендации по приоритетам и черновики сообщений; ничего не отписывай и не отправляй.
```

## Подробный запрос

```text
/ecc-connections-optimizer
Помоги перестроить мою профессиональную сеть вокруг цели [цель] и канала [X/LinkedIn]. Используй только предоставленные или явно доступные данные. Сначала сформулируй критерии релевантности, затем сгруппируй контакты по сигналам и неопределённости, подготовь список кандидатов для сохранения/удаления и предложи новые типы контактов для поиска. Составь несколько персонализированных черновиков в моём стиле на основе примеров [примеры]. Не выполняй подписку, отписку, лайк, сообщение или иное действие в аккаунте; перед любым таким действием запроси отдельное явное подтверждение конкретного действия и получателя. Итог — обоснованные рекомендации, сомнительные случаи и черновики без отправки.
```
