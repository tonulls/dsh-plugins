# `/ecc-prediction-market-risk-review`

**Назначение:** Проверяет сценарии работы с рынками прогнозов, корзинами, оракулами и торговыми агентами на риски соблюдения требований, безопасности, качества данных, приватности и исполнения. Используйте до того, как сценарий получит доступ к авторизации на площадке, данным портфеля, API-ключам или планированию сделок.

## Короткий промт

```text
/ecc-prediction-market-risk-review Проведи read-only проверку workflow рынка прогнозов на риски данных, исполнения и приватности.
```

## Шаблонный промт

```text
/ecc-prediction-market-risk-review
Контекст: [архитектура workflow, типы данных, полномочия и предоставленные конфигурации].
Задача: проверить workflow прогнозного рынка, oracle или торгового агента на риски для [целевой компонент/результат].
Фокус: комплаенс-контекст, качество данных, приватность, venue auth/API keys и границы планирования/исполнения.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-prediction-market-risk-review
Выполни задачу «проверить workflow прогнозного рынка, oracle или торгового агента на риски» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: комплаенс-контекст, качество данных, приватность, venue auth/API keys и границы планирования/исполнения.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
