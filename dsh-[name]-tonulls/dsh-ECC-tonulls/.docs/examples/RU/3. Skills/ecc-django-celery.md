# `/ecc-django-celery`

Помогает настраивать фоновые и периодические задачи Django с Celery: конфигурацию, retries, canvas, мониторинг и тестирование.

## Простой запрос

```text
/ecc-django-celery Предложи надёжную Celery-задачу Django для обработки загруженного отчёта.
```

## Шаблонный запрос

```text
/ecc-django-celery
Версии Django/Celery и broker: [данные]
Задача и ожидаемая длительность: [описание]
Требования к повторам/идемпотентности: [условия]
Текущая конфигурация: [фрагменты]
Предложи task, обработку ошибок, мониторинг и тесты в стиле проекта.
```

## Подробный запрос

```text
/ecc-django-celery
Спроектируй фоновую обработку [операция] для Django [версия] и Celery [версия], broker [тип]. Определи границы транзакции и момент постановки задачи, идемпотентный ключ, таймауты/retry с backoff, поведение при исчерпании попыток, маршрутизацию очередей и периодическое расписание при необходимости. Учитывай сериализуемость аргументов, повторную доставку и наблюдаемость. Предложи unit/integration тесты без вызовов внешнего сервиса. Сначала только рекомендация; изменения и установка зависимостей — лишь после подтверждения. Итог: схема задачи, конфигурационные места, риски, тесты и локальные команды проверки.
```
