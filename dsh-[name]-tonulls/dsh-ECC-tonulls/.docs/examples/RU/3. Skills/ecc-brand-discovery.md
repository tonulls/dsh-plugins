# `/ecc-brand-discovery`

Структурированное интервью по созданию или переосмыслению бренда: восемь модулей, включая цель, позиционирование, аудиторию, характер, голос, нарратив и напряжение основателя. Интервью можно продолжать в несколько сессий, сохранять ответы и свести их в `90_SYNTHESIS.md`.

## Короткий запрос

```text
/ecc-brand-discovery Проведи интервью, чтобы прояснить позиционирование нового бренда студии и подготовить основу для брендбука.
```

## Шаблон

```text
/ecc-brand-discovery Помоги [создать/переосмыслить] бренд [название/проект] для [рынок/аудитория]. Начни с [модуль или интервью с нуля], задавай по одному содержательному вопросу и углубляй ответы через уточнения. Сохраняй мои формулировки отдельно от выводов; если работа ведётся в проекте, предложи место для заметок до записи файлов.
```

## Поэтапный запрос

```text
/ecc-brand-discovery Проведи многоэтапное интервью по бренду [название/проект]. Цель: [новый бренд / репозиционирование / бриф для дизайнеров или авторов].
1. Проверь, есть ли уже сохранённые ответы; при продолжении не задавай повторно то, что подтверждено, и обозначь незаполненные модули.
2. Иди по модулям: цель, позиционирование, аудитория, личность, голос, нарратив и напряжение основателя (и остальные предусмотренные интервью темы). Используй уточнения вроде «почему?» и проективные вопросы, но не подменяй ответы собственными предположениями.
3. В конце каждого этапа кратко отрази услышанное и попроси подтвердить или поправить спорные выводы. Не записывай материалы на диск без согласованного расположения.
4. После завершения согласованных модулей подготовь синтез в `90_SYNTHESIS.md`, отделяя факты и цитаты от интерпретаций.

Результат: список пройденных/открытых модулей, подтверждённые формулировки бренда, противоречия и итоговый брендбук. Если информации недостаточно, задай следующий вопрос, а не заполняй пробелы выдуманными фактами.
```
