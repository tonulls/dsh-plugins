# ecc-finance-billing-ops

**Команда:** `/ecc-finance-billing-ops`

**Назначение:** Основанный на данных процесс ECC для выручки, цен, возвратов, командного биллинга и проверки реальной модели оплаты. Используйте для сводки продаж, сравнения тарифов, диагностики двойного списания или проверки биллинга по коду вместо общих советов об оплате.

## Промты

### 1. Короткий запрос

> /ecc-finance-billing-ops Разбери расхождение в оплате по доступным данным.

### 2. Шаблон с контекстом

> /ecc-finance-billing-ops Период: [даты], продукт/план: [название], вопрос: [выручка/возврат/дубли]. Используй только доступные подтверждённые сведения, не инициируй платежи и возвраты.

### 3. Подробный запрос

> /ecc-finance-billing-ops Сверь код и предоставленные данные для [вопрос billing]. Раздели факты/гипотезы, сопоставь суммы и периоды, проверь возможные дубли. Не открывай внешние системы и не выполняй финансовые операции без явного согласия. Выдай расчёт и неизвестные.
