# `/ecc-bengali-nlp`

Для задач обработки бенгальского (Bangla) текста: Unicode-нормализация, определение письма, токенизация, корректная работа с conjunct-последовательностями и особенности NLP для AI-приложений.

## Короткий запрос

```text
/ecc-bengali-nlp Проверь токенизацию бенгальских строк: учти Unicode-нормализацию и conjunct-символы, предложи тестовые случаи.
```

## Шаблон

```text
/ecc-bengali-nlp Проанализируй [модуль/фрагмент] для обработки текста на бенгальском. Входы: [примеры, включая смешанный текст]. Нужны: [нормализация / детекция письменности / токенизация / иное]. Сохрани различия, значимые для языка; не предполагай, что байты, кодовые точки и пользовательские символы совпадают.
```

## Поэтапный запрос

```text
/ecc-bengali-nlp Разбери конвейер обработки Bengali/Bangla в [путь/функция] для сценария [поиск/классификация/генерация].
1. Проследи входную кодировку и нормализацию; укажи, какие Unicode-преобразования допустимы и где могут исказить данные.
2. Проверь детекцию бенгальского письма и смешанные строки на конкретных примерах: [примеры].
3. Оцени токенизацию и обработку conjunct-форм, знаков и границ; не делай выводов о лингвистической корректности без подтверждающих примеров.
4. Предложи компактный набор регрессионных случаев и критерии ожидаемого поведения.

Результат: таблица «вход / наблюдаемая проблема / ожидаемое поведение», приоритеты и минимальный план исправления. Если просили только review — никаких правок. При реализации меняй лишь относящиеся к задаче файлы; не устанавливай пакеты, не используй сеть и не деплой без отдельного согласия.
```
