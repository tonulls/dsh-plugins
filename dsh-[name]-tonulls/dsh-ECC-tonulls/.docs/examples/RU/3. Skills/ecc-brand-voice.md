# `/ecc-brand-voice`

Выводит профиль стиля из реальных текстовых образцов — публикаций, эссе, заметок о запуске, документации или сайта — и применяет его к контенту, письмам и соцсетям без типовых «AI-штампов».

## Короткий запрос

```text
/ecc-brand-voice Выведи стиль из приложенных публикаций и перепиши анонс запуска так, чтобы он звучал в этом голосе, а не как generic AI-текст.
```

## Шаблон

```text
/ecc-brand-voice Используй эти источники стиля: [тексты/файлы]. Построй профиль на наблюдаемых признаках — лексика, ритм, тон, структура, характерные приёмы и чего избегать. Затем адаптируй [материал] для [канал и аудитория]. Не копируй факты из образцов, если они не относятся к новому материалу.
```

## Поэтапный запрос

```text
/ecc-brand-voice Создай воспроизводимый профиль голоса [автор/бренд] на основе [перечень реальных текстов]. Нужно подготовить [письмо/пост/страницу] для [аудитория, канал, задача].
1. Проверь достаточность и разнообразие образцов; отметь их жанры и возможные различия тона.
2. Извлеки профиль с примерами наблюдаемых особенностей: длина фраз, словарь, степень формальности, ритм, юмор, структура, прямота. Отдели подтверждённое от предположений.
3. Зафиксируй запреты на клише и нежелательные особенности. Не имитируй личность за пределами предоставленных источников.
4. Подготовь материал для указанного канала, сохраняя исходные факты и требования к длине [лимит].
5. Покажи короткое обоснование соответствия профилю и перечисли места, где не хватило данных.

Формат: профиль стиля; готовый текст; краткая самопроверка. Не выдумывай факты и не публикуй/не отправляй текст без отдельного согласия.
```
