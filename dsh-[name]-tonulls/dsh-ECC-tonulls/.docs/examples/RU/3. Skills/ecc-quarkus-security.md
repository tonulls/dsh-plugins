# `/ecc-quarkus-security`

**Назначение:** Практики безопасности Quarkus: аутентификация JWT и OIDC, RBAC через `@RolesAllowed` и проверки SecurityIdentity, Bean Validation и пользовательские валидаторы, параметризованные запросы Panache, хеширование BCrypt, CORS и заголовки безопасности, ограничение частоты запросов, аудит, секреты в Vault или переменных окружения и проверка CVE зависимостей. Используйте для настройки доступа, валидации ввода, управления секретами и укрепления Quarkus-приложений.

## Короткий промт

```text
/ecc-quarkus-security Проведи read-only аудит Quarkus endpoint на auth/authz, валидацию и утечки секретов.
```
