# `/ecc-motion-patterns`

**Назначение:** Готовые к выпуску анимации React/Next.js: кнопки, модальные окна, всплывающие уведомления, каскадные эффекты, переходы страниц, анимация выхода, прокрутка и компоновка. Используют токены и пружины навыка `motion-foundations`. Используйте для анимации конкретных элементов интерфейса.

## Короткий промт

```text
/ecc-motion-patterns Спроектируй доступную анимацию [кнопки/модального окна/перехода] для React/Next.js.
```
