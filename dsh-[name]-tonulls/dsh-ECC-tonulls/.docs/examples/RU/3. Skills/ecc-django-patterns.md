# `/ecc-django-patterns`

Помогает строить и проверять Django-приложения: архитектуру, DRF API, ORM-запросы, кэширование, сигналы, middleware и организацию production-кода.

## Простой запрос

```text
/ecc-django-patterns Проверь ORM-запрос списка заказов на N+1 и предложи улучшение.
```

## Шаблонный запрос

```text
/ecc-django-patterns
Версия Django: [версия]
Компонент: [модель/API/view/service]
Текущая реализация: [путь/код]
Ограничения производительности и поведения: [описание]
Предложи решение в рамках имеющейся архитектуры и миграций.
```

## Подробный запрос

```text
/ecc-django-patterns
Разбери задачу [функция] в Django [версия], используя [DRF/ORM/кэш]. Сначала изучи релевантные соглашения проекта; затем предложи разделение ответственности, форму API/валидацию, эффективные запросы и нужные select_related/prefetch_related или кэширование, если это подтверждено. Проверь транзакции и побочные эффекты сигналов; предложи тесты на поведение и граничные случаи. Не меняй файлы и схему БД, не устанавливай пакеты. Если реализация затрагивает данные или контракт API, сначала опиши совместимость и запроси подтверждение. Выведи анализ, конкретный вариант, риски и проверки.
```
