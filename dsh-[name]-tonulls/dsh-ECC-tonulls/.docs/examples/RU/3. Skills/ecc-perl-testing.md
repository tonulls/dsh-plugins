# `/ecc-perl-testing`

**Назначение:** Практики тестирования Perl с Test2::V0, Test::More, запуском через prove, моками, покрытием Devel::Cover и методологией TDD. Используйте при написании тестов или измерении покрытия.

## Короткий промт

```text
/ecc-perl-testing Составь тесты для Perl-функции [имя] на [Test2::V0/Test::More] с граничными случаями.
```

## Шаблонный промт

```text
/ecc-perl-testing
Контекст: [функция/модуль, ожидаемое поведение, выбранный тестовый фреймворк и существующие тесты].
Задача: спроектировать тесты Perl через Test2::V0 или Test::More для [целевой компонент/результат].
Фокус: табличные случаи, фикстуры, моки, негативные сценарии и обоснованное покрытие.
Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-perl-testing
Выполни задачу «спроектировать тесты Perl через Test2::V0 или Test::More» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: табличные случаи, фикстуры, моки, негативные сценарии и обоснованное покрытие.
3. Сформируй набор тестов или эскиз кода, используя только уже имеющийся в проекте стек; отдели предложенные проверки от реально выполненных.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Подготовь тест-план/примеры в стиле репозитория; не запускай команды и не устанавливай зависимости без разрешения.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
