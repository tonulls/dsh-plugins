# `/ecc-springboot-security`

Проверяет практики безопасности Spring Security: аутентификацию и авторизацию, валидацию, CSRF, секреты, заголовки, ограничение частоты и зависимости.

## Простой запрос
```text
/ecc-springboot-security Проведи read-only проверку конфигурации Spring Security: [фрагмент]. Файлы не меняй.
```
## Шаблонный запрос
```text
/ecc-springboot-security
Компонент/дифф: [пути или фрагмент]
Механизм входа и роли: [описание]
Тип клиентов: [браузер/API]
Проверь authn/authz, CSRF, валидацию, секреты и заголовки; не раскрывай значения секретов и не исправляй код.
```
## Подробный запрос
```text
/ecc-springboot-security
Проведи аудит безопасности Spring Boot/Spring Security [область] строго без изменений файлов. Проследи конфигурацию цепочек фильтров, границы аутентификации и авторизации, доступ к endpoint, валидацию, CSRF по типу клиента, защитные заголовки, ограничение частоты, управление секретами и риски зависимостей. Для каждого вывода приведи кодовое свидетельство и сценарий, отделяй подтвержденное от предположений. Не запускай активные тесты, не запрашивай сеть, не печатай секреты и не вноси исправления. Итог: серьезность, область, влияние, рекомендация и приоритет; отмечай непроверенные настройки окружения.
```
