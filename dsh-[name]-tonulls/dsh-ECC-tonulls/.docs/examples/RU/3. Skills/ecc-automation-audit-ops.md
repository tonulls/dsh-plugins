# `/ecc-automation-audit-ops`

Проводит инвентаризацию и аудит пересечений автоматизаций ECC по фактам: задания, хуки, коннекторы, MCP-серверы и обёртки. Помогает понять, что работает, сломано, дублируется или отсутствует, прежде чем что-либо исправлять.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-automation-audit-ops Инвентаризируй автоматизации этого проекта и найди подтверждённые дубли и сбои. Пока ничего не исправляй.
```

### 2. Шаблонный запрос
```text
/ecc-automation-audit-ops Проведи аудит [репозиторий/область]: проверь [jobs/hooks/connectors/MCP/wrappers]. Используй доступные локальные конфиги и статус; разделяй факт, предположение и неизвестное. Никаких изменений. Сведи результат в таблицу «компонент — назначение — состояние — доказательство — пересечение/пробел».
```

### 3. Подробный запрос
```text
/ecc-automation-audit-ops Выполни evidence-first аудит автоматизаций [проект/область]. 1) Определи доступные источники инвентаризации для заданий, хуков, коннекторов, MCP-серверов и обёрток; не считай отсутствующий источник доказательством отсутствия компонента. 2) Для каждого обнаруженного компонента зафиксируй назначение, состояние и подтверждающий путь/вывод. 3) Сопоставь функции, отметь реальные дубли, поломки и пробелы с уровнем уверенности. 4) Не исправляй, не запускай и не перенастраивай автоматизации. Вывод: сводная таблица, приоритетные выводы и перечень недоступных для проверки областей.
```
