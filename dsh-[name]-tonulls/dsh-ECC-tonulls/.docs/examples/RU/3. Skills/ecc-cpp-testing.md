# `/ecc-cpp-testing`

Поддерживает написание и исправление C++-тестов, настройку GoogleTest/CTest, диагностику flaky-тестов и добавление покрытия или санитайзеров.

## Простой запрос

```text
/ecc-cpp-testing Добавь тесты граничных случаев для парсера диапазонов в C++.
```

## Шаблонный запрос

```text
/ecc-cpp-testing
Компонент: [описание/путь]
Тестовый стек: [GoogleTest/CTest/другое]
Ожидаемое поведение: [правила и края]
Существующие тесты: [путь или пример]
Сначала предложи матрицу случаев; изменяй только нужные тестовые файлы после согласования.
```

## Подробный запрос

```text
/ecc-cpp-testing
Нужно покрыть [функцию/дефект] в C++ проекте, где используются [GoogleTest/CTest/конфигурация]. Изучи текущие соглашения, составь тесты для нормальных, граничных и ошибочных входов, а для дефекта сначала создай воспроизводимый регрессионный случай. Сохраняй тесты детерминированными, не зависящими от сети и внешних сервисов; санитайзеры/покрытие предлагай только если уместно. До изменения файлов представь план и уточни, если требуются новые зависимости или изменение сборки. После подтверждения меняй только связанные тестовые/конфигурационные файлы и запускай только локальные разрешённые команды. Отчёт: изменённые места, сценарии и фактический результат проверок.
```
