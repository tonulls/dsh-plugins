# `/ecc-carrier-relationship-management`

Практика управления портфелем грузовых перевозчиков: поиск и проверка FMCSA, переговоры о ставках и топливных надбавках, RFP и routing guide, scorecard, распределение объёмов и продление отношений для truckload, LTL и intermodal.

## Короткий запрос

```text
/ecc-carrier-relationship-management Составь структуру scorecard для оценки наших LTL-перевозчиков по своевременности, претензиям, стоимости и качеству данных.
```

## Шаблон

```text
/ecc-carrier-relationship-management Помоги с [онбордингом / RFP / переговорами / оценкой / распределением / продлением] перевозчика для [truckload/LTL/intermodal]. Линии/регионы: [данные], объём: [период и диапазон], ограничения сервиса: [условия]. Отдели подтверждённые данные от допущений; не выдумывай котировки или статус FMCSA.
```

## Поэтапный запрос

```text
/ecc-carrier-relationship-management Подготовь план [RFP/пересмотра портфеля/продления] для [сеть, регионы, типы перевозок] на период [даты]. Цели: [экономия/надёжность/ёмкость], ограничения: [сервис, страхование, политика закупок].
1. Сегментируй потребность по lanes, объёму и режимам truckload/LTL/intermodal; перечисли недостающие данные.
2. Для новых кандидатов задай процедуру проверки перевозчика и FMCSA; текущий статус считай неподтверждённым, пока нет источника и даты.
3. Сформируй сравнимую структуру RFP: ставка, топливная надбавка, accessorials, условия и срок действия; не сочиняй предложения поставщиков.
4. Предложи scorecard с определениями метрик и периодичностью (например, сервис, претензии, затраты, отклонения); укажи, как результат влияет на allocation и routing guide.
5. Подготовь переговорные приоритеты и варианты продления, обозначив решения, требующие одобрения закупок.

Формат: недостающие данные; матрица перевозчиков/критериев; риски и план следующих шагов. Не заключай соглашения, не меняй распределение и не связывайся с перевозчиками без явного согласия.
```
