# ecc-iterative-retrieval

**Команда:** `/ecc-iterative-retrieval`

**Назначение:** Шаблон последовательного уточнения поиска контекста для решения проблемы нехватки контекста у субагента. Используйте, когда контекст субагента нужно улучшать в несколько проходов.

## Промты

### 1. Короткий запрос

> /ecc-iterative-retrieval Помоги уточнить контекст для подзадачи агента.

### 2. Шаблон с контекстом

> /ecc-iterative-retrieval Подзадача: [описание], уже известный контекст: [данные], пробел: [вопрос]. Предложи следующий узкий запрос на извлечение.

### 3. Подробный запрос

> /ecc-iterative-retrieval Спланируй итеративное получение контекста для подзадачи [описание]. Сначала перечисли недостающие факты, сформулируй минимальный запрос/пути для следующего прохода, затем критерий остановки; ограничь поиск только разрешёнными файлами. Не раскрывай секреты и не запускай команды. Выведи контекст-пакет для исполнителя и остаточные пробелы.
