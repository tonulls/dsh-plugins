# `/ecc-defi-amm-security`

Проверяет Solidity AMM, пулы ликвидности и swap-потоки по рискам реентерабельности, CEI, манипуляции оракулом, slippage, админ-контролям и целочисленной арифметике.

## Простой запрос

```text
/ecc-defi-amm-security Проведи security-review функции swap в этом Solidity AMM; файлы не меняй.
```

## Шаблонный запрос

```text
/ecc-defi-amm-security
Контракт/фрагмент: [путь или код]
Версия Solidity и зависимости: [данные]
Тип AMM/пула: [описание]
Границы доверия и роли: [описание]
Только анализ: не меняй файлы, не запускай транзакции и не взаимодействуй с сетью.
```

## Подробный запрос

```text
/ecc-defi-amm-security
Выполни статический аудит предоставленных Solidity-контрактов AMM. Файлы не изменяй; не выполняй exploit, транзакции, деплой или сетевые действия. Проследи потоки внешних вызовов и состояния, проверь reentrancy и CEI-порядок, donation/inflation атаки, допущения оракула, расчёт slippage, округления/переполнения, ограничения ликвидности и административные полномочия. Для каждой находки укажи точное место, предпосылки эксплуатации, влияние, серьёзность и безопасную рекомендацию; отделяй подтверждённый дефект от гипотезы. Не давай инструкций по краже средств. Заверши приоритетным списком, областью проверки и непроверенными предположениями.
```
