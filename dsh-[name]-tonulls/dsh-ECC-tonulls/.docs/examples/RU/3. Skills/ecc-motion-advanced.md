# `/ecc-motion-advanced`

**Назначение:** Продвинутые приёмы Motion для React/Next.js: перетаскивание, жесты, анимация текста, рисование SVG-путей, пользовательские хуки, императивные последовательности (`useAnimate`), индикаторы загрузки и выбор API. Требует навык `motion-foundations`. Используйте для реализации таких анимаций.

## Короткий промт

```text
/ecc-motion-advanced Предложи реализацию жеста перетаскивания и последовательности анимации для [компонент] на Motion.
```
