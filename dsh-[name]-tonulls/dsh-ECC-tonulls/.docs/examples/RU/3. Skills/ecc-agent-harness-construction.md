# `/ecc-agent-harness-construction`

Проектирует и улучшает пространство действий агента: набор инструментов, их определения и формат наблюдений — с целью повысить долю успешно завершённых задач.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-agent-harness-construction Проанализируй доступные агенту инструменты и предложи, как упростить их набор и сделать результаты вызовов понятнее. Только анализ, код не меняй.
```

### 2. Шаблонный запрос
```text
/ecc-agent-harness-construction Оцени harness агента для задачи [тип задач]. Изучи [описание/файлы конфигурации инструментов и наблюдений]. Найди избыточные или недостающие действия, неоднозначные определения инструментов и шум в наблюдениях. Предложи конкретные изменения и ожидаемый эффект; ничего не изменяй.
```

### 3. Подробный запрос
```text
/ecc-agent-harness-construction Пересмотри пространство действий агента для сценария [сценарий] в [репозиторий или файлы]. 1) Зафиксируй текущие инструменты, входы/выходы и формат наблюдений по исходникам. 2) Найди дублирование, пробелы в действиях и неоднозначность, мешающую выбору инструмента. 3) Предложи минимальные изменения с объяснением влияния на завершение задач и рисков. 4) Не меняй файлы и не утверждай об улучшении без измерений. Результат: текущая схема, приоритетные проблемы с доказательствами, целевая схема и проверяемые гипотезы для последующей оценки.
```
