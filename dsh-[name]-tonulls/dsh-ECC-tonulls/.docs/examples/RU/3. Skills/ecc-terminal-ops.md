# `/ecc-terminal-ops`

Организует доказательное выполнение команд в репозитории: проверки, разбор ошибок CI и узкие исправления с точным учетом того, что было запущено и подтверждено.

## Простой запрос
```text
/ecc-terminal-ops Разбери эту ошибку CI по имеющимся логам и предложи безопасную проверку: [лог]
```
## Шаблонный запрос
```text
/ecc-terminal-ops
Репозиторий/задача: [контекст]
Команда или ошибка: [данные]
Разрешенный охват: [read-only/конкретные локальные проверки]
Сначала перечисли план команд и побочные эффекты; не запускай ничего за пределами согласованного охвата.
```
## Подробный запрос
```text
/ecc-terminal-ops
Нужно проверить/диагностировать [задача] в репозитории [область]. Сначала осмотри относящиеся файлы и доступные инструкции, затем составь минимальный план безопасных локальных команд с ожидаемыми побочными эффектами. До запуска команд, записи файлов, обращения к сети, установки, изменения Git, push или deploy запроси мое отдельное подтверждение для соответствующего действия. Сохраняй точные команды и фактические коды/выводы; секреты маскируй. Не заявляй об успешной проверке, если она не выполнялась. Итог: выполненные действия, доказательства, не выполненные проверки и следующий безопасный шаг.
```
