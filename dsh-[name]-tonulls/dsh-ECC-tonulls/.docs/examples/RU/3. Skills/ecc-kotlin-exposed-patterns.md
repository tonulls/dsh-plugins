# ecc-kotlin-exposed-patterns

**Команда:** `/ecc-kotlin-exposed-patterns`

**Назначение:** Практики JetBrains Exposed ORM: DSL-запросы, DAO, транзакции, пулы соединений HikariCP, миграции Flyway и паттерн repository. Используйте при работе с Exposed — DSL/DAO-запросами, транзакциями, пулами или миграциями.

## Промты

### 1. Короткий запрос

> /ecc-kotlin-exposed-patterns Оптимизируй Exposed запрос для [сценарий].

### 2. Шаблон с контекстом

> /ecc-kotlin-exposed-patterns Используется [DSL/DAO], сущности: [описание], проблема: [запрос/транзакция/pool]. Проверь SQL, HikariCP и миграции, но не запускай их.

### 3. Подробный запрос

> /ecc-kotlin-exposed-patterns Изучи использование JetBrains Exposed в [модуль]. Сравни DSL/DAO, транзакционные границы, HikariCP, repository pattern и план миграции Flyway. Не подключайся к БД и не применяй миграции. Дай конкретную рекомендацию, риски и тесты.
