# `/ecc-docker-patterns`

Помогает создавать и проверять Docker/Compose-конфигурации, безопасность контейнеров, сети и тома, а также тестовые harness для CLI-установщиков.

## Простой запрос

```text
/ecc-docker-patterns Проверь Dockerfile моего Python-сервиса на избыточные права и размер образа.
```

## Шаблонный запрос

```text
/ecc-docker-patterns
Docker/Compose-файлы: [пути или содержимое]
Цель: [локальная разработка/production/тест установщика]
Среды: [OS и архитектура]
Ограничения сети, томов и пользователя: [описание]
Сделай review без сборки/запуска контейнеров и без изменения файлов.
```

## Подробный запрос

```text
/ecc-docker-patterns
Проанализируй [Dockerfile/Compose/installer harness] для задачи [описание]. Файлы не меняй и контейнеры не запускай. Проверь минимальные привилегии и пользователя, слои и воспроизводимость, секреты без раскрытия значений, сеть, тома и границы доступа, health checks и взаимодействие сервисов. Для installer harness укажи, какие ОС реально покрыты и где требуется нативная проверка macOS/Windows, не выдавая эмуляцию за неё. Предложи конкретные безопасные улучшения и проверку; не устанавливай пакеты и не выполняй сетевые операции. Итог — находки с путями, серьёзность, предлагаемые изменения и матрица платформенной валидации.
```
