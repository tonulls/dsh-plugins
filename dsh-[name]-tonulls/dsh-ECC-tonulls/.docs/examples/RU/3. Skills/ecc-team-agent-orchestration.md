# `/ecc-team-agent-orchestration`

Помогает координировать параллельную работу группы агентов: декомпозиция с владельцами и границами, Kanban-состояния, изоляция веток, контрольная панель и условия слияния.

## Простой запрос
```text
/ecc-team-agent-orchestration Разбей [задачу] на независимые работы для команды агентов с владельцами и критериями приемки.
```
## Шаблонный запрос
```text
/ecc-team-agent-orchestration
Цель: [результат]
Объем и ограничения: [описание]
Доступные агенты/среда: [если известно]
Предложи work items, владельцев, зависимости, статусы и merge gates; не запускай агентов и не меняй ветки без подтверждения.
```
## Подробный запрос
```text
/ecc-team-agent-orchestration
Спланируй командную работу над [задача]. Этапы: выдели независимые части и общие интерфейсы; назначь каждой задаче владельца, входы/выходы и критерии готовности; отрази зависимости и Kanban-переходы; предложи изоляцию веток/worktrees и контроль конфликтов; определи проверки и условия слияния/остановки. Не создавай ветки, worktrees, файлы и не запускай агентов до моего явного подтверждения; не выполняй merge/push/deploy. Итог: план работ, карта зависимостей, риски координации, контрольные точки и порядок интеграции.
```
