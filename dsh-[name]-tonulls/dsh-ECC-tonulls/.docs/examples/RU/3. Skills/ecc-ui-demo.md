# `/ecc-ui-demo`

Создает видеодемонстрацию веб-приложения через Playwright: запись WebM с видимым курсором, плавным темпом и оформлением walkthrough/tutorial.

## Простой запрос
```text
/ecc-ui-demo Подготовь сценарий демонстрации интерфейса [страница/функция]; ничего не записывай без моего подтверждения.
```
## Шаблонный запрос
```text
/ecc-ui-demo
Приложение и разрешенный адрес: [локальная среда/URL]
Сценарий и аудитория: [шаги]
Окно/разрешение: [значения]
Предложи план записи WebM через доступный Playwright; не входи в реальные аккаунты и не отправляй данные.
```
## Подробный запрос
```text
/ecc-ui-demo
Нужна демонстрация [функция] для [аудитория]. Сначала согласуй сценарий, разрешенную среду и тестовые данные; затем перечисли безопасные шаги браузера, точки пауз/курсора и критерии готового видео WebM. Не устанавливай Playwright и не подключайся к сети без разрешения; не используй настоящие учетные данные, не отправляй формы, письма, платежи и не меняй серверные данные. Создание записи или взаимодействие с интерфейсом начинай только после отдельного подтверждения. Отчет: фактическое покрытие сценария, путь результата, ограничения и любые пропущенные шаги.
```
