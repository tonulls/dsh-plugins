# `/ecc-customer-billing-ops`

Помогает разбирать клиентские биллинговые процессы — подписки, возвраты, отток, доступ к billing portal и планы — с использованием подключённых биллинговых инструментов, если они доступны.

## Простой запрос

```text
/ecc-customer-billing-ops Помоги разобраться, почему клиент видит два списания за этот месяц.
```

## Шаблонный запрос

```text
/ecc-customer-billing-ops
Запрос клиента: [текст без лишних персональных данных]
Идентификатор обращения: [без секрета]
Известные факты о подписке/счёте: [данные]
Нужно: [проверить состояние / подготовить ответ / оценить варианты]
Сначала только просмотр и объяснение; возврат, смену тарифа или отмену не выполнять без моего подтверждения.
```

## Подробный запрос

```text
/ecc-customer-billing-ops
Разбери обращение [краткое описание] по вопросу [подписка/возврат/дублирующее списание/портал]. Используй только разрешённые подключённые инструменты и минимально необходимые данные; не запрашивай карточные реквизиты, пароли или токены. Сначала проверь доступные факты и отдели подтверждённое от гипотез; затем сопоставь с правилами биллинга и подготовь ответ клиенту. Любое финансовое или изменяющее состояние действие (возврат, отмена, изменение плана, письмо клиенту) не выполняй без отдельного подтверждения с точным объектом и суммой/текстом. Не обращайся к сети или внешнему сервису, если подключённый инструмент/разрешение отсутствует. Итог: найденные факты, неясности, предлагаемый безопасный следующий шаг и черновик ответа.
```
