# `/ecc-swift-protocol-di-testing`

Помогает тестировать Swift-код через узкие протоколы внедрения зависимостей, подменяя файловую систему, сеть и внешние API в Swift Testing.

## Простой запрос
```text
/ecc-swift-protocol-di-testing Предложи протокол и тестовый mock для этой внешней зависимости Swift: [код]
```
## Шаблонный запрос
```text
/ecc-swift-protocol-di-testing
Компонент: [описание]
Внешние зависимости: [файлы/сеть/API]
Требуемые сценарии: [успех/ошибка/повтор]
Покажи узкий протокол и тесты Swift Testing, не вызывая реальные сервисы.
```
## Подробный запрос
```text
/ecc-swift-protocol-di-testing
Сделай дизайн тестируемым для [Swift-функция/сервис], использующего [файловую систему, сеть или API]. 1) Найди минимальную границу зависимости. 2) Предложи протокол и внедрение без чрезмерного абстрагирования. 3) Создай концептуальный mock/fake с управляемыми результатами и ошибками. 4) Опиши Swift Testing тесты для успеха, отказа и граничных условий. Исключи реальные сетевые вызовы и чтение/запись пользовательских файлов; не меняй проект и не добавляй зависимости без подтверждения. Итог: интерфейс протокола, примеры тестов, проверяемые инварианты и ограничения.
```
