# `/ecc-redis-patterns`

**Назначение:** Практики Redis: структуры данных, стратегии кэширования, распределённые блокировки, ограничение частоты запросов, обмен сообщениями pub/sub и управление подключениями для приложений в рабочей среде. Используйте при добавлении этих возможностей или проверке схемы ключей.

## Короткий промт

```text
/ecc-redis-patterns Проверь схему ключей Redis и выбранную структуру данных для [нагрузка].
```

## Шаблонный промт

```text
/ecc-redis-patterns
Контекст: [операция/нагрузка, схема ключей, TTL, клиенты/пулы и наблюдаемый симптом].
Задача: проверить или спроектировать Redis-паттерн для приложения для [целевой компонент/результат].
Фокус: структура данных, cache invalidation, distributed locks, rate limiting, pub/sub и connection management.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-redis-patterns
Выполни задачу «проверить или спроектировать Redis-паттерн для приложения» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: структура данных, cache invalidation, distributed locks, rate limiting, pub/sub и connection management.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
