# ecc-frontend-a11y

**Команда:** `/ecc-frontend-a11y`

**Назначение:** Практики доступности для React и Next.js: семантический HTML, атрибуты ARIA, подписи полей, клавиатурная навигация, управление фокусом и поддержка экранных дикторов. Используйте при создании и проверке форм, модальных окон, выпадающих списков, подсказок и вкладок, исправлении замечаний доступности или настройке клавиатуры и фокуса.

## Промты

### 1. Короткий запрос

> /ecc-frontend-a11y Проверь доступность этой React-формы.

### 2. Шаблон с контекстом

> /ecc-frontend-a11y Компонент: [путь], элементы: [форма/модалка/табы]. Проверь семантику, labels, клавиатуру, фокус и экранный диктор; файлы не меняй.

### 3. Подробный запрос

> /ecc-frontend-a11y Сделай read-only аудит [компонент]. Проверь HTML/ARIA, метки полей, порядок клавиатуры, управление фокусом и screen reader поведение. Выдай дефекты по серьёзности с конкретными местами и проверками исправления; не редактируй файлы.
