# `/ecc-cost-aware-llm-pipeline`

Помогает сокращать расходы LLM через маршрутизацию по сложности, бюджетирование, управляемые повторы и кэширование промптов.

## Простой запрос

```text
/ecc-cost-aware-llm-pipeline Предложи, как снизить стоимость классификации обращений LLM без потери качества.
```

## Шаблонный запрос

```text
/ecc-cost-aware-llm-pipeline
Текущий поток: [задачи и модели]
Объём и стоимость: [оценки]
Требования к качеству/задержке: [пороговые значения]
Повторяемые префиксы: [описание]
Предложи маршрутизацию, бюджетные пределы, повторы и кэширование; не запускай запросы к API.
```

## Подробный запрос

```text
/ecc-cost-aware-llm-pipeline
Проанализируй LLM-пайплайн [описание] с целью уменьшить стоимость при требованиях качества [метрики], задержки [порог] и общего бюджета [лимит]. Раздели задачи по сложности и цене ошибки; предложи правила выбора модели, лимиты затрат на запрос/период, повторы с защитой от лавинообразных затрат и места для prompt caching. Определи, какие измерения нужны для проверки экономии и регрессии качества. Не отправляй данные в модели/API и не меняй конфигурацию без подтверждения. В отчёте приведи текущие неизвестные, целевую схему, контрольные метрики, риски и безопасный план эксперимента.
```
