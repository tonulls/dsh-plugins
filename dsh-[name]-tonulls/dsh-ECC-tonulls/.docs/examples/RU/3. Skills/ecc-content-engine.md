# `/ecc-content-engine`

Создаёт нативный для площадок контент-системы: публикации, треды, видео-сценарии, календари и адаптации исходного материала для X, LinkedIn, TikTok, YouTube и рассылок.

## Простой запрос

```text
/ecc-content-engine Преврати анонс запуска нашей функции в пост для LinkedIn и короткий тред для X.
```

## Шаблонный запрос

```text
/ecc-content-engine
Исходный материал: [тезисы/ссылка на предоставленный документ]
Целевая аудитория: [кто]
Цель: [информировать/обсуждение/регистрация]
Площадки и формат: [список]
Тон и ограничения бренда: [описание]
Подготовь разные версии, подходящие формату каждой площадки.
```

## Подробный запрос

```text
/ecc-content-engine
Разработай контент-систему для [кампания/тема] на основе [исходный материал]. Аудитория: [сегменты], цель: [измеримый результат], период: [даты], площадки: [список], голос бренда: [описание/примеры]. Сначала выдели подтверждённые ключевые тезисы и пробелы; затем предложи контент-углы и календарь; подготовь отдельные нативные форматы для каждой площадки и правила переупаковки исходника. Не придумывай факты, метрики или отзывы. Ничего не публикуй и не отправляй; внешние источники не используй без разрешения. Представь календарь, готовые черновики, CTA и список утверждений, требующих проверки.
```
