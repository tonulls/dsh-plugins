# `/ecc-rust-testing`

Помогает писать и диагностировать тесты Rust: модульные, интеграционные, асинхронные и property-based, а также оценивать покрытие в стиле TDD.

## Простой запрос
```text
/ecc-rust-testing Предложи тесты для этой Rust-функции, включая граничные случаи: [код]
```
## Шаблонный запрос
```text
/ecc-rust-testing
Поведение под тестом: [описание]
Код/интерфейс: [фрагмент]
Текущая проблема: [ошибка или пробел покрытия]
Среда и используемый тестовый стек: [данные]
Составь набор тестов; новые зависимости не предлагай без обоснования и согласия.
```
## Подробный запрос
```text
/ecc-rust-testing
Нужно проверить [модуль/поведение]. Сначала извлеки ожидаемые контракты из предоставленного кода и требований. Затем составь тесты: обычные случаи, границы, ошибки, асинхронные сценарии и свойства там, где уместно. Для дефекта покажи сначала тест, воспроизводящий его, и ожидаемый способ убедиться в падении; после минимального исправления — проверку прохождения. Не меняй файлы и не запускай команды без разрешения; не устанавливай пакеты и не используй сеть. Отчет: покрытые инварианты, пропущенные риски, рекомендуемые команды проверки и результат только реально выполненных проверок.
```
