# `/ecc-mcp-dependency-review`

**Назначение:** Статически проверяет конфигурацию MCP на изменяемые ссылки на пакеты до одобрения или запуска CI, не запуская обнаруженные MCP-серверы. Используйте для проверки `.mcp.json` и настроек MCP репозитория в Cursor, VS Code, Claude, Windsurf и других средах.

## Короткий промт

```text
/ecc-mcp-dependency-review Проведи статический аудит `.mcp.json` и конфигурации MCP на изменяемые ссылки и риски; серверы не запускай.
```

## Шаблонный промт

```text
/ecc-mcp-dependency-review
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: статически проверить конфигурацию MCP на изменяемые зависимости для [цель или объект].
Фокус: ссылки на пакеты, закрепление версий, скрипты и install hooks, границы доверия; не запускай MCP-сервер.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-mcp-dependency-review
Выполни задачу «статически проверить конфигурацию MCP на изменяемые зависимости» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: ссылки на пакеты, закрепление версий, скрипты и install hooks, границы доверия; не запускай MCP-сервер.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
