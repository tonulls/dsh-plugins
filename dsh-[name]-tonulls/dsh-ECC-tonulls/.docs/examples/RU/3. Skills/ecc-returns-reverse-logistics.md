# `/ecc-returns-reverse-logistics`

Помогает организовать возвраты: авторизацию и прием, осмотр и оценку состояния, выбор дальнейшего обращения, возврат средств, выявление мошеннических признаков и гарантийные претензии.

## Простой запрос
```text
/ecc-returns-reverse-logistics Предложи порядок обработки возврата товара с оценкой состояния и вариантов решения.
```
## Шаблонный запрос
```text
/ecc-returns-reverse-logistics
Товар и категория: [описание]
Причина возврата: [причина]
Состояние при приемке: [факты]
Политика/сроки: [условия]
Помоги выбрать дальнейшее обращение и обоснуй решение; неизвестные данные выдели отдельно.
```
## Подробный запрос
```text
/ecc-returns-reverse-logistics
Разбери случай возврата: [товар, причина, даты и обезличенные факты осмотра]. По шагам: проверь достаточность сведений; классифицируй состояние по предоставленным правилам; сравни варианты (повторная продажа, восстановление, уценка, списание или возврат поставщику, если применимо); оцени экономические последствия и признаки возможного злоупотребления без обвинений; предложи проверяемое решение по возврату/гарантии. Не инициируй возврат денег, списание, связь с клиентом или изменение записей без отдельного подтверждения. Итог: факты, недостающие данные, варианты, рекомендация и границы уверенности.
```
