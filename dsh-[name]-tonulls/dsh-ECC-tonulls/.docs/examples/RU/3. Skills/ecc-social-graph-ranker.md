# `/ecc-social-graph-ranker`

Ранжирует социальные связи для поиска теплых знакомств, оценивает посредническую роль контактов и пробелы сети в X и LinkedIn.

## Простой запрос
```text
/ecc-social-graph-ranker По предоставленной обезличенной таблице найди наиболее перспективные мосты для знакомства по критериям [критерии].
```
## Шаблонный запрос
```text
/ecc-social-graph-ranker
Цель связей: [цель]
Данные графа: [обезличенные узлы/ребра и признаки]
Вес критериев: [значения]
Проранжируй связи и объясни вклад факторов; не делай выводов о людях сверх данных.
```
## Подробный запрос
```text
/ecc-social-graph-ranker
Оцени предоставленный экспорт социального графа для задачи [цель]. Сначала уточни схему и ограничения данных; затем предложи прозрачные веса для релевантности, силы пути и bridge score; вычисли ранжирование только по переданным сведениям; выяви пробелы охвата и проверь чувствительность к весам. Используй только законно полученные минимально необходимые данные, не ищи людей в сети и не выгружай/изменяй контакты. Не отправляй сообщения и не выполняй follow/connect действия без отдельного подтверждения. Результат: метод и допущения, ранжированный список с объяснением, неопределенность и рекомендации по безопасному ручному следующему шагу.
```
