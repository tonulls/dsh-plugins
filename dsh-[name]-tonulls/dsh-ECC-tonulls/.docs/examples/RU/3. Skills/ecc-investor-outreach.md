# ecc-investor-outreach

**Команда:** `/ecc-investor-outreach`

**Назначение:** Подготовка холодных писем, текстов для тёплых рекомендаций, follow-up, обновлений и коммуникации с инвесторами при привлечении средств. Используйте для кратких персонализированных сообщений бизнес-ангелам, VC, стратегическим инвесторам и акселераторам.

## Промты

### 1. Короткий запрос

> /ecc-investor-outreach Напиши короткое письмо инвестору о [компания].

### 2. Шаблон с контекстом

> /ecc-investor-outreach Инвестор: [имя/фонд], стадия: [раунд], повод: [теплое знакомство/первый контакт], доказанные тезисы: [данные]. Не выдумывай связь или метрики.

### 3. Подробный запрос

> /ecc-investor-outreach Составь персонализированное [холодное письмо/интро/follow-up] инвестору [профиль] о [компания]. Используй только предоставленные факты, тон [тон], длина до [лимит]. Подготовь тему и текст; не отправляй и не ищи сведения в сети без разрешения. Отметь поля, требующие подтверждения.
