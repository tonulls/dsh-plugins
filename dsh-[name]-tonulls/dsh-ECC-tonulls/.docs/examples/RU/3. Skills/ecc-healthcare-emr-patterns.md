# ecc-healthcare-emr-patterns

**Команда:** `/ecc-healthcare-emr-patterns`

**Назначение:** Практики разработки EMR/EHR для медицинских приложений: клиническая безопасность, процессы приёма, формирование рецептов, интеграция CDSS и доступный пользовательский интерфейс для ввода медицинских данных. Используйте при создании функций EMR/EHR, например процессов приёма, рецептов и ввода клинических данных.

## Промты

### 1. Короткий запрос

> /ecc-healthcare-emr-patterns Набросай безопасный поток ввода медицинской записи.

### 2. Шаблон с контекстом

> /ecc-healthcare-emr-patterns EMR/EHR функция: [описание], пользователь: [роль], данные: [категории]. Учти клиническую безопасность, доступность и проверку человеком.

### 3. Подробный запрос

> /ecc-healthcare-emr-patterns Спроектируй [сценарий] EMR/EHR: этапы encounter, валидация записи, доступность интерфейса и интеграция CDSS при необходимости. Не используй реальные данные пациентов; обозначь аудит и подтверждение клиницистом. Верни поток, инварианты безопасности и тестовые сценарии.
