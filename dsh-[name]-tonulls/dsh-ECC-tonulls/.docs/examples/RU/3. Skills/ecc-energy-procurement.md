# `/ecc-energy-procurement`

Помогает анализировать закупку электроэнергии и газа для коммерческих объектов: тарифы, пиковую мощность, RFP поставщиков, хеджирование и возобновляемые PPA/REC.

## Простой запрос

```text
/ecc-energy-procurement Сравни варианты снижения платы за пиковую мощность для нашего склада.
```

## Шаблонный запрос

```text
/ecc-energy-procurement
Объект и регион: [данные]
Потребление/счета: [агрегаты без персональных данных]
Пиковая нагрузка и график: [описание]
Тариф/контракт: [условия]
Цель: [снижение затрат/возобновляемая энергия/бюджет]
Сделай предварительный анализ и укажи, какие данные нужно подтвердить.
```

## Подробный запрос

```text
/ecc-energy-procurement
Оцени варианты энергоснабжения для [объект/регион/период]. Используй предоставленные агрегированные данные о потреблении, тарифе, пиках и контрактных условиях [данные]. Раздели анализ тарифной оптимизации и demand charges, вариантов fixed/index/block-and-index, RFP поставщиков и PPA/REC, если применимо. Покажи ключевые допущения, чувствительность к цене/нагрузке и риски срока/объёма; не представляй оценку как гарантированную экономию или профессиональную консультацию. Не связывайся с поставщиками, не подавай заявки и не меняй контракт без отдельного подтверждения. Итог: сравнение вариантов, нужные сведения и список вопросов для квалифицированного закупочного/энергетического специалиста.
```
