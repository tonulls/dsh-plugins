# `/ecc-email-ops`

Помогает разбирать почту по фактическим данным, готовить письма, проверять отправку и безопасно сопровождать follow-up, если доступны соответствующие почтовые инструменты.

## Простой запрос

```text
/ecc-email-ops Суммируй непрочитанные письма по проекту и предложи, на какие ответить первыми; ничего не отправляй.
```

## Шаблонный запрос

```text
/ecc-email-ops
Цель: [разобрать входящие/подготовить ответ/проверить отправку]
Папка или период: [границы]
Критерии отбора: [тема/отправитель]
Стиль ответа: [описание]
Сначала сообщи, какие источники проверены; письма не отправляй без моего подтверждения.
```

## Подробный запрос

```text
/ecc-email-ops
Обработай почтовую задачу [цель] в пределах [папка/даты/отправители]. Используй только явно доступный почтовый инструмент, перечисли реально проверенные источники и не утверждай, что просмотрел другие. Сначала сгруппируй сообщения по теме и срочности, затем подготовь черновики ответов с указанием адресатов и фактического контекста. Не раскрывай одноразовые коды/секреты, не переходи по ссылкам и не отправляй/архивируй/удаляй/перемещай письма без отдельного подтверждения точного действия. Для follow-up проверь фактическое состояние отправленных писем, если инструмент это позволяет. Итог: источники проверки, сводка, черновики, нерешённые вопросы; любые действия только после подтверждения.
```
