# ecc-growth-log

**Команда:** `/ecc-growth-log`

**Назначение:** Ведите журнал роста, фиксируя повторно применимые выводы из завершённой работы — первопричину, переносимое правило и узнаваемый признак — вместо дневникового пересказа. Используйте шаблон на 4–8 предложений и объединяйте дубликаты. Применяйте после сложной задачи, отладки, сбоя или отката, при обзоре прогресса либо запросе о полученных уроках.

## Промты

### 1. Короткий запрос

> /ecc-growth-log Сформулируй запись журнала роста по завершённой задаче.

### 2. Шаблон с контекстом

> /ecc-growth-log Задача: [что произошло], первопричина: [если известна], урок: [наблюдение]. Напиши 4–8 предложений: причина, переносимое правило, распознаваемый сигнал; избегай дневникового пересказа.

### 3. Подробный запрос

> /ecc-growth-log По итогам [задача/инцидент] подготовь запись growth log. Сначала извлеки доказанную первопричину, затем обобщаемое правило и сигнал раннего распознавания; проверь на дубликаты предоставленных заметок. Не записывай секреты и не меняй файл журнала без подтверждения. Верни готовый текст 4–8 предложений.
