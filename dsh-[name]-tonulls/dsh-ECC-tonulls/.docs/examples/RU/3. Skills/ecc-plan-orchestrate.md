# `/ecc-plan-orchestrate`

**Назначение:** Читает документ плана, разбивает его на шаги, классифицирует их и для каждого формирует готовую ECC slash-команду с идентификатором и областью шага в документированном формате аргументов. Только генерирует команды — не запускает их и не утверждает, что управляет их внутренним выполнением. Если команда не поддерживает область плана, шаг не включается. Используйте для подбора команд к многоэтапному плану.

## Короткий промт

```text
/ecc-plan-orchestrate Разбей этот план на точные ECC slash-команды, но не выполняй их.
```

## Шаблонный промт

```text
/ecc-plan-orchestrate
Контекст: [путь или текст плана, ограничения задачи и допустимые команды].
Задача: разложить многошаговый план и подобрать документированную команду ECC для каждого этапа для [целевой компонент/результат].
Фокус: зависимости, id и границы шагов, поддерживаемый формат аргументов команд и отказ закрытым образом при невозможности передать scope.
Ограничения: Сформируй только готовые к вставке шаги/команды; не вызывай их и не заявляй, что они выполнены.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-plan-orchestrate
Выполни задачу «разложить многошаговый план и подобрать документированную команду ECC для каждого этапа» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: зависимости, id и границы шагов, поддерживаемый формат аргументов команд и отказ закрытым образом при невозможности передать scope.
3. Для каждого шага укажи точный документированный вызов и scope; если команда не может передать границы шага — не включай её и обозначь блокер.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Сформируй только готовые к вставке шаги/команды; не вызывай их и не заявляй, что они выполнены.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
