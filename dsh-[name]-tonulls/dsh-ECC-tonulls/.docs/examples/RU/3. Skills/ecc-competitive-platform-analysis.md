# `/ecc-competitive-platform-analysis`

Определяет границы конкурентного ландшафта: кого считать конкурентом, к какому уровню отнести и какие источники изучать. Это этап определения состава до сравнительной оценки.

## Простой запрос

```text
/ecc-competitive-platform-analysis Определи основных конкурентов нашего сервиса управления задачами для небольших распределённых команд.
```

## Шаблонный запрос

```text
/ecc-competitive-platform-analysis
Продукт: [описание и категория]
Целевые клиенты: [сегмент и география]
Рынок: [границы]
Известные альтернативы: [список]
Сформируй критерии включения, распределение по уровням и рекомендуемые источники. Не выдавай неподтверждённые предположения за факты.
```

## Подробный запрос

```text
/ecc-competitive-platform-analysis
Скоупируй ландшафт для [продукт] на рынке [география/категория]. Сначала зафиксируй определение конкурента и критерии отбора; затем раздели кандидатов на прямых, смежных и альтернативные решения, укажи основание для каждого и предложи источники для дальнейшего исследования. Отметь пробелы и спорные включения отдельно. Не переходи к выставлению оценок или рекомендациям по стратегии: это следующий этап. Используй только доступные материалы; не выполняй сетевой поиск без разрешения. Итог — границы выборки, таблица кандидатов с уровнем и обоснованием, список источников/вопросов для проверки.
```
