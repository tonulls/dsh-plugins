# `/ecc-customs-trade-compliance`

Помогает анализировать таможенную классификацию, документы, Incoterms 2020, преференции и пошлины, санкционные ограничения и таможенные запросы для указанных юрисдикций.

## Простой запрос

```text
/ecc-customs-trade-compliance Какие сведения нужны, чтобы предварительно определить тарифную классификацию промышленного датчика для импорта в ЕС?
```

## Шаблонный запрос

```text
/ecc-customs-trade-compliance
Товар и назначение: [характеристики]
Страна происхождения/экспорта: [страна]
Страна импорта: [страна]
Маршрут и Incoterm: [данные]
Документы/ограничения: [что известно]
Подготовь предварительный анализ, укажи недостающие сведения и необходимость официального подтверждения.
```

## Подробный запрос

```text
/ecc-customs-trade-compliance
Проанализируй поставку товара [техническое описание, материалы, функция] из [страна] в [страна/регион], условия [Incoterm 2020], предполагаемый режим [описание]. По этапам: перечисли факты и недостающие характеристики; объясни возможный подход к классификации с применимыми правилами и альтернативами; проверь, какие коммерческие/ввозные документы и происхождение нужны; обозначь потенциальные ограничения и вопросы denied-party screening только на основании предоставленных данных. Не делай юридически окончательных выводов и не подавай декларации/платежи/запросы; не используй сетевые источники без разрешения. Выведи предварительную оценку, уверенность, доказательства, риски и список проверок у таможенного специалиста.
```
