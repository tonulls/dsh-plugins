# `/ecc-deployment-patterns`

Помогает проектировать CI/CD и контейнеризацию, health checks, откат и проверять готовность веб-приложения к выпуску.

## Простой запрос

```text
/ecc-deployment-patterns Проверь план релиза веб-приложения и предложи безопасные проверки и стратегию отката.
```

## Шаблонный запрос

```text
/ecc-deployment-patterns
Стек приложения: [описание]
CI/CD и контейнеры: [инструменты]
Среды: [локальная/staging/production]
Ожидаемая доступность и rollback: [ограничения]
Нужен только план и ревью; ничего не разворачивай и не отправляй.
```

## Подробный запрос

```text
/ecc-deployment-patterns
Оцени готовность к выпуску приложения [стек] и предложи pipeline. Рассмотри сборку и тесты, контейнеризацию и минимальные права, health/readiness checks, секреты через штатное хранилище без вывода значений, миграции, постепенное включение и проверяемый rollback. Для каждого этапа задай gate и сигнал успеха/остановки; учти отличие staging от production. Не устанавливай пакеты, не обращайся к сети, не запускай CI, не деплой и не меняй конфигурацию без моего отдельного подтверждения. Выведи архитектуру процесса, риски, контрольный список и план отката.
```
