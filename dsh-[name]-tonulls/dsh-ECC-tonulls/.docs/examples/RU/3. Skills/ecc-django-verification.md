# `/ecc-django-verification`

Выполняет поэтапную проверку Django-проекта перед PR/релизом: окружение, линтеры, миграции, pytest и покрытие, security scans, настройки и diff.

## Простой запрос

```text
/ecc-django-verification Подготовь отчёт проверок моего Django PR, ничего не исправляя.
```

## Шаблонный запрос

```text
/ecc-django-verification
Проект: [путь/версия Django]
Область изменений: [описание]
Проверки проекта: [команды, если известны]
Разрешённые локальные команды: [список]
Только аудит: не меняй файлы, не устанавливай пакеты и не запускай сетевые сканеры.
```

## Подробный запрос

```text
/ecc-django-verification
Подготовь phased pass/fail отчёт для Django PR [описание]. До выполнения перечисли необходимые команды и проверь, что они локальные и не изменяют окружение или данные; запускай только явно разрешённые команды [список]. Проверь доступность окружения, lint/type checks, безопасность миграций, pytest и целевое покрытие, имеющиеся локальные pip-audit/bandit проверки, конфигурацию settings/logging и diff. Не устанавливай зависимости, не обращайся к сети, не применяй миграции и не исправляй файлы. Пропускай недоступные проверки с причиной. В отчёте для каждого этапа укажи команду, код завершения/наблюдение, результат, риск и вердикт готовности; не объявляй успешным то, что не запускалось.
```
