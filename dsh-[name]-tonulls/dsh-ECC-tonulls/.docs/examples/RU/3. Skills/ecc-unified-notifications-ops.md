# `/ecc-unified-notifications-ops`

Помогает организовать единый процесс уведомлений между GitHub, Linear, desktop alerts, hooks и подключенными каналами: маршрутизация, дедупликация, эскалация и снижение перегрузки inbox.

## Простой запрос
```text
/ecc-unified-notifications-ops Предложи правила дедупликации и эскалации уведомлений для [команда/проект].
```
## Шаблонный запрос
```text
/ecc-unified-notifications-ops
Источники уведомлений: [GitHub/Linear/прочее]
Каналы и аудитория: [описание]
Проблема: [дубли/шум/пропуски]
Ограничения эскалации: [условия]
Подготовь схему маршрутизации; не меняй реальные настройки.
```
## Подробный запрос
```text
/ecc-unified-notifications-ops
Спроектируй единый workflow уведомлений для [команда/цель]. 1) Инвентаризируй только предоставленные источники и правила. 2) Определи ключ дедупликации и приоритеты сигналов. 3) Предложи маршруты, ответственных, окна эскалации и защиту от циклов/шума. 4) Опиши аудит и метрики пропусков/дублей. Не подключайся к аккаунтам, не меняй подписки/hooks/правила и не отправляй уведомления без отдельного подтверждения. Не раскрывай токены. Итог: схема, примеры решений, неизвестные настройки и безопасный план внедрения с точками подтверждения.
```
