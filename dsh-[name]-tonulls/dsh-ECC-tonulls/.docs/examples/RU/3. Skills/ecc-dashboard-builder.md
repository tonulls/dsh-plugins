# `/ecc-dashboard-builder`

Помогает строить панели мониторинга в Grafana, SigNoz и подобных системах вокруг реальных вопросов операторов, а не декоративных графиков.

## Простой запрос

```text
/ecc-dashboard-builder Спроектируй панель Grafana, которая поможет дежурному быстро понять состояние очереди задач.
```

## Шаблонный запрос

```text
/ecc-dashboard-builder
Пользователь панели: [роль]
Вопросы, на которые нужно отвечать: [список]
Доступные метрики и лейблы: [перечень]
Платформа: [Grafana/SigNoz/другая]
Предложи панели, пороги и переменные; не меняй рабочую конфигурацию.
```

## Подробный запрос

```text
/ecc-dashboard-builder
Спроектируй операционную панель для [система/сервис] на [Grafana/SigNoz]. Целевая роль: [роль], сценарии принятия решений: [инцидент/ежедневный контроль], доступные источники и метрики: [перечень]. Сначала сопоставь каждый вопрос оператора с сигналом; затем предложи панели, временные диапазоны, переменные, группировки и пороги, отличая симптомы от причин. Избегай vanity-метрик и неподтверждённых SLO. Учти объём кардинальности и читаемость при инциденте. Не подключай источники, не меняй дашборды и не вызывай API без явного подтверждения. Отчёт: раскладка, назначение панелей, запросы/метрики при наличии данных, пробелы инструментирования и критерии проверки.
```
