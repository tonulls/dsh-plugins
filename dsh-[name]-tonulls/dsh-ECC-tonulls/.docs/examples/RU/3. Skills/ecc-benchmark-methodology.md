# `/ecc-benchmark-methodology`

Оценивает согласованный набор конкурентов по девяти взвешенным измерениям — позиционированию, голосу, визуальному исполнению, упаковке предложения, доказательствам, готовности к enterprise, лидерству мнений, цене и напряжениям для клиентов. Формирует карточки с оценками 1–5, привязанными к свидетельствам, и карту напряжений 2×2; следует после конкурентного скоупинга и до структуры отчёта.

## Примеры промтов

### 1. Короткий запрос
```text
/ecc-benchmark-methodology Оцени конкурентов [список] по девяти критериям. Для каждой оценки приведи свидетельство; пробелы данных отметь явно.
```

### 2. Шаблонный запрос
```text
/ecc-benchmark-methodology Составь сопоставимые карточки для [конкуренты/сегмент]. Используй критерии позиционирования, голоса, визуального исполнения, предложения, доказательств, enterprise-готовности, thought leadership, цены и клиентских напряжений. Источники: [материалы]. Примени шкалу 1–5 только с обоснованием; не заполняй пробелы догадками.
```

### 3. Подробный запрос
```text
/ecc-benchmark-methodology Подготовь evidence-anchored бенчмарк набора [конкуренты], уже отобранного для анализа. 1) Проверь, что сравнение охватывает сопоставимые компании/продукты; сомнительный состав вынеси как ограничение, не расширяй набор самовольно. 2) Для каждого участника собери доступные свидетельства по девяти измерениям: позиционирование, голос, визуальный craft, упаковка оффера, доказательства, enterprise-готовность, лидерство мнений, ценообразование и клиентские напряжения. 3) Поставь оценки 1–5 по единой рубрике и привяжи каждую оценку к конкретному источнику; отсутствующие данные обозначь как неизвестные. 4) Построй 2×2 карту напряжений с объяснением осей. Формат: карточки конкурентов, сравнительная матрица, карта и методологические ограничения; это этап оценки, не финальный стратегический отчёт.
```
