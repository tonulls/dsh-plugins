# `/ecc-token-budget-advisor`

Предлагает выбрать глубину ответа (25%, 50%, 75% или 100%) с примерной оценкой токенов, а затем отвечает в выбранном масштабе.

## Простой запрос
```text
/ecc-token-budget-advisor Дай короткий вариант ответа на вопрос: [вопрос]
```
## Шаблонный запрос
```text
/ecc-token-budget-advisor
Тема: [вопрос]
Предпочтение по глубине: [25/50/75/100% или попросить выбор]
Нужный формат: [список/объяснение/пример]
Сначала оцени объем вариантов и токены, если я не указал глубину; затем ответь выбранным уровнем.
```
## Подробный запрос
```text
/ecc-token-budget-advisor
Мне нужен ответ о [тема] для [аудитория/цель]. Предложи выбор глубины 25/50/75/100% с ориентировочными токенами и тем, что войдет/не войдет в каждый вариант; не выдавай оценку за точный счетчик. Дождись моего выбора, если он не задан. После выбора дай ответ в указанном масштабе, сохранив важные оговорки и фактическую точность. Не путай бюджет текста с криптографическим/платежным токеном. Укажи кратко допущения оценки.
```
