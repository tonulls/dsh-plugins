# `/ecc-dart-flutter-patterns`

Помогает создавать и проверять Flutter/Dart-код: null safety, неизменяемое состояние, асинхронность, архитектуру виджетов, BLoC/Riverpod/Provider, GoRouter, Dio, ошибки и тесты.

## Простой запрос

```text
/ecc-dart-flutter-patterns Как безопасно организовать загрузку и отображение состояния списка во Flutter?
```

## Шаблонный запрос

```text
/ecc-dart-flutter-patterns
Версии Flutter/Dart: [версии]
Текущий state management: [BLoC/Riverpod/Provider/другое]
Задача: [виджет/навигация/сеть/состояние]
Код и ограничения: [фрагмент/описание]
Предложи идиоматичное решение, совместимое с текущей архитектурой.
```

## Подробный запрос

```text
/ecc-dart-flutter-patterns
Разбери реализацию [функция] в приложении на Flutter/Dart [версии]. Учитывай текущий подход [BLoC/Riverpod/Provider], маршрутизацию [GoRouter/другое] и сетевой слой [Dio/другое]. Проверь null safety, неизменяемость состояния, жизненный цикл виджетов, асинхронные ошибки/отмену, разделение UI и логики, доступность и тестируемость. Предложи конкретные изменения и тесты, сохраняя существующие соглашения. Не добавляй зависимости, не выполняй сетевые запросы и не редактируй файлы до подтверждения. Итог — рекомендуемая структура, фрагменты решения, риски и тестовая матрица.
```
