# `/ecc-orch-change-feature`

Координирует изменение исправно работающей функции под новые требования: обновление тестов, реализации и обзор с отдельным допуском к изменениям.

## Простой запрос
```text
/ecc-orch-change-feature Измени правило сортировки по новому требованию; сначала предложи план.
```
## Шаблонный запрос
```text
/ecc-orch-change-feature Функция: [описание/путь]. Новое поведение: [требование]. Сохраняемые свойства: [список]. Предложи план и тесты, реализацию начни только после моего одобрения.
```
## Подробный запрос
```text
/ecc-orch-change-feature Измени [функцию] так, чтобы она соответствовала [новой спецификации]. Сначала исследуй текущий контракт и тесты, выяви затронутые места и сформируй план; дождись подтверждения. Затем измени/добавь тесты под новое поведение, внеси минимальную реализацию и выполни локальные проверки. Не устанавливай пакеты, не обращайся к сети, не выполняй деплой. Перед коммитом остановись и запроси отдельное подтверждение. В отчёте сравни старое и новое поведение и перечисли проверки.
```
