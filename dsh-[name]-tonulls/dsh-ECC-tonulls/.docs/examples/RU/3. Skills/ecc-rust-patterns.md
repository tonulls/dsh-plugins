# `/ecc-rust-patterns`

Подсказывает идиоматические и безопасные подходы в Rust: владение и заимствование, обработку ошибок, трейты и конкурентность.

## Простой запрос
```text
/ecc-rust-patterns Проверь этот Rust-фрагмент на проблемы владения и идиоматичность: [код]
```
## Шаблонный запрос
```text
/ecc-rust-patterns
Задача: [что реализовать]
Контекст и версия Rust: [данные]
Фрагмент/ограничения: [код, интерфейсы]
Предложи безопасный вариант, объяснив владение, ошибки и компромиссы. Не добавляй зависимости без моего согласия.
```
## Подробный запрос
```text
/ecc-rust-patterns
Нужно [описание функции] в Rust [версия/контекст]. 1) Изучи предоставленный код и контракты. 2) Определи модель владения и границы мутабельности. 3) Предложи идиоматичный дизайн типов, ошибок и трейтов. 4) Рассмотри конкурентность и производительность только там, где они существенны. 5) Покажи решение и тестируемые граничные случаи. Не меняй файлы, не устанавливай пакеты и не обращайся к сети. Перед любыми изменениями сначала представь план и запроси подтверждение. В отчете перечисли допущения, риски безопасности и обоснование выбора.
```
