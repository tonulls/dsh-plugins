# ecc-frontend-patterns

**Команда:** `/ecc-frontend-patterns`

**Назначение:** Практики разработки клиентской части для React и Next.js: управление состоянием, производительность и пользовательский интерфейс. Используйте при создании или проверке компонентов, состояния и скорости отрисовки React/Next.js.

## Промты

### 1. Короткий запрос

> /ecc-frontend-patterns Предложи улучшения этого React-компонента.

### 2. Шаблон с контекстом

> /ecc-frontend-patterns Компонент: [путь], проблема: [состояние/рендер/производительность]. Ориентируйся на существующие паттерны проекта и не добавляй зависимости.

### 3. Подробный запрос

> /ecc-frontend-patterns Изучи [компонент/страницу] в контексте проекта. Определи границы состояния, обновления и дорогие рендеры; предложи подход с минимальным изменением, затем тесты/проверку. Сначала план, файлы не изменяй до моего согласия.
