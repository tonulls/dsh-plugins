# `/ecc-prompt-caching-strategy`

**Назначение:** Повышает долю повторных попаданий в кэш промптов LLM, чтобы снизить расходы на API и задержки. Анализирует структуру промпта, определяет кэшируемые и некэшируемые части и рекомендует изменения для повторного использования кэша. Используйте при запросах о кэшировании промптов, доле попаданий, снижении затрат на LLM, экономии токенов и кэшировании у OpenAI, Anthropic и других поставщиков. Не используйте для улучшения качества одного промпта или общей инфраструктуры кэширования.

## Короткий промт

```text
/ecc-prompt-caching-strategy Найди, как повысить cache-hit у этого LLM prompt без изменения его смысла.
```

## Шаблонный промт

```text
/ecc-prompt-caching-strategy
Контекст: [текущий prompt, провайдер/модель, динамические поля, объёмы и доступные метрики].
Задача: оптимизировать кэширование LLM-промта ради стоимости и задержки для [целевой компонент/результат].
Фокус: стабильная и динамическая части, порядок сегментов, cache hit-rate, цена/latency и ограничения провайдера.
Ограничения: Составь план и критерии проверки; не меняй код, данные, расписание или внешние системы.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-prompt-caching-strategy
Выполни задачу «оптимизировать кэширование LLM-промта ради стоимости и задержки» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: стабильная и динамическая части, порядок сегментов, cache hit-rate, цена/latency и ограничения провайдера.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Составь план и критерии проверки; не меняй код, данные, расписание или внешние системы.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
