# `/ecc-nasiko-control-plane`

**Назначение:** Управляет жизненным циклом экспериментальной Nasiko CLI через ECC: только чтение статуса, установка закреплённой проверенной версии с предварительным dry-run и согласием пользователя, удаление с проверкой владельца, явные ограничения телеметрии и секретов. Используйте по запросам установить, проверить или удалить Nasiko CLI либо узнать, установлена ли она.

## Короткий промт

```text
/ecc-nasiko-control-plane Проверь, установлена ли Nasiko CLI и какая версия; пока не устанавливай и не удаляй её.
```

## Шаблонный промт

```text
/ecc-nasiko-control-plane
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: проверить статус установки Nasiko CLI для [цель или объект].
Фокус: read-only status first, pinned verified version, dry-run, ownership check and explicit consent for install/remove.
Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-nasiko-control-plane
Выполни задачу «проверить статус установки Nasiko CLI» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: read-only status first, pinned verified version, dry-run, ownership check and explicit consent for install/remove.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Работай в режиме диагностики: не меняй устройство, конфигурацию или внешнее состояние; при необходимости активной проверки сначала запроси разрешение.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
