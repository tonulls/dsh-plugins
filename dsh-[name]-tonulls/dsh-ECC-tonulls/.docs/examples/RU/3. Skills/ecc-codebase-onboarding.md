# `/ecc-codebase-onboarding`

**Назначение:** Изучите незнакомую кодовую базу и создайте структурированный вводный документ: карту архитектуры, ключевые точки входа, соглашения и стартовый CLAUDE.md. Используйте при подключении к новому проекту или первой настройке Claude Code в репозитории.

## Короткий промт

```text
/ecc-codebase-onboarding Изучи этот репозиторий и подготовь краткий onboarding-гайд с картой архитектуры и точками входа.
```

## Шаблонный промт

```text
/ecc-codebase-onboarding
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: подготовить новичка к работе с незнакомой кодовой базой для [цель или объект].
Фокус: архитектура, entry points, соглашения, команды разработки и проверенные источники информации.
Ограничения: Создавай или редактируй только явно указанный файл результата; не добавляй другие файлы без согласия.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-codebase-onboarding
Выполни задачу «подготовить новичка к работе с незнакомой кодовой базой» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: архитектура, entry points, соглашения, команды разработки и проверенные источники информации.
3. Подготовь результат в точно указанном формате и месте; если путь/разрешение не заданы, сначала покажи проект и запроси подтверждение на запись.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Создавай или редактируй только явно указанный файл результата; не добавляй другие файлы без согласия.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
