# `/ecc-context-budget`

Проверяет доступный остаток контекста через штатный счётчик Codex или Claude Code без сканирования файлов; статический аудит компонентов выполняет только по отдельному запросу.

## Простой запрос

```text
/ecc-context-budget Сколько контекста сейчас осталось?
```

## Шаблонный запрос

```text
/ecc-context-budget
Режим: [проверить текущий остаток / явно запросить статический аудит компонентов]
Среда: [Codex/Claude Code/другая]
Если штатный счётчик недоступен, сообщи об этом; не сканируй файлы без моего явного запроса.
```

## Подробный запрос

```text
/ecc-context-budget
Проверь текущий бюджет контекста в доступном штатном счётчике Codex или Claude Code. Не обходи каталоги, не читай исходники и не оценивай размер файлов для этой проверки. Если среда не предоставляет счётчик, укажи ограничение и не подменяй измерение догадкой. Только если я отдельно включаю аудит: [ДА/НЕТ], выполни ограниченный статический обзор перечисленных компонентов [список] и опиши методику и границы. Верни измеренное значение/доступный статус, момент и источник показания, либо ясное объяснение, почему получить его нельзя.
```
