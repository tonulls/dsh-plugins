# `/ecc-netmiko-ssh-automation`

**Назначение:** Безопасные практики Python Netmiko: сбор данных только для чтения, ограниченные параллельные SSH-подключения, разбор TextFSM, контролируемые изменения конфигурации, тайм-ауты и обработка ошибок автоматизации сетей. Используйте для автоматизации доступа к сетевым устройствам — при сборе данных и изменении конфигурации.

## Короткий промт

```text
/ecc-netmiko-ssh-automation Проверь сценарий Netmiko для сбора состояния устройств; по умолчанию не выполняй команды изменения конфигурации.
```
