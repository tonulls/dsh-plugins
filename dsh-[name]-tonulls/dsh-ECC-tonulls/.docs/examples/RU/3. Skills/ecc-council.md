# `/ecc-council`

Организует обсуждение неоднозначного выбора четырьмя различающимися точками зрения, чтобы выявить компромиссы и обоснованно принять решение.

## Простой запрос

```text
/ecc-council Помоги выбрать между монолитом и разделением сервиса на два компонента.
```

## Шаблонный запрос

```text
/ecc-council
Решение: [вопрос]
Варианты: [A, B, другие]
Критерии и ограничения: [срок, бюджет, риски]
Контекст: [факты]
Проведи структурированное обсуждение разных позиций и дай условную рекомендацию.
```

## Подробный запрос

```text
/ecc-council
Нужно принять решение: [вопрос]. Рассмотри варианты [список] в контексте [факты], с ограничениями [срок/стоимость/безопасность/обратимость]. Пусть четыре голоса отдельно представят: аргументы за каждый путь, риски и неудобные возражения; затем сопоставь их по критериям, укажи факты и допущения и сформулируй решение либо условия, при которых предпочтение меняется. Не выполняй действия и не меняй систему: требуется только анализ. Заверши кратким решением, открытыми вопросами и следующими безопасными проверками.
```
