# `/ecc-swift-actor-persistence`

Помогает спроектировать потокобезопасное хранение в Swift с actor, кэшем в памяти и файловым хранилищем, устраняя гонки данных архитектурно.

## Простой запрос
```text
/ecc-swift-actor-persistence Спроектируй actor-хранилище Swift с кэшем и файловым сохранением для [модель].
```
## Шаблонный запрос
```text
/ecc-swift-actor-persistence
Модель и операции: [описание]
Формат/путь хранения: [условия]
Требуемая согласованность и ошибки: [требования]
Предложи actor API, обработку IO и тестируемые границы без раскрытия пользовательских данных.
```
## Подробный запрос
```text
/ecc-swift-actor-persistence
Нужно сохранять [тип данных] в Swift в памяти и на диске. 1) Определи инварианты конкурентного доступа и жизненный цикл данных. 2) Предложи actor API и стратегию чтения/записи/восстановления. 3) Разбери атомарность, ошибки файловой системы, кодирование, очистку и согласованность кэша. 4) Предложи тесты конкурентности и сбоя без обращения к реальным пользовательским файлам. Не меняй файлы и не выполняй запись на диск; не добавляй пакеты без согласия. Отчет: модель состояний, эскиз интерфейса, риски гонок и план тестирования.
```
