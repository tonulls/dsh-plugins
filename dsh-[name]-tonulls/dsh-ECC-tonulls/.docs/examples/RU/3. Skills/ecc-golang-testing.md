# ecc-golang-testing

**Команда:** `/ecc-golang-testing`

**Назначение:** Практики тестирования Go: табличные тесты, под-тесты, замеры производительности, фаззинг и покрытие; TDD и идиоматичный Go. Используйте при написании Go-тестов, сравнительных замерах производительности, фаззинг-тестировании или проверке покрытия.

## Промты

### 1. Короткий запрос

> /ecc-golang-testing Предложи table-driven тесты для [функция] в Go.

### 2. Шаблон с контекстом

> /ecc-golang-testing Пакет: [имя], функция: [сигнатура], ожидаемые случаи: [перечень]. Добавь subtests и подходящие fuzz/benchmark идеи, не запускай код.

### 3. Подробный запрос

> /ecc-golang-testing Спланируй тесты для [пакет] по TDD: таблица валидных/ошибочных входов, subtests, при уместности fuzz и benchmark, покрытие границ. Сначала покажи тест-код и команды; не исполняй их и не редактируй файлы без подтверждения.
