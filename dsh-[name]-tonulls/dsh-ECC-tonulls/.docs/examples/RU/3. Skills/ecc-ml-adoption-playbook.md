# `/ecc-ml-adoption-playbook`

**Назначение:** Методология внедрения машинного обучения в существующие проекты без ML для ИИ-агентов и инженеров: постановка задачи, готовность данных, архитектурное разделение и интеграция базовой модели. Используйте при добавлении ML-возможностей — от формулировки задачи до первой модели.

## Короткий промт

```text
/ecc-ml-adoption-playbook Предложи путь от задачи [бизнес-цель] до первой проверяемой ML-модели в существующем приложении.
```

## Шаблонный промт

```text
/ecc-ml-adoption-playbook
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: спланировать внедрение ML-возможности в существующий проект для [цель или объект].
Фокус: постановка задачи, качество/доступность данных, базовая модель, архитектурные границы и критерии оценки.
Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-ml-adoption-playbook
Выполни задачу «спланировать внедрение ML-возможности в существующий проект» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: постановка задачи, качество/доступность данных, базовая модель, архитектурные границы и критерии оценки.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Подготовь рекомендации, не применяй изменения, не отправляй сообщения и не выполняй публикацию.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
