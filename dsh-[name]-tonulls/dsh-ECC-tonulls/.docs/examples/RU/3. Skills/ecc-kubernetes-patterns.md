# ecc-kubernetes-patterns

Команда: `/ecc-kubernetes-patterns`

Помогает проектировать и анализировать Kubernetes-манифесты, ресурсы, RBAC, probes, autoscaling и конфигурацию.

### Короткий запрос
```text
/ecc-kubernetes-patterns Проверь этот Deployment: [манифест]. Найди риски probes и лимитов ресурсов.
```

### Шаблонный запрос
```text
/ecc-kubernetes-patterns Разбери манифесты для [сервиса] в [среде]. Нагрузка [описание], требования доступности [требования], ограничения ресурсов [значения]. Предложи безопасные настройки probes, RBAC и масштабирования.
```

### Подробный запрос
```text
/ecc-kubernetes-patterns Выполни статический разбор приложенных Kubernetes-манифестов для [среда]. Проверь requests/limits, startup/readiness/liveness probes, RBAC на минимальные привилегии, autoscaling и обращение с ConfigMap/Secret. Отдели подтверждённые проблемы от предположений и предложи минимальные исправления в виде фрагментов. Ничего не применяй к кластеру, не запускай kubectl и не меняй файлы. В отчёте укажи приоритет, доказательство и рекомендации.
```
