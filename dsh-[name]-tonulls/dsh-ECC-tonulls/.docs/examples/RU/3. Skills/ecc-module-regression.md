# `/ecc-module-regression`

**Назначение:** Управляет регрессионными рисками между модулями крупных репозиториев с помощью `REGRESSION.md`, где указаны потребители каждого модуля и исполняемые команды приёмки. После изменений проверяет изменённый модуль и все затронутые команды; коды завершения служат доказательствами согласно правилам проекта. Используйте для анализа регрессий, зависимостей и изменений, где правка A может сломать B.

## Короткий промт

```text
/ecc-module-regression Оцени, какие модули и команды могут регрессировать из-за этого изменения; построй цепочку зависимостей.
```

## Шаблонный промт

```text
/ecc-module-regression
Контекст: [путь к проекту / фрагмент / система / симптом].
Задача: оценить риск межмодульной регрессии после изменения для [цель или объект].
Фокус: потребители модулей, зависимости, контрактные пути и релевантные команды приёмки.
Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
Формат результата: [краткий вывод, подтверждения, приоритеты и следующие шаги].
```

## Подробный промт

```text
/ecc-module-regression
Выполни задачу «оценить риск межмодульной регрессии после изменения» для [проект/компонент/сценарий].
1. Зафиксируй исходные данные, область работы и критерии результата; перечисли недостающие сведения.
2. Изучи только относящийся к задаче контекст и проверь: потребители модулей, зависимости, контрактные пути и релевантные команды приёмки.
3. Сформулируй выводы и следующие шаги, не применяя изменений и не выдавая предположения за факты.
4. Сопоставь результат с критериями, укажи доказательства и отдели подтверждённые выводы от предположений.

Ограничения: Только чтение: не меняй файлы, не запускай активные или внешние проверки.
В отчёте укажи итог, важные находки/действия, непроверенные части, риски и безопасные следующие шаги.
```
