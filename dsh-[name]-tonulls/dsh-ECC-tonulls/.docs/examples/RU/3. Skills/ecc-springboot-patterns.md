# `/ecc-springboot-patterns`

Подсказывает архитектурные подходы Spring Boot для REST API, слоистых сервисов, доступа к данным, кэширования, асинхронной обработки и логирования.

## Простой запрос
```text
/ecc-springboot-patterns Предложи структуру Spring Boot endpoint для [задача] с разделением контроллера и сервиса.
```
## Шаблонный запрос
```text
/ecc-springboot-patterns
Версии Java/Spring: [значения]
Функция или API: [описание]
Текущая архитектура: [слои/код]
Ограничения: [БД, транзакции, нагрузка]
Предложи решение в стиле существующего проекта и поясни компромиссы.
```
## Подробный запрос
```text
/ecc-springboot-patterns
Спроектируй [функцию] для проекта на [версии Java и Spring Boot]. 1) Сопоставь решение с текущими пакетами и соглашениями. 2) Определи REST-контракт, валидацию, границы сервиса и транзакции. 3) Разбери доступ к данным, кэш/async только при обоснованной необходимости. 4) Опиши обработку ошибок и безопасное логирование. 5) Перечисли тестовые сценарии и риски. Не меняй файлы, не добавляй зависимости и не подключай внешние сервисы без моего подтверждения. Итог: предлагаемая структура/эскиз кода, обоснование, допущения и проверки.
```
