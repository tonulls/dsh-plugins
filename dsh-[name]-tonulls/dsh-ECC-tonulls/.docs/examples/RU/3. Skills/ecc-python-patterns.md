# `/ecc-python-patterns`

**Назначение:** Идиомы Python, стандарты PEP 8, аннотации типов и практики разработки надёжных, эффективных приложений, удобных в сопровождении. Используйте при написании или проверке кода Python, если важны идиоматичная структура, типизация или PEP 8.

## Короткий промт

```text
/ecc-python-patterns Проверь этот Python-модуль на типизацию, идиомы и соответствие стилю проекта.
```

## Шаблонный промт

```text
/ecc-python-patterns
Контекст: [путь к Python-файлу, версия, назначение и соглашения проекта].
Задача: проверить или спроектировать Python-код для [целевой компонент/результат].
Фокус: PEP 8, type hints, Python-идиомы, читаемость и устойчивость без навязывания неиспользуемых абстракций.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-python-patterns
Выполни задачу «проверить или спроектировать Python-код» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: PEP 8, type hints, Python-идиомы, читаемость и устойчивость без навязывания неиспользуемых абстракций.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
