# `/ecc-dynamic-workflow-mode`

Помогает проектировать задаче-специфичные harness, eval-gates и извлекать повторно используемые навыки из адаптивного процесса работы агента.

## Простой запрос

```text
/ecc-dynamic-workflow-mode Спроектируй eval-gate для агента, который извлекает поля из счетов.
```

## Шаблонный запрос

```text
/ecc-dynamic-workflow-mode
Задача агента: [описание]
Типичные входы и ошибки: [примеры без чувствительных данных]
Критерии успеха: [измеримые условия]
Ограничения инструментов: [описание]
Предложи task-local harness и eval-набор; ничего не запускай на реальных данных.
```

## Подробный запрос

```text
/ecc-dynamic-workflow-mode
Спроектируй ограниченный harness для повторяющейся задачи [описание] в [Claude dynamic workflow/другой адаптивный harness]. Определи контракт входа/выхода, декомпозицию, разрешённые действия, запреты, критерии завершения и остановки. Создай концепцию eval-набора с репрезентативными позитивными, граничными и adversarial-входами без реальных секретов/персональных данных; задай метрики качества и пороги gate. Затем оцени, какие инструкции действительно универсальны и могут стать повторно используемым skill. Не выполняй задачи на живых системах, не меняй конфигурации и файлы без подтверждения. Отчёт: схема harness, eval-план, риски переобучения на тесты и кандидатные инструкции для переиспользования.
```
