# `/ecc-perl-security`

**Назначение:** Комплексная безопасность Perl: taint mode, проверка входных данных, безопасный запуск процессов, параметризованные запросы DBI, веб-безопасность (XSS/SQLi/CSRF) и политики безопасности perlcritic. Используйте при проверке обработки ввода, запуска процессов, запросов DBI и веб-кода.

## Короткий промт

```text
/ecc-perl-security Проведи read-only аудит Perl-кода на опасный ввод, процессы и SQL.
```

## Шаблонный промт

```text
/ecc-perl-security
Контекст: [пути к Perl-коду, точки входа, источники данных и границы доверия].
Задача: проверить безопасность Perl-кода и пути обработки недоверенных данных для [целевой компонент/результат].
Фокус: taint mode, валидация ввода, безопасный запуск процессов, параметризованные DBI-запросы и применимые XSS/SQLi/CSRF риски.
Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Формат: [краткий итог, доказательства/обоснования, риски и следующий шаг].
```

## Подробный промт

```text
/ecc-perl-security
Выполни задачу «проверить безопасность Perl-кода и пути обработки недоверенных данных» для [целевая система/сценарий].
1. Уточни цель, scope, исходные сведения и критерии результата; перечисли недостающий контекст.
2. Изучи только относящиеся к запросу материалы и проверь: taint mode, валидация ввода, безопасный запуск процессов, параметризованные DBI-запросы и применимые XSS/SQLi/CSRF риски.
3. Сформулируй находки или варианты с фактами, рисками, критериями проверки и неразрешёнными вопросами; ничего не применяй.
4. Проверь выводы по заданным критериям, укажи доказательства, допущения и непроверенное.

Ограничения: Только анализ: файлы и данные не меняй, внешние/разрушающие проверки не запускай.
Оформи результат так: [ожидаемый формат]. Не придумывай факты; перед любым непредусмотренным побочным действием остановись и запроси согласие.
```
