# ecc-flutter-dart-code-review

**Команда:** `/ecc-flutter-dart-code-review`

**Назначение:** Не зависящий от библиотек контрольный список проверки кода Flutter/Dart: практики виджетов, управление состоянием (BLoC, Riverpod, Provider, GetX, MobX, Signals), идиомы Dart, производительность, доступность, безопасность и чистая архитектура. Используйте при проверке кода Flutter/Dart независимо от выбранной библиотеки управления состоянием.

## Промты

### 1. Короткий запрос

> /ecc-flutter-dart-code-review Проведи read-only review Flutter-кода.

### 2. Шаблон с контекстом

> /ecc-flutter-dart-code-review Файлы: [пути], управление состоянием: [BLoC/Riverpod/другое]. Проверь виджеты, Dart-идиомы, производительность, доступность и безопасность; ничего не меняй.

### 3. Подробный запрос

> /ecc-flutter-dart-code-review Проведи обзор [изменение/PR] без редактирования файлов. Проверь архитектуру виджетов, состояние, перерисовки, доступность, безопасность и тестируемость; ранжируй только подтверждённые замечания с файлом/строкой, риском и рекомендацией.
