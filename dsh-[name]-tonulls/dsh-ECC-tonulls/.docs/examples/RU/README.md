# Примеры промтов ECC — русский язык

Здесь собраны примеры вызова компонентов ECC и управления их автоматическим выбором в DeepSeek Harness. Для каждого компонента и переключателя предусмотрен отдельный Markdown-файл с коротким, шаблонным и подробным вариантом промта.

## Разделы

| Раздел | Компоненты | Описание |
| --- | ---: | --- |
| [Bundle](<1. Bundle/README.md>) | 4 | Пользовательские переключатели автоматического выбора Agents, Skills и проверенных Commands на текущую сессию. |
| [Agents](<2. Agents/README.md>) | 71 | Роли для явного вызова в текущем сеансе DSH. |
| [Skills](<3. Skills/README.md>) | 236 | Навыки и специализированные рабочие сценарии. |
| [Commands](<4. Commands/README.md>) | 3 | Пользовательские команды ECC для DSH. |

В разделах Agents, Skills и Commands используются точные имена вызова `/ecc-*`. Переключатели Bundle вызываются отдельным прямым сообщением `/dsh-ecc-<компонент> on|off`; задачу отправляйте только следующим сообщением после подтверждения режима. Заменяйте заполнители контекстом своего проекта и явно указывайте ограничения на изменения, запуск команд и сетевые действия.
