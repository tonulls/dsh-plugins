## Использование

- Для отдельного компонента сохраняйте точное имя slash-команды `/ecc-*` из примера; заменяйте заполнители своим контекстом.
- Для Bundle используйте `/dsh-ecc-agents`, `/dsh-ecc-skills`, `/dsh-ecc-commands` или `/dsh-ecc-tonulls` с аргументом `on|off`. После подтверждения режима отправляйте задачу отдельным следующим сообщением.
- Перед отправкой проверьте, что промт задаёт нужную область и ограничения на изменения, запуск команд, сеть и другие побочные действия.
