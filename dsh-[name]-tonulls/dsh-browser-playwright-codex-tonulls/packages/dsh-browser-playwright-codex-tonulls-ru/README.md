# DSH Browser Playwright Codex DSH reference package

Справочный Skill по браузерной автоматизации на основе DSH Browser Playwright Codex. Помогает оценить применимость автоматизации и спланировать её для конкретной задачи. Автоподбор выключен по умолчанию для каждого Agent; включайте его командой `/dsh-browser-playwright-codex-tonulls on` и выключайте `/dsh-browser-playwright-codex-tonulls off`. Skill также доступен по прямому вызову.

## Установка

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-browser-playwright-codex-tonulls/packages/dsh-browser-playwright-codex-tonulls-ru'
```

## Использование

Вызовите `/browser-automation-review` напрямую или включите автоподбор для текущего Agent командой `/dsh-browser-playwright-codex-tonulls on`. Для отключения используйте `/dsh-browser-playwright-codex-tonulls off`.

## Лицензия

Лицензия исходного репозитория и уведомления указаны в [UPSTREAM.json](UPSTREAM.json); для DSH адаптирован способ установки.
