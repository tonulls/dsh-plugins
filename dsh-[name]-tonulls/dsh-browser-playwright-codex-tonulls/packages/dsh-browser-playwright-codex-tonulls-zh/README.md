# DSH Browser Playwright Codex DSH reference package

基于 DSH Browser Playwright Codex 的参考 Skill，用于评估浏览器自动化并规划实施。 自动选择默认在每个 Agent 中关闭；使用 `/dsh-browser-playwright-codex-tonulls on` 和 `/dsh-browser-playwright-codex-tonulls off` 切换。仍可直接调用 Skill。

## 安装

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-[name]-tonulls/dsh-browser-playwright-codex-tonulls/packages/dsh-browser-playwright-codex-tonulls-zh'
```

## 使用

直接调用 `/browser-automation-review`，或使用 `/dsh-browser-playwright-codex-tonulls on` 为当前 Agent 启用自动选择。使用 `/dsh-browser-playwright-codex-tonulls off` 关闭。
