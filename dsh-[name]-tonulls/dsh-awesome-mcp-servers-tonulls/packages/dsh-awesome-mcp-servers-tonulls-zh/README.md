# Awesome MCP Servers DSH reference package

Language: Simplified Chinese.

Registers the `mcp-server-selection` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. 生命周期指南（安装、启动、验证、调用、更新/重启、无专用禁用命令、停止与删除）见[此处](../../.docs/zh-CN/guide/setup.md)，来源记录见 [UPSTREAM.json](UPSTREAM.json)。

## 自动选择

自动选择默认在每个 Agent 中关闭。使用 `/dsh-awesome-mcp-servers-tonulls on` 和 `/dsh-awesome-mcp-servers-tonulls off` 控制；仍可直接调用 Skill。
