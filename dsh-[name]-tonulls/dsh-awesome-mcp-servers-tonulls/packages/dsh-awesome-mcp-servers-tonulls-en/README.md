# Awesome MCP Servers DSH reference package

Language: English.

Registers the `mcp-server-selection` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. See the [locale guide for installation, start, verification, invocation, update/restart, disable/stop distinction, and removal](../../.docs/en/guide/setup.md) and [UPSTREAM.json](UPSTREAM.json).

## Automatic selection

Automatic selection is off by default for each Agent. Use `/dsh-awesome-mcp-servers-tonulls on` and `/dsh-awesome-mcp-servers-tonulls off`; direct Skill invocation remains available.
