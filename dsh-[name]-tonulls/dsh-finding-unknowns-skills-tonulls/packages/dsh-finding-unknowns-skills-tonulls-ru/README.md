# Finding Unknowns Skills для DSH

14 навыков для выявления неизвестных требований, допущений и пробелов проверки.

Автоматический выбор выключен по умолчанию и управляется командами `/dsh-finding-unknowns-skills-tonulls on` и `/dsh-finding-unknowns-skills-tonulls off` для текущего Agent. Навык также доступен напрямую. Лицензия и уведомления исходного проекта включены в пакет.

🛠️ Модифицировано с помощью Codex
