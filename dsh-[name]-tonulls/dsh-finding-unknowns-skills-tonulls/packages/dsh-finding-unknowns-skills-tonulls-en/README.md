# Finding Unknowns Skills for DSH

Fourteen skills for surfacing unknown requirements, assumptions, and verification gaps.

Automatic selection is off by default and controlled for the current Agent with `/dsh-finding-unknowns-skills-tonulls on` and `/dsh-finding-unknowns-skills-tonulls off`. Direct invocation remains available. The source license and notices are included in the package.
