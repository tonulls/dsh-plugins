# p5.brush DSH reference package

Language: English.

Registers the `p5-brush-integration` reference Skill. It grants no tools and includes no upstream code, documentation, data, examples, or assets. See the [locale guide for installation, start, verification, invocation, update/restart, disable/stop distinction, and removal](../../.docs/en/guide/setup.md) and [UPSTREAM.json](UPSTREAM.json).

## Automatic selection

Automatic selection is off by default for each Agent. Use `/dsh-p5-brush-tonulls on` and `/dsh-p5-brush-tonulls off`; direct Skill invocation remains available.
