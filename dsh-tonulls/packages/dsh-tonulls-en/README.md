# dsh-tonulls-en

One bundle combines 37 skill projects for development, design, research, security, and tools. `/dsh-tonulls on|off` enables or disables automatic selection for the current Agent.

## Install

Install the package from GitHub:

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-tonulls/packages/dsh-tonulls-en'
```
