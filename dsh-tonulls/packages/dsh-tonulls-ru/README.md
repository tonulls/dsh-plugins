# dsh-tonulls-ru

Один bundle объединяет 37 проектов с навыками для разработки, дизайна, исследований, безопасности и инструментов. `/dsh-tonulls on|off` включает или выключает их автоподбор для текущего Agent.

## Установка

Установите пакет из GitHub:

```sh
dsh plugin --profile web add 'git+https://github.com/tonulls/dsh-plugins.git#tonulls&path:/dsh-tonulls/packages/dsh-tonulls-ru'
```
